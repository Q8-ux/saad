# مصدر لوحة سابق الأصلية

هذه نسخة GitHub من مصدر لوحة Vinext المنشورة، مستقلة عن مركز الإدارة الثابت الموجود في المجلد الأب. مصدر بياناتها خادم سابق نفسه، عبر عقود HMAC وصلاحيات الأقسام. المصدر التشغيلي الأصلي محفوظ في مستودع الموقع المستضاف؛ لا يتضمن هذا المجلد أسرار الإنتاج أو ملف ربط النشر. تشغيل اختبارات عقد الربط من هذا المجلد بعد npm ci، وتشغيل فحص Spec Kit من جذر هذا المصدر. مشروع Supabase الآخر لا يُعد منشوراً أو موصولاً بتغيير هذه الملفات.

المسارات موثقة في docs/engineering-paths.md، وعقد الربط في lib/public-service.ts وtests/public-service.test.mjs.
