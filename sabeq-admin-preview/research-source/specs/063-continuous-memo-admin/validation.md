# التحقق

- فحص بصمات Spec Kit وعزل السكربتات: 5/5 في كل مشروع.
- اختبارات تجهيز المذكرة والعقد والدفعات والإدارة: 99/99 محلياً ببيانات اصطناعية.
- اختبارات مرسل اللوحة وصلاحيات الوكيل: 5/5 محلياً.
- فحص البناء الكامل للموقع نجح: المصادر 33/33، المذكرة 128/128، الوصول 74/74، ثم تجميع Worker والواجهة بنجاح. بناء لوحة التحكم نجح أيضاً.
- المعاينة المحلية أظهرت واجهة المذكرة؛ لا تحمل حساب العميل أو أسرار الإنتاج. لم تُنشأ فاتورة ولم يُنفّذ خصم.
- التحقق الحي من الاتصال والسعر يأتي بعد النشر، ولا يساوي اختبار تحصيل حقيقي.

## تحقق النسخة المنشورة

انتقل وصف اصطناعي بلا أسماء أو أرقام قضايا مباشرةً إلى مراجعة المسودة؛ استخلص النظام طلب رفض المطالبة، وأبقى الأسماء غير المذكورة معلّمة. ظهرت رسوم 50 د.ك. لم يضغط المختبِر زر متابعة الدفع ولم تنشأ فاتورة. أرفقت لقطتا شاشة من الاختبار نفسه.

نُشر الموقع الإصدار 160 واللوحة الإصدار 5 بنجاح. تبقى معاينة جلسة المالك الخاصة واختبار التحصيل الحقيقي خارج هذا التحقق.
