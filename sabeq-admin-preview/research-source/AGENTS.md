# تطوير لوحة سابق وربطها بالموقع

النطاق هو هذه اللوحة وعقد API مع خادم سابق فقط. اقرأ .specify/memory/constitution.md واستخدم مهارات .agents/skills/speckit-* من جذر المشروع. وثق الميزة في specs/ قبل التنفيذ، واربط مهامها باختبار.

- اجعل خادم سابق مصدر بيانات المستخدمين والطلبات والمدفوعات لهذه اللوحة؛ لا تنسخ مخزنه إلى واجهة أو قاعدة مستقلة تلقائياً.
- حافظ على requireAdminPermission في كل endpoint، وعلى توقيع الطلبات وفحص إعادة استخدامها. لا تنقل ADMIN_SERVICE_TOKEN إلى المتصفح أو السجلات.
- استخدم /api/admin/sadad لإدارة سداد، واختبار مصادقة فقط دون تحصيل. ثبت السعر في الخادم واحفظ حق العميل في إعادة المحاولة.
- طبق مسار التبسيط والتدقيق: تتبع المتصلين وأعد استخدام الكود، وأكمل الاختبارات المناسبة دون تغيير وظائف أخرى.
- طبق جودة الواجهات: Cairo وRTL والجوال وحالات الانتظار والفشل، ولا تعرض نجاح الربط عند تعذره.
- حافظ على قيود مصادر التشريعات وعدم اختلاق وقائع أو أحكام. استخدم بيانات اصطناعية فقط في الاختبارات.
- شغّل فحوص Spec Kit واختبارات عقد الربط وبناء المشروع قبل النشر؛ فرّق بين الاختبار المحلي والنشر والتحقق الحي.
