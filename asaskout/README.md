# أساس كوت — Asas Kout

موقع عربي وإنجليزي لشركة أساس كوت للمقاولات العامة وتشييد المباني في الكويت.

- العربية: https://q8-ux.github.io/saad/asaskout/
- English: https://q8-ux.github.io/saad/asaskout/en/
- المصدر: https://github.com/Q8-ux/saad/tree/main/asaskout
- تصميم قابل للتحرير في كانفا: https://canva.link/unxoisbunm4tz5g

## التشغيل

Node.js 22 أو أحدث. لا يحتاج الموقع إلى حزم npm أو مفاتيح API.

```bash
node build.mjs
node verify.mjs
```

انشر محتويات `dist/` في المسار المخصص للموقع. النصوص في `content.mjs`، الواجهة والتفاعل في `assets/`، وتجميع الصفحتين في `build.mjs`.

## الوظائف

صفحتان مستقلتان مفهرستان بالعربية RTL والإنجليزية LTR، عرض متجاوب، قائمة جوال، تكبير الصور، أسئلة قابلة للفتح، الاتصال والخريطة والحسابات الاجتماعية. نموذج طلب المشروع يتحقق من الحقول ويدعم الأرقام العربية ثم يعرض معاينة للرسالة وروابط فتح واتساب والبريد.

لا يرسل الموقع رسالة تلقائياً، ولا يحفظ بيانات العملاء، ولا يدعي وجود نظام CRM أو لوحة إدارة أو تسعير آلي. الإرسال النهائي يتم من تطبيق المستخدم. الصور مرخصة توضيحية وليست مشروعات الشركة، ولا يتضمن الموقع شهادات عملاء أو أرقام إنجازات أو تصنيف مناقصات غير مثبت.

## النشر والحفاظ على المشاريع

ينشر `deploy-asaskout.yml` الموقع بعد التحقق منه، باستعادة حزمة آخر نشر ناجح وإضافة `asaskout/` فقط. يقارن الناشر بصمات بقية الملفات ويرفض التغيير إذا مسّ مشروعاً آخر. لا يعيد بناء بقية التطبيقات. أضيفت خطوة تضمين الموقع إلى مسار نشر الصفحات المشترك حتى لا يُحذف في إعادة بناء شاملة لاحقة.

راجع `SOURCES.md` للمصادر و`DESIGN.md` لقرارات التصميم و`QA.md` للتحقق الفعلي وحدوده.
