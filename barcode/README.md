# مكتبة المسلسلات

تجمع الصفحة نفسها باركود أولًا وخارج الستوري ثانيًا. تختار العمل ثم الحلقة دون الانتقال إلى موقع أو صفحة أخرى. نصوص باركود العشرة محفوظة كما كانت؛ خارج الستوري مسودة أولى من ثماني حلقات وستة وخمسين مشهدًا، بتأليف وسيناريو وحوار سعد روضان. يتيح العمل الجديد مراجعة الشخصيات وبناء القصة وتصدير ملف المشروع الكامل.

يبقى الدخول السابق كما هو. ملفات الصفحة والسيناريو الأساسية موجودة في المستودع العام؛ واجهة الدخول الحالية ليست حماية خادمية للملفات. لا تضف أسرارًا إلى المصدر أو بيانات الدخول في الروابط.

نص السيناريو بخط Amiri المرفق وفق ترخيص SIL OFL. الواجهة تحتفظ بخط القاهرة وألوان وتنسيق باركود. نسختا WOFF مشتقتان من خط المسار المعتمد مع الحروف العربية واللاتينية وعلامات الترقيم وخصائص تشكيل العربية.

تعديلات مشاهد خارج الستوري تحفظ محليًا في المتصفح باسم العمل ومعرّف كل فقرة. تصدير المشروع يجمع النص مع تلك التعديلات. لا توجد مزامنة لتعديلات القارئ بين الأجهزة. النص الأساسي المنشور متاح من الرابط نفسه على جميع الأجهزة.

```sh
node --test barcode/tests/*.test.mjs
python -m unittest discover -s barcode/tests -p 'test_*.py'
```

النشر يستعيد آخر حزمة Pages ناجحة ويحدّث مجلد barcode وحده ويتحقق من بصمات الملفات الأخرى. قائمة الأعمال معرفة في assets/catalog.mjs؛ إضافة عمل مستقبلًا تكون في هذه القائمة وملف مشروعه دون إنشاء صفحة مستقلة.
