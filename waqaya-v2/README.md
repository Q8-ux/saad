# وقاية V2

إعادة برمجة كاملة ومستقلة لنظام وقاية لتحصين الثروة الحيوانية.

## روابط
- الموقع: https://q8-ux.github.io/saad/waqaya-v2/
- ملفات المشروع: https://github.com/Q8-ux/saad/tree/main/waqaya-v2

## ما تم دمجه من البداية
- المواعيد والطلبات والقطعان والفرق وسجل التحصينات.
- مساعد وقاية النصي والصوتي.
- Google Maps: فتح المواقع ومسارات الفرق.
- Google Calendar: تصدير ICS مع تذكير.
- WhatsApp: إسناد المربي للفريق وفق قواعد الإدارة وفتح الرسائل.
- Canva + Compositor: Queue لطلبات التصميم ومعالجة الصور.
- إعدادات الإدارة لقواعد المناطق وأرقام فرق WhatsApp.
- خط AL-Mohanad من الحزمة المعتمدة في مشروع وقاية القديم.

## ملاحظة
هذه النسخة Static على GitHub Pages. الربط التلقائي الحقيقي مع Google Calendar API وWhatsApp Business API وRealtime AI يحتاج Backend آمن ومفاتيح خدمة.
