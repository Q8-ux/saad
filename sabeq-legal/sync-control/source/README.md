# سابق — مركز الربط والمزامنة

واجهة RTL عربية بخط Cairo لمراقبة المذكرات وسجل الطلبات وحالة النشر والاختبارات. المصدر والنشر محفوظان عبر GitHub. لا يوجد مزود بيانات تجريبي أو توليد لحالات نجاح.

المسار المنشور: `sabeq-legal/sync-control/` داخل `Q8-ux/saad`. عمليات المتابعة في المستودع الخاص `Q8-ux/sabeq-admin-console` عبر `.github/workflows/sabeq-sync-monitor.yml`.

## الوضع الفعلي

قراءات الاختبارات المرجعية موثّقة بتاريخها. المذكرات والمزامنة معلّقة حتى توافر مسار إنتاج ومصادقة. نجاح GitHub Actions أو HTTP 200 لا يثبت استلام مذكرة. لا يوجد نسخ لنصوص المذكرات إلى المستودع.

## التشغيل

`npm run dev` للمعاينة. `node node_modules/vite/bin/vite.js build --config github.vite.config.mjs` يبني نسخة GitHub Pages. `node --test scripts/monitor/core.test.mjs` يتحقق من شروط الأدلة وحدود الشبكة.

## اعتماد الإنتاج

راجِع `monitor/contract.json` في المستودع الخاص واضبط مسارات الإنتاج للمصدر والجهة المستقبلة. القيم الافتراضية null مقصودة لأن مسارات الكتابة الحالية لم تُثبت. المخولون يضعون رمز الخدمة في GitHub Secret باسم `SABEQ_MONITOR_TOKEN`، وليس داخل الملفات. لا تقبل العمليات نطاقات مؤقتة، ولا تتبع التحويلات. جميع المسارات تحتاج HTTPS وPOST و`{success:true}`. القوائم تعيد `memos`؛ التفاصيل تعيد `memo.id`؛ الإرسال يعيد `memo_id`؛ إعادة المزامنة تعيد `memo_ids`. الطلبات تستخدم Idempotency-Key ويجب أن يطبّق الخادم منع تكرارها. حالات الاستلام تحتاج قراءة مستقلة وتطابق المعرّف.

من الواجهة: اتصال GitHub برمز محدود بالمستودع مع Actions وChecks للقراءة، وActions للكتابة لتنفيذ العمليات. لا يُحفظ الرمز خارج ذاكرة الصفحة. يُحفظ سجل العمليات المحلي في هذا المتصفح؛ ليس سجل الخادم الكامل. لا يُحفظ نص المذكرات. الملف المرجعي `public/monitor/evidence.json` لقطة معلنة التاريخ وليست حالة حية. استيراد المذكرات لا يمنحها حالة مؤكدة. CSV يعطل صيغ الجداول الضارة. تحديث GitHub لا يعيد تنفيذ طلبات الكتابة تلقائيًا.
