# تطبيق مجموعة سابق القانونية لأندرويد
تطبيق متصل يعرض النسخة المعتمدة https://q8-ux.github.io/saad/sabeq-legal/ دون نسخ قاعدة القضايا أو مفاتيح الخدمات إلى الهاتف. يحافظ على الموقع والمساعد ومولد المذكرات وخط المهند. الحد الأدنى Android 8، هدف Android 15. ليس وضعاً بلا اتصال ولا نشر متجر Google Play.
قبول: HTTPS فقط، الشعار الرسمي، طلب الميكروفون عند الاستخدام للموقع الموثوق فقط، اختيار ملفات متعدد، حفظ تنزيلات المستخدم عبر منتقي النظام، عزل صفحات المواقع الخارجية في المتصفح، رفض أخطاء TLS، رسالة تعذر اتصال مع إعادة محاولة، رجوع لا يغلق التطبيق بالخطأ. توقيع مستقل محفوظ خارج GitHub ومفتاح API غير موجود في التطبيق.
