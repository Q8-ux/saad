# سابق القانونية — Android
تطبيق متصل بالنسخة الحالية: https://q8-ux.github.io/saad/sabeq-legal/
الحزمة `legal.sabeq.app`، إصدار 1.0.0، Android 8 أو أحدث. مصدر واجهة الموقع وخلفيته يظل مستقلاً، فلا تُحفظ مفاتيح API أو قاعدة التشريعات/القضايا في APK. يحتاج إلى الإنترنت وإصدار حديث من Android System WebView. ليس منشوراً في Google Play.

- العربية وRTL وخط المهند والشعار من الموقع القائم.
- إذن ميكروفون عند الاستخدام فقط، من صفحة سابق الموثوقة؛ لا كاميرا أو SMS أو جهات اتصال أو إذن تخزين شامل.
- اختيار مستندات متعدد (25 كحد أقصى؛ إجمالي الرفع والتحقق من الأنواع يظل خادمياً حسب إعداد الموقع).
- حفظ التصدير المحلي حتى 10MiB عبر منتقي النظام؛ Blob بقناة رسائل مقيدة بالمصدر والإطار الرئيسي، دون `addJavascriptInterface` شامل.
- الروابط الخارجية في المتصفح؛ HTTP والملفات المحلية وJavaScript كتنقلات مرفوضة. أخطاء HTTPS لا تُتجاوز. رسالة إعادة محاولة عند انقطاع الاتصال.
- زر الرجوع عند الصفحة الأولى يطلب تأكيد الإغلاق، ولا يحذف بيانات الموقع.

## البناء
Java 17 + Android SDK 35 + Gradle 8.11.1 + AGP 8.9.2. من هذا المجلد:
```
gradle testDebugUnitTest lintDebug assembleRelease
```
GitHub Actions ينفذ نفس الأوامر ويرفق APK غير موقع مع تقرير lint ونتائج JUnit ومعرّف المصدر؛ يحتاج APK إلى توقيع خاص خارج المستودع. لا ترفع مفاتيح التوقيع أو كلمات المرور إلى GitHub. احتفظ بالنسخة الخاصة للتحديثات المستقبلية.

## اختبار الهاتف المطلوب قبل الإطلاق العام
تثبيت APK، رفض/قبول الميكروفون والتسجيل والتشغيل، اختيار PDF/DOCX/صور، تحليل اصطناعي، تصدير وحفظ وطباعة، الرجوع وإغلاق المساعد، انقطاع الإنترنت/HTTPS، حجم الخط والكيبورد على الهاتف واللوحي. البناء والاختبارات الآلية لا تثبت وحدها عمل الصوت على كل جهاز.
