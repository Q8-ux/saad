# خطة التنفيذ

1. إنشاء حزمة Python داخل legal-memo-platform في مستودع GitHub الحالي، مع مكتبات مثبتة الإصدارات.
2. إنشاء عامل NDJSON طويل التشغيل ورابط Node محمي بسر، مع طابور محدود ومهل وإلغاء العمليات المتأخرة.
3. استخدام StateGraph لكل قضية بذاكرة مؤقتة مستقلة؛ لا نحفظ حالة القضية أو نصها في سجلات مشتركة.
4. استخدام PydanticAI للمخرجات المنظمة والتحقق من معرفات الاستشهادات وأرقام المواد والبيانات غير المذكورة.
5. توفير فهرسة Cognee إدارية صريحة للمصادر العامة والقوالب الفارغة. البحث يعيد ترتيب المصادر التي أقرها خادم سابق فقط، ويتحقق من بصمتها.
6. إضافة موصل Cloudflare يستدعى بعد فحوص المسار الحالي. بناء المستند وتصديره يظلان في خادم سابق.
7. تشغيل اختبارات المدخلات والهلوسة ونقص المصادر والعزل والمهل والقوالب، ثم حفظ التغيير في GitHub للمراجعة.
8. بعد تحديد مساحة Render: نشر العامل، فهرسة المعرفة المعتمدة، ضبط أسرار الطرفين واختبار توليد منشور قبل التفعيل.

لا توجد هجرة لبيانات العملاء أو تغيير في جداول القضايا. نشر نسخة الموصل دون إعداد مفاتيحه يبقي المسار الحالي فعالاً.
