# مسار الوكلاء لصياغة سابق

الطلب: دمج LangGraph لتنظيم التنفيذ، PydanticAI لضبط المدخلات والمخرجات، وCognee لاسترجاع المعرفة الموثقة.

## الحدود والافتراضات
- التطبيق الحالي يعمل على Cloudflare؛ Python يعمل في خدمة Render القائمة خلف اتصال خادم إلى خادم محمي بسر مشترك.
- مواصفات القالب وصلاحيات المستخدم وحدوده وبناء المستند تبقى في خادم سابق الحالي.
- نحافظ على التحويل العربي الحالي للمذكرة؛ تغيير لغة المستند ليس جزءاً من هذه المهمة.
- معرفة Cognee تضم مصادر عامة وقوالب فارغة معتمدة فقط، ولا تُفهرس وقائع العملاء أو المحادثات.
- لا يُعتبر النشر أو التفعيل ناجحاً قبل اختبار الخدمة المنشورة. يلزم تأكيد مساحة Render طبقاً لمتطلبات الموصل.

## معايير القبول
- الرسم ينفذ التحقق ثم المعرفة ثم الصياغة المنظمة ثم تدقيق الاستشهادات، مع حد أقصى ثلاث استدعاءات للنموذج.
- لا يستطيع العميل إرسال قالب بديل أو مفتاح الخدمة، ولا يجري الاتصال قبل التحقق من الصلاحيات والحدود.
- الاستشهادات تستند حصراً إلى معرفات ونصوص أعاد الخادم قراءتها؛ نتائج Cognee لا تصبح مصادر جديدة تلقائياً.
- عند غياب المصادر تحفظ الوقائع والطلبات كما هي، ويظهر نقص المصادر في التحليل خارج متن المذكرة.
- فشل عامل Python عند تفعيله يعيد خطأ واضحاً بدلاً من تجاوز التحقق أو عرض نتيجة ناقصة.
- اختبارات فعلية لـLangGraph وPydanticAI، واختبارات عزل وتحقق Cognee، واختبارات الاتصال والتوافق مع القالب.
- لا تتغير العربية وRTL والخط والشعار وبنية القالب المعتمد.
