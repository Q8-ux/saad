# ذوق واجهات سابق

## المهمة والاتجاه
يصل الزائر إلى المساعد القانوني أو نظام كتابة المذكرات، ويقرأ الحقول والإرشادات بوضوح على الجوال. الاتجاه: واجهة قانونية هادئة، كحلي وتركواز وسلفر، وخط المهند الموجود فعلياً. ضوابط التخطيط الداخلية: تنوع 3، حركة 2، كثافة 4. لا تظهر أسماء المسارات أو هذه الضوابط للزائر.

## النطاق والافتراضات
- المصدر الأصلي الحالي 566b7a7b4e3b1fccc7d202c1eeeff45522be1d09 مطابق لمصدر نسخة GitHub المنشورة.
- نحافظ على الشعار والصور والأسماء وألوان الهوية وترتيب الأقسام وأزرار الدخول المعتمدة.
- تغييرات العرض وتسميات الوصول فقط؛ لا تغيير للخادم أو التسجيل أو الدفع أو توليد النصوص أو حافظة المستندات أو قوالب التصدير.
- لا مكتبات أو صور أو خطوط جديدة، ولا أرقام أداء أو قدرات قانونية إضافية.

## معايير القبول
- النص العربي الأساسي 20px؛ الحقول والإرشادات والأزرار المهمة بين 18 و20px، مع تباعد أسطر يسمح بالتشكيل.
- قائمة العربية والأردية على اليمين والإنجليزية على اليسار، وتسميات القوائم بلغتها، دون أسهم قوائم إضافية.
- بطاقات الخدمات بعمودين عند توفر المساحة وعمود واحد على الجوال؛ لا تصغير النص لكسب الكثافة.
- خطوات المذكرة واضحة ومتجاوبة؛ تنكسر التسميات الطويلة دون إخفاء المحتوى.
- أهداف اللمس الأساسية لا تقل عن 44px، وتركيز الكيبورد ظاهر، وخيارات المذكرة تُظهر التركيز أيضاً.
- تباين النصوص والأزرار المعدلة يحقق AA؛ الوضع الداكن له ألوانه المقابلة؛ تقليل الحركة يوقف الحركة الزخرفية والتمرير السلس.
- لا يمتد شريط الدخول العائم خارج عرض 320px، ويُحجز له مكان أسفل الفوتر، وتبقى نافذة المساعد فوقه.
- بناء المصدر الأصلي ونسخة GitHub وفحوص اللغة وإغلاق المساعد وتدفق المذكرات والنشر تجتاز الفحص.

## حدود التحقق
لا تتوفر مهارة control-browser المدعومة في هذه الجلسة؛ صور العرض الحقيقية عند 320/390/768/1440 واختبار اللمس والميكروفون والتوليد الحي ليست نتائج ناجحة مفترضة. تظل بحاجة إلى تحقق بصري على جهاز فعلي.
