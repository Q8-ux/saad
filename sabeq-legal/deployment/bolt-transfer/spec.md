# نقل سابق إلى Bolt

طلب المستخدم ربط حسابه في Bolt ونقل موقع مجموعة سابق القانونية. تُجهز واجهة React وVite مستقلة قابلة للاستيراد، مع الهوية والعربية وRTL والخطوط والأخبار وسياسة الخصوصية. لا يتوفر دخول Bolt حالياً؛ لا يوصف النقل بأنه مكتمل قبل إنشاء المشروع والتحقق منه.

حدود النقل: الواجهة والملفات العامة فقط. تبقى خدمة المساعد والمذكرات والهوية والتخزين الخاص في الخلفية الحالية، إلى أن تُعتمد خطة نقلها واختبارها. لا مفاتيح API ولا ملفات قضايا ولا قواعد بيانات خاصة ضمن الحزمة. يجب إضافة نطاق مشروع Bolt المحدد لقائمة CORS للخلفية قبل اعتبار الخدمات متصلة؛ لا wildcard ولا تمرير مصطنع للأصل.

القبول: بناء مستقل ناجح بأمر npm run build، أصول محلية بلا مسارات GitHub الثابتة، سياسة بثلاث لغات، ستة أخبار قضايا موثقة وصورها الأصلية فقط، وعدم وجود قاعدة المصادر الخاصة أو مفاتيح في مخرجات المتصفح. حفظ تعليمات النقل وحدود الوظائف بوضوح. لا تغيير للنطاق الرسمي ولا صلاحيات مستودعات غير المشروع.
