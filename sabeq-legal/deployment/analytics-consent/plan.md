# الخطة

إصلاح المتتبع القائم بإشراف خفيف يستمع لتغير الموافقة في الصفحة والتبويبات. المفتاح الجديد `sabeq-analytics-consent` لا يقبل إلا `granted` للموافقة؛ `denied` للرفض، والقيم القديمة لا تمنح إذناً. فحص الإذن يسبق إنشاء أي UUID وكل إرسال، والتوقف يلغي الطلبات والمؤقتات ومستمعي نشاط الزائر دون إرسال أخير. إعادة استخدام سياسة التخزين السابقة لمنع القياس الداخلي واحترام إشارات الخصوصية.

إضافة إعدادات ظاهرة داخل تدفق الصفحة بجانب الهوية القائمة، بأزرار متساوية الوضوح، وخط المهند الكبير وRTL/LTR، دون تغطية المساعد أو المحتوى. صفحات السياسة تستخدم العقد نفسه وتبيّن أن القياس اختياري ومتوقف افتراضياً.

حساب البطاقة الأقرب فعلياً داخل أمر تنقل الأخبار، مع فصل طلب التمرير عن حالة قديمة حتى يعمل الرجوع إلى البطاقة ذات الرقم نفسه بعد السحب. لا حاجة لمستمع تمرير دائم أو اعتماد جديد.

التحقق ببيئة متصفح اصطناعية لـ UUID والتخزين والمؤقتات والطلبات والأحداث، وتشغيل وظائف المكونات الفعلية للقبول والرفض والسحب والأخبار. إعادة استخدام فحوص المساعد والمذكرات واللغات، وبناء GitHub وWorker. تُعدّل ملفات مصدر الخدمة ثم تُطابق مع مرآتها في PR؛ تبقى المصادر الخاصة خارج حزم العميل.
