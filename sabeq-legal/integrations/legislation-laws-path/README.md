# مسار التشريعات داخل سابق

البحث داخل قاعدة الملف المرفوع فقط، دون بحث قانوني خارجي. الواجهة لا تحمل الأصل أو ملف SQLite؛ تستدعي خدمة سابق الآمنة.

القاعدة: 1710 صفحات، 82 قسماً، 7769 موضع مادة، و43 طبقة OCR مستقلة تحتاج مراجعة. هذه ليست 7769 مادة فريدة مكتملة أو معتمدة.

## الربط
- المساعد النصي ومسار تحليل الصوت يستخدمان نفس استرجاع التشريعات.
- محرك المذكرات يعيد قراءة معرفات المصادر من الخادم قبل الصياغة.
- أدوات البحث والمكتبة تسترجع من الملف نفسه.
- رقم المادة يربط بقسمه وصفحته؛ المكرر يبقى ملتبساً.
- رقم القانون والسنة يستخدمان فقط عند مطابقة ترويسة الصفحة وبيانات القسم؛ لا تستنتج أرقام من ذاكرة النموذج.
- الاستمرار عبر الصفحات يعود بسجل المصدر الصحيح ولا ينسب للمادة التالية.
- روابط المصدر تفتح عارض صفحات GitHub؛ البيانات من الخلفية.
- سريان النصوص واكتمال المواد غير معتمدين. المسودات تحتاج مصادقة المجموعة.

لا توجد سجلات أحكام تمييز مستقلة مستخرجة في هذا الملف. ذكر المحكمة أو حكم دستوري في حاشية لا يصبح حكماً للتمييز؛ يرجع النظام حالة الغياب ولا ينشئ سابقة وهمية. لا ينفذ بحثاً خارجياً احتياطياً.

## الاختبارات والتراجع
اختبارات بصمات جميع المقاطع والبحث والأرقام العربية والتكرار والسياق وإعادة قراءة المعرفات ورفض الاستشهادات المزيفة وعدم تسرب القاعدة إلى حزمة المتصفح.
التراجع: إعادة نشر إصدار خلفية سابق 101 قبل هذا الربط؛ القاعدة الأصلية وبيانات الموقع السابقة لم تُحذف. واستعادة ملفات عارض GitHub من الالتزام السابق عند الحاجة.
