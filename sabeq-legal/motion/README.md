# مسار الفيديو البرمجي — سابق

إضافة عرض عند الطلب بعد الخدمات. ثلاث مراحل ثابتة متاحة بالعربية والإنجليزية والأردية؛ لا تتضمن وعود نتائج أو تفعيل دفع أو اتصالاً بمحرك المذكرات. تبقى النصوص متاحة بجانب Canvas وتُحرك العبارات كاملة للحفاظ على وصل العربية. لا تشغيل تلقائياً ولا مصادر أو تحليلات أو مكتبات خارجية.

المرجع الذي طلبه المستخدم: https://github.com/yihui-dev/awesome-opus5-5-videos . استُلهم أسلوب الرسم والحركة بالكود فقط. المحرك هنا مكتوب للمشروع؛ لم تُنسخ فيديوهات صناع المحتوى أو علاماتهم ولا يُدّعى استدعاء Claude أو تركيب API للمستودع.

النطاق: `motion/` ومرجعاه في index، مع تحميل الإضافة من مدخل بناء GitHub المصدرية مستقبلاً. لا تغيير في المصدر التشريعي أو الدفع أو المستندات أو API. هذه إضافة عرض مستقلة، وينطبق استثناء التغييرات العرضية المحدودة من دورة المواصفات الكاملة في تعليمات المشروع.

معايير القبول: ظهور واحد بعد الخدمات؛ التشغيل والإيقاف والتنقل؛ عدم التشغيل التلقائي؛ دعم اللغات والاتجاه والخط؛ إلغاء الحركة عند إخفاء الصفحة؛ عمل مسارات النشر النسبية على الدومين وPages. محرك الرسم نفسه يُنسخ إلى استوديو الكتابة كي يبقى نشر المشروعين مستقلاً، مع اختبار تطابق النسختين.

التحقق: `node --test sabeq-legal/motion/motion.test.mjs` و`python sabeq-legal/deployment/test_release.py`، بالإضافة إلى اختبار المتصفح الموضح في تقرير التنفيذ. المصدر والاختبار والنشر حالات مستقلة.
