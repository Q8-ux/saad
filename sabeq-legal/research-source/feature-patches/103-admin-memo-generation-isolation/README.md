# Case isolation and intake recovery

The native service source commit is `9b88bb8f565dcc2bdb4fe8dfb6a0741e1851b01f`, based on `6b3dc83a97f2bf8d79d10fea00a2576c69dd959c`.

The patch is for that exact native base. Do not overwrite the independent research snapshot or its MetaMuse/Heretic additions. Check context and reconcile intentional differences before applying it in Bolt. The public dashboard calls the existing native service; a successful preview build alone does not deploy that service.

Changes prevent old case fields from surviving a new handoff, reject unrelated original parties before generation, add administrator-only input repair with encrypted originals and optimistic concurrency, and generate a separate child request through the existing protected memo engine. Repeated operations are idempotent; public authentication and payments remain enforced. The model instructions, templates, source gates, human revisions and existing memos remain protected.

Intake can use its explicitly configured alternate once after a quota rejection and retains explicitly stated criminal courts, subtype and accused role when AI is unavailable. This recognition does not establish jurisdiction or readiness. No new provider, secret, paid model or legal source is introduced. Meta key activation requires a tested server-side setting; a Bolt secret name alone is not proof of activation.

Validation: 436 internal tests passed (42 source, 273 memo, 121 access), plus all six dashboard verification groups. Private production record repair still requires an authenticated administrator session. No real case facts, identifiers or keys are present in this patch.
