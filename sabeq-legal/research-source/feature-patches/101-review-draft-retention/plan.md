# الخطة
1. اختبار انحدار في مسار API الحالي ببيانات اصطناعية؛ فحص سبب الفشل قبل التعديل.
2. تعديل فرع خطأ تحليل المراجعة فقط: بناء النص بالقالب الحالي وحفظه للمراجعة عند اجتياز الفحوص المتاحة ووجود دفاع مستقل.
3. منع إعادة توصيف المسودة كنجاح أو صرف الاستحقاق. عدم تغيير الجداول أو الصلاحيات أو الوصول إلى النص.
4. تشغيل الاختبارات والبناء وفحص بصمات المحرك، ثم نشر المصدر ومزامنة فرق GitHub المحدود.
5. توليد القضية التي اختارها المستخدم، وفحص محتوى المسودة وحفظه في اللوحة؛ تحديد أي مراجعة لم تكتمل دون ادعاء اعتمادها.
