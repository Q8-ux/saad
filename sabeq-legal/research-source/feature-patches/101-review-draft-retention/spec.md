# الاحتفاظ بمسودة المذكرة للمراجعة

المطلوب توليد نص بدفوع وأسانيد، لا عرض نسخة من بيانات الطلب. في النسخة 232 يعيد تعذر تحليل المراجعة المستقلة حالة defense_review لكنه يمحو فرصة مراجعة النص الذي صاغه الكاتب.

## النطاق
- لا تتغير تعليمات الكاتب أو المراجع أو النماذج أو المصادر أو القوالب.
- إذا اجتاز النص فحوص الاستشهادات النهائية وبنية المستند ومسار القضية، واحتوى دفاعًا مستقلًا عن نسخ الوقائع والطلبات، يحتفظ سجل المكتب بالنص كمسودة needs_review / defense_review عند تعذر تحليل المراجعة المستقلة.
- يبقى رد الزائر 422 دون نص أو مستند أو اعتماد، مع بيان أن المسودة متاحة للمراجعة في اللوحة. لا صرف دفع ولا أرشيف نجاح.
- لا يحتفظ بهذا المسار بوقائع فقط أو طلبات فقط أو مسودة بلا مصادر أو أقسامها ناقصة أو مسارها مخالف.
- لا تسجل بيانات أي قضية حقيقية في المصدر أو سجلات الأخطاء أو الاختبارات.

## القبول
يثبت اختبار API فقد النص في النسخة السابقة ثم الاحتفاظ بالنص الحقيقي قيد المراجعة، مع استمرار حجب التسليم والدفع. اختبارات النسخ والنقص والمصادر المخالفة تبقى محجوبة. يُفحص النص المحفوظ داخل اللوحة بعد النشر.
