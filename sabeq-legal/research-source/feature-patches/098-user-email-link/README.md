## ما تغير
- إنشاء الحساب من اللوحة والتحقق منه عبر الموقع يحافظان على المعرّف والصلاحيات؛ لا يتكرر الترحيب عند الدخول المتكرر.
- تنبيه إداري عند إنشاء الحساب، وإشعارات بريد للحسابات وطلبات المذكرات وتغير حالتها.
- سجل D1 لكل رسالة، مع قفل الإرسال وإيصال قبول المزود وإعادة محاولة بمحتوى ومفتاح ثابتين.
- الرسائل لا تتضمن نصوص القضايا أو المستندات. إشعار العميل يتطلب بريد الحساب المتحقق.
- بقي زر الدخول الإداري الإضافي مخفياً وفق الواجهة المعتمدة.

## التفعيل
من «ربط البريد» حدّد بريد المكتب والأحداث المطلوبة ثم احفظ التفعيل. الإضافة غير مفعّلة افتراضياً، ولا تنقل مستلمين من مشاريع أخرى أو تعيد إرسال أحداث سابقة. تستخدم الإشعارات إعداد إرسال الرموز الحالي؛ إرسال أصل المسودة عبر Gmail مستقل.
