# دليل الفحص

- قبل الإصلاح: اختبارا محو النص المحفوظ ووصول التوليد الآلي بعد المراجعة البشرية يفشلان؛ حالة المراجعة دون نص تنجح.
- بعد الإصلاح: 32 اختبارًا مركّزًا للواجهة والنقل والسجل نجحت، و29 اختبارًا على نسخة واجهة GitHub مع الحفاظ على تخصيصاتها الستة نجحت. بناء GitHub نجح.
- فحص البصمات: 87 ملفًا من مكونات المحرك والقوالب والمصادر والتصدير مطابق تمامًا لنسخة 229؛ خصائص instructions في API مطابقة أيضًا. يشمل الفرق غلاف الإرسال والحفظ ومعالجة الأخطاء فقط.
- أُصلحت بيئة اختبار العرض القائمة لدعم الملف mjs المستورد بالفعل، ومحاكاة meta.changes بعقد D1 الحقيقي، وفحص ترتيب المراجعة ثم الحفظ ثم الأرشيف بعد وضع الأرشفة الثانوية في try/catch. لم تُضعف توقعات المحتوى القانوني أو المصادقة أو الدفع.
- المعاينة المؤقتة خارج موقع الإنتاج لم تُنفذ: رفضها فحص الموافقة الآلي بسبب احتمال تصدير المصدر إلى خدمة معاينة أخرى. أُوقفت، ويستكمل الفحص عبر النشر المأذون على موقع سابق نفسه.
- اجتازت بوابات الجودة الست وفحوص الإصدار الداخلية: مصادر 42، مذكرات 243، وصول 112، بإجمالي 397؛ بناء Worker وواجهة GitHub نجحا. نسخة المصدر العام اجتازت 29 اختبار واجهة/نقل و8 اختبارات سجل مشترك مستقلة.
- أعيد إنتاج الرسالة نفسها فعليًا في النسخة القديمة: تقديم نموذج فارغ ثم تصحيح الوقائع والانتقال بنجاح إلى شاشة المراجعة يُبقي حالة error القديمة ويعرض النص العام رغم نجاح التحضير. التعديل يعيد الحالة إلى idle عند بدء المحاولة ويحتفظ بسبب الفشل الجديد فقط.
- النشر وفحص النسخة الجديدة الحي يُوثقان بعد اكتمالهما. لا يُعد اختبار source_review الاصطناعي مذكرة قانونية مكتملة ولا إثباتًا لفحص بيانات القضية الشخصية.
- نشر الإصلاح الأول في النسخة 230 أكد اختفاء الخطأ القديم بعد تصحيح الإدخال، ووصول التوليد إلى مراجعة الأسانيد. كشف الفحص الحي طلب تحضير إضافيًا مدته 45ms بسبب قيم حقول المراجعة الافتراضية؛ أضيف اختبار مستقل وإصلاح يمرر الحقول المعتمدة للخادم مباشرة دون إعادة استخلاص. فحوص النسخة النهائية والتأكد من عدد الطلبات تُستكمل قبل إعلان الإكمال.
- اجتاز الإصلاح النهائي 399 فحصًا داخليًا: مصادر 42، مذكرات 245، وصول 112. نجحت بوابات الجودة الست والبناء الأصلي؛ نجح بناء واجهة GitHub و31 اختبار واجهة/نقل. فحص عدد الطلبات بعد النشر النهائي يبقى مسجلاً في مهمة T007 حتى رصده حيًا.
