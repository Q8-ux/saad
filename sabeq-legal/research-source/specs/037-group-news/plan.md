# الخطة
التعديل الحالي: حذف العبارة التوضيحية وأزرار التنقل والتشغيل المحددة بالأحمر، مع حذف مؤقت الحركة التلقائية. الحفاظ على سحب الصور والتنقل بلوحة المفاتيح بعد السحب اليدوي والتكبير في اللغات الثلاث، ومزامنة الموقع والخدمة من المصدر نفسه.
إزالة سطر العنوان والتاريخ الخارجي تحت بطاقة الصورة فقط، مع إبقاء التصاميم الأصلية والتكبير وتاريخ الحكم داخل نافذته دون تغيير. تحديث اختبار العرض إلى عدم تكرار العناوين والتواريخ تحت الصور مع استمرار تحقق البيانات.
التوسعة الحالية: ثلاث صور قضائية إضافية من الصفحات العامة المباشرة، بإجمالي ستة. تُحفظ الصور كما هي وتواريخ الحكم فقط؛ لا تعتمد تواريخ النشر كتاريخ كسب القضية. لا يُوصف الامتناع عن النطق بالعقاب بأنه براءة. يستمر استبعاد جميع شروحات القوانين والنصائح.
استبدال المكوّن النصي بمكوّن صور مستقل تحت الفيديوهات. يفصل سجل الصور الأصلية المستوردة عن الملخصات المراجعة، ويعرض الصور المستوردة فقط. ينسخ بناء GitHub الصور المحلية نفسها دون روابط CDN منتهية أو تضمين خارجي. نافذة dialog أصلية لتكبير الصور واحتواء التركيز. CSS محدود بالهوية الكحلية والتركواز والفضي، مع ضوابط الحركة والوصول. لا تغيير لـ API أو التوليد أو قاعدة المصادر القانونية.

تُعرض صور الأخبار القضائية الثلاثة فقط، وتستبعد النصائح والتوعية والتحذيرات العشرة من البيانات والأصول المنشورة، وتزال الأخبار النصية القديمة. يبقى الأرشيف الإضافي والدقة الأعلى متوقفين على تسجيل الدخول أو تقديم الملفات الأصلية؛ رفض المستخدم نموذج الدخول الآمن فلا يُكرّر. لا تنشر بدائل شكلية ولا تدّعي المزامنة الآلية.
