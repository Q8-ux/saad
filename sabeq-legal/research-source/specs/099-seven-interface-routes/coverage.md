## عيوب مثبتة ومعالجة
- لم تكن نافذة ModalShell تحصر التركيز أو تعالج Escape؛ أضيفت معالجة للنافذة الظاهرة الأعلى فقط، مع استعادة المشغّل.
- القائمة المحمولة لم تكن تغلق عند Escape أو الخروج والترحيل إلى قياس الكمبيوتر؛ أضيفت المعالجة دون تغيير مسارات الخدمات.
- مراحل المذكرة كانت عناصر عامة بلا aria-current أو إعلان المرحلة؛ أضيفت قائمة مرتبة وحالة نصية تعتمد على الحالة الفعلية، دون تجاوز التحقق.
- المكونات الجديدة تلتزم بلوحة الألوان الحالية وتظل مقروءة دون الحركة.

## فحوص المتصفح المنفذة
- نافذة المذكرة ومركز الإدارة عند 320 و390 و768 و1440 بكسل CSS، دون تمرير أفقي على مستوى الصفحة. جداول اللوحة لها تمريرها المحدد.
- العربية والإنجليزية والأردية، واتجاه النص؛ الإنجليزية والأردية داخل نافذة الهاتف عند 390 بكسل.
- الوضع الفاتح والداكن؛ عرض المرحلة الحالية وتباينها.
- Tab وShift+Tab داخل النافذة، Escape وعودة التركيز، إغلاق وإعادة فتح المذكرة مع بقاء نص اصطناعي.
- قائمة الهاتف وعودة التركيز إلى زرها عند Escape.
- مركز الإدارة يستخدم في المعاينة شيفرته الحالية مع ناقل HTTP اصطناعي وطلب اصطناعي؛ فشل الاتصال وإعادة المحاولة مع رجوع السجل. أزيلت جميع ملفات المعاينة قبل البناء.

## حدود التحقق
فحوص المقاسات تستخدم iframes بذات المصدر، ولا تثبت أجهزة لمس فعلية. اختصار التكبير لم يغير قياس المتصفح المتاح، فلا يُدّعى فحص 200%. روجعت قواعد تقليل الحركة وتنظيفها؛ لم يُحاكَ تفضيل نظام التشغيل. لم تُفتح مذكرات عملاء حقيقية، ولم ينفذ تحصيل أو توليد حي أو اختبار ميكروفون. اختبارات عقد الربط والتصدير بعينات اصطناعية لا تثبت المزامنة الحية أو الاعتماد القانوني.

## حالة الإصدار وإصلاح النشر
نُشر المصدر الأصلي بالإصدار 229، واجتاز بناء الإنتاج 383 فحصًا داخليًا، إضافة إلى فحوص الواجهة والتصدير. حُفظت تخصيصات نسخة GitHub في الاسم والعرض، واجتاز عقد العميل والإدارة والتحليل البرمجي فحوص GitHub.

أظهرت محاولة نشر GitHub الأولى تأخر ظهور حزمة github-pages، والثانية وجود حزمتين بالاسم نفسه. عُدلت خطوة الرفع لتستبدل حزمة المحاولة السابقة عبر overwrite مع إبقاء الاسم الذي تعتمد عليه أدوات حفظ المواقع الأخرى. أضيف انتظار محدود لظهور معرّف الحزمة المرفوعة وحده ثلاث مرات متتابعة، دون تغيير صلاحيات النشر أو فحوص الحفظ.
