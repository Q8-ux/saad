# خطة التنفيذ

React 19 + Vinext/Vite، مصدر الموقع الحالي b29baa1f872eb8e20d5324926bee10571abc018f. لا تغييرات في قاعدة البيانات أو API. واجهة Pages مشتقة من المصدر الأصلي؛ مركز الإدارة HTML/CSS/JS قائم.

1. رصد الهوية والواجهة، وتسجيل عيوب التركيز والمراحل الحالية.
2. فصل مكوّن المراحل وإضافة دلالاته، وإصلاح تركيز النوافذ والقائمة.
3. GSAP 3.15.1 محمّل عند الحاجة في مقدمة الصفحة؛ CSS لحركة النوافذ والمراحل، وتقليل حركة فعلي.
4. صقل مركز الإدارة بملف CSS مستقل يحافظ على بياناته وصلاحياته.
5. اختبارات المراحل والتركيز وحفظ الرحلة وعقد الربط، ثم البناء المعتمد وبناء Pages.
6. فحص المتصفح عبر الأداة المدعومة، ثم نشر النسخة ومزامنة الأصول العامة فقط إلى GitHub.

فحص الدستور: المصادر القانونية والخصوصية والمصادقة والدفع محفوظة؛ لا صور أو هوية بديلة؛ المقاييس والاختبارات وحدها أساس التقرير.
