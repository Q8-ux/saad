# ربط حالة الموقع بمصدره الحالي

## السبب والنطاق
الدومين الرسمي يعرض واجهة GitHub الحالية، وطلبات هذه الواجهة تذهب إلى خدمة سابق نفسها التي تقرؤها لوحة التحكم. لوحة مصادر المتابعة ما زالت تسمي جسر Render القديم «خدمة الموقع الرسمي»، مع أن مساره الحي يرجع 404.

## المتطلبات والقبول
- إثبات اتصال المصدر الحالي بعد نجاح قراءات قاعدة بيانات الموقع فقط، وإرجاع حالة صريحة مع زمن التحقق؛ لا يفترض العميل نجاحاً عند غياب هذه البيانات.
- عرض الموقع واللوحة كمصدر بيانات مشترك، وفصل الأرشيف السابق وحالته دون إخفاء فشله أو اعتباره صفراً.
- إبقاء قراءة الأرشيف وتوقيعه وصلاحيات كل المسارات كما هي؛ لا تعديل للمفاتيح أو الحسابات أو سجلات العملاء أو توليد المذكرات.
- اختبار طلب مذكرة اصطناعي يظهر في قراءة اللوحة ولو كان جسر الأرشيف يرجع 404، ورفض القراءة دون جلسة.
- تحقق مرئي ببيانات اصطناعية، ونشر الخادم وعميل GitHub ثم تحقق حي من حقول الحالة فقط.

## حدود الدليل
نجاح ربط قاعدة الموقع الحالية لا يعني نشر جسر الأرشيف القديم، ولا استعادة بيانات لم تحفظ أصلاً. إثبات اتصال المصدر ليس اختباراً للدفع أو نتيجة التوليد.
