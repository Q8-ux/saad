# التحقق من عرض السجلات

- عرض بيانات الطلب والمذكرة عبر معالج التفاصيل الحقيقي: 8/8 اختبارات سلوكية، تشمل البيانات القديمة، JSON المزدوج، علامات الأسطر، الحقن عبر HTML، جميع مصادر السجل، الإغلاق ورفض الوصول.
- فحص الإصدار: مصادر 33/33، مذكرة 128/128، صلاحيات 74/74؛ ثم نجاح بناء Worker والواجهة.
- معاينة اصطناعية على عرض 320 و390 و768 و1440؛ المحاذاة إلى اليمين وخط Cairo مُحمّل. لا يتجاوز محتوى النافذة العرض، ويتوفر التمرير والإغلاق، واختُبر التمرير بلوحة المفاتيح.
- صورة المعاينة لسجل اصطناعي فقط، دون أي ملف عميل أو بيانات دخول.
- النشر والتحقق من وصول إصدار أصول الإدارة إلى GitHub يأتيان بعد هذه الفحوص.
