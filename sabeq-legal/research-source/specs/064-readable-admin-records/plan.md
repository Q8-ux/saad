# الخطة

إصلاح عارض تفاصيل المذكرة المشترك في public/management/admin.js، مع CSS خاص بالنافذة ونسخة أصول محدثة لمنع ظهور العرض القديم من الذاكرة. تعرض الحقول القانونية المعروفة فقط، ويظل النص غير المقروء بحالة عربية واضحة. تحقق سلوكي ببيانات اصطناعية يتضمن التهريب الأمني والنص المزدوج الترميز، ثم معاينة الجوال/الكمبيوتر ونشر الأصل المستضاف ونسخة GitHub.
