# عرض سجل الطلبات والمذكرات

المطلوب: قراءة سجل الطلب والمذكرة كنص عربي منسق في مركز الإدارة الحالي، بمحاذاة اليمين، مع الحفاظ على Cairo والهوية والصلاحيات.

معايير القبول: تحويل بيانات الطلب JSON إلى حقول عربية وإخفاء الفارغ والتقني، فك طبقات النص المحفوظ وعلامات الأسطر القديمة دون تعديل التخزين أو مضمون القضية، عرض فقرات وعناوين واضحة، دعم السجلات القديمة والرسمية والحالات الفارغة، منع تنفيذ HTML من البيانات، وإبقاء الإغلاق والتمرير قابلين للاستخدام على الجوال.

الاختيار: نص داخل الداشبورد؛ طلب المستخدم يجيز النص أو PDF. لا تغيير لقالب المذكرة أو توليدها أو الدفع أو مخزن البيانات.

إضافة المستخدم: نص خانتي اسم المستخدم وكلمة المرور في الدخول يُحاذى إلى اليسار وباتجاه LTR؛ تبقى تسميات النموذج بالعربية وRTL.
