# نطاق التحقق الآلي

فحص Client Admin Contract في GitHub يشغّل 23 اختباراً لعقد التوقيع ومنع إعادة الطلب وتجهيز المدخلات والانتقال إلى مراجعة المذكرة، و5 اختبارات لمرسل اللوحة وصلاحياته، وفحوص بصمات Spec Kit في الجانبين. لا يحمّل قواعد التشريعات أو PDFs أو seed SQL إلى النسخة العامة من المصدر.

اختبارات معاملات سداد الكاملة والإدارة (ضمن 99 اختباراً محلياً) نُفذت في المصدر التشغيلي الكامل، حيث توجد بنية قاعدة الاختبار القانونية. لم تُخفَّف فحوص الفواتير أو الاستحقاق ولم تُنفذ عملية خصم حية. يتطلب إثبات اتصال لوحة المالك الحي دخولاً إلى موقعها الخاص. اختبر وصفاً اصطناعياً بلا أسماء فانتقل إلى المراجعة عند 50 د.ك دون إنشاء فاتورة.

نقل مصدر اللوحة إلى sabeq-admin-preview/research-source يقيه اكتشاف الاختبارات المتداخل في الخلفية القديمة. تغيرات الأدوات وسجلات التنفيذ لا تطلق إعادة استيراد التشريعات. فحص النشر يقبل مسارات سابق المحددة فقط ويظل يرفض تغيير أي مشروع آخر ضمن الإصدار المحدود.
