# خطة محدودة

إعادة استخدام مكوّن Assistant ومعالجاته القائمة. إضافة غلاف للمنطقة القابلة للتمرير وغلاف للمحرر، وإفصاح لإعدادات الصوت والمعلومات، دون تغيير إدارة الجلسة أو الطلبات. تبقى بطاقة توليد المذكرة قبل منطقة المحادثة وفي نفس ترتيب المكوّنات المعتمد.

إضافة طبقة CSS محصورة في النافذة التي تحتوي legal-intake، مع متغيرات لون محلية فاتحة للتوافق مع الثيم الداكن الخارجي. تبقى أحجام اللمس 44 بكسل والتركيز المرئي والتباين المقروء. لا مكتبات أو أصول جديدة.

التحقق: اختبارات الإغلاق والصوت والتسليم للمذكرة واللغات والإدخال الطويل، بناء العامل وGitHub Pages، ثم المعاينة على سطح المكتب والجوال بما فيها كتابة مسودة وإغلاق النافذة وإعادة فتحها. النشر محدود بسابق مع حفظ الملفات المنشورة الأخرى.
