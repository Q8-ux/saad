# نافذة المساعد القانوني — ثيم المحادثة الفاتح

طلب المستخدم 2026-11-01 مطابقة الطابع البصري لصورة المحادثة المرفقة: خلفية فاتحة هادئة، رسائل المساعد بيضاء بإطار رقيق، رسائل المستخدم رمادية، وحقل كتابة أبيض مستدير بأدوات بسيطة.

النطاق نافذة المساعد فقط. نحافظ على صورة المساعد المعتمدة وخط المهند وRTL، وإدخال النص والصوت وحالاتهما، وتوليد المذكرة وتعديل الرسائل وحذفها وتصديرها ومشاركتها. الصورة مرجع بصري؛ لا نضيف جمع البريد أو حالة اتصال بشري أو وظيفة مرفقات.

معايير القبول:
- النافذة فاتحة ومقروءة أيضاً عند اختيار الثيم الداكن للموقع؛ بقية النوافذ لا تتأثر.
- محادثة قابلة للتمرير وحقل كتابة ظاهر، مع عدم قص أدوات الإغلاق والصوت والإرسال عند عرض 320 و390 و768 و1440 بكسل.
- الفقاعات والأدوات المحايدة تقارب الصورة، مع استمرار العربية/الأردية RTL والإنجليزية LTR وخط المهند.
- تبقى حالة توليد المذكرة وزرها ورسائل الخطأ ومراجعة المحامي متاحة، وتبقى إعدادات الصوت ومعلوماته داخل إفصاح واضح.
- نجاح اختبارات المساعد ذات الصلة والبناء، ومعاينة فعلية قبل نشر الواجهة والخلفية المتطابقتين.

لا تغيير في النصوص القانونية أو المصادر أو الدفع أو الصلاحيات. تستخدم المعاينة وقائع اصطناعية فقط؛ لا اختبار لميكروفون فعلي ضمن هذه المهمة.
