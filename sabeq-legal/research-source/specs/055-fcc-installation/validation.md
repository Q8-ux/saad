# التحقق من موصل FCC

- اختبارات الإدارة الحالية نجحت، بما فيها تسجيل الدخول والصلاحيات والخزنة والإلغاء وحدود التوليد ومنع التحويل الصامت.
- اختبارات حالة التركيب الجديدة نجحت: غياب المفتاح لا يسجل نجاح توليد، وحذف مفتاح المزود يلغي جاهزية الاختبار السابق، وتبقى أسرار الاتصال مخفية.
- اختبارات العميل: 4 ناجحة، تشمل بقاء تجربة التوليد معطلة عند غياب مفتاح المزود.
- اختبارات حماية بوابة ASGI: 6 ناجحة باستخدام Python 3.12 واختبار نقل اصطناعي. لا تثبت هذه الاختبارات تحميل FCC الحقيقي على Python 3.14.9.
- فحص الواجهة الفعلية ببيانات محلية اصطناعية على الكمبيوتر وعلى إطارين بعرض 390 و320: العرض الداخلي 375 و305 دون تجاوز أفقي، وحالة غياب الربط واضحة.
- حذفت ملفات المعاينة المحلية قبل حزمة النشر. ينفذ فحص الإصدار الداخلي والبناء بعد هذا الفحص؛ نتيجة أداة النشر هي المرجع النهائي لحالة النشر.
- التشغيل الفعلي لخدمة Python وربطها وتوليد إجابة حية يحتاج تحديد مساحة Render وإضافة مفتاح NVIDIA أو OpenRouter. لم يُنشأ مفتاح مزود أو يفترض توفر حصة مجانية.
- صلاحيات التشغيل الخمسة باقية كما هي؛ المبرمج متاح للحساب الإداري المصرح له.
