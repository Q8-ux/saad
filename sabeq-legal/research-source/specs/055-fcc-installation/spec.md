# تركيب بوابة FCC لمركز تحكم سابق

## الهدف
إكمال الموصل الموجود بمؤشرات جاهزية صادقة وحزمة خدمة FCC مستقلة، مع بقاء المبرمج للإدارة المصرح لها.

## الافتراضات والبيانات الناقصة
- مصدر الموقع الحالي يحتوي موصل FCC بالفعل؛ لا يوجد إعداد programmer في خزنة الإنتاج عند الفحص.
- FCC يتطلب Python 3.14.9 ولا يعمل داخل Cloudflare Workers؛ يستضاف كخدمة منفصلة.
- لا يوجد مفتاح NVIDIA أو OpenRouter ضمن متغيرات الموقع. لا تُفترض مجانية التوليد أو نجاحه دون مفتاح وتجربة فعلية.
- أداة Render لا تحتوي مساحة عمل مختارة. إنشاء الخدمة ينتظر اختيار المستخدم للمساحة.

## معايير القبول
1. تظهر حالة الإعداد منفصلة عن نجاح قراءة النماذج وعن نجاح التوليد.
2. جلب النماذج يوضح مفتاح المزود المفقود إن صرحت البوابة بذلك؛ لا يحول إلى خدمة سابق المدفوعة.
3. الخدمة المستقلة تثبت إصدار FCC وتكشف GET /healthz، وGET /v1/models، وPOST /v1/messages فقط؛ الطلبان الأخيران بمفتاح قوي.
4. لا تعرض /admin أو جلسات تنفيذ الأوامر أو مفاتيح المزود أو ملفات القضايا.
5. تفشل الطلبات الكبيرة/غير الصالحة قبل الوصول للنموذج، ولا تسجل محتوى المدخلات أو الأسرار.
6. تختبر حماية البوابة وحدود الطلبات، واختبارات الموصل والعميل، والبناء قبل نشر المصدر والواجهة.
7. لا يعلن تشغيل النموذج إلا بعد اختبار توليد حقيقي؛ يُذكر صراحة أي عائق خارجي.
