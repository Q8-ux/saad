# الخطة

- تمديد الإعداد الحالي بحالة جلب القائمة ومفتاح المزود، بلا مخطط بيانات جديد أو توسيع صلاحيات.
- إضافة حالة تركيب واضحة واسم المسار في public/management/programmer.js، مع الحفاظ على RTL والهوية.
- إضافة integrations/fcc بخادم ASGI ضيق فوق إصدار FCC المثبت. إعداداته عبر متغيرات خدمة الاستضافة، لا عبر مصدر GitHub.
- استخدام NVIDIA أو OpenRouter بمفتاح يقدمه المستخدم إلى بيئة الخدمة. إبقاء الخدمة في حالة انتظار صريحة إذا غاب المفتاح.
- نشر تحديث اللوحة بنفس Site ومزامنة الملفات المتعلقة في Q8-ux/saad. خدمة Render free مستقلة لا تنشأ قبل تحديد مساحة العمل.
- فحص Python دون استيراد FCC لا يثبت تشغيل الإصدار الحقيقي؛ تحقق التشغيل والتوليد الحي مرحلتان مستقلتان.
