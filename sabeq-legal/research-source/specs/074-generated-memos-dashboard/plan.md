# التنفيذ والتحقق

إعادة استخدام سجل المذكرات والعارض الموجودين. تضيف قائمة الإدارة بيان وجود النص ومرشح `view=generated` قبل الترقيم، مع الحفاظ على النداء القديم الذي يعيد كل الطلبات. لا تنشأ مزامنة مستقلة أو نسخ مكررة من القضية.

تفتح واجهة الإدارة على العرض المولد، وتتيح كل الطلبات عبر مرشح واضح. تبقى حالة المراجعة والبحث والعرض الآمن كما هي. يدخل قسم المذكرات ضمن التحديث الدوري الحالي، مع التوقف عند إخفاء الصفحة أو تبديل القسم دون استبدال نافذة مذكرة مفتوحة.

يربط عنوان fragment السجل المحفوظ بالعارض القائم. تُفحص الجلسة والصلاحية أولاً، ثم يُطلب السجل من نفس endpoint المحمي. يحفظ متصفح الإدارة المعرف فقط خلال مسار الدخول القائم، دون إنشاء جلسة أو تغيير صلاحيات. لا تحفظ معرفات سجلات العميل أو نصوصها في الشيفرة أو المواصفة أو لقطات الاختبار.

الانحدار أولاً: اكتمال الحفظ لا الحالة وحدها، الضيف والمستخدم والسجلات القديمة، البحث والترقيم، اختيار العرض في الواجهة ورفض الوصول غير المصرح. ثم بوابات الإصدار وبناء Worker ومعاينة اصطناعية للعربية وRTL. تنشر ملفات الإدارة والخدمة ومرآتها المحددة فقط؛ تبقى حزمة الواجهة العامة الصالحة دون إعادة بناء إذا لم تتغير.
