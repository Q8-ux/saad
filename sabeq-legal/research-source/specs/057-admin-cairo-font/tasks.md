# المهام

- [x] T001 توثيق طلب الخط ومراجعة ملفات لوحة الإدارة والخط المحلي الموجود.
- [x] T002 اعتماد Cairo في أنماط الإدارة وتحميله المسبق مع ملف الخط والترخيص.
- [x] T003 فحص تحميل الخط ووراثته للحقول والأزرار وعرض الجوال.
- [ ] T004 فحوص البناء والنشر والتحقق من النسخة الحية.

## التحقق
- تحقق من اسم Cairo ومحوري الوزن 200–1000 والميل داخل ملف الخط.
- نجح تحميل الخط محلياً بوزني 400 و600، وظهر في شاشة الدخول والأزرار والحقول.
- فُحصت النماذج محلياً داخل عرضي 375 و305 بكسل، دون تمرير أفقي للصفحة.
