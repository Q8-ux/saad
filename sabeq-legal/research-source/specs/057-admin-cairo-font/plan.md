# التنفيذ

استبدال تعريفات Sabeq Plex بخط Cairo المحلي، وتعديل تحميل الخط المسبق ومعرف تخزين CSS المؤقت. حفظ ملف الخط وترخيصه في مجلد إدارة الموقع، مع إعادة استخدام بصمة ملف الخط الموجود في مستودع GitHub عند النشر. فحص شاشة الدخول وعينة محلية من نماذج الإدارة على الجوال، ثم بناء الحزمة ونشرها دون تغيير الخادم الوظيفي أو أسرار البيئة.
