# خط القاهرة للوحة الإدارة

طلب المستخدم اعتماد خط القاهرة في لوحة التحكم الحالية. يشمل التغيير شاشة الدخول والعناوين والقوائم والحقول والأزرار والجداول والتفاصيل، مع بقاء الشفرة والمعرفات التقنية بخطها المتساوي العرض.

يستخدم الخط المحلي نفسه الموجود في الموقع العام، وتبقى سياسة تحميل الخطوط من نفس المصدر. لا يغيّر هذا الطلب الصلاحيات أو البيانات أو خدمات الموقع. يتقدم طلب المستخدم الصريح على قاعدة المحافظة على خط الهوية السابق.

معايير القبول: تعريف Cairo متغير بأوزانه الفعلية، تحميل محلي ناجح، وراثة الحقول والأزرار للخط، وعدم خروج شاشة الجوال عن عرضها، ثم نشر نسخة لوحة GitHub ومصدرها المطابق.
