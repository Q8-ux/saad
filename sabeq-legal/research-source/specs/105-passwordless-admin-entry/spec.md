# مدخل الحساب الإداري في نسخة العميل المحفوظة

تتبع هذه النسخة [المواصفة والخطة والمهام المعتمدة](../../../../legal-memo-platform/specs/105-passwordless-admin-entry/spec.md). التغيير هو إظهار sign-in الحالي ومعالجة ?signin=account مرة واحدة. تطابق public/management/admin.js مع عميل لوحة GitHub شرط اختباره القائم، ولا يتغير أي endpoint أو صلاحية أو مستخدم أو مفتاح. لا تعني مزامنة هذه النسخة نشر خادم جديد.
