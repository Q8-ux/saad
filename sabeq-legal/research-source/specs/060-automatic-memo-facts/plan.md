# خطة التنفيذ

إعادة استخدام وحدة نقل بيانات المذكرة لتحديد مصدر الوقائع. تمرير جلسة المساعد إلى نموذج المذكرة، وتعبئة حقل الوقائع الفارغ عند فتح النموذج فقط. إبقاء بوابات الدفع والتوليد والنقل الكامل كما هي، دون إضافة API أو تغيير قاعدة البيانات أو الهوية.

التحقق: حالات اصطناعية لاختيار الوقائع وحفظ التعديلات، ثم بناء الهدفين وفحص مسار الانتقال والعودة في المتصفح.
