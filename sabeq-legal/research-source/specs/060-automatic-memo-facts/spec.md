# استيراد وقائع القضية تلقائيًا

عند الانتقال من المساعد إلى المذكرة عبر فتحها أو العودة إليها، يبقى حقل الوقائع فارغًا ما لم يُستخدم زر النقل الكامل. المطلوب تعبئة الوقائع المتاحة تلقائيًا وتصحيح تسمية الاستخراج.

معايير القبول:
- يبدأ زر المستندات بكلمة «استخراج» ويصف استخراج الوقائع والبيانات.
- الحقل الفارغ يأخذ وقائع المساعد المنظمة، ثم قائمة الوقائع، ثم رسائل المستخدم فقط إذا غاب الاستخلاص؛ لا تُستورد أجوبة المساعد باعتبارها وقائع.
- تبقى الوقائع التي كتبها أو عدّلها المستخدم كما هي عند العودة أو إغلاق المذكرة وإعادة فتحها في الجلسة نفسها.
- لا يتغير محتوى محاولة دفع أو مذكرة مولدة، ولا تُتجاوز مراجعة البيانات أو موافقة التوليد.
- تحليل المستندات الحالي يظل يعبئ الوقائع عبر مساره الموجود.

الافتراض: مصدر الاستيراد هو محادثة المساعد الحالية، دون حفظ ملفات القضايا أو الجلسات في المستودع أو إضافة تخزين دائم.
