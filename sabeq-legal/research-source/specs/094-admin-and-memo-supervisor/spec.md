# حساب مدير النظام ومشرف المذكرات

طلب المستخدم تأجيل نشر واجهة النقل على Bolt إلى ما بعد الدفع، وإنشاء/تحديث حساب saad بكامل صلاحيات اللوحة وحساب Ahmad لمتابعة المذكرات والمواعيد والرسائل والاستشارات. تحفظ كلمات المرور في إعدادات تشغيل محمية ولا توضع في الملفات أو GitHub أو التقارير.

## معايير القبول
- AC1: حساب saad إداري كامل، وحساب Ahmad دور مستقل محدود؛ لا يعاد تعريف حسابات التشغيل الأخرى أو ترقيتها.
- AC2: مشرف المذكرات يستطيع عرض النصوص ونسخ المراجعة ومتابعة رسائل الموقع وطلبات الاستشارة والمواعيد. يمنع خادميًا من الدفع والمستخدمين والمفاتيح والمبرمج والإعدادات والتشريعات وإدارة الحسابات، حتى بطلب API مباشر.
- AC3: التطبيع يجعل Ahmad/ahmad اسمًا واحدًا؛ الجلسة تستمد الدور من إعداد الخادم ولا تقبل role أو sections من المتصفح.
- AC4: تخزين مشتقات كلمات المرور مع ملح وpepper و600000 PBKDF2؛ تجديد بيانات saad فقط عبر آلية الإصلاح الحالية دون تغيير حساب آخر، وإبطال الجلسات القديمة للحساب الذي تغيرت بياناته.
- AC5: تبقى المذكرات وبيانات العملاء والدفع محفوظة، ولا ينشر Bolt الآن. يختبر الدخول والرفض لكل دور ويعرض رابط GitHub الحالي.

توجيه المستخدم اللاحق: كلمة المرور الجديدة لا يشترط فيها طول أدنى أو فئات محارف أو تعقيد. يقبل أي نص غير فارغ كما أدخله المستخدم؛ تبقى حماية الخادم والتجزئة ومكافحة المحاولات كما هي. ينطبق ذلك على دخول حسابات اللوحة وتحديثها واستعادة المشرف.
