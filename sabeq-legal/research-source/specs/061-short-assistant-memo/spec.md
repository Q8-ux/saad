# Short assistant-to-memorandum path
The user requests fewer steps and less time, and explicitly removes the Sabeq Tools buttons from the assistant. The primary assistant handoff must open one editable review screen populated with the existing case data. A single explicit approve-and-generate action validates the form and enters the existing payment/generation flow, without another Next screen or duplicate approval checkbox. Unknown required fields still need correction; do not guess facts, courts, names or legal sources. Upload/extraction stays optional and available. Existing manual entry, retained drafts, source review, server payment checks, cancellation and legal approval safeguards remain.
Acceptance: no LegalToolsPanel in the assistant; an assistant handoff starts at editable review; submitting review never advances to another review screen; facts and requests remain editable and retained; upload can return to the same review; unpaid attempts cannot generate; incomplete required fields do not call generation; one explicit approval is still visible.
