# أدلة التنفيذ

- اختبار القائمة قبل إضافة API أخفق 404؛ بعد التنفيذ نجحت ست حالات API جديدة فعلية على D1 اصطناعية: الصلاحيات وعدم كشف الاعتماد، إعادة التسمية، إعادة تعيين كلمة المرور، رفض التصادم/الحقول غير المسموحة/التزامن، تغيير حساب المشرف، وفساد الخزنة.
- جميع اختبارات management القائمة مع الحالات الجديدة: 56 نجحت قبل إضافة فحص البريد. لا تغيير للاعتماد أو الدور الحقيقي لأي مستخدم.
- فحص المتصفح الاصطناعي: رفض الاسم المكرر، حفظ اسم جديد، رفض تأكيد كلمة مرور مختلفة، حفظ الكلمة المطابقة، وإعادة شاشة الدخول عند تغيير اسم المشرف. عرض 390 بكسل دون خروج عرض الصفحة. أعيد استخدام Cairo والتخطيط الحالي مع أزرار تعديل كاملة العرض على الجوال.
- فحص TypeScript لم يجد أخطاء جديدة في الملفات المتأثرة بعد استبعاد غياب تعريف cloudflare:workers الموجود في المشروع؛ لا ادعاء نجاح فحص TypeScript الكامل.
- بوابات الإصدار السابقة خلال هذا التغيير: 33 مصدر +152 مذكرة +84 وصول =269 ناجحة، وبناء Vinext ناجح. ستُعاد البوابة بعد إضافة إرسال الاختبار المأذون به ضمن التغليف النهائي.
- الفحص الحي يقتصر على القراءة وفتح نموذج تعديل فارغ؛ لا إعادة تسمية أو تعيين كلمة مرور حقيقية لغرض الاختبار. النشر والتحقق الحي تتبعهما أدوات النشر في المحادثة، ولا يثبتهما هذا الملف وحده.
