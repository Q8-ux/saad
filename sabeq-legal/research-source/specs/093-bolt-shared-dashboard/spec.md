# استبدال واجهة Bolt بلوحة سابق المشتركة

## الطلب والنطاق
استبدال واجهة https://q8-ux-sabeq-admin-co-u4ma.bolt.host/ باللوحة الحالية المنشورة في sabeq-admin-preview، مع عرض المذكرات الواردة من الموقع الرسمي www.sabeq.legal ونصوصها المحفوظة. لا يطلب نقل أو حذف بيانات Supabase أو D1 أو تغيير السعر أو الصلاحيات أو إرسال بريد.

## الحقائق والافتراضات
- رابط Bolt الحالي يعرض نموذج دخول قديمًا. مصدره Q8-ux/sabeq-admin-console.
- اللوحة الحالية تقرأ API الإدارة من قاعدة خدمة سابق المشتركة. أصل CORS ورد الدخول مثبتان على GitHub Pages فقط.
- مستودع Bolt يملك أمر بناء إلى dist، ولا توجد في workflows المفحوصة خطوة تنشر الواجهة إلى bolt.host. دفع GitHub لا يعد إثبات نشر Bolt.
- نشر الاستبدال في Bolt والتدفق الحي يحتاجان تحققًا مستقلًا؛ لا يستعاض عنهما باختبارات محلية.

## معايير القبول
- AC1: واجهة وميزات اللوحة المعتمدة تعرض محليًا على جذر Bolt دون iframe أو تحويل المستخدم إلى GitHub.
- AC2: يقبل خادم الإدارة الأصلين المحددين فقط، ويبقى فحص المدير والصلاحيات والتحقق من PKCE وإعادة الاستخدام قائمًا.
- AC3: يعود تسجيل الدخول إلى الأصل الذي بدأه من قائمة ثابتة؛ لا يوجد redirect URL حر.
- AC4: المذكرات وتفاصيلها والتحرير تقرأ وتكتب المصدر الحالي نفسه. لا تنشأ قاعدة مذكرات بديلة أو بيانات تجريبية في الحزمة العامة.
- AC5: بناء صالح وفحوص إيجابية وسلبية للأصلين وفشل الجلسة وعدم تطابق الطلب؛ الاختبار الحي على sabeq.legal موثق دون دفع حقيقي.
- AC6: لا يدعى استبدال bolt.host حتى تعرض الصفحة الحية الحزمة الجديدة. تحفظ الواجهة السابقة في سجل Git ولا تحذف سجلات العملاء.
