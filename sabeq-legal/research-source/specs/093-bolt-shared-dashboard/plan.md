# الخطة

إعادة استخدام public/management كما هي مع اختيار callback ثابت وفق الأصل. يسمح خادم الإدارة بأصل Bolt المحدد، ويطابق ترويسة CORS بالأصل المسموح لكل استجابة، بما في ذلك تنزيل ملفات التشريعات، دون wildcard. لا يغير نطاق واجهات التوليد العامة أو قواعد البيانات. نسخ الأصول الحالية إلى public في مستودع Bolt، تحديث أمر البناء والاختبارات والوثائق وCI للمصدر الجديد، وإبقاء وظائف Supabase وسجلاتها دون تعديل. تثبيت بصمات المصدر المنسوخ ومنع حزم ملفات القضايا أو مفاتيح الخدمة. نشر backend عبر مساره الحالي، ثم دفع تغييرات GitHub إلى المستودعين دون force. التحقق من نشر Bolt الفعلي ومقارنة طلب رسمي بتفاصيله في الإدارة. غياب إذن نشر/جلسة Bolt قيد منفصل لا يبرر إزالة المصادقة.
