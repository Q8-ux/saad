# الخطة

استعمل تحديث السجل بالمفتاح الأساسي. احفظ سجل الخدمة الاختياري مع الطلب داخل D1 batch ذرية وبمعرّف خدمة حتمي مشتق من request ID، ثم تحقق من النص المحفوظ قبل التسليم. امنع المسح في تحديثات الفشل. افصل review_pending عن needs_review.

استرجع البدائل فقط بروابط JSON الدقيقة؛ لا تطابق أسماء ولا تنفذ تحديثاً أثناء GET. طبّع الغلاف المعروف إلى نص. حافظ على فشل القراءة كخطأ. لا migration مطلوب: مفاتيح id الحالية فريدة. تغييرات اللوحة في PR مستقل، ولا نشر لأي طرف.
