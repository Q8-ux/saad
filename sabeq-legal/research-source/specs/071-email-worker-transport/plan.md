# الخطة

1. أضف اختبار انحدار يشغّل الشيفرة الحالية داخل Miniflare/workerd المثبتين، مع عزل جميع الطلبات الخارجية بمزود اصطناعي.
2. أثبت الفشل قبل تغيير الشيفرة؛ الاختبارات الحالية التي تستبدل fetch لا تختبر دعم إعدادات workerd.
3. استعمل `redirect: manual` في طلبي Resend. يحافظ فحص `response.ok` القائم على رفض التحويلات والاستجابات المرفوضة دون اتباع Location.
4. شغّل الاختبار الجديد وفحوص اللوحة والبناء المطلوبة، ثم انشر الخلفية ضمن الجمهور الحالي.
5. اختبر طلب رمز واحد إلى صندوق يخص مالك الموقع؛ لا تقرأ الرمز ولا تنشئ جلسة بوساطة الاختبار. افصل أي رفض لدى المزود عن خلل النقل.

لا يتطلب الإصلاح تغيير قاعدة البيانات أو الصلاحيات أو واجهات API أو تبعيات المشروع أو الواجهة. تبقى اتصالات المزودين الآخرين خارج النطاق.
