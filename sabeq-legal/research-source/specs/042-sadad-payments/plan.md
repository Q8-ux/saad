# Implementation Plan: SADAD Kuwait
## Summary
أعد استخدام خدمة Workers/Vinext وD1 وسياسة service_settings وخزنة الإدارة المشفرة. أضف lib/sadad-payments.ts ومساري app/api/payments/sadad وwebhook وجدول drizzle/0006. لا اعتماد جديد.
## Technical Context
React/Vinext؛ D1؛ عميل GitHub Pages؛ لوحة إدارة مستقلة؛ Express/Render مدخل إضافي. KWD فقط وأعداد صحيحة بالفلس. الأسرار في الخادم أو management_vault المشفرة.
## Constitution Check
المصادر والنصوص القانونية والضيف والهوية محفوظة. لا وقائع قضية أو بيانات بطاقة إلى سداد. اختبارات اصطناعية؛ لا تحصيل فعلي أثناء الفحص ولا ادعاء نشر النطاق الرسمي دون دليل.
## Phase 0: Research
ارجع إلى research.md. لم يحدد السعر؛ يبقى التحصيل غير مفعل حتى ضبطه وتأكيد حساب التاجر. لا يُعاد إنشاء فاتورة بعد انقطاع غامض.
## Phase 1: Design
حالات creating/pending/uncertain/paid/generating/consumed؛ بصمة مدخلات ورمز عشوائي وحجز ذري مدته 6 دقائق؛ استرجاع ناتج خاص لمدة 7 أيام. إعادة محاولة التوليد الفاشل لا تستلزم دفعاً جديداً. invoice_id/key/reference/amount/currency ثابتة للتحقق.
## Phase 2: Implementation
واجهة app/sabeq-site.tsx للسعر ورابط سداد والتحقق قبل التوليد. public/management/admin.js ومسار management للإعداد والفحص والسجل. ربط المدخل الرسمي بالخدمة المعتمدة عند اشتراط الدفع. اختبر ثم انشر Worker وعميل GitHub على حدة.
## Validation
اختبارات SQLite وواجهات API مع سداد اصطناعية للتزوير والمبالغ والتكرار والتزامن والفشل والاسترجاع؛ اختبارات المذكرات والإدارة وTypeScript وبناء الموقع وGitHub. تفاصيل contracts/payments.md وquickstart.md.

## Review refinements
تحقق مشترك قبل الدفع في lib/memo-input.ts، مع الحفاظ على missingFacts في API. تصحيح مدخلات الطلب مسموح لصاحب الرمز قبل الحجز فقط؛ شرط الحجز يتضمن بصمتها. إعادة التحقق من الفاتورة عند استعادة الحجز المنتهي. إغلاق محاولات sandbox محلياً عند الانتقال للإنتاج، دون إسقاط دفعة حقيقية. تسوية المحاولة الغامضة بمعرف فاتورة متحقق منه في الإدارة. أسرار الطلب فقط في sessionStorage دون وقائع، واسترجاع النتيجة المكتملة برمزها. مدة السبعة أيام لاسترجاع الناتج؛ تنظيفه الفعلي عند العمليات التالية وليس مهمة دورية مستقلة. لا ضمان للاسترجاع بعد إغلاق تبويب المتصفح.
