# أدلة التحقق

- قبل الإصلاح فشل اختباران لأن الخادم لم يرفض نوع جنح مع دائرة إدارية، ولأنه قبل نوعاً غير محدد حتى في وضع البيانات المتاحة. نجحا بعد إضافة حاجز المسار.
- اختبارات التصنيف تستخدم بيانات اصطناعية، وتشمل التخصصات العشرة، درجات الإداري، صفة المستأنف ضده، الوصاية والرعاية، الخبرة الطبية، رفض الخبرة، اختلاف النوع والدائرة، والطلبات التي تحتاج قالباً خاصاً.
- نجحت 132 حالة موجهة في الصياغة والمحادثة والتحضير واستيراد النص والتنسيق، ثم فحوص إضافية لهوية المسار قبل حجز الدفع وتمريره لجميع استدعاءات النموذج والحفظ ومنع حفظ عنوان من مسار آخر بعد محاولة إصلاح واحدة.
- نجح فحص بناء أولي قبل اللمسات الأخيرة. فحص النشر النهائي يسجل منفصلاً أدناه؛ لا تمثل الاختبارات تجربة استدلال حي ببيانات قضية أو دفعاً حقيقياً أو ضماناً قانونياً.
- راجعت الملفات الجديدة نصياً وبصرياً لاستخراج الهيكل فقط، بما فيها النسخ المتكررة. لم تدخل ملفات PDF أو أسماؤها أو النصوص المستخرجة أو بياناتها أو استشهاداتها في المصدر أو طلبات مزود التوليد.
- قواعد الصياغة المرجعية أصبحت بالإصدار `reference-pleading-style-2`. يشمل نطاق الملاحظة صحف الدعاوى والطلبات المذكورة في الكتالوج؛ لم تُرصد صحيفة استئناف مستقلة في المراجع المضافة.
- المزود والمفتاح والإعدادات والأسعار وقاعدة القوانين لم تتغير. المذكرات السابقة المحفوظة لم تُعدّل.

- فحص بصري فعلي لمكوّن المراجعة نفسه بعينات اصطناعية على عرض مكتب وعرض هاتف داخل إطارات 390 بكسل: ظهر مسار المدني/ندب خبير، وظهر سؤال تعارض الجنح والإداري دون ادعاء صيغة جاهزة. عرض المحتوى في الهاتف يساوي عرضه الداخلي (375 بكسل بعد شريط التمرير)، دون امتداد أفقي. حذفت صفحة الاختبار قبل بناء النشر.
- نجح فحص متطلبات Spec Kit بتحديد مجلد الميزة الحالي؛ مراجعة الاتساق يدوية بين A1–A9 والشيفرة والاختبارات، ولا يدعى تشغيل دورة CLI كاملة.

- كشف اختبار إضافي قبول صفة مستأنف مع إبقاء المحكمة الحالية أول درجة؛ أضيف حاجز يميز المحكمة التي أصدرت الحكم عن الجهة التي تنظر الإجراء الحالي، مع سؤال محدد عند التعارض. النسخة المحفوظة السابقة لم تنشر، وتعتمد إعادة البناء النهائية هذا الحاجز.

## النشر والتحقق النهائي
- نشر الخادم نجح بالإصدار 213 من المصدر `bcd7e5b142dcc64cb78576bda104f2a15f4be082`؛ مراجعة إعدادات الإنتاج 30 لم تتغير. الإصدار المحفوظ 212 لم يُنشر لأن فحص درجة المحكمة أضاف حاجزاً قبل التفعيل.
- نجح البناء النهائي وفحوص الإصدار في المصدر الكامل. نجحت جميع خطوات JavaScript لعقد المرآة العامة محلياً، بما فيها فحص الصياغة والمصادر والتحضير والحفظ والواجهة وصلاحيات الإدارة.
- أعيد بناء واجهة GitHub من المصدر الكامل مع الحفاظ على تغييرات المرآة السابقة؛ الحزمة الجديدة `assets/index-D2CQW3RZ.js`. فرق ملفات النشر يقتصر على ملف JavaScript الجديد ومسار دخوله في index.html؛ لا صور أو خطوط أو إضافات قائمة تغيرت.
- فحص الحزمة لم يجد أسماء ملفات المراجع الجديدة أو مفاتيح مزود مضمّنة. فحص التغيير النصي لم يجد أسماء المراجع أو معرفاتها الرقمية الطويلة.
