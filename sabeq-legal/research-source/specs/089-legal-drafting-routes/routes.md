# كتالوج مسارات الصياغة

يحدد الخادم المسار من نوع القضية والدائرة والمحكمة الحالية والصفة والمستند المطلوب. لا يعتمد عنوان ملف مرجعي أو أسماء أطرافه، ولا يأخذ معرف مسار جاهزاً من الزائر. المعرف مركب من التخصص + نوع الطلب + الدرجة + صيغة المستند + صفة الطرف.

| المسار الأساسي | ما يضبطه |
| --- | --- |
| الجنح | الاتهام الحالي ودور المتهم وأدلة الإسناد وحدود الطلب؛ منفصل عن الجنايات |
| الجنايات | كل اتهام ودور صاحبه وعناصره ودليله والإجراءات المتعلقة به |
| الإداري | القرار أو التصرف أو المركز محل النزاع والصفة والطلب؛ مستقل عن درجة التقاضي |
| المدني | مصدر الالتزام أو المسؤولية والمقدار والوفاء، مع تمييز الحكم الجزائي السابق عن الدعوى الحالية |
| التجاري | طبيعة التعامل والتزامات الأطراف والإخلال والمستندات وحدود الطلب |
| العمل الأهلي | نظام علاقة العمل والقطاع؛ لا يحل محل الوظيفة العامة أو النظام الخاص |
| الأسرة والأحوال الشخصية | طبيعة الطلب والتمثيل والصفة، دون خلط الوصاية والحضانة والقوامة |
| الإيجارات | العلاقة الإيجارية والعين والأجرة والفترة والطلب المحدد |
| العقار والملكية | العين والحق وسنده والتصرف محل المنازعة؛ مستقل عن الإيجارات |
| التنفيذ ومنازعاته | السند وأطرافه وإجراء التنفيذ محل المنازعة، دون إعادة الفصل في أصل الحكم |

| المسار الفرعي للطلب | ضابط الصياغة |
| --- | --- |
| مطالبة مالية | المنشأ والمقدار وطريقة الحساب والوفاء والطلبات التابعة المأذونة |
| ندب خبير | مسألة فنية ومهمة محددة وصلتها بالطلب، دون افتراض حكم في أصل الحق |
| خبرة المسؤولية الطبية | الادعاء والفحص الفني والضرر والسببية من البيانات الفعلية؛ لا يشمل كل خبرة طبية في قضية جزائية |
| وصاية | التعيين أو الاستبدال والتمثيل وحدود الإدارة بحسب الطلب الفعلي |
| تكليف بالرعاية | المستفيد والمكلف والإجراء المطلوب؛ لا يحوّل إلى وصاية أو حضانة |
| طلب آخر في تخصص معلوم | الخطة المستندة إلى الوقائع والطلبات الفعلية، دون إضافة طلب من نموذج |

تتفرع الصيغ إلى صحيفة دعوى وصحيفة استئناف ومذكرة في إجراء قائم، مع تمييز المدعي والمدعى عليه والمتهم والشاكي والمستأنف والمستأنف ضده وصفات التمييز والتنفيذ. تعارض الصفة والصيغة يوقف الانتقال ويطلب توضيح الإجراء.

الصحف الجزائية الخاصة وصحيفة التمييز وطلبات التنفيذ الخاصة وإجراءات الجهات ذات النظام الخاص لا تستبدل بالقالب المدني. الحالة `template_review` تعني الحاجة لقالب معتمد مناسب، ولا تعني إنشاء ذلك القالب أو اعتماد قابلية الإجراء قانوناً.

لا يغير هذا الكتالوج المذكرات القديمة المحفوظة ولا يستورد المواد أو الأحكام أو الوقائع من النماذج المرفقة. المصادر القانونية الموثقة للقضية الجديدة وحدها تدخل التحقق.
