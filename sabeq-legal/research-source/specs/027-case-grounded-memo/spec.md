# Case-grounded memorandum quality
Authorized scope: improve existing Sabeq generator for any case, not copy one insurance defense.
Inputs remain allegations, not proven facts. No invented names, amounts, law, cases or procedural facts. No case data in repository/logs.
Acceptance: shared analysis rules in intake and drafting; structured party/issue/document/opposing-case/alternative-relief plan before drafting; each issue quotes an input fact and selects only retrieved markers; independent semantic audit after drafting; source verification unchanged; incomplete research explicitly outside pleading; audit rejection never archived. Insurance checks settlement scope/timing/payment/subrogation/repair valuation/responsibility without mandatory discount or solidarity. Criminal checks charge elements and evidence without assuming innocence facts.
Assumptions: current verified statute corpus remains incomplete; metadata and model audits do not prove current amendments or legal correctness. Missing evidence returns incomplete factual draft, not full legal defense. Uploaded documents must already be present in approved case input; no new file storage.

## Defense strength repair — 2026-11-07
Observed: the no-evidence route skips drafting and semantic audit. The memorandum renderer substitutes a stock reservation for empty grounds. An auditor can report every issue addressed without identifying any actual reasoning in the draft. Flattened retrieval fills the source budget with the first queries.

- D1: retrieve across the material issues, including payment scope, originals and expert-report disputes only when present in the approved facts. Preserve the bound-file and reviewed-judgment source boundary.
- D2: draft numbered, fact-specific grounds with the applicable source, application, strongest opposing argument and a reasoned response. Factual arguments remain possible without a legal source; unsupported legal propositions and automatic procedural objections remain prohibited.
- D3: audit every path, including no-source drafts. An addressed issue needs verbatim excerpts from the final grounds identifying a fact anchor, application, opposing argument, response and only its planned source markers. A false or generic audit cannot authorize archiving. Permit one bounded revision; preserve the existing citation gate.
- D4: empty grounds never become a generic defense in the exported memorandum. Missing research stays outside the body as incomplete quality status. Existing documents are not rewritten.
- D5: keep the current UI, payment, identity, admin memo linkage, templates and export formats. No dependencies, external legal research, new providers or data migrations.
- D6: record before/after regression results using synthetic cases, then publish the current backend and mirror only changed files to GitHub. Distinguish software checks from a live model result and legal review.
- D7: preserve actual legal reasoning during language cleanup after source decoration. A verb such as يقدم/يراجع/يتحقق is not a request to the visitor to supply law. Direct requests for legal authorities must still be removed, and literal source quotations must remain byte-for-byte unchanged.
