# التنفيذ

1. إضافة إعداد إداري مستقل إلى محقق كلمات المرور الحالي، دون تعديل أسرار حسابات التشغيل. قصر requireManager وpasswordManagerLogin على الإداريين، والتحقق الحي من منح الإدارة وإلغائها.
2. ترحيل إضافي لسياسات المستخدمين، مع حفظ صلاحيات الخدمات والدور. دعم CRUD والاستعادة بالاعتماد على public_users، دون حذف السجلات القانونية.
3. توسيع واجهة الإدارة بمكوّن مستقل لإدارة المستخدمين والصلاحيات والمحتوى والخدمات والحجوزات.
4. حفظ محتوى الموقع في الخزنة الحالية مع فصل البيانات العامة عن أسرار التكامل. مسار عام محدود للقراءة، وتطبيقه على واجهة React والنسخة المنشورة.
5. اختبارات مصادقة وتفويض وCRUD وصلاحيات خدمات ومحتوى، ثم البناء، إعداد بصمة الدخول عبر أسرار Sites، نشر الخادم وواجهة GitHub والتحقق الحي.

المخطط إضافي فقط، ولا تستبدل أسرار البيئة الحالية أو بيانات المستخدمين الموجودة. يمنع إدراج كلمة المرور الحقيقية أو بصمتها أو pepper في ملفات المشروع أو الاختبارات.
