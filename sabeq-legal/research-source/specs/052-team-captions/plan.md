# خطة التنفيذ

تعديل CSS الحالي فقط: قياسات مرتبطة بعرض البطاقة، تصغير الصفة والاسم واسم المجموعة، وتوحيد التباعد. حد أصغر مناسب للأسماء الإنجليزية الأطول، دون حذف أجزاء منها أو استخدام نقاط الاختصار. إزالة استثناء تكبير اسم البطاقة الأولى حتى يبقى الفريق متسقاً.

يُراجع خط المهند في النسخة الأصلية وخط Cairo المعتمد حالياً في GitHub Pages، مع الحفاظ على إضافات فهرس Pages. تشمل المعاينة أحجام الجوال والتابلت والكمبيوتر، ثم نشر المصدر الأصلي والحزمة العامة المطابقة له دون لمس مشاريع المستودع الأخرى.
