# إدارة مستخدمي سابق وبريد المكتب

## User stories
- US1 (P1): يتابع المدير حسابات مستخدمي الموقع ويبحث فيها ويعدل بيانات الاسم والهاتف وحدود الخدمات ويوقف الحساب أو يعيد تفعيله.
- US2 (P1): يهيئ المدير مزود صناديق البريد المستقلة، ويعرض حسابات نطاق المكتب وينشئ عناوين مثل info@sabeq.legal ويوقف حساب موظف أو يعيده بعد تأكيد صريح.
- US3 (P1): يستعمل لوحة عربية أوضح بخط جديد وقائمة قابلة للتمرير على الهاتف مع بقاء الشعار الرسمي وإخفاء بريد المدير أسفل القائمة.

## Functional Requirements
- FR-001: كل بيانات المستخدمين وعمليات البريد تستلزم جلسة إدارية معتمدة وتحقق المصدر من الخادم.
- FR-002: عرض المستخدمين مع بحث وحالة واستهلاك وحدود الخدمات وترقيم صفحات. الاسم والهاتف وحدود الاستخدام قابلة للتعديل؛ البريد وهوية التحقق لا يغيران من هذا النموذج.
- FR-003: تعليق مستخدم يلغي جلساته دون حذف سجلاته أو إظهار بياناته لزوار الموقع. التسجيل والتحقق من البريد يستمران عبر المسار القائم.
- FR-004: صناديق البريد مستقلة عن حسابات الموقع وعن عرض البريد الوارد. غياب الربط يظهر بوضوح ولا ينشئ صناديق وهمية.
- FR-005: موصل إدارة بريد مؤسسي يحفظ بيانات التفويض مشفرة، ويعرض بيانات حسابات نطاق المكتب فقط، وينشئ حساب عضو بكلمة مرور أولية تتغير عند أول دخول ولا تحفظ أو تعاد في الاستجابة.
- FR-006: إيقاف بريد الموظف وإعادته يتطلبان تأكيداً في الواجهة؛ لا يسمح بإيقاف حساب المدير أو أي حساب إدارة عند المزود. لا حذف حساب أو تغيير اشتراك أو DNS أو إرسال رسالة في هذه المهمة.
- FR-007: فشل المزود أو انتهاء التفويض أو نفاد المقاعد يظهر كفشل حقيقي، ولا تسجل نتيجة إنشاء ناجحة قبل تأكيد المزود. إنشاء الصندوق لا يثبت توجيه البريد إليه قبل تهيئة النطاق.
- FR-008: تحسين RTL والخط والقائمة والمقروئية على الجوال دون تغيير الدخول أو المذكرات أو التشريعات أو إعدادات واتساب.

## Acceptance and success
- SC-001: مجهول الهوية أو مصدر غير مسموح يفشل قبل أي استعلام حساب أو اتصال خارجي.
- SC-002: تحديث مستخدم اصطناعي يحفظ الحالة والحدود؛ التعليق يلغي جلسته وتظل سجلاته موجودة.
- SC-003: ربط اصطناعي للبريد ينعش التفويض ويسترجع الحسابات ويُنشئ عضواً واحداً بنطاق المكتب، مع رفض التكرار أو النطاق الآخر أو بيانات التفويض المكشوفة.
- SC-004: الحساب الإداري والمستخدم خارج نطاق المكتب لا يمكن إيقافهما عبر الموصل.
- SC-005: البناء والاختبارات المتعلقة وملفات الخط الحقيقية والنشر تتحقق، مع التصريح بحدود اختبار المتصفح والتفعيل الحي للمزود.

## Assumptions and boundaries
- المستخدم اختار صناديق مستقلة. موصل Zoho Mail قابل للتهيئة؛ لا توجد حالياً بيانات إدارة بريد موصولة. لا شراء خطة أو مقاعد.
- سجلات MX العامة التي فُحصت في 20 أكتوبر تشير إلى ImprovMX؛ لا تعد دليلاً على وجود عنوان info ولا يعدل التوجيه في هذه الميزة.
- إدارة المستخدمين تخص قاعدة الخدمة المستضافة. مصدر Render المتوقف يعرض كغير متاح؛ لا يدعى تعديل مستخدميه.
- طلب الخط الجديد يجيز تبديل خط لوحة الإدارة إلى IBM Plex Sans Arabic فقط. يبقى الشعار الرسمي وهوية التركواز والكحلي، ولا تغيير لخط المذكرات أو الموقع العام.
