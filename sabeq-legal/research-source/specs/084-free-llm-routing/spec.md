# مزودو النص القانوني — 8 نوفمبر 2026

## النطاق والافتراضات
طلب المستخدم تطبيق دليل awesome-freellm-apis على المساعد وكتابة المذكرات. الدليل مرجع اكتشاف؛ لا يُشغّل كودًا منه ولا يستورد مفاتيح أو إعدادات متغيرة تلقائيًا. يضاف دعم Groq وNVIDIA وOpenRouter إلى مسار النص الموجود مع Gemini وOpenAI. تبقى مصادر التشريعات المغلقة والتحقق القانوني والحفظ والدفع والهوية كما هي.

## قصص المستخدم ومعايير القبول
- P1: يستطيع الخادم اختيار مزود نص مهيأ صراحةً لكل مراحل المساعد والمذكرة، دون اشتراط مفتاح مزود آخر.
- P1: يحافظ النقل على الوقائع والتعليمات والمخطط، ويرفض نتيجة ناقصة أو مخالفة للمخطط قبل العرض والبث.
- P1: لا تنتقل ملفات أو معرّفات ملفات أو صوت إلى مزودي النص.
- P1: يحدث الرجوع لمزود ثانٍ مسمى ومهيأ مرة واحدة بعد رفض صريح 429/502/503/504 فقط، وليس بعد الإلغاء أو فشل شبكة مبهم أو رد مقبول/ناقص أو مصادقة مرفوضة. الاستدعاءات ذات محاولة واحدة لا تتجاوز ميزانيتها.
- P1: لا تتسرب المفاتيح أو الوقائع إلى الروابط والسجلات؛ الوجهات ثابتة، وإعادة التوجيه ممنوعة.
- P2: يوضح فحص الصحة المزود الأساسي والاحتياطي المهيأين، دون ادعاء نجاح طلب حي.

## حدود القبول
تُختبر عيّنات مصطنعة فقط. تهيئة دعم مزود لا تثبت وجود مفتاحه أو مجانيته أو جودة دفوعه. تظل أرقام المواد والنصوص والأحكام خاضعة للتحقق القائم ومراجعة المختص.
