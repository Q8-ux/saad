# Kuwait Fund homepage prototype

نموذج تفاعلي ثنائي اللغة لإعادة تصميم الصفحة الرئيسية للصندوق الكويتي للتنمية الاقتصادية العربية.

- العربية افتراضيًا مع دعم RTL كامل
- واجهة إنجليزية LTR
- خط المهند بأوزان Regular وBold وExtra Bold
- تصميم متجاوب للجوال والتابلت والديسكتوب
- قوائم وبحث وبطاقات تفاعلية ونموذج نشرة بريدية
- محتوى وإحصاءات مبنية على البيانات المحددة للمشروع دون إضافة مشاريع أو أرقام جديدة

## التشغيل

افتح `index.html` من خلال GitHub Pages. الملفات داخل هذا المجلد هي نسخة نشر ثابتة ومحسنة للويب.
