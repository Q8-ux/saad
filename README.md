# منصة العقود والترجمة القانونية

مصدر منصة قانونية عربية لإدارة المكاتب القانونية، والبحث في المصادر النظامية، وإدارة القضايا والموكلين والمذكرات.

## ما يتضمنه هذا المشروع

- تسجيل دخول باسم مستخدم وكلمة مرور مع جلسات آمنة.
- عزل بيانات المكاتب والصلاحيات.
- إدارة الموكلين والقضايا والجلسات والفواتير والمذكرات.
- فهرسة وبحث في الوثائق القانونية ومصادرها الرسمية.
- واجهة عربية متجاوبة للويب والجوال.

## التشغيل

يتطلب المشروع Node.js 22 أو أحدث وبيئة Cloudflare Workers مع قاعدة D1 مرتبطة بالاسم `DB`.

```bash
npm ci
npm run dev
```

لا تُحفظ كلمات المرور أو مفاتيح البيئة أو بيانات المكاتب في المستودع. اضبط المتغيرات السرية من بيئة الاستضافة فقط.

## قاعدة البيانات

ملفات بيانات المصادر القانونية وتاريخ الاستيراد ونتائج OCR غير مضمّنة هنا، لأن البيانات التشغيلية تحتاج مراجعة قانونية ومصدرًا رسميًا قبل النشر. يعتمد المشروع على `db/schema.ts` لتوليد migrations نظيفة لكل بيئة.

## النشر

لا يصلح GitHub Pages لتشغيل هذه المنصة كاملة، لأن تسجيل الدخول وقاعدة البيانات يحتاجان خادمًا وبيئة أسرار. استخدم GitHub لحفظ الكود والمراجعة، ثم انشره على بيئة Workers/D1 أو بنية خلفية مكافئة.
