# سياسة المصدر الواحد

النطاق المعتمد: ملف التشريعات الذي حدده المستخدم، والنسخ المشتقة منه فقط. المصدر مسجل في `bound-source.json` الخاص، والنسخة العامة تستخدم alias دون بيانات وصول.

- اجلب الملف المحدد نفسه من Drive، واحفظه مع بصمة SHA-256 وتاريخ التعديل والحجم وعدد الصفحات. لا تنفذ بحثاً في ملفات أخرى دون طلب.
- لا تستخدم مواقع وزارات أو جرائد رسمية أو موسوعات أو بحث ويب أو كشط مواقع أو معرفة النموذج لاستكمال النصوص.
- عند تحديث المستخدم للملف، استخرج نسخة جديدة مع سجل فروق؛ لا تحدث القاعدة من خارج الملف تلقائياً.
- احفظ النص الخام والمنطقي والأصل، وأرقام صفحات PDF والمطبوع، ومناطق الكتل، والصور والروابط والجداول المكتشفة.
- افصل اقتباس المصدر عن تصحيح استخراجي مقترح؛ لا تعدّل صياغة أو مبلغاً أو مدة أو رقم مادة دون إظهار الأصل.
- ميّز «آخر تعديل يذكره الغلاف» عن «تحقق مستقل من السريان». في النطاق الحالي لم يحصل تحقق قانوني خارجي، ولا يلزم لإتمام بناء قاعدة البحث الداخلية.
- إذا لم تجد المادة أو الحكم أو المعلومة فارجع بنقص معلن، دون جلب بديل خارجي.
- لا تنشر محتوى الملف أو معرّفه الخاص في GitHub لمجرد حفظ كود المسار هناك. احفظ القاعدة والنسخة الأصلية في مساحة الملفات الخاصة.
