# قاعدة مسار التشريعات

## الاسترجاع والاستيراد

استرجع معرّف SQLite المسجل في `bound-source.json` باستخدام مهارة Library، ثم ابحث محلياً. إذا احتجت الأصل والصور ونسخ JSONL فاسترجع حزمة المصدر المسجلة هناك. لا تعتمد مسار scratch بعد انتهاء الجلسة؛ معرّفات الملفات المحفوظة هي المرجع.

استورد PDF الرقمي بـ `scripts/import_compendium.py`. تنفذ الأداة Poppler لاستخراج نص منسّق بالاتجاه المنطقي، وPyMuPDF للاحتفاظ بالنص الخام وهندسة الصفحة والروابط والصور. لا تنفذ بحثاً خارجياً أو OCR تلقائياً ولا تدّعي اعتماداً قانونياً.

## جداول SQLite

| الجدول | المحتوى |
| --- | --- |
| `source_documents` | هوية الأصل والبصمة والبيانات الوصفية وحالة التحقق |
| `pdf_pages` و`pages_fts` | كل الصفحات كاملة والنص المنطقي والخام والترقيم والبحث |
| `compendium_documents` | الأقسام المستخرجة من فهرس المصدر أو تكرار العناوين |
| `text_blocks` | مواقع الكتل والأسطر والخطوط وإحداثيات النص |
| `pdf_links` | روابط المصدر الداخلية والخارجية كما وردت؛ لا تُفتح تلقائياً |
| `image_assets` و`image_occurrences` | بصمات الصور ومساراتها ومواقعها |
| `image_ocr` | طبقات OCR محلية مستقلة للصور الكبيرة مع الكلمات والثقة والإحداثيات؛ تحتاج مراجعة |
| `extracted_tables` | خلايا الجداول التي اكتشفها المحلل، بحالة تحتاج مراجعة |
| `article_fragments` | مواضع عناوين المواد ونصوص مقاطع الصفحة |
| `reference_mentions` | إشارات المواد مع سياقها، دون حل تخميني للهدف |
| `records` و`lookup` | سجلات الفهرس المتوافقة مع أداة الأدلة السابقة |
| `qa_findings` و`corpus_stats` | نواقص الجودة والتكرار والقياسات وحدود الاستخراج |

## قواعد الدقة

- عدد الأقسام لا يساوي عدد القوانين؛ قد تشمل لائحة أو جدولاً أو ملحقاً.
- عدد مواضع المواد لا يساوي عدد المواد الفريدة أو الكاملة. احتفظ بالمكرر لأنه قد يمثل مادة إصدار أو مادة من القانون المرافق أو تعديلاً مقتبساً.
- المقاطع لا تُدمج آلياً عبر الصفحات، ويجب قراءة سياق الصفحة التالية عند استمرار النص.
- النص الرقمي قد يحوي أخطاء خرائط الخطوط العربية؛ الأصل المرئي مرجع المراجعة. لا تصف النص المستخرج بأنه مصحح حرفياً دون فحص.
- اكتمال حفظ الصفحات لا يعني اكتمال تصنيف كل عنصر فيها. يحفظ الأصل والصور والكتل عناصر لم تتحول إلى حقول مستقلة.
- البحث الداخلي يرجع ما في الملف مع `current_law_verified=false`. لا تشغّل بوابة الاعتماد القانوني القديمة كشرط لعرض محتويات المصدر؛ تستخدم فقط إذا طُلب اعتماد مستقل لاحقاً مع تفويض واضح.

## قراءة الصور محلياً

استخدم `scripts/ocr_compendium_images.py` مع Tesseract ونماذج `ara+eng` المثبتة محلياً. لا ينزل السكربت بيانات ولا يتصل بالشبكة. احفظ النص وTSV ودرجة ثقة المحرك منفصلة عن النص الرقمي وبحالة `needs_review`، وأضفها لفهرس الصفحة. أعد طبقة OCR للمستخدم عند وجودها، ولا تعتبر نتيجة بحث سلبية في النص الرقمي وحده دليلاً على غياب معلومة داخل صورة.

تستخدم أداة البحث بدائل محدودة لأزواج حروف شوهدت معكوسة في خرائط خطوط PDF عند فشل المطابقة الحرفية. تظهر `match_mode=pdf_glyph_search_variants` والبدائل المستخدمة؛ لا يتغير النص الأصلي أو تُصحح كلمة قانونية تلقائياً.
