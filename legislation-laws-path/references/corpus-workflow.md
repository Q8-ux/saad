# قاعدة مسار التشريعات

## الاسترجاع والاستيراد

استرجع معرّف SQLite المسجل في `bound-source.json` باستخدام مهارة Library، ثم ابحث محلياً. إذا احتجت الأصل والصور ونسخ JSONL فاسترجع حزمة المصدر المسجلة هناك. لا تعتمد مسار scratch بعد انتهاء الجلسة؛ معرّفات الملفات المحفوظة هي المرجع.

استورد PDF الرقمي بـ `scripts/import_compendium.py`. تنفذ الأداة Poppler لاستخراج نص منسّق بالاتجاه المنطقي، وPyMuPDF للاحتفاظ بالنص الخام وهندسة الصفحة والروابط والصور. لا تنفذ بحثاً خارجياً أو OCR تلقائياً ولا تدّعي اعتماداً قانونياً.

## جداول SQLite

| الجدول | المحتوى |
| --- | --- |
| `source_documents` | هوية الأصل والبصمة والبيانات الوصفية وحالة التحقق |
| `pdf_pages` و`pages_fts` | كل الصفحات كاملة والنص المنطقي والخام والترقيم؛ فهرس النص الرقمي والتفريغ المرئي المدقق فقط |
| `compendium_documents` | الأقسام المستخرجة من فهرس المصدر أو تكرار العناوين |
| `text_blocks` | مواقع الكتل والأسطر والخطوط وإحداثيات النص |
| `pdf_links` | روابط المصدر الداخلية والخارجية كما وردت؛ لا تُفتح تلقائياً |
| `image_assets` و`image_occurrences` | بصمات الصور ومساراتها ومواقعها |
| `image_ocr` | طبقات OCR محلية مستقلة للصور الكبيرة مع الكلمات والثقة والإحداثيات؛ تحتاج مراجعة |
| `extracted_tables` | خلايا الجداول التي اكتشفها المحلل، بحالة تحتاج مراجعة |
| `article_fragments` | مواضع عناوين المواد ونصوص مقاطع الصفحة |
| `source_lines` | أسطر المصدر وإزاحاتها ونوعها وهندستها؛ المتن والحاشية والمذكرة والتوقيع منفصلة |
| `heading_overrides` و`inline_annotations` | مراجعة عناوين مدمجة أو ناقصة الحروف، مع حدود العنوان والحاشية في السطر نفسه |
| `article_range_notices` | إشعارات الملف عن نطاقات أرقام مواد؛ لا تعني تحققاً خارجياً من الإلغاء |
| `page_subsections` | جداول الملحق التابعة للائحة، مستقلة عن آخر مادة |
| `source_issues` | انقطاع أو فجوة ترقيم أو تكرار ظاهر في الأصل، مربوط بصفحات الدليل |
| `article_units` و`article_segments` | تجميع المواد عبر الصفحات مع أجزاء مطابقة للنص الأصلي وبصماتها وحدودها |
| `article_annotations` و`commentary_headings` | سياق الصفحة والعناوين التفسيرية خارج متن المادة |
| `heading_candidate_reviews` و`quoted_provisions` | مراجعة الأسطر الملتبسة والفقرات المعدلة المقتبسة |
| `image_ocr_alternatives` و`image_table_cells` | قراءتا العربية والإنجليزية وإحداثيات الخلايا المحتملة؛ جميعها تحتاج مراجعة |
| `image_transcriptions` | تفريغ الصورة والخلايا المطابق بصرياً، مربوط ببصمتي الأصل والصورة |
| `ocr_candidates_fts` | فهرس منفصل لاقتراح مواضع داخل الصور؛ غير مؤهل للاقتباس الآلي |
| `reference_mentions` | إشارات المواد مع سياقها، دون حل تخميني للهدف |
| `records` و`lookup` | سجلات الفهرس المتوافقة مع أداة الأدلة السابقة |
| `qa_findings` و`corpus_stats` | نواقص الجودة والتكرار والقياسات وحدود الاستخراج |

## قواعد الدقة

- عدد الأقسام لا يساوي عدد القوانين؛ قد تشمل لائحة أو جدولاً أو ملحقاً.
- عدد مواضع المواد لا يساوي عدد المواد الفريدة أو الكاملة. احتفظ بالمكرر لأنه قد يمثل مادة إصدار أو مادة من القانون المرافق أو تعديلاً مقتبساً.
- يجمع `refine_compendium.py` استمرار المتن حتى العنوان التالي أو التوقيع أو حد القسم، ويستبعد الحواشي والمذكرات والملاحة. كل جزء قابل للمطابقة مع إزاحات الصفحة وبصمتها. تبقى الحدود المستنتجة مختلفة عن مراجعتها بصرياً.
- `complete_article_verified=true` يتطلب مراجعة الحدود والمحارف صراحة. لا تنقل اعتماد الاستخراج إلى اعتماد السريان القانوني.
- لا تنسب حاشية لمادة بعينها اعتماداً على موضعها أسفل الصفحة وحده؛ تعرضها الأداة كسياق صفحة.
- بعض عناوين المصدر مدمج في سطر المتن، أو في صف الحاشية، أو مطبوع دون أول حرف. طبّق تجاوزاً صريحاً بعد فحص الصورة، واحتفظ بصيغة العنوان كما طبعت وبإزاحاته. لا توسّع محلل العناوين ليقبل كل جملة تبدأ بإحالة إلى مادة.
- افصل إشعارات نطاقات المواد والجداول الملحقة عن المادة السابقة. يجيب الاسترجاع عن رقم داخل نطاق ملغى بإشعار المصدر وصفحته؛ لا يختلق نص المادة المفقود.
- لا يمكن إصلاح انقطاع موجود في ملف المصدر بإعادة الاستخراج. تعرض `source_issues` موضعه ويعود `answer_status=source_incomplete` أو `source_gap`؛ لا تعامل هذه الحالات كغياب عادي ولا كنص كامل.
- النص الرقمي قد يحوي أخطاء خرائط الخطوط العربية؛ الأصل المرئي مرجع المراجعة. لا تصف النص المستخرج بأنه مصحح حرفياً دون فحص.
- اكتمال حفظ الصفحات لا يعني اكتمال تصنيف كل عنصر فيها. يحفظ الأصل والصور والكتل عناصر لم تتحول إلى حقول مستقلة.
- البحث الداخلي يرجع ما في الملف مع `current_law_verified=false`. لا تشغّل بوابة الاعتماد القانوني القديمة كشرط لعرض محتويات المصدر؛ تستخدم فقط إذا طُلب اعتماد مستقل لاحقاً مع تفويض واضح.

## قراءة الصور محلياً

استخدم `scripts/ocr_compendium_images.py` مع Tesseract ونماذج `ara+eng` المحلية. لا ينزل السكربت بيانات ولا يتصل بالشبكة. احفظ النص وTSV والثقة مستقلة عن النص الرقمي وبحالة `needs_review`؛ يُبحث فيها عبر `ocr_candidates_fts` فقط.

للجداول المصورة، استخدم `scripts/structure_image_tables.py --db DATABASE --data-dir DATA_DIR --tessdata-dir MODELS --first-page FIRST --last-page LAST`. يحتفظ بقراءتين مستقلتين ومرشحات خلايا تستند إلى خطوط الجدول؛ قد يكون اكتشاف الشبكة جزئياً. لا تصف مرشحات الخلايا بأنها جدول مكتمل مدقق.

بعد معاينة صورة فعلية، اكتب تفريغها في ملف مراجعة خاص وطبّقه بـ `review_image_layers.py --db DATABASE --reviews REVIEWS_JSON`. يطابق السكربت بصمتي الأصل والصورة ويبني فهرس الإجابة من النص الرقمي والتفريغ المدقق وحدهما. لا تعتمد الصورة بسبب ثقة المحرك أو اتفاق قراءتين. احفظ الشرطات كقيمة غير رقمية، ولا تحولها صفراً.

يعيد البحث تطابقات الصور غير المدققة في `unreviewed_ocr_candidates` مع `answer_eligible=false`. حالة `needs_image_review` ليست دليلاً على الغياب؛ افتح صورة المصدر قبل جواب يتطلب رقماً أو رمزاً دقيقاً.

تستخدم أداة البحث اتحاد المطابقات الحرفية وبدائل محدودة لأزواج حروف شوهدت معكوسة في خرائط خطوط PDF، حتى مع وجود تطابق حرفي. تعرض نمط كل نتيجة، و`total_match_count` و`exact_match_count` و`glyph_variant_match_count` قبل الحد العددي للعرض. لا يتغير النص الأصلي ولا تصحح كلمة قانونية تلقائياً. يطبّق البحث في أسماء الأقسام بدائل الخطوط أيضاً.
