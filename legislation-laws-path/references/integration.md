# عقد ربط مسار التشريعات بسابق

المرحلة الحالية: قاعدة مشتقة من ملف المستخدم ووحدة بحث جاهزة للتركيب لاحقاً. لم يُعدّل مشروع سابق في هذه المرحلة.

## الوظائف

- قارئ الوثيقة: الأصل والصفحات والفهرس والكتل والصور.
- محلل الأقسام والمواد: عناوين التشريعات واللوائح والملاحق وأرقام المواد وإحالاتها.
- فهرس محلي: SQLite FTS5 وفلاتر القسم والمادة والصفحة.
- مراجع الجودة: اكتمال الصفحات والبصمات وحدود الاستخراج والمكرر والمفقود.
- بوابة السياق: استرجاع الصفحة الكاملة وما يلزم من استمرار المادة قبل صياغة جواب.

تجري كل هذه الوظائف داخل الملف وقاعدته، دون بحث قانوني خارجي أو نموذج مطلوب لاستخراج البيانات.

## عقد استدعاء مقترح

```json
{"query":"المسألة أو الكلمة","document_id":null,"component_id":null,"article_number":null,"pdf_page":null,"source_scope":"bound_file_only"}
```

أعِد النص ومعرّف المصدر وبصمته وعنوان القسم ورقم المادة ومكوّنها وصفحات البداية والنهاية وأجزاء المصدر بإزاحاتها. احترم أعلام `boundary_review` و`transcription_verified` و`complete_article_verified`، وأبقِ `current_law_verified=false` لكل نتيجة في النطاق الحالي. عند تكرر الرقم بين مواد الإصدار والقانون المرافق، أعِد الخيارات واطلب/طبّق `component_id`.

أبقِ مرشحات OCR غير المدققة منفصلة عن حزمة الاقتباس. لا يمرر مولد المذكرات `unreviewed_ocr_candidates` كنص معتمد؛ يطلب معاينة الصورة أو يستخدم التفريغ المرئي المدقق إن وجد. لا تملأ مدة مفقودة بصفر لمجرد وجود شرطات في المصدر.

عند ربط المساعد ومولد المذكرات لاحقاً، مرّر حزمة النص والصفحة والسياق، وافصل الاقتباس عن الاستنتاج. إذا لم توجد إجابة في القاعدة فاذكر الغياب؛ لا تستخدم البحث الخارجي كبديل تلقائي. لا تعتمد رقم مادة بلا تحديد القانون عند تعدد الاحتمالات.

## متطلبات التركيب اللاحق

افحص نسخة سابق الفعلية وإرشاداتها وBackend الآمن، ثم أضف استدعاء قراءة فقط للفهرس مع صلاحيات المشروع. خزّن ملف SQLite والأصل في مساحة خاصة للخادم؛ واجهة GitHub Pages تستدعي الخدمة ولا تحتوي القاعدة أو الأسرار.

اختبر: استعلام معلوم، واستعلام غائب، وأرقام عربية، وتحديد قسم، واستمرار مادة، ثم سؤال المساعد ومخرجات المذكرة بالإحالة الصحيحة. سجّل حالات بناء القاعدة وربط الخادم وربط المساعد وربط المذكرة واختبار الإنتاج منفصلة.
