# ربط المشاريع وبسابق

هذه مواصفة تركيب وأداة محلية مرجعية، وليست إعلاناً عن API منشور أو ربط قائم. افحص المستودع الحالي وإرشاداته ونسخة الإنتاج قبل التعديل.

| الجزء | المسؤولية |
| --- | --- |
| مكتبة التشريعات | المصادر والاستخراج والمراجعة والإصدارات والبحث |
| المساعد القانوني | الوقائع والمسائل والتاريخ واستدعاء البحث وشرح نقص الأدلة |
| مولد المذكرات | استهلاك الأدلة المعتمدة وبناء الحجة ومراجعة الإحالات |
| Backend | الصلاحيات والرفع والتخزين والاستخراج والأسرار |
| واجهة الموقع | النص والمصدر والصفحة وتاريخ التحقق وحالة النقص |

أبقِ العربية RTL والخطوط كبيرة حسب تصميم المشروع. لا تضف هاتفاً أو دخولاً لمولد سابق لمجرد تركيب المسار. لا تكرر شاشة بحث موجودة.

## عقد خدمة مقترح

طابق العقد مع API المشروع الحقيقي، ولا تصف الأسماء التالية بأنها مجربة:

```json
{"question":"السؤال","jurisdiction":"KW","facts_date":"YYYY-MM-DD","procedure_date":null,"document_id":null,"article_number":null}
```

اشتق صلاحيات المصادر من الجلسة في الخادم. أعد حزمة `evidence[]` مع هويات الإصدارات والنص والمصدر والصفحة والفترة والتحقق، و`missing_information[]` و`conflicts[]`. اجعل `ready_for_draft=false` عند نقص تاريخ مؤثر أو دليل أو وجود تعارض غير محلول. لا يثبت العثور على نتيجة واحدة اكتمال المسألة.

## بوابة المذكرة

1. استخرج المسائل ثم ابحث لكل منها.
2. تحقّق من المصدر والزمن واحجب غير المؤهل.
3. افحص الانطباق والاستثناءات والاختصاص والانتقال الزمني وأقوى دفع مقابل.
4. مرّر حزمة بهويات ثابتة؛ لا تطلب من النموذج استكمال مواد مجهولة.
5. طابق كل إحالة واقتباس؛ أبقِ المذكرة مسودة معلنة النقص إذا بقيت إحالة غير مسندة.

لا تنقل مستندات خاصة إلى أدوات عامة دون التفويض المناسب. لا تضع مفتاح Drive أو وثائق القضايا أو قاعدة النصوص في GitHub. المصدر المرتبط محفوظ بإعدادات المهارة الخاصة؛ نسخة GitHub العامة تستخدم alias وإعداداً فارغاً دون نشر معرّف ملف المستخدم.

## اختبار الربط الفعلي

افحص رفع ملف والوصول المقيد وصفحة المادة ورقمها؛ قبل التعديل وبعده؛ مادة غير موجودة؛ عدم التكرار؛ عزل المستخدمين؛ ثم سؤال المساعد ومذكرة مع إحالات مطابقة. استخدم بيانات معزولة ثم عينة فعلية مأذوناً بها.

أبلغ حالات `skill_saved`, `source_accessible`, `corpus_imported`, `backend_connected`, `assistant_verified`, `memo_verified`, `production_verified` منفصلة. لا تعتبر SQL أو واجهة ساكنة دليلاً على قاعدة عاملة.
