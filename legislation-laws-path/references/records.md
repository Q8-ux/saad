# عقد سجلات البحث

في «مسار التشريعات» الحالي، استخدم `corpus_query.py` لعرض محتويات الملف دون اشتراط اعتماد خارجي. حقول الأهلية أدناه تخص أداة الاعتماد القديمة `legal_index.py` ولا تمنع البحث الداخلي أو تلزم بجلب مصادر خارجية. تبقى سجلات المصدر بحالة تحتاج مراجعة، ويُصرّح بحدودها في النتيجة.

استخدم UTF-8 JSONL: كائن واحد لكل سطر، ومادة بإصدار محدد أو حكم في كل كائن. الأداة لا تستخرج الحقول من PDF ولا تصادق على قرار المراجع.

| الحقل | القاعدة |
| --- | --- |
| `id` | هوية فريدة ثابتة للإصدار؛ لا تعِد استخدامها لنص مختلف |
| `jurisdiction` | رمز الدولة مثل `KW` |
| `kind` | `article` أو `case` |
| `document_id` | هوية القانون أو وثيقة الحكم |
| `title` | الاسم ورقم القانون وسنته، أو عنوان الحكم |
| `number` | رقم المادة مع لاحقتها، أو هوية الطعن كاملة |
| `text` | النص الأصلي الكامل دون تطبيع أو استكمال |
| `text_sha256` | SHA-256 لبايتات النص UTF-8 |
| `source_url` | رابط HTTPS دقيق، أو مرجع داخلي `private://` |
| `source_locator` | الصفحة/الفقرة/العدد مع تمييز صفحة PDF والمطبوع |
| `source_sha256` | بصمة ملف المصدر، مطلوبة للاعتماد |
| `provenance` | `official` أو `user_document` أو `licensed_secondary` |
| `verification_status` | `verified` أو `unverified` أو `needs_review` |
| `verified_by` | مراجع موثوق؛ لا يقبل من الزائر |
| `verified_at` | تاريخ آخر تحقق فعلي `YYYY-MM-DD` |
| `temporal_status` | `verified` أو `unknown` |
| `checked_through` | آخر تاريخ غطته مراجعة التعديلات/وضع الحكم؛ لا يتجاوز التحقق |
| `temporal_evidence` | مرجع سند النفاذ والتعديلات أو مراجعة الأحكام اللاحقة |
| `valid_from` و`valid_to` | فترة إصدار المادة؛ النهاية أول يوم لا يسري فيه، أو `null` بعد مراجعتها |
| `decision_date` و`court` و`chamber` | تاريخ الحكم والمحكمة والدائرة |
| `fixture` | `true` للمثال الاصطناعي؛ يمنع استخدامه دليلاً |

أضف بيانات الجريدة ونوع التشريع واللغة وعلاقة التعديل والمرفقات عند توفرها. احتفظ بعلاقة الحكم بالمادة وسبب الربط ومراجعه؛ تشابه الكلمات لا يثبت الانطباق.

## أهلية الدليل

تشترط الأداة اعتماد النص والزمن، ومصدراً رسمياً وبصمته، ومراجعاً وتاريخاً، وتغطية التحقق حتى تاريخ البحث، ووقوع التاريخ داخل فترة المادة، وعدم وسم السجل كمثال. للحكم تشترط بيانات المحكمة والجلسة وعدم صدوره بعد تاريخ البحث. تبقى مراجعة صلته بالوقائع وقوته واجبة خارج الأداة.

تحجب المصادر الثانوية وملفات المستخدم افتراضياً حتى ترتبط بنسخة رسمية محققة بسجل مستقل. وسم `official` وحده لا يثبت الأصالة: تتولى خدمة إدخال موثوقة مطابقة الوثيقة، ولا تسمح للنموذج أو المستخدم العام بتعديل حقول الاعتماد.

تعالج الفترة `[valid_from, valid_to)`، ولا يستبدل تاريخ الواقعة باليوم. افحص الأحكام الانتقالية والاستثناءات خارج الفحص الزمني البسيط. تحجب الأداة الإصدارين المتداخلين للمادة نفسها حتى تسوية التعارض.

## أوامر الأداة

- `validate FILE`: افحص الحقول والبصمات والتواريخ والتكرار دون تعديل.
- `ingest FILE --db PATH`: أضف في معاملة واحدة؛ التكرار المطابق لا يكرر السجل، وتغيير الهوية نفسها يُرفض. استخدم قاعدة جديدة أو نسخة سجل جديدة موصولة بالأصل عند مراجعة البيانات، ثم استبعد النسخة المتقادمة من الفهرس المعتمد.
- `search QUERY --db PATH --jurisdiction KW --as-of DATE`: بحث كلمات FTS5؛ لا بحث دلالي أو ضمان استيعاب كل المواد ذات الصلة.
- `--number '١ مكرر' --document-id ID`: بحث هوية المادة مع تطبيع الأرقام والحركات لأغراض المطابقة فقط.
- `--kind article|case`: فلتر نوع الدليل.
- `--include-review`: يعيد المحجوب وأسبابه للتدقيق الداخلي فقط.

تتضمن النتيجة `record` و`evidence_eligible` و`blocking_reasons` و`as_of`. خزّن قاعدة SQLite خارج Git ولا تعرضها عبر GitHub Pages. لا تحفظ أسئلة القضايا في سجلات عامة.
