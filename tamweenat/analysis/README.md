# مسار التحليل — تموينات

هذا الربط يخصص الوحدة المشتركة `/masar-analysis` لمشروع تموينات.

## الاستخدام
- مراقبة أسعار الموردين والمنافسين.
- اكتشاف مواد ومنتجات جديدة.
- تحليل احتياجات مطاعم البرجر.
- تحليل احتياجات مطاعم الطبخ الكويتي.
- كشف النواقص في الكتالوج والتصنيفات.

## ضابط الاعتماد
المسار **اقتراحي فقط**: لا يغير سعرًا، ولا يضيف منتجًا للبيع، ولا يحذف منتجًا تلقائيًا. كل نتيجة يجب أن تصل إلى مراجعة الأدمن مع المصدر قبل اعتمادها.

## التشغيل الخلفي
الخدمة المشتركة موجودة في `/masar-analysis` وتحتاج خادمًا دائمًا؛ GitHub Pages وحده لا يشغل Python/Agent-Reach/Scrapling/Patchright.

أنشئ إعداد مشروع مستقل باسم `tamweenat` ومفتاحًا خاصًا به على خادم مسار التحليل، ثم اربط Backend تموينات بمتغيري البيئة:
`MASAR_API_URL`
`MASAR_API_KEY`

لا تضع المفتاح داخل GitHub Pages أو JavaScript العام.
