# روافد الكويت

واجهة النشاط المدرسي للسوق الكويتي، مستندة إلى ملف المستخدم الأصلي ومربوطة بفهرس المناهج الرسمي.

الموقع: https://q8-ux.github.io/saad/sinad-kuwait/

المصدر الرسمي: https://elibrary.moe.edu.kw/StudentsLibrary

## التشغيل
افتح الموقع المنشور. سجلات المدرسة تبقى داخل جهازك؛ لا يوجد Backend تجاري متعدد المستخدمين في هذه النسخة.

## تحديث قاعدة المناهج
`python sinad-kuwait/scripts/sync_moe.py`

تستخدم نفس واجهات Lookup وlibrarysearch التي استُخرجت من JavaScript الوزارة. لا تعني أنها API عامة موثقة أو مضمونة الاستقرار. الفهرس لا يعيد نشر ملفات الكتب ولا بيانات المستخدمين. تتم فهرسة البيانات الوصفية والروابط فقط.

## استخراج صفحات الكتاب
`pip install -r sinad-kuwait/requirements.txt`

`python sinad-kuwait/scripts/extract_books.py book-1315`

النصوص الممسوحة تحتاج OCR. افحص ترتيب الحروف العربية قبل استخدامها. لا تُنسب الاقتراحات إلى المصدر عندما لا توجد مقاطع موثقة. يبدأ corpus بملخص مراجع بصريًا لمقدمة كتاب التطوع (صفحة PDF رقم 8، والمطبوعة 7). يتوسع بالكتب المطلوبة؛ المقاطع الآلية reviewed=false ولا يستشهد بها المساعد قبل المراجعة.

للاستخراج من الصفحات المصورة: ثبّت Tesseract ولغة ara، ثم مرّر --ocr. فشل خط العربية في عينة PDF؛ نجح OCR للعينة وتمت المقارنة بصريًا.

## MarkItDown
`python sinad-kuwait/scripts/convert_document.py local-reference.docx output.md`

الموصل يعمل محليًا ولا يفترض وجود خدمة API منشورة. لا تنشر مستندات المدرسة الخاصة أو مخرجاتها في المستودع العام.

## حدود التحقق
تم فحص JavaScript وبيانات المصدر والمزامنة واستخراج عينة. لم يتوفر تحكم متصفح لهذه الجلسة؛ يلزم اختبار عرض الهاتف وخط القاهرة والطباعة والصوت على جهاز المستخدم. PDF يُنشأ من حوار طباعة المتصفح وليس محرك PDF خلفي.
