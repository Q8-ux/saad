# مسار الوكلاء لسابق

تطبيق حقيقي للمكتبات الثلاث: `StateGraph` لتنظيم الدورة، `PydanticAI.Agent` للمخرجات المنظمة والمحاولات المحدودة، و`cognee.add/cognify/search` للمعرفة العامة المعتمدة.

## دورة الطلب

خادم سابق الحالي يتحقق من الزائر وحدود الخدمة، يحوّل البيانات حسب سلوك اللغة الحالي، يقرأ القالب المعتمد من D1/R2 ويسترجع المصادر الموثقة. يرسل المحتوى إلى العامل عبر اتصال محمي من خادم إلى خادم. العامل ينفذ `validate → knowledge → draft → audit`. ثم يبني خادم سابق المستند بنفس القالب ويحتفظ بروابط المصادر.

لا يُستخدم خادم Node القديم بديلاً عن صلاحيات خادم سابق. endpoint الجديد `/internal/sabeq-agents/memo` لا يقبل طلبات المتصفح، ويحتاج سراً عشوائياً من 32 حرفاً على الأقل. لا تضع السر في JavaScript الواجهة أو GitHub أو السجلات.

الحالة مؤقتة لكل طلب؛ لا توجد استعادة دائمة أو تنفيذ في الخلفية. نسخة الخدمة تعالج صياغة واحدة في كل لحظة؛ الازدحام يعيد `agent_busy`. المهلة توقف العامل ولا تعيد الطلب المدفوع تلقائياً. النموذج مسموح له بثلاث محاولات تصحيح وبحد إجمالي 24,000 رمز مخرجات.

## المعرفة

يصدر خادم سابق المعرفة من `/api/admin/agent-knowledge?after=0` باستخدام صلاحية الإدارة الحالية. التصدير يشمل القوالب الفارغة المعتمدة والمقتطفات العامة الموثقة من وزارة العدل فقط، مع المعرف وبصمة النص. لا يقرأ أرشيف القضايا أو سجلات خدمة العملاء.

يستوعب كل طلب تصدير 100 مقتطف؛ اتبع `nextAfter` حتى يصبح `null`. احفظ مصفوفة `items` من كل صفحة في ملف مؤقت آمن داخل الخادم وشغّل:

```sh
cd /app/agents
/opt/sabeq-agents/bin/python -m sabeq_agents.ingest approved-public-export.json
```

التشغيل يحتاج `OPENAI_API_KEY` ويستهلك استدعاءات للنموذج والتضمين. لا تُفهرس ملفات القضايا بهذا الأمر. البيانات ذات `visibility=private_case` والحقول الإضافية وبصمات النص الخاطئة مرفوضة. يعيد الاستيراد فهرسة النصوص المتغيرة فقط، ولا يضع علامة جاهزية قبل نجاح Cognee. يقبل القالب الفارغ وصفه وتعليماته فقط، دون شعار base64 أو بيانات عميل.

بحث Cognee يستخدم أسماء المراجع العامة فقط؛ لا يرسل وقائع العملاء أو محادثاتهم إلى ذاكرة البحث المشتركة. يعيد ترتيب المصادر التي أقرها خادم سابق، مع مطابقة المعرف والبصمة واحتواء المقتطف في الأصل المفهرس. يتجاهل نتائج المعرفة المجهولة أو القديمة؛ لا تتحول إجابات الرسم المعرفي إلى أحكام أو نصوص قانونية جديدة.

## إعداد النشر

داخل خدمة Render القائمة:

```text
SABEQ_AGENT_BRIDGE_TOKEN=<random-secret>
SABEQ_COGNEE_ROOT=/var/data/sabeq-knowledge
SABEQ_AGENT_PYTHON=/opt/sabeq-agents/bin/python
OPENAI_API_KEY=<existing-server-secret>
OPENAI_MODEL=<approved-model>
```

داخل خادم سابق الحالي، بعد نجاح فهرسة المعرفة وفحص `/internal/sabeq-agents/status`:

```text
SABEQ_AGENT_ENABLED=true
SABEQ_AGENT_URL=https://<existing-render-host>/internal/sabeq-agents/memo
SABEQ_AGENT_BRIDGE_TOKEN=<same-random-secret>
```

العنوان يجب أن يكون HTTPS دون بيانات اعتماد أو إعادة توجيه. تغيير `SABEQ_AGENT_ENABLED` إلى `false` يعيد مسار الصياغة الحالي. عند التفعيل، الفشل لا يتجاوز تدقيق العامل بصمت.

موصل Cloudflare وتصدير المعرفة والمواصفات والاختبارات محفوظة في `sabeq-legal/deployment/agent-pipeline/cloudflare/` كنسخة مطابقة لملفات المصدر الأصلية. ليست هذه الواجهة إعادة توجيه المتصفح إلى Render.

## التحقق والحدود

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt pytest==9.1.1
.venv/bin/python -m pytest -q tests
cd ..
SABEQ_TEST_PYTHON="$PWD/agents/.venv/bin/python" npm test
```

اختبارات Python تشغل LangGraph وPydanticAI الفعليين بنموذج محلي مضبوط؛ اختبارات Cognee تتحقق من العقد والعزل بأجوبة مضبوطة دون استدعاء مدفوع. اختبار Node يشغل عامل Python الحقيقي ويثبت أن غياب المصادر لا يستدعي النموذج. لم تُختبر فهرسة Cognee أو صياغة قانونية بمفتاح إنتاج في هذه المرحلة.

التدقيق يرفض الاستشهاد المجهول وأرقام المواد/القوانين/الطعون غير المدعومة والحقول المختلقة وبعض تسريبات المراجعة. مطابقة الأرقام لا تثبت صحة التفسير القانوني أو سلامة OCR أو استمرار سريان التشريع. مراجعة المجموعة تبقى لازمة قبل اعتماد المستند.

لا يُدّعى تفعيل الإنتاج قبل نشر العامل، فهرسة المعرفة، إعداد أسرار الطرفين واختبار طلب منشور. سجل التحقق الحالي في `sabeq-legal/deployment/agent-pipeline/cloudflare/specs/019-agent-pipeline/validation.md`.
