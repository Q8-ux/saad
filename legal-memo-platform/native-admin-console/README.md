# لوحة تحكم مجموعة سابق القانونية

نظام إداري مستقل عن الموقع العام لإدارة:

- المستخدمين وحدود استخدام الخدمات.
- المذكرات والأسئلة وتحليلات المستندات المحفوظة.
- أدوات الذكاء الاصطناعي الداخلية وأرشيف نتائجها.
- المواعيد وطلبات الاستشارة.
- تفعيل الخدمات ومتطلبات الدفع والأسعار.
- الموظفين والأدوار والصلاحيات.
- سجل تدقيق للإجراءات الإدارية الحساسة.

## التشغيل المحلي

```bash
npm install
npm run dev
```

## متغيرات الخادم

- `ADMIN_AUTH_SECRET`: مفتاح سري طويل لتجزئة الرموز والجلسات.
- `ADMIN_OWNER_EMAIL`: البريد الأول المصرح له بإنشاء حساب مالك النظام.
- `ADMIN_SERVICE_TOKEN`: مفتاح الربط الخادمي بالموقع العام.
- `PUBLIC_SERVICE_ORIGIN`: عنوان خدمة الموقع العام الداخلي، ولا يُعرض للمستخدمين.

## قاعدة البيانات

```bash
npm run db:generate
```

تُحفظ بيانات الموظفين والجلسات والأرشيف وسجل التدقيق في قاعدة بيانات لوحة التحكم المستقلة.
