# الخطة
1. توحيد تجهيز بيانات المسودة في دالة مشتركة وواجهة prepare-memo قبل الدفع، مع الاستخلاص من السياق وحماية التصحيحات اليدوية.
2. السماح بمسودة متحفظة من البيانات المتاحة؛ تبقى النواقص خارج متن الوقائع، وتمنع الأسانيد المختلقة. لا تُعامل المسودة كاعتماد قانوني.
3. إصلاح حالات الاتصال والمخرجات غير الصالحة للدفع وإضافة تشخيص منقح؛ إبقاء المحاولة واستحقاقها ثابتين.
4. إضافة سجل مسارات وفحص اتصال إداري محمي، وتثبيت تعليمات Spec Kit ومسارات العمل المناسبة في مصدر اللوحة.
5. تشغيل اختبارات التكامل والواجهة، وبناء الخلفية ونسخة GitHub، ونشرهما والتحقق من النسخ المنشورة.
