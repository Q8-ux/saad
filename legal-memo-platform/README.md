# دُفوع — منصة توليد المذكرات القانونية

نسخة تشغيلية مستقلة تشمل تسجيل المستخدمين، عزل ملفات كل مستخدم، قاعدة SQLite، رفع مستندات القضايا، وتوليد مسودات المذكرات عبر OpenAI.

## تشغيل محلي

1. انسخ `.env.example` إلى `.env.local` وأدخل الإعدادات السرية محلياً فقط.
2. نفّذ `npm install` ثم `npm start`.
3. افتح `http://localhost:3000`.

## النشر

الملف `render.yaml` يجهز خدمة Docker وقرصاً دائماً بسعة 5GB. أضف `OPENAI_API_KEY` كمتغير سري في Render. لا تضع المفتاح في GitHub.

## حدود النسخة الأولى

- أسماء المرفقات تدخل في سياق التوليد؛ تحليل محتوى PDF وWord نفسه يحتاج مرحلة استخراج نص وفهرسة قانونية لاحقة.
- SQLite مع قرص دائم مناسب للنسخة الأولية. عند التوسع لعدة خوادم، انقل البيانات إلى PostgreSQL والتخزين إلى خدمة ملفات كائنية.
- كل مسودة تحتاج مراجعة محامٍ مرخص قبل الاعتماد أو الإيداع.


## مكتبة التشريعات الرسمية

- يسحب الأمر `npm run ingest:moj` روابط PDF المنشورة في صفحة قوانين وزارة العدل الكويتية.
- تُحفظ بيانات المصدر أولاً، ثم يُستخرج النص بواسطة Poppler، مع OCR عربي للملفات المصورة.
- تُصنّف الوثائق وتُجزأ إلى مقاطع وتُفهرس في SQLite FTS5 للبحث وربطها بمولد المذكرات.
- الاستيراد قابل للاستكمال: الوثائق المكتملة لا تعاد معالجتها إلا باستخدام `npm run ingest:moj -- --force`.
- للاختبار السريع: `npm run ingest:moj -- --limit=3`.
- للاكتفاء بفهرسة عناوين وروابط الوزارة: `npm run ingest:moj -- --metadata-only`.
- الواجهات الداخلية بعد تسجيل الدخول: `/api/legal-library` و`/api/legal-library/stats` و`/api/legal-library/:id`.

> الفهرسة لا تعني أن النص نافذ أو موحد حتى تاريخ الاستخدام. يجب التحقق من آخر التعديلات والجريدة الرسمية قبل اعتماد أي استشهاد أو إيداع قضائي.
