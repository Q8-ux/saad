# Validation guide
من مصدر الخدمة الكامل: node --test tests/indirect-intake.test.mjs tests/procedural-position.test.mjs tests/connected-intake.test.mjs ثم npm run build وnpm run build:github. افحص استئناف خصم في قضية إدارية ونقص بيانات الحكم، ثم موافقة النقل مع امتلاء الحقول. الاختبار الحي لا يُدعى إلا عند تشغيله فعليًا؛ لا تُستخدم قضية عميل للاختبار.
