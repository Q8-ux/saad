# مزودا Gemini وMeta للنص القانوني

المطلوب: تمكين اختيار مزود نصي خادمي للمساعد والمذكرات ومجلس المراجعة، دون تسريب المفتاح أو تغيير المصادر أو بوابة الدفع. يظل OpenAI الافتراضي حتى ضبط المزود صراحةً.

القبول: يصل السؤال والتعليمات والمصادر كما هي إلى المزود المختار؛ تُرفض المفاتيح الناقصة والردود المحجوبة/المبتورة والفارغة؛ لا يتحول الطلب إلى مزود آخر تلقائياً. لا تشمل هذه الإضافة الصوت أو رفع الملفات. يلزم اختبار حي بعد ضبط أسرار خادم الإنتاج.

المجهول: حساب Render المتصل ليس حساب سابق وفق تأكيد المستخدم. أرسل المستخدم أمر تثبيت OpenCode وليس مفتاح Meta. لا يمكن اعتبار التفعيل الإنتاجي مكتملاً قبل الوصول للحساب الصحيح وتوفير مفتاح Meta.
