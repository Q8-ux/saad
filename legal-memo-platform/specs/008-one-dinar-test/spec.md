# Feature Specification: سعر اختبار مؤقت للمذكرة

Created: 2026-10-28. Input: تخفيض رسوم اختبار المذكرة من 50 دينارًا إلى دينار واحد مؤقتًا.

## User Scenarios & Testing
US1 (P1): عند بدء طلب جديد يظهر دينار واحد وتصدر الفاتورة بالمبلغ نفسه. يظل السعر الأساسي 50 محفوظًا لعودته بعد الاختبار. اختبار مستقل بمزود اصطناعي.
US2 (P1): فاتورة سابقة بمبلغ 50 لا يعاد تسعيرها؛ حذف إعداد الاختبار يعيد السعر الأساسي للطلبات الجديدة مع بقاء الفاتورة ذات الدينار صحيحة.

## Requirements
FR-001: سعر مؤقت من الخادم 1000 فلس عند تفعيل إعداد الاختبار المالك، دون الثقة بسعر يرسله المتصفح.
FR-002: لا تغيير لبيئة سداد أو المفاتيح أو اشتراط الدفع أو الصلاحيات أو مبالغ المحاولات القائمة.
FR-003: العودة إلى السعر المحفوظ عند تعطيل إعداد الاختبار دون تعديل مخزن الإعدادات.

## Success Criteria
SC-001: السعر المعروض وسياسة الخادم والفاتورة الجديدة متطابقة بدينار واحد في الاختبار.
SC-002: اختبار 50 ثم 1 ثم استعادة 50 يحفظ مبالغ الفواتير المنشأة ويجتاز فحوص الدفع القائمة.

## Assumptions
لا موعد انتهاء محدد؛ يبقى إعداد الاختبار فعالًا حتى يعاد إيقافه. لا تُنفذ دفعة حقيقية أو استرداد تلقائيًا.
