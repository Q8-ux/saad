# التنفيذ

1. اختبار الواجهة نفسها ببيئة DOM اصطناعية: زر الحساب وPKCE والرابط المباشر والحالات القائمة/الخاطئة وفشل التخزين.
2. إظهار المدخل الموجود وتوجيه الراية signin=account إلى signIn(false) دون إنشاء مصادقة بديلة.
3. تحديث بصمة تحميل admin.js وبيان إصدار اللوحة فقط؛ الحفاظ على أحدث إصلاح استعادة الرمز.
4. فحص صيغ JavaScript واختبارات عقد اللوحة والتحقق الخادمي الحالي، ثم نشر GitHub Pages والتحقق من الواجهة الحية. لا نشر خادم جديد ولا تعديل بيانات عملاء.
