# دخول الإدارة بالحساب المعتمد دون كلمة مرور اللوحة

الطلب: إعطاء المالك دخولاً إلى لوحة الإدارة دون كتابة كلمة مرور.

النطاق إصلاح مدخل الواجهة الموجود إلى مصادقة الحساب الحالية. لا تعديل في قائمة الإداريين أو الصلاحيات أو API أو جلسات الخادم. لا يجيز الرابط العام قراءة بيانات دون مصادقة.

الافتراض: الحساب الإداري معتمد لدى الخادم. إن لم تكن جلسة موفر الهوية مفتوحة، قد يطلب الموفر إثبات الهوية؛ لا يمكن وعد الزائر بتخطيه.

القبول: زر ظاهر يستخدم signIn(false)، ورابط ?signin=account يبدأ مرة واحدة ويحتفظ بالقسم المطلوب. تُحفظ PKCE/state في sessionStorage ويستبدل الرمز عبر endpoint القائم. أخطاء الهوية لا تسبب حلقات دخول، والجلسة القائمة تستخدم فحص session المعتاد. تستمر كلمة المرور والاستعادة وتغيير الحساب دون تغيير. لا أسرار في الرابط أو المصدر، ولا وصول مجهول أو منح دور من الواجهة.
