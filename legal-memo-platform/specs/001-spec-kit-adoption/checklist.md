# Acceptance checklist — تركيب المسار

- [x] الإصدار والبصمات وتكامل Codex مطابقون للمصدر المثبت.
- [x] السكربتات تعمل من نطاق سابق دون الكتابة في جذر المستودع المشترك.
- [x] إنشاء الميزة وإعداد الخطة وفحص prerequisites يعمل؛ والخطة الموجودة محمية.
- [x] حالات غياب المتطلبات والقالب الفارغ تفشل بوضوح.
- [x] خصوصية الملفات وحدود المصادر والهوية محددة بالدستور.
- [x] أدوات التطوير مستبعدة من Docker، ولا يوجد تغيير في شيفرة التطبيق أو قاعدة البيانات.
- [x] التغيير محفوظ على GitHub ونتيجة CI مسجلة دون ادعاء اختبارات منتج حي.
