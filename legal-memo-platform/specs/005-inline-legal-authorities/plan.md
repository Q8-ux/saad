# Implementation Plan: الأسانيد في صلب المذكرات

**Branch**: `codex/inline-legal-authorities` | **Date**: 2026-10-24 | **Spec**: [spec.md](spec.md)

## Summary

إعادة استخدام التحقق القائم، مع فصل علامة التتبع الداخلية عن بيانات السند الظاهرة. يدرج الخادم هوية المصدر من بياناته المتحققة، ويزيل محول العرض علامات البحث وصفحات الفهرسة. يحسب سجل المصادر من المحتوى الذي اجتاز التحقق قبل تحويله للعرض.

## Technical Context

- TypeScript 5.9.3، React 19، Cloudflare Workers، واختبارات Node القائمة.
- لا حزم جديدة ولا تعديل لقواعد البيانات أو الملفات القانونية أو صلاحيات الدخول والدفع.
- مصدر التشغيل الحالي هو نسخة سابق الأصلية؛ ملفات bound-draft وlegal-citation-review وpleading-document ومسار memo تطابق مرآة GitHub عند بدء العمل.
- النطاق: `../sabeq-legal/research-source/lib/{bound-draft,pleading-document,legal-citation-review,sabeq-agent-bridge}.ts`، ومسار `app/api/legal/memo/route.ts` واختبارات التوليد والصادرات.
- تقابل هذه الملفات `lib/` و`app/` في مصدر الموقع الأصلي. تحفظ المواصفة الأصلية في `specs/045-inline-legal-authorities/`، وهذه المواصفة تضبط نطاق المستودع المشترك.
- لا يضاف بحث خارجي إلى مكتبة التشريعات المغلقة؛ الأحكام لا تتجاوز السجلات المراجعة والمناسبة للواقعة.

## Constitution Check

1. التحقق من الأسانيد يسبق إخفاء العلامات؛ لا تستخدم المعالجة الشكلية لإخفاء سند مجهول.
2. تبقى الصفحات والمعرفات والبصمات في سجل المراجعة، لا في وثيقة المحكمة.
3. أمثلة الاختبار مصطنعة؛ لا بيانات قضية فعلية أو أسماء أشخاص حقيقيين.
4. لا تغيير للوقائع أو الطلبات أو الهوية أو المراجعة البشرية.
5. النشر لا يدعي التحقق من سريان التشريعات أو الأحكام اللاحقة.

## Project Structure

- `bound-draft.ts`: تعليمات السرد الموحدة وإلحاق هوية السند دون صفحة فهرسة.
- `legal-citation-review.ts`: رفض قوائم مراجع البحث في سياق صياغة المحكمة.
- `pleading-document.ts`: تنظيف علامات العرض فقط لجميع الصادرات والأنواع الثلاثة.
- `memo/route.ts`: تعليمات التوليد والتصحيح، وسجل المصادر قبل التنظيف.
- `sabeq-agent-bridge.ts`: تمرير القاعدة نفسها إلى مسار الوكلاء.
- `tests/inline-authorities.test.mjs`: سلوك المادة والحكم والرفض والتصدير وعدم تغيير الوقائع.

## Validation

اختبارات الأسانيد والقوالب والتمييز ومراجعة القضية والصادرات، فحص TypeScript والبناء، ثم فحص Word/PDF اصطناعي بصرياً. تفصل نتائج الاختبار المحلي والنشر عن أي توليد حي يستهلك رصيداً أو يتضمن قضية عميل.
