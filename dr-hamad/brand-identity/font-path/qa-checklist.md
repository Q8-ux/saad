# قائمة تدقيق مسار الخط
- [ ] التحقق من الاسم الداخلي للعائلة ومن الشكل المختار؛ لا تخلط Noor وManal وAzer وAl-Mohanad.
- [ ] فحص ترخيص الاستخدام والطباعة والويب قبل تضمين أي خط أو نشره.
- [ ] العنوان عربي واضح عالي التباين في مقاس الهاتف.
- [ ] تباعد مناسب بين الشعار والعنوان، دون تقارب خانق.
- [ ] لا فراغ أبيض كبير بعد حذف كتلة من التصميم.
- [ ] لا إنجليزي في المنشورات العربية عدا Dr.hamads.
- [ ] لا اسم الطبيب أو تخصصه أو كتلة توقيع أو عبارات «قواعد مسار...» ضمن الشرائح.
- [ ] المحافظة على شعار H الأصلي، وإخراج كل شريحة 1080×1350.
- [ ] تدقيق الهجاء وتنسيق RTL وعلامات الترقيم والأرقام.
- [ ] عدم اعتماد خط لمجرد تشابه صورة مولّدة معه؛ يجب استخدام ملف TTF/OTF الحقيقي.
- [ ] التحقق من أن صور المعاينة استخدمت ملفات الخط محليًا، لا بدائل النظام.
- [ ] موافقة صاحب المشروع على العائلة/الأوزان قبل تعميمها على باقي الكاروسيلات.
- [ ] موافقة الطبيب أو فريقه على النص الطبي النهائي قبل النشر.
