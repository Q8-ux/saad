# للذاكرين والذاكرات | Dhikr | ذاکرین و ذاکرات

موقع عربي وإنجليزي وأردي للقراءة والاستماع. تلاوة القرآن بصوت الشيخ ماهر المعيقلي، والأدعية بقراءة آلية عربية مستقلة.

**الموقع:** https://q8-ux.github.io/saad/dhikr/

- ١٣ مقطعًا قرآنيًا و٧ أدعية من الصورة المرفقة، مع تكرار المقطع كاملًا بحسب القائمة.
- قسم مستقل لسورة البقرة كاملة: قراءة ٢٨٦ آية، الاستماع المتتابع، والانتقال إلى آية محددة. لا تُضاف السورة كاملة تلقائيًا إلى الورد.
- ثلاث واجهات مكتملة، واتجاه RTL للعربية والأردية وLTR للإنجليزية، مع ترجمة معاني القرآن الإنجليزية لبكتال والأردية لجالندھري.
- عدّادات القراءة، حفظ الموضع والإعدادات محليًا، تحكم بالخط، وضع ليلي، مشاركة المقطع، ومفاتيح مشغل الهاتف.
- قراءة دون اتصال بعد اكتمال حفظ الزيارة الأولى. بث القرآن يحتاج الإنترنت. نص القرآن العربي كما ورد من المصدر؛ لم يُنشأ أو يُعدّل بواسطة نموذج لغوي.

## تشغيل وفحص

```sh
npm run check
npm test
npm run build
```

قدّم محتويات `dist/` عبر خادم ملفات ثابت. لا يوجد حساب مستخدم أو مفاتيح API أو قاعدة بيانات مطلوبة.

## المصادر

- النص: [Al Quran Cloud](https://alquran.cloud/api)، إصدار `quran-uthmani`، عن [تنزيل](https://tanzil.net). إشعار الترخيص في `data/TANZIL-LICENSE.txt`، وبصمة النص في `data/source-record.json`.
- ترجمة المعاني: `en.pickthall` و`ur.jalandhry` من Al Quran Cloud، للاستخدام غير التجاري وفق [شروط تنزيل للترجمات](https://tanzil.net/trans/).
- التلاوة: [EveryAyah — MaherAlMuaiqly128kbps](https://everyayah.com/data/MaherAlMuaiqly128kbps/). المصدر الاحتياطي `verse.mp3quran.net/data/MaherAlMuaiqly128kbps/` يحافظ على القارئ. تُضاف بسملة التسجيل `SSS000.mp3` عند بداية السور عدا الفاتحة.
- أصوات الأدعية: قراءة آلية عربية بصوت `ar-KW-FahedNeural`، وليست منسوبة إلى ماهر المعيقلي. نصوصها في `library.mjs` وملفاتها في `assets/dua-*.mp3`.
- الخطوط: Cairo وAmiri Quran وNoto Naskh Arabic، مع تراخيص OFL في `assets/`.

الترتيب والتكرار وصيغ الأدعية مبنية على قائمة المستخدم الشخصية، دون تقرير أحكام على أشخاص أو ادعاء مزايا علاجية.

## النشر

ينشر `.github/workflows/deploy-dhikr.yml` المجلد فقط، مع استعادة آخر حزمة GitHub Pages ناجحة والتحقق من عدم تغيير ملفات بقية المواقع. تُنسخ النسخة أيضًا خلال النشر المجمع اللاحق.
