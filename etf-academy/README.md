# دليل ETF التعليمي

موقع عربي مستقل يشرح موضوعات دليل Trade Academy Global (20 صفحة) في 12 درسًا و5 مراحل، مع 12 سؤال فهم و24 مصطلحًا و4 معامل حسابية. لا إعادة استضافة لملف الناشر أو صوره، ولا ادعاء الانتماء إليه. صفحة المصادر تربط الموضوعات بصفحات الدليل والمراجع المالية الرسمية.

## التشغيل

موقع ساكن، بلا بناء أو حزم خارجية. `index.html` يحمل ملفات JavaScript وCSS والخطوط محليًا. افتح الموقع من خادم HTTP. روابط الدروس تستخدم hash لتعمل على GitHub Pages داخل المجلد الفرعي.

## النطاق

- شرح عام، وليس نصيحة شخصية أو توصيات منتجات.
- لا APIs أو أسعار سوق أو معاملات مالية أو تسجيل مستخدمين.
- التقدّم وآخر إجابات الفهم وحجم الخط في localStorage، مع تحمل تعذر التخزين.
- المراجع التنظيمية أمريكية؛ الضرائب المحلية والتوافق الشرعي ليست محسومة بهذا المسار.
- خط القاهرة (Cairo) بأوزان عادي وعريض من Google Fonts، مرخّص وفق SIL OFL المرفق. ملفات الخط مستضافة محليًا بلا اتصال خارجي وقت التشغيل.

## النماذج الرياضية

`calculations.js` مستقل عن الواجهة. نموذج الرسوم يطرح النسبة السنوية من العائد السنوي المفترض، ثم يحول النمو إلى معدل شهري مكافئ. المساهمات تدخل نهاية الشهر. هذا تقريب تعليمي وليس محاكاة طريقة الاستقطاع اليومية الفعلية. الرسم يبدأ من السنة صفر ويعرض القيم الاسمية.

معمل التوزيع يستخدم صدمة افتراضية للأسهم −30% والسندات −5% والنقد 0%. معمل الأوامر يفترض أسعارًا ثابتة وتوافر الكمية الكاملة وعمولة متساوية لكل عملية. إعادة التوازن تفترض عدم وجود إيداعات جديدة أو ضرائب أو عمولات. جميع المعامل تعرض هذه الحدود داخل الصفحة وتتحقق من المدخلات.

المصدر: https://tradeacademyglobal.ovh/wp-content/uploads/2026/09/ETF_Ebook_AR.pdf

آخر مراجعة تعليمية: 2026-09-28.

## مساعد التعلّم والمسارات

المساعد يبحث محليًا في مقاطع الدروس ويعرض مراجعها؛ لا يستخدم نموذجًا لغويًا ولا يجلب معلومات حية. يقترح مراجعة الدروس حسب آخر إجابات الفهم. القراءة العربية عبر 12 تسجيل MP3 مستضافًا مع الموقع، مع مشغّل يدعم الإيقاف المؤقت والتقديم. مقاطع المساعد تستخدم حدودًا زمنية من التسجيلات نفسها. لا تحتاج القراءة صوتًا عربيًا مثبتًا أو خدمة توليد وقت التشغيل. الإملاء يبقى حسب دعم المتصفح وإذن الميكروفون؛ المستخدم يراجع النص قبل البحث.

تفاصيل التطبيق والحدود في [المسارات](docs/TRACKS.md)، ومعايير القبول في [المواصفات](specs/001-learning-tracks/spec.md).

## التحقق قبل النشر

```sh
node --test etf-academy/tests/*.test.cjs
```

الأمر من جذر المستودع. ينفّذه سير GitHub Pages قبل تجميع الموقع. لا تتطلب الاختبارات حزمًا إضافية أو اتصالًا خارجيًا.

## التسجيلات العربية

أُنتجت قراءة الدروس بصوت `ar-EG-SalmaNeural`، وحُفظت MP3 أحادي القناة بمعدل 48 kbps. التوليد تم مسبقًا؛ لا مفاتيح أو استدعاءات توليد في المتصفح. `audio-manifest.js` يربط كل درس ومقطع بالتسجيل وحدوده الزمنية وبصمة `content.js` حتى تمنع بوابة النشر تغيّر النص دون تحديث الصوت. تحميل الصوت يتطلب الاتصال. الإيقاف عند تغيير الدرس أو مغادرة الصفحة يمنع تداخل التسجيلات؛ إخفاء الصفحة لا يوقف التسجيل تلقائيًا.
