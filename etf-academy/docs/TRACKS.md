# تطبيق المسارات وحدودها

هذه قائمة تنفيذ تقنية؛ وجود اسم المسار لا يعني تشغيل كل الأدوات التي قد تندرج تحته.

| المسار | التطبيق في موقع ETF | الحالة الدقيقة |
|---|---|---|
| هندسة المشاريع | مواصفات ومعايير قبول وخطة تنفيذ في `specs/001-learning-tracks/spec.md` | مطبّق كمنهج عمل؛ لا ادعاء تثبيت Spec Kit CLI |
| التحليل | تصنيف سؤال، استخراج مقاطع من الدروس، عرض صفحات الدليل والمراجع | تحليل محلي للمحتوى المُراجع؛ خادم masar-analysis وأدوات جمع الويب غير موصولين |
| تحليل قوقل | فصل التخطيط والاسترجاع ومراجعة المصدر في `learning-engine.js` | تكييف محلي لبنية العمل فقط؛ لا اتصال Google/Gemini ولا بحث Google حي |
| التحدث | تكييف وحدة `talking-path` للقراءة العربية وإملاء السؤال ومراجعة النص | مُدمج في الدروس والمساعد؛ الدعم حسب المتصفح والجهاز والإذن |
| المراجعة والتعلّم | اقتراح الدروس من آخر إجابة والتقدّم المحلي | فعّال دون حساب أو رفع بيانات التقدّم |
| الهندسي والجودة | وحدات حساب مستقلة واختبارات قبل النشر | فعّال ضمن GitHub Actions |
| تنظيم الوكلاء | مراحل محددة للتخطيط والاسترجاع والمراجعة؛ حالات توقف واضحة | سير حتمي داخل المتصفح، وليس وكلاء LLM مستقلين |

## ما لا يخدم هذا النطاق مباشرة

لم تُربط Buzz/OpenShorts/AutoClip أو مسارات إنتاج الفيديو، ولا CodeWiki كخدمة حية. الموقع مسار قراءة وتطبيق، وليس خط إنتاج محتوى أو منصة إدارة مستودعات. لا مفاتيح أو وجهات خدمة لهذه الأدوات ضمن التطبيق؛ لا أزرار توحي بتفعيلها.

## بنية التنفيذ

`content.js` يعرّف corpus المنشور ومراجعه. `learning-engine.js` يطبع العربية ويصنّف الطلب، ثم يرتّب المقاطع ويستبعد المكرر وغير المُسنَد. `app.js` يعرض النص والمراجع دون إدخال نص المستخدم كـ HTML. لا إجابات حرة مولّدة، ولا استدعاء شبكة أثناء البحث.

`calculations.js` يحتوي النماذج التعليمية. `integrations/talking-path.js` يستخدم واجهات الصوت المتاحة؛ يتوقف عند تغيير الصفحة أو إخفائها. البحث لا يبدأ تلقائيًا بعد الإملاء. بعض المتصفحات قد تعالج الصوت لدى مزوّدها عبر الشبكة، وهو موضح قبل زر الإملاء.

البيانات المحفوظة في المتصفح: الدروس المقروءة، آخر إجابات أسئلة الفهم، وتفضيل حجم الخط. لا حفظ لنص الأسئلة أو التسجيلات في التطبيق. الأسئلة المالية الشخصية غير مطلوبة.

## بوابة النشر

تفحص الاختبارات الحسابات والحالات غير الصالحة، سلامة بنية الدروس والمراجع، النتائج الأساسية للمساعد، الامتناع عن تخمين إجابات مفقودة، أولوية المراجعة، وحالات الصوت الناجحة والفاشلة والإلغاء. فشلها يوقف نشر التحديث.

المراجع ثابتة ومراجعة بتاريخ 2026-09-28؛ الاختبارات تتحقق من الربط والبنية ولا تجري تحديثًا حيًا للمعلومات التنظيمية أو الأسعار.
