# توسيع موقع ETF بالمسارات المتوائمة

الحالة: مُنفّذ، 28 سبتمبر 2026.

## هدف المستخدم

تحويل الدليل العربي إلى موقع واضح وموسّع وتعليمي، بخط القاهرة، وتطبيق المسارات التي تخدم التعلّم فعليًا.

## المتطلبات ومعايير القبول

1. اثنا عشر درسًا في خمس مراحل تغطي الدليل مع أمثلة وسؤال فهم لكل درس، وربط بصفحات المصدر ومراجع رسمية.
2. أربعة معامل تحسب افتراضات تعليمية مع رفض المدخلات غير الصالحة وشرح حدود النموذج.
3. مساعد يعيد مقاطع من المحتوى المنشور فقط، مع مراجعة وجود المصدر؛ يوضح عدم وجود نتيجة ولا يولّد أسعارًا أو توصيات شخصية.
4. اقتراح مراجعة الدروس ذات الإجابات الخاطئة قبل الدروس غير المقروءة. حفظ التقدّم محليًا مع توضيح عدم المزامنة.
5. قراءة الدرس والمقاطع من تسجيلات عربية محلية دون اعتماد على أصوات الجهاز، وإملاء اختياري يعيد النص للمراجعة قبل البحث. زر إيقاف وتنظيف الصوت عند مغادرة الصفحة. فشل تحميل الملف أو رفض الميكروفون حالة واضحة.
6. القاهرة محليًا، واجهة RTL، تحكم بحجم الخط، تسميات للنماذج، رسائل حالة لقارئ الشاشة، وقائمة متكيفة مع العرض.
7. فحص النماذج والمصادر والمساعد ودورة الصوت آليًا قبل نشر GitHub Pages.

## الخطة المنفّذة

- فصل المحتوى والحسابات ومنطق التعلّم والصوت عن عرض الواجهة.
- تكييف talking-path بوضع المتصفح مع الإلغاء وحالات الخطأ وتحقق توفر صوت عربي.
- تطبيق سير عمل تصنيف السؤال ← استخراج المقاطع ← مراجعة المصادر ← العرض، دون استدعاء نموذج لغوي.
- إضافة اختبارات للحالات الناجحة والفاشلة، ثم دمجها في سير النشر الحالي دون تغيير المواقع الأخرى.

## التحقق

`node --test etf-academy/tests/*.test.cjs`

الاختبار الآلي للصوت يستخدم بدائل محكومة لواجهات المتصفح؛ ليس إثباتًا لجودة الصوت أو الميكروفون على كل جهاز. يلزم التحقق من العرض وتفاعل المساعد بعد النشر. القراءة تستخدم مشغّل MP3 أصليًا وتتطلب تحميل التسجيل؛ الإملاء وحده يعتمد على دعم المتصفح وإذن المستخدم.

## خارج النطاق الحالي

حسابات المستخدمين، المزامنة، تداول أو بيانات سوق حية، البحث الخارجي التلقائي، خدمات Google/Gemini أو نماذج أخرى، رفع المستندات، توليد الفيديو. أي تكامل خارجي لاحق يحتاج نقطة خدمة فعلية وإدارة أسرار بالخادم والتحقق من مصادره وتكلفته.
