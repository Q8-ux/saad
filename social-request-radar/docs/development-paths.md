## موصلات المنصات الست

الخادم `comment-radar` يحتوي موصلات Instagram وX وYouTube وTikTok وFacebook وReddit عبر ScrapeCreators؛ يحتاج مفتاح حساب صاحب المشروع ورصيد الخدمة. حفظ المفتاح مشفرًا لا يثبت الوصول: أول جمع غير فارغ هو دليل القراءة. X يجلب منشورات عامة مفهرسة، وليس فهرسًا كاملاً للردود، وFacebook يحتاج روابط منشورات محددة. يتوفر مسار مستقل لـYouTube وInstagram ضمن الأدوات. لا يمكن البحث في كل تعليقات المنصات أو قوائم المتابعين بمجرد تثبيت الحزم.

## التشغيل والاستبقاء

[GitHub Actions Worker](https://github.com/Q8-ux/saad/actions/workflows/radar-tools-worker.yml) يُشغّل يدويًا أو عند تحديث ملفات العامل. يعمل ١٥ دقيقة بعد جاهزية النموذج، ثم يتوقف. لا بحث مجدول أو خادم دائم. تتحدث حالة العامل في الواجهة، ولا تُقبل مهمة جديدة وهو متوقف.

Supabase Edge `radar-tools` يتحقق من GitHub OIDC وrepo ID/owner ID وworkflow وفرع main. الجدولان محجوبان عن anon/authenticated بـRLS وسحب الصلاحيات؛ غياب سياسات إتاحة عامة مقصود. لا تحتوي مفاتيح الخدمة في الواجهة.

طابور المهام مشفر AES-256-GCM، وتحتاج النتيجة رمزًا عشوائيًا محفوظًا على جهاز صاحب المهمة. تُحفظ النتيجة في IndexedDB ثم تُمسح الحمولتان المشفرتان من الخادم. تبقى بيانات الحالة والمعرّف وhash الرمز حتى التنظيف بعد ساعتين عند إدخال مهام جديدة، لمنع تجاوز حد ٨ مهام بالساعة بمجرد الحذف. تنتهي صلاحية قراءة الحمولات بعد ساعة حتى لو لم يعد العميل. دون تشغيل العامل أو إدخال مهام لاحقة قد تبقى الحمولات المشفرة المنتهية؛ لا ندعي حذفًا مجدولًا مستمرًا.

لا تُكتب جلسة Instagram في المتصفح أو الملفات أو سجل GitHub. تُرسل لهذه المهمة فقط عبر HTTPS، وتُشفّر في الطابور وتستخدم في ذاكرة عملية الجمع. تتوقف العملية عند رفض المصدر أو تحدي الحساب؛ لا تسجيل دخول آلي أو متابعة أو إرسال رسائل أو تعليقات.

## نتيجة الاختبار المتكامل

عامل GitHub رقم `39172210585` اتصل بهوية OIDC صحيحة، واستلم مهمة صناعية عبر الطابور المشفر، وحلّل ١٢ نصًا وأعاد ٤ مجموعات و١٢ زوجًا متقاربًا. حُذفت حمولتا المهمة بعد استرجاع النتيجة؛ تحققنا من بقائهما null في القاعدة. نجح أيضًا منع مهمة Instaloader الناقصة قبل إدخالها للطابور (HTTP 424).

اختبار YouTube على فيديو من اختبارات yt-dlp الأصلية لم يجلب تعليقات: `SOURCE_UNAVAILABLE` بعد طلبي نقل، ثم توقف دون تبديل مصدر أو وكيل. لا يُدّعى نجاح الوصول الحي. لم يتوفر مفتاح ScrapeCreators أو جلسة Instagram حقيقية في هذه الجلسة. لذلك الموصلات البرمجية مربوطة، لكن حسابات المصادر تحتاج بيانات اعتماد المالك قبل إثبات الجمع.
