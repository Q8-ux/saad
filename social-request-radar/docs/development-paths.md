# مسارات تطوير راصد

الموقع: [راصد الطلبات ونمو الحسابات](https://q8-ux.github.io/saad/social-request-radar/). افتح «المسارات والتطوير» للاطلاع على الحالة داخل الموقع.

راجعت المصادر الأصلية في ١٨ أكتوبر ٢٠٢٦. [سجل المراجعة](upstream-review.json) يحفظ معرّفات النسخ وتراخيص المستودعات وقت المراجعة. هذه مراجعة للتوافق والتصميم؛ لم تُثبّت كل المكتبات ولم تُختبر جلسات المنصات أو النماذج على بيانات حقيقية.

## ما طُبّق

| المسار | التغيير | دليل التحقق |
| --- | --- | --- |
| المصدر وهوية السجل | قبول nativeId وid المعياري دون مضاعفة بادئة المنصة؛ ثبات المعرّفات المحلية عند إعادة الاستيراد | اختبارات إعادة الاستيراد ثلاث مرات وإزالة التكرار |
| أوقات المصدر | حفظ createdAt وcollectedAt عند وجودهما وتسجيل importedAt منفصلًا؛ وقت الجمع المفقود يبقى غير مسجل | اختبارات وقت الجمع الأصلي والمجهول وأوقات Unix |
| التوافق | استيراد تعليقات yt-dlp وردود Instaloader وحقول instagrapi: created_at_utc وreplied_to_comment_id وlike_count | اختبارات بيانات محلية؛ لا تعني اختبار وصول حي إلى المنصة |
| العربية | أسئلة «كم، بكم، كيف، شلون» وطلبات التوصية، وتصنيف مع قرائن الكلمات | حالات عربية تشمل النفي والإعلانات والهمزات والتشكيل |
| دقة الكلمات | مطابقة كلمات وعبارات مع بادئات عربية محددة؛ «بيت» لا يطابق «تثبيت» | اختبارات حدود الكلمات؛ لا ندّعي اشتقاقًا صرفيًا أو بحثًا دلاليًا |
| فهم الجمهور | حتى ثلاثة أسئلة أصلية مختلفة مع مصادرها لكل مجموعة، وإزالة التعليقات المكررة، وزاوية محتوى وتجربة مقترحة | اختبارات الشواهد وعدد التعليقات واستبعاد الإعلانات |
| القياس | عرض المقامات: المتابعات/الزيارات والزيارات/الظهور؛ المقام الصفري يعني بيانات غير كافية | اختبارات حساب النسب وصافي المتابعين |
| الواجهة | خط أكبر، قرائن أوضح، أهداف لمس ٤٤ بكسل، رابط تجاوز القائمة، RTL، دفعات ٢٤ نتيجة | فحص الأنواع والبناء وتكامل الملفات؛ الفحص البصري التفاعلي غير متاح في بيئة التنفيذ |
| التصدير | JSON للنص والبيانات الأصلية، وCSV يهيئ الخلايا الآتية كصيغ للاستخدام في الجداول | اختبارات هوية CSV وحماية الصيغ؛ JSON هو صيغة الأرشفة الأدق |
| الخادم | Supabase Edge مستقل، مفتاح مزود البيانات مشفر، حدود لكل جولة، تمييز التعطل عن غياب التطابق | اختبارات HTTP وتحقق حي للصحة والتشفير دون استدعاء مزود البيانات |

التصنيف والدرجة قواعد للمراجعة، وليسا احتمال شراء أو متابعة. استشارة عامة لا تُصنّف قانونية بمجرد كلمة «استشارة». يبقى النص الأصلي مرجعًا؛ وقد تفوت القواعد سخرية أو نفيًا غير مشمول أو تهجئات ولهجات أخرى.

## مسار YouTube البديل عبر الاستيراد

المصدر الرسمي يدعم `--write-comments` و`--write-info-json` مع `--skip-download`. حد `max_comments` قائمة بالترتيب: الإجمالي، الآباء، الردود، الردود لكل سلسلة، العمق. القيم الافتراضية قد تجمع دون حد؛ المثال التالي يطلب حتى ٢٠٠ تعليق أب دون ردود على فيديو واحد:

```bash
timeout 120s yt-dlp \
  --skip-download --write-comments --write-info-json --no-playlist \
  --retries 0 --extractor-retries 0 --socket-timeout 20 \
  --extractor-args 'youtube:comment_sort=new;max_comments=200,200,0,0,1' \
  --output 'comments/%(id)s.%(ext)s' \
  -- 'https://www.youtube.com/watch?v=VIDEO_ID'
```

هذا مثال إعداد لم يُنفذ على فيديو حقيقي. يحتاج yt-dlp مثبتًا و`timeout` في بيئة Linux، ورابط فيديو صحيحًا. حد التعليقات ليس حدًا لعدد طلبات HTTP، وقد لا يُنتج timeout ملفًا مكتملًا. بعدها استورد ملف `.info.json` في الموقع واختر YouTube؛ يقرأ المستورد `comments` و`webpage_url`. وقت الجمع غير الموجود في الملف يبقى غير مسجل؛ لا يستبدله الموقع بوقت رفع الملف.

## عقد البيانات

النص الأصلي ورابط المصدر ومُعرّف التعليق أهم من اقتراح المحتوى. نقبل مصفوفة JSON، أو كائنًا يحوي `records`/`comments`، أو JSONL/CSV. لكل سجل منصة معروفة ونص ورابط HTTPS تابع لها. رابط المنشور مع معرّف تعليق لا يعني أننا تحققنا من رابط مباشر للتعليق نفسه.

- `id`: معرّف معياري بالشكل `platform:nativeId` أو `platform:derived:hash` عند فقد معرّف المنصة.
- `nativeId`: معرّف المنصة الأصلي. المعرّف المشتق لا يُعرض كأنه أصلي.
- `parentId` و`kind`: ربط الرد بأصله. `answers` و`replies` مدعومان عند الاستيراد.
- `createdAt`: تاريخ نشر التعليق إن توفر؛ وقت غير معروف يبقى null.
- `collectedAt`: وقت الجمع المسجل في بيانات المصدر؛ الاستيراد لا يختلقه. الموصل الحي يسجل وقت الجلب الفعلي.
- `importedAt`: وقت أول استيراد مسجل؛ يُحفظ عند إعادة استيراد JSON المعياري.
- `collectionMethod`: اسم الجامع إن توفر. بيانات الملفات مرفقة من صاحبها وليست إثباتًا مستقلاً لصحتها.

لا تُرفع ملفات التعليقات أو بيانات الحسابات أو الجلسات إلى مستودع الشيفرة. السجلات الحالية في المتصفح، ولذا تصدير JSON مهم للنسخ الاحتياطي. لا توجد مزامنة سحابية للنتائج بين الأجهزة.

## أولويات التوسع

1. **جولة حقيقية صغيرة:** مفتاح مصدر صاحب المشروع أو ملف تعليقات جمعه من رابط محدد. راجع التقرير والصفحات المتبقية والتكلفة الفعلية قبل توسيع الجمع.
2. **عينة دقة عربية:** صنّف يدويًا طلب/سؤال/إعلان/غير واضح ودليل الدولة، ثم قارن ما التقطته القواعد وما فاتها. لا نضع نسبة دقة من اختبارات صناعية.
3. **الوصول الرسمي للحسابات المملوكة:** قياسات الحسابات وتعليقات محتواها عبر صلاحيات المنصة حيث تتاح. هذا اتصال مستقل، ولا يتيح تلقائيًا كل تعليقات حسابات الآخرين.
4. **استمرار البحث:** طابور عمل وتخزين نقاط التوقف والتكلفة ومؤشرات الصفحات لكل مصدر؛ النموذج الحالي جولة محدودة ويبلغ عن المتبقي.
5. **ميزانية مشتركة:** سجل إنفاق ومفاتيح طلبات دائم وحد يومي عند تشغيل عدة أجهزة/مستخدمين. التخزين المؤقت الحالي لكل isolate وليس ضمانًا عالميًا لمنع التكرار.
6. **مزامنة اختيارية:** مصادقة وملكية سجلات وسياسات صفوف ونسخ احتياطي قبل نقل بيانات المتصفح إلى قاعدة مشتركة. لم تُنشأ جداول سحابية ضمن هذا التحديث.
7. **جدولة الرصد:** تحتاج مصدرًا قادرًا على العمل دون فتح المتصفح وتخزينًا دائمًا وميزانية؛ لا يوجد بحث مجدول مفعّل الآن.
8. **فهرس/نموذج عند الحاجة:** اختبر MiniSearch أولًا للحجم والإملاء؛ قيّم نموذجًا متعدد اللغات للأسئلة المتقاربة لاحقًا. النموذج المدمج gte-small في أمثلة Supabase إنجليزي، فلا يُعتمد كحل عربي جاهز.

النمو هنا يعتمد على أسئلة الجمهور ومحتوى نافع وتجارب قابلة للمراجعة. المتابعة قرار صاحب الحساب؛ لا تتضمن المسارات تشغيل متابعة جماعية أو إرسال رسائل وتعليقات آلية. تحليل السؤال لا يكشف الاحتياجات الخاصة أو موقع الإقامة غير المعلن.

## التحقق وحدوده

الاختبارات تستخدم بيانات محلية صناعية واضحة ولا تُعرض كفرص حقيقية. يشمل التحقق البحث والاستيراد والحفظ والتشفير وحدود الجولة والتعطل وبناء الواجهة وتكامل الملفات. صحة الخادم واختبار تشفير مفتاح صناعي لا يثبتان صلاحية مزود البيانات أو رصيده؛ الجمع الحي لم يُختبر دون مفتاح صاحب الحساب. تعذر فحص الواجهة تفاعليًا في بيئة التنفيذ، فلا ندّعي اجتياز مراجعة بصرية على كل الشاشات.
