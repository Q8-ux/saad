# مسار إنشاء المحتوى في راصد

[افتح مصنع المحتوى](https://q8-ux.github.io/saad/social-request-radar/?content=1)

أضيف المسار إلى راصد الحالي دون استبدال البحث أو نتائجه المحفوظة. الواجهة عربية RTL بخط القاهرة، ويُحمّل الاستوديو كحزمة مستقلة عند فتحه.

## ما يعمل في الواجهة

- إنشاء حملات مستقلة للعلامة والجمهور والهدف والنبرة واللغة والمنصات والمدة.
- إرفاق حتى ١٢ سؤالاً أصلياً من نتائج الجولة الحالية والفرص المحفوظة، مع روابط المصادر. لا تُختلق مصادر عند غياب البيانات.
- تحرير العنوان والافتتاحية والسكربت والتعليق والدعوة إلى إجراء، ولوحة مشاهد حتى ٣٠ مشهداً.
- توليد مسودة منظمة عبر Gemini بعد ربط مفتاح من حساب المالك والتحقق من توفر النموذج. لا يستخدم رصيداً دون طلب توليد صريح.
- مراجعة النسخ واعتمادها. تعديل محتوى نسخة معتمدة يعيدها إلى مسودة، مع رقم نسخة جديد.
- حفظ صور وصوت وفيديو ونص على الجهاز، حتى ١٢ مادة و١٠٠ ميجابايت للحملة و٢٠ ميجابايت للمادة؛ معاينة وتنزيل وحذف المواد.
- تقويم محلي بتوقيت الكويت، وتصدير ICS. حفظ الموعد لا ينشئ مهمة نشر سحابية. تسجيل النشر يتطلب إضافة رابط المنشور الفعلي يدوياً.
- تصدير السكربت Markdown وحزم JSON للمشاريع المكتبية. التصدير ليس إنتاجاً لوسائط أو إرسالاً إلى منصة.
- تضمين الحملات في ملف نقل الربط والنتائج الحالي؛ تستعاد كمسودات للمراجعة. الملفات الثنائية ومفاتيح خدمات المحتوى ومهام العامل لا تدخل النقل؛ تُنقل المواد بتنزيلها وإرفاقها على الجهاز الآخر.

## الأدوات العشر وحدود ربطها

| الأداة | المسار المتاح | المتطلب المتبقي للإنتاج |
|---|---|---|
| Social Media Research Skills | موجز جمهور من نتائج الرصد وروابط المصدر، مع الرجوع للجمع القائم عبر ScrapeCreators | وصول مزود البيانات الحالي؛ لم ننسخ مهارات المستودع إلى مهارات المستخدم العامة |
| Local Deep Research | محول HTTP مصادق عليه، بدء بحث ومتابعة التقرير وإلغاء البحث عند مهلة المحول | خادم LDR وحساب يهيئهما مشغل العامل |
| OpenCreator | حزمة موجز وسكربت ومشاهد ومصادر وبرومبت | فتح الحزمة في التطبيق؛ لا ندّعي وجود API مكتبي غير موثق |
| FLUX.2 | محول Python إلى Flux2KleinPipeline، صورة غلاف PNG | diffusers وGPU ونسخة محلية من klein 4B؛ لا تنزيل أوزان تلقائياً |
| Kokoro | محول KPipeline للصوت المحلي | المكتبة والنموذج والأصوات؛ العربية محظورة في هذا المحول لأنها ليست لغة مدعومة رسمياً |
| ACE-Step 1.5 | release_task ثم query_result واستلام الصوت من أصل الخدمة نفسه | REST API يهيئه المشغل؛ لا يعلن النجاح قبل وجود الملف |
| Short Video Factory | حزمة مشاهد ونصوص ومواد للعمل داخل التطبيق | التطبيق ومواد المشاهد، وترخيص AGPL-3.0 مستقل |
| AI YouTube Shorts Generator | CLI بالوضع المحلي وملف نتيجة، مع حفظ المقاطع الفعلية | مصدر المستودع، اعتمادياته، FFmpeg ومفتاح Gemini على العامل؛ يقبل رابط YouTube فقط |
| Podcastfy | generate_podcast على النص واللغة ثم استلام الملف | الحزمة وخدمات النموذج والصوت المهيأة في العامل |
| Social Media Agent | حزمة مسودة ومصادر وموعد مقترح لـX وLinkedIn | ربط الحسابات ومراجعة المشغل في الأداة؛ لا نشر تلقائي من راصد |

هذه موصلات وحدود تشغيل، وليست ادعاء بأن نماذج الصور والصوت والفيديو تعمل في GitHub Pages. مصدر كل مستودع مثبت إلى SHA في `content-worker/upstream-lock.json`؛ لم تُدمج شفراتها أو تراخيصها في حزمة واجهة واحدة.

## البوابة والمفاتيح

`content-edge/` بوابة Supabase مستقلة عن `comment-radar` و`radar-tools`. مفتاحها المشتق من سر الخادم له نطاق مستقل؛ لا تُقبل بيانات ربط الرصد لتشغيل المحتوى. تبقى مفاتيح Gemini والعامل في حاوية AES-256-GCM مشفرة على الجهاز، ولا تُعاد المفاتيح الأصلية إلى الاستجابة أو مسودات الحملات. التوليد يرسل موجز الحملة والمصادر إلى مزود الكتابة المختار، وليس ملفات المكتبة المحلية.

نقطة Gemini ثابتة على خادم Google. أصل العامل يؤخذ فقط من متغير الخادم `RADAR_CONTENT_WORKER_ORIGIN`؛ لا يستطيع طلب من المتصفح تغيير عنوانه. العامل يحتاج مفتاحاً شخصياً بطول ٣٢ حرفاً على الأقل، ومفتاحه لا يدخل الحزمة العامة. سياسة CORS وحدها ليست المصادقة؛ القدرة المشفرة ومفتاح العامل هما إذن الاستخدام.

لا إعادة محاولة تلقائية للطلبات المدفوعة. منع التكرار وميزانية ٦ طلبات/ساعة وعمليتين متزامنتين تعمل داخل isolate فقط؛ ليست محاسبة إنفاق دائمة أو ضماناً عبر كل نسخ الخادم. إعداد نموذج Gemini يتحقق باستعلام بيانات النموذج ولا يولد محتوى.

## ما نُشر وما لم يُختبر

الواجهة والبوابة قابلتان للنشر مستقلتين. مصدر العامل والمحولات متاحان في المستودع؛ تشغيل GPU أو ربط خدمة سحابية ليس نتيجة بناء الواجهة. عند عدم ربط العامل تعرض البوابة `workerConfigured:false` وتُعطل أزرار تشغيل المحركات. لا تُعرض أمثلة كإنتاج حقيقي.

اختبارات Node تغطي الحفظ والمصادر والاعتماد والتقويم والمفاتيح وحدود الطلبات ومنع التكرار. اختبارات Python تغطي مصادقة العامل وملكية المواد وانتهاء الصلاحية. هذه اختبارات ببيانات صناعية محلية، لا تقيس جودة لهجة كويتية أو دقة تقرير بحث أو جودة فيديو. لم يُنفذ اختبار إنتاج حي لأي محرك بلا حساب أو عتاد مهيأ، ولم يتوفر فحص بصري تفاعلي في هذه البيئة.
