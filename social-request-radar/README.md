# راصد الطلبات ونمو الحسابات

[افتح الموقع](https://q8-ux.github.io/saad/social-request-radar/) · [إعداد المصدر](https://q8-ux.github.io/saad/social-request-radar/?setup=1) · [المسارات وخطة التطوير](docs/development-paths.md)

مساحة عربية RTL للبحث في التعليقات العامة المتاحة عن طلب خدمة أو سؤال، مع قرائن الدولة، وحفظ النتائج، وتحويل الأسئلة إلى أفكار محتوى وقياسات لنمو الحساب.

## الحالة الفعلية

واجهة GitHub Pages مربوطة بخادم Supabase Edge مستقل. أُعدّ مصدر حساب المالك واختُبرت قراءات حقيقية غير فارغة من المنصات الست: جولة الاكتشاف فحصت ٧٩ سجلًا وأعادت ٧ مطابقات، منها ٤ دولتها غير واضحة؛ وقرأ اختبار Facebook مستقل ١٠ تعليقات. X هنا منشورات عامة. [سجل التحقق الإجمالي](deployment/provider-verification-20261019.json) لا يحتوي بيانات الاعتماد أو نصوص المستخدمين. الربط يخص المتصفح الذي أُعدّ؛ فتح الرابط من هاتف آخر لا ينقل الربط أو النتائج تلقائيًا. حفظ مفتاح جديد لا يستدعي المزود ولا يثبت رصيده أو صلاحية الوصول.

الاستيراد والبحث في الملفات يعملان دون مفتاح. يبدأ الموقع فارغًا، ويميز بين مصدر غير مربوط، أو مصدر تعطل، أو عدم وجود بيانات، أو فحص بيانات فعلية دون تطابق. لا تُعرض نتائج أو حسابات تجريبية كأنها حقيقية.

محاولة Render السابقة فشلت لنفاد دقائق البناء في مساحة العمل؛ لم تُرفع حدود الإنفاق، وRender ليس الخادم النشط. [حالة الخادم وبصمات مصدره](deployment/supabase-function.json) تحفظ الإصدار الفعلي.

## ما يعمل في هذه النسخة

- موضوع ودولة ومنصات وفترة، مع مطابقة عربية للكلمات والعبارات وبادئات محددة. قرائن للأسئلة وطلبات الخدمة والتوصية والإعلانات؛ القواعد والدرجة تساعدان على المراجعة وليستا احتمالات شراء أو متابعة.
- النص الأصلي ورابط المنشور ومعرّف التعليق الأصلي أو معرّف محلي واضح. جمع التعليق واستيراده لهما وقتان منفصلان؛ الوقت المجهول يبقى غير مسجل. إعادة الاستيراد لا تضاعف بادئة المنصة ولا تغيّر الهوية.
- JSON/JSONL/CSV، وكائنات records/comments، وملفات yt-dlp ذات comments وwebpage_url، وردود answers/replies، وحقول Instaloader/instagrapi المراجعة. حد ٢٠٠٠ تعليق ورد لكل ملف و١٫٨ ميجابايت من واجهة الرفع.
- حفظ الفرص، وتصدير JSON للنص والبيانات الأصلية، وCSV بخلايا مهيأة للاستخدام في الجداول. بحث داخل كامل النتائج عبر MiniSearch وعرض سريع عبر TanStack Virtual، مع بديل دفعات ٢٤ وتصدير كل النتائج المحددة.
- نمو الحساب: مجموعات كلمات تدعمها حتى ثلاثة أسئلة أصلية مختلفة مع الروابط، وزوايا محتوى وتجربة مقترحة. قياسات بفترة وحساب ومنصة ومقامات واضحة؛ لا توجد معادلة تضمن المتابعات.
- قسم «المسارات والتطوير» يحتوي الأدوات العشر المثبتة وأزرار الجمع والتحليل وحالة عامل Python. فحص الحزم والنماذج منفصل عن صلاحية الوصول إلى المنصات. [تفاصيل التوافق والتراخيص والأولويات](docs/development-paths.md).

## التغطية

Instagram: اكتشاف عدد محدود من الريلز المفهرسة ثم تعليقاتها، أو روابط منشورات/Reels تضيفها. X: منشورات عامة مفهرسة، وليس بحثًا كاملًا في الردود. TikTok وYouTube: فيديوهات محدودة وصفحة تعليقات لكل فيديو مختار. Reddit: بحث تعليقات المزود. Facebook: روابط منشورات محددة. قد تبقى صفحات وردود غير مجموعة؛ يوضح التقرير المؤشرات المتبقية والأخطاء والطلبات والكريدتس.

الدولة المذكورة في النص أو الموقع المعلن في الملف قرينة منفصلة؛ لا تثبت الإقامة أو الجنسية. لا يُستنتج البلد من اللهجة أو حساب صاحب المنشور. النتائج مجهولة الدولة تبقى منفصلة عند طلب إظهارها. لا يوجد فهرس شامل لكل تعليقات الإنترنت أو قوائم المتابعين.

## استخدام راصد من هاتف آخر

1. من «مصادر البيانات» في المتصفح المرتبط اضغط «تصدير الربط والنتائج».
2. نزّل الملف على جهازك الآخر، وافتح «مصادر البيانات» في راصد ثم «استيراد ملف الربط والنتائج».
3. تُفتح الجولة المحفوظة مباشرة وتبقى معروضة بعد تحديث الصفحة. يعرض زر «تعديل البحث أو بحث جديد» إعداداتها لبدء جولة جديدة دون إدخال المفتاح ثانية. يقبل مدخل ملفات التعليقات ملف نقل الربط أيضًا تلقائيًا.

[فتح النتائج المحفوظة مباشرة](https://q8-ux.github.io/saad/social-request-radar/?results=1) يستعيد بيانات المتصفح الحالي فقط؛ لا ينشر نتائج المالك لزوار الرابط، ولا يستهلك رصيد جمع جديد.

الملف شخصي: يحمل صلاحية المصدر المشفرة والجولات والملفات والمحفوظات والقياسات. لا يحتوي المفتاح الأصلي أو مهام العامل ورموزها أو جلسات Instagram. حيازة الملف تتيح استخدام رصيد المصدر؛ لا تنشره في GitHub أو تشاركه. هذه آلية نقل عند الطلب وليست مزامنة تلقائية. يتحقق الخادم من صلاحية الربط قبل أي حفظ، ثم تُدمج السجلات بمعرّفاتها في معاملة واحدة؛ تبقى البيانات الأخرى على الجهاز. يُرفض الملف التالف أو الصادر لخادم آخر. حد النقل ١٠ ميجابايت و٢٠ ألف سجل، وبحد أقصى ٢٠٠٠ سجل في المجموعة الواحدة.

## البيانات والربط

نسخة GitHub Pages تحفظ الملفات والجولات والمحفوظات والقياسات في IndexedDB بالمتصفح الحالي؛ لا تزامن بين الأجهزة. المفتاح يُرسل عبر HTTPS إلى الخادم ويعاد كبيان مشفر AES-256-GCM؛ لا يُحفظ نصه في المتصفح. سر التشفير يبقى في بيئة Supabase ولا يدخل ملفات البناء. لا يوجد حساب مزود مشترك. مهام الأدوات الجديدة تستخدم طابورًا مؤقتًا مشفرًا: تُرسل دفعة النصوص للتحليل الخلفي، أو الجلسة لجمع الرابط، وتُمسح بيانات المهمة بعد حفظ النتيجة محليًا. صلاحية قراءة المهمة ساعة؛ تُنظّف البيانات المنتهية عند إدخال مهام جديدة. تبقى معرّفات وحالات مؤقتة لحدود الاستخدام دون نصوص أو جلسات بعد الحذف.

حد الخادم ١٢ طلبًا و٢٠ كريدت تقديريًا للجولة؛ قد تختلف رسوم المزود الفعلية. لا إعادة محاولات تلقائية أو اتصالات مدفوعة أثناء البناء والاختبارات. التخزين المؤقت ومنع تكرار الطلبات لكل isolate؛ لا يُدّعى وجود سجل إنفاق يومي دائم أو ضمان عالمي لعدم التكرار.

راجع [خادم Edge](edge/README.md) و[محوّل Node البديل](server/README.md) لتفاصيل النطاق المشترك ومدة البيان المشفر وتدوير المفاتيح. CORS ليس وسيلة مصادقة؛ بيان المفتاح المشفر هو صلاحية تنفيذ بحث بحساب صاحبه.

المصدر الأصلي الخاص موجود أيضًا في app/components مع مسارات مصادقة وملكية D1؛ لم يُعد نشر تلك النسخة ضمن تحديث GitHub Pages. إعداد SCRAPECREATORS_API_KEY في سر استضافة تلك النسخة يخصها، ولا يربط نسخة GitHub Pages تلقائيًا. لا توجد رسائل صادرة أو متابعة جماعية أو نشر آلي.

## التطوير والتحقق

Node 24 وpnpm 11.25.0 وPython 3.12. أضيفت MiniSearch 7.2.0 وTanStack Virtual 3.14.14 وTransformers.js 4.3.1؛ إصدارات أدوات Python السبع واعتمادياتها مثبتة في worker/requirements.lock.txt.

```bash
pnpm install --frozen-lockfile
node --test tests/*.test.mjs
node node_modules/typescript/bin/tsc --project github-pages/tsconfig.json --noEmit
node scripts/build-github-pages.mjs
node scripts/verify-github-pages.mjs
```

تختبر الحالات المنطق والحفظ والتشفير والمصادر والأخطاء والاستيراد ببيانات صناعية محلية؛ لا تقيس دقة التصنيف على جمهور حقيقي. يتحقق البناء من بصمات المصدر والأصول. النشر يضيف هذا المشروع فقط إلى آخر نسخة GitHub Pages ناجحة، مع تحقق أن ملفات المشاريع الأخرى مطابقة بايتًا ببايت. الفحص البصري التفاعلي غير متاح في بيئة التنفيذ؛ لا ندّعي اجتيازه.

## تشغيل الأدوات العشر

افتح «مصادر البيانات» أو «المسارات والتطوير». جمع YouTube عبر yt-dlp وجمع Instagram عبر Instaloader/instagrapi يعملان من رابط محدد؛ Agent-Reach يوجه الرابط إلى مسار الجامع. أدوات التحليل الخلفي تستخدم Sentence Transformers وBERTopic وCAMeL Tools فعليًا، مع نسخة تحليل مطبّعة واحتفاظ بالنص الأصلي. لا تُنزّل حزم بيانات CAMeL الإضافية. Transformers.js يعمل في Web Worker اختياري على الجهاز، والنموذج متعدد اللغات Apache-2.0 بإصدار ثابت، نحو ١١٨ ميجابايت للتنزيل الأول.

[عامل الأدوات في GitHub](https://github.com/Q8-ux/saad/actions/workflows/radar-tools-worker.yml) يعمل ١٥ دقيقة بعد جاهزية النموذج في كل تشغيل، ثم يتوقف. هو بديل محدود التشغيل، وليس خدمة ٢٤ ساعة. الاتصال إلى Supabase بهوية GitHub OIDC مع قصر الثقة على المستودع والمالك بأرقامهما وملف workflow وفرع main؛ لا تُخزّن مفاتيح GitHub أو Supabase في الواجهة أو المستودع.

الحدود: ٨ مهام بالساعة على العامل المشترك، ٣ معلقة أو جارية، حتى ٨٠ تعليقًا/نصًا لكل مهمة، ١٢ طلب جمع و١٠٠ ثانية، ومهلة ١٥٠ ثانية للعملية. يوجد سقف حجم للنتيجة ويُبلغ التقرير عن السجلات التي لم تُحفظ بسببه دون قص النص بصمت. لا إعادة محاولة بعد 401/403/429 أو تحدي الحساب، ولا تبديل أداة لتجاوز الرفض. جلسة Instaloader مطلوبة قبل أي اتصال؛ لا تسجيل دخول آلي.

موصلات Instagram وX وYouTube وTikTok وFacebook وReddit موجودة في خادم المزود. تحتاج مفتاح ScrapeCreators من حساب المالك، بينما الجامعان المستقلان لهما متطلبات الوصول الخاصة أعلاه. تركيب المكتبات لا يمنح صلاحية تلقائية للمنصات.
