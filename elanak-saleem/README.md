# إعلانك سليم

منصة موبايل لفحص وضوح الإعلانات ومتطلبات الامتثال الأساسية قبل النشر، مع واجهة عربية وإنجليزية وسجل محلي للتقارير.

## المزايا

- فحص قواعد عامة وقواعد مخصصة للإعلانات الصحية والعقارية وإعلانات المؤثرين والاشتراكات.
- احتساب درجة وضوح ومخاطر مع توصيات قابلة للتنفيذ.
- إنشاء نص مقترح وحفظ التقارير على جهاز المستخدم.
- تطبيق ويب تقدمي يعمل على الجوال ويمكن تثبيته.

> النسخة الحالية إرشادية وتجريبية، وليست اعتماداً قانونياً أو ترخيصاً حكومياً.
