# التحقق المنفذ وحدوده

## منطق القراءة

نجحت 14 حالة فعلية بواسطة Node Test Runner: ترابط المراجع وحجز المختلف في نسبته، تطبيع العربية، عدم مطابقة أجزاء كلمات أخرى، شاهد اللبن، تقديم الآداب عند الفزع وحجب الرموز، عدم إثبات اتهام، عدم تحذير خاطئ من كلمة «كلمات»، عدم تصديق هوية نبوية آلياً، عدم إعطاء درجة للتكرار، الامتناع عند غياب الشاهد، عدم تنفيذ تعليمات مدخلة في المنام، تصدير المراجع مع النص، البحث العربي، وفحص مسودات JSON والروابط غير الآمنة والنص الناقص.

فحص JavaScript بـ `node --check`، وتجميع Python نحوياً. لا حزم مطلوبة للتشغيل أو الاختبارات.

## المتصفح

فُحصت الواجهة العربية بصرياً في Chrome ضمن المعاينة. جُرّب نموذج اللبن وظهرت مراجع البخاري 7006 والبخاري 7046 ومسلم 2263. جُرب الحفظ الاختياري وظهر السجل في الدفتر. اكتُشف عدم توافر `crypto.randomUUID()` في معاينة HTTP وصُحّح إنشاء معرف السجل المحلي، ثم أُعيد اختبار الحفظ بنجاح.

جُرب البحث عن ابن سيرين وفتح بطاقته مع حالة «مستبعد من القراءة»، والبحث الذي لا يجد نتيجة مع زر التعافي. نُزّلت قاعدة JSON من زر الواجهة فعلياً وفُحصت البايتات؛ طابقت قاعدة المشروع واحتوت 49 مرجعاً و32 قاعدة و28 مدخلاً. أداة مراقبة حدث التنزيل انتهت بمهلة رغم وصول الملف؛ لم يُعامل ذلك كفشل للتنزيل.

## عرض الصفحة

فُحص العرض عبر إطار معاينة مستقل يملك viewport فعلياً للعناصر المتجاوبة، وليس محاكاة هاتف أو تغييراً لبصمة المتصفح:

| عرض الإطار CSS px | عرض المحتوى بعد شريط التمرير | scrollWidth | النتيجة |
|---|---:|---:|---|
| 320 | 305 | 305 | لا تجاوز أفقي |
| 390 | 375 | 375 | لا تجاوز أفقي |

| 1440 | 1425 | 1425 | لا تجاوز أفقي |

فُحصت كذلك مكتبة المصادر عند 390، وكانت 375/375 دون تجاوز. عائلة الخط المحسوبة Cairo، والملف المحلي يطابق ملف Cairo المستخدم في المستودع ببصمة Git `025bdcf309daab2eb481ed249061478f7df836fc`. شوهد اتصال الحروف بصرياً.

## ما لم يُختبر أو يُعتمد

لم يجر اختبار هاتف Android أو iPhone حقيقي، أو لوحة مفاتيح هاتف، أو ميكروفون بإذن فعلي، أو صوت عربي مثبت ولهجة كويتية. لم يُصدّر PDF مستقل لمراجعته بصرياً؛ الزر يفتح طباعة المتصفح. لم تجر شهادة وصول كاملة أو فحص جميع قارئات الشاشة أو التكبير 200%. ليست مراجعة علمية أو تحقيقاً لكامل الكتب، ولا دليلاً على صحة تعبير حلم معين.

النشر يتحقق بسير GitHub Actions، ويقارن بصمات ملفات المشاريع الأخرى قبل الرفع. حالة النشر الحالية تُؤخذ من تشغيل السّير نفسه؛ وجود الشفرة في GitHub وحده ليس إثباتاً أن الرابط حي.
