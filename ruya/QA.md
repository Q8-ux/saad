# التحقق المنفذ وحدوده

## منطق القراءة

مجموعة Node Test Runner تغطي ترابط مخطط corpus v2، وحجز المصدر المختلف في نسبته، وتطبيع العربية، وعدم مطابقة أجزاء الكلمات، وتغير النتيجة بتغير الفعل والنفي والفاعل والصفة والضرر. ومن حالات الانحدار المهمة: شرب اللبن مقابل رؤيته أو سكبه، المطر غير المؤذي مقابل السيل، الماء الصافي مقابل الكدر، المفتاح مع فعل الفتح، والحية دون تعيين شخص أو إثبات سحر.

تغطي الاختبارات كذلك تقديم الآداب عند الفزع وحجب القراءة الرمزية، الامتناع عند غياب الشاهد، عدم إعطاء نسبة صدق للتكرار، عدم تنفيذ تعليمات داخل نص المنام، سلامة أثر المصادر في التصدير، وفحص مسودات JSON والروابط غير الآمنة. الرقم النهائي للحالات هو ما يطبعه `npm test`؛ لا يُثبت نجاح الاختبار صحة تأويل حلم حقيقي.

فحص JavaScript بـ `node --check`، وتجميع Python نحوياً. لا حزم مطلوبة للتشغيل أو الاختبارات.

## المتصفح

الفحص البصري السابق في Chrome أثبت عمل الاتجاه العربي والحفظ المحلي والحالات الفارغة وتنزيل corpus. بعد إدخال المحرك v2 يجب أن تتضمن جولة القبول: نموذج اللبن، والمطر غير المؤذي، والمشهد المنفي، والمنام المفزع، وحالة الامتناع، مع فتح أثر المصدر من النتيجة.

يجب إبقاء اختبار البحث عن ابن سيرين وفتح بطاقته مع حالة «مستبعد من القراءة»، والتأكد من أن أي قراءة فعلية لا تستشهد به. كما يجب أن يطابق تنزيل JSON مخطط الإصدار الثاني: 70 مصدراً، 33 قاعدة، 28 مدخلاً، 8 أعمال، 12 مقطعاً، 9 أنماط و9 دعاوى.

## ما لم يُختبر أو يُعتمد

لم يجر اختبار هاتف Android أو iPhone حقيقي، أو لوحة مفاتيح هاتف، أو ميكروفون بإذن فعلي، أو صوت عربي مثبت ولهجة كويتية. لم يُصدّر PDF مستقل لمراجعته بصرياً؛ الزر يفتح طباعة المتصفح. لم تجر شهادة وصول كاملة أو فحص جميع قارئات الشاشة أو التكبير 200%. ليست مراجعة علمية، ولا تحقيقاً لكامل الكتب، ولا اختبار دقة على مجموعة أحلام ذات نتائج معلومة، ولا دليلاً على صحة تعبير حلم معين.

النشر يتحقق بسير GitHub Actions، ويقارن بصمات ملفات المشاريع الأخرى قبل الرفع. حالة النشر الحالية تُؤخذ من تشغيل السّير نفسه؛ وجود الشفرة في GitHub وحده ليس إثباتاً أن الرابط حي.
