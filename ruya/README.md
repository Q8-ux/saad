# رؤيا — قراءة مشهد المنام بالمصادر

منصة عربية RTL بخط أميري محلي مرخّص تقرأ **المشهد** لا الكلمة المنفردة: من فعل ماذا، وبأي شيء، وما صفته، وهل نُفي الفعل أو وُجد ضرر. ثم تقارن هذا الوصف بشواهد محررة من قاعدة محلية وتعرض قوة المصدر منفصلة عن ملاءمة المشهد ونقص السياق. تعمل دون مفاتيح أو حسابات، ولا تستخدم نموذجاً لغوياً خارجياً.

النتيجة قراءة ترجيحية محدودة، وليست فتوى أو تعبيراً معتمداً أو تنبؤاً بالغيب. يمكن للمحرك أن يمتنع، وأن يقدّم آداب المنام المكروه بدلاً من التأويل، وأن يطلب قرينة مفقودة.

## التشغيل

اخدم هذا المجلد عبر HTTP، ثم افتح `index.html`. لا تفتحه بـ `file://` لأن المتصفح يحتاج تحميل `corpus.json`.

```bash
cd ruya
python3 -m http.server 8080
```

الاختبارات دون تثبيت حزم:

```bash
cd ruya
npm test
npm run check
```

## المحتوى الفعلي

- 70 سجلاً مرجعياً وإحالة، تشمل الأصول الشرعية، والضوابط المؤسسية، والمصنفات، وسجلات المخطوطات، ومواضع تراثية محددة الصفحة.
- 33 قاعدة موصولة بأصولها، مع فصل النص والاستنباط وضوابط المنتج، ومنها الفصل بين قوة المصدر وملاءمة تنزيله.
- 28 مدخلاً موضوعياً للبحث؛ بعضها شواهد خاصة وبعضها يصرّح بعدم وجود دليل خاص، وستة منها رُبطت بمواضع تراثية مشروطة.
- 8 سجلات أعمال: عملان نشطان للمقارنة، وستة سجلات بحث أو حجر ببليوغرافي مفصولة الهوية.
- 12 مقطعاً محرراً على مستوى الموضع، و9 أنماط مشهد، و9 دعاوى تفسيرية ذات صياغة آمنة وحدود صريحة.
- 22 إحالة تاريخية محجوزة، ورد ذكرها في مقدمة ابن شاهين؛ لم تتحقق نسخها أو نسبتها.
- 5 خرائط بصرية للمشهد، والمصادر، والمنهج، وآداب المنام المكروه.

هذه الأعداد **ليست 70 كتاباً كاملاً** ولا حصراً لكل المصادر. المواد التراثية المستخدمة حالياً ملخصات تحريرية لمواضع بعينها، لا نسخاً من الكتب. `tools/build-corpus.py` هو الملف المحرر؛ يولد `corpus.json` بصورة قابلة للتكرار. فحص الموضع لا يساوي اعتماد كل محتوى الكتاب أو صحة تنزيله على الرائي. لا توجد مراجعة شرعية مستقلة حتى الآن. انظر [BOOK-CORPUS.md](./BOOK-CORPUS.md).

## الوظائف

كتابة أو فتح ملف TXT محلي، إملاء المتصفح عند الضغط، سياق اختياري، تحليل مشاهد ومطابقة أفعال وصفات، استرجاع قراءات وشواهد مع روابطها، أسئلة متابعة، بحث عربي، فلاتر، بطاقة مصدر، دفتر محلي باختيار المستخدم، حذف وتصدير، تنزيل نص القراءة، نسخ، وطباعة المتصفح. يمكن تصدير JSON للمراجع واستيراد مسودات مصادر في ذاكرة الجلسة مع منع دخولها في المحرك.

الصوت يعتمد على دعم المتصفح والأصوات المثبتة؛ لا نضمن لهجة كويتية أو صوتاً رجولياً، ولم يُربط VoiceStudio أو ElevenLabs. الإملاء قد يرسل الصوت إلى مزود المتصفح. لا يبدأ أي تسجيل أو نطق تلقائياً.

## الخصوصية

القراءة الحالية محلية، دون تحليلات أو طلبات إلى مزود تفسير. الاستضافة تحتفظ بسجلاتها المعتادة. الدفتر في `localStorage` وغير مشفر وغير متزامن؛ المواقع الأخرى ضمن أصل GitHub Pages نفسه ليست معزولة عنه. لا تستخدمه لبيانات حساسة. لا تُرسل نصوص المنام إلى مستودع أو سير تحويل الوثائق. `source-documents/` للمصادر العامة المأذونة فقط.

## ضوابط الإسناد

لكل سجل معرف وموضع ورابط وحالة فحص وحقوق وتاريخ مراجعة. `catalog_only` و`manuscript_record_checked` يثبتان وجود السجل لا قراءة المخطوط، و`attribution_disputed` مستبعد من القراءة. الإحالات التاريخية لا تُعتمد تلقائياً. أصول الآداب والضوابط العامة منفصلة عن الشواهد الخاصة؛ لا ندّعي أن آية عامة تثبت معنى رمز، ولا أن ثبوت حديث خاص يجعل تطبيقه على حلم جديد يقينياً.

افتح [RESEARCH.md](./RESEARCH.md) لخطة الاستكمال العلمية، و[INTEGRATIONS.md](./INTEGRATIONS.md) لحالة المسارات، و[QA.md](./QA.md) لحدود الاختبار.

## النشر

سير `deploy-ruya.yml` ينسخ آخر حزمة GitHub Pages ناجحة من `main` ويحدّث مجلد `ruya/` فقط، ثم يتحقق من بصمات بقية الملفات. يعيد إدراج رؤيا بعد نجاح سير النشر العام للمستودع إذا أعاد البناء من قائمة ثابتة. لا يغير نطاقات المشاريع أو روابطها. لا تُنشر الأدوات والاختبارات ومدخلات المستندات ضمن حزمة الموقع.
