# رؤيا — مصادر تعبير الرؤى وقراءة أولية

نسخة عربية RTL بخط Cairo، تعمل دون بناء أو مفاتيح أو حسابات، وتسترجع شواهد محررة من قاعدة محلية. المشروع ليس جهة إفتاء أو معبّراً بشرياً أو تنبؤاً بالغيب. لا يستخدم الإصدار الحالي نموذجاً لغوياً خارجياً.

## التشغيل

اخدم هذا المجلد عبر HTTP، ثم افتح `index.html`. لا تفتحه بـ `file://` لأن المتصفح يحتاج تحميل `corpus.json`.

```bash
cd ruya
python3 -m http.server 8080
```

الاختبارات دون تثبيت حزم:

```bash
cd ruya
npm test
npm run check
```

## المحتوى الفعلي

- 49 سجلاً مرجعياً وإحالة: 17 موضعاً قرآنياً، 12 حديثاً من الصحيحين، 5 أبواب بحث في السنة، 5 إحالات تفسير، 5 فتاوى/تفريغات، و5 مصنفات/فهارس تراثية.
- 32 قاعدة موصولة بأصولها، مع فصل النص والاستنباط وضوابط المنتج.
- 28 مدخلاً للرموز: 13 شاهداً خاصاً و15 مدخلاً يُصرَّح فيه بعدم وجود دليل خاص في النواة.
- 18 إحالة تاريخية محجوزة، ورد ذكرها في مقدمة ابن شاهين؛ لم تتحقق نسخها أو نسبتها.
- 3 خرائط بصرية للمصادر والمنهج وآداب المنام المكروه.

هذه الأعداد سجلات وإحالات، وليست 49 كتاباً كاملاً ولا حصراً لكل المصادر. `tools/build-corpus.py` هو الملف المحرر؛ يولد `corpus.json` بصورة قابلة للتكرار. فحص الموضع لا يساوي اعتماد محتوى الكتاب أو صحة تنزيله على الرائي. لا يوجد اعتماد شرعي مستقل حتى الآن.

## الوظائف

كتابة أو فتح ملف TXT محلي، إملاء المتصفح عند الضغط، سياق اختياري، استرجاع شواهد مع روابطها، بحث عربي، فلاتر، بطاقة مصدر، دفتر محلي باختيار المستخدم، حذف وتصدير، تنزيل نص القراءة، نسخ، وطباعة المتصفح. تصدير JSON للمراجع. استيراد مسودات مصادر JSON في ذاكرة الجلسة مع منع دخولها في المحرك.

الصوت يعتمد على دعم المتصفح والأصوات المثبتة؛ لا نضمن لهجة كويتية أو صوتاً رجولياً، ولم يُربط VoiceStudio أو ElevenLabs. الإملاء قد يرسل الصوت إلى مزود المتصفح. لا يبدأ أي تسجيل أو نطق تلقائياً.

## الخصوصية

القراءة الحالية محلية، دون تحليلات أو طلبات إلى مزود تفسير. الاستضافة تحتفظ بسجلاتها المعتادة. الدفتر في `localStorage` وغير مشفر وغير متزامن؛ المواقع الأخرى ضمن أصل GitHub Pages نفسه ليست معزولة عنه. لا تستخدمه لبيانات حساسة. لا تُرسل نصوص المنام إلى مستودع أو سير تحويل الوثائق. `source-documents/` للمصادر العامة المأذونة فقط.

## ضوابط الإسناد

لكل سجل معرف وموضع ورابط وحالة فحص وحقوق وتاريخ مراجعة. `catalog_only` لا يثبت قراءة الكتاب، و`attribution_disputed` مستبعد من القراءة. الإحالات التاريخية لا تُعتمد تلقائياً. أصول الآداب والضوابط العامة منفصلة عن الشواهد الخاصة؛ لا ندّعي أن آية عامة تثبت معنى خاصاً لرمز.

افتح [RESEARCH.md](./RESEARCH.md) لخطة الاستكمال العلمية، و[INTEGRATIONS.md](./INTEGRATIONS.md) لحالة المسارات، و[QA.md](./QA.md) لحدود الاختبار.

## النشر

سير `deploy-ruya.yml` ينسخ آخر حزمة GitHub Pages ناجحة من `main` ويحدّث مجلد `ruya/` فقط، ثم يتحقق من بصمات بقية الملفات. يعيد إدراج رؤيا بعد نجاح سير النشر العام للمستودع إذا أعاد البناء من قائمة ثابتة. لا يغير نطاقات المشاريع أو روابطها. لا تُنشر الأدوات والاختبارات ومدخلات المستندات ضمن حزمة الموقع.
