# المسارات المناسبة وحالتها الفعلية

| المسار أو الأداة | التطبيق في رؤيا | الحالة |
|---|---|---|
| ذوق الواجهات | اتجاه واحد هادئ، Cairo، نهاري وليلي، نموذج واضح | طُبق في ملفات الواجهة |
| إتقان الواجهات | نموذج، حالات فارغة، دلالات الفلاتر، RTL، استجابة للجوال، اختبارات الوظائف | طُبق ضمن النطاق؛ حدود الأجهزة في QA.md |
| المكتبة البصرية | ثلاث خرائط دقيقة: مسار القراءة، مراتب الصلة، وآداب المنام المكروه | تعمل في صفحة أصول التعبير |
| البحث والفهرسة العربية | تطبيع التشكيل والألف والياء والتاء المربوطة، بحث متعدد الحقول وربط المعرفات | يعمل محلياً في engine.mjs |
| الرصد والاستخلاص | أصل كل مادة وحالتها وحقوقها، وحجز المصادر غير المراجعة | نُفذ السجل والتحقق؛ لا رصد دوري مفعّل |
| MarkItDown المشترك | مشروع ruya/source-documents داخل نطاق الوثائق لسير المستودع الموجود | مربوط بسير التحويل العام؛ لم تُرفع كتب أو تُحوّل ملفات في هذه المهمة |
| الإدخال الصوتي | SpeechRecognition بالعربية عند الضغط فقط مع معالجة فشل الإذن | مبرمج؛ يعتمد على جهاز المتصفح، لا يُساوى بـ VoiceStudio |
| القراءة الصوتية | speechSynthesis بصوت عربي مثبت وبدء/إيقاف صريحين | مبرمجة؛ لم يثبت صوت كويتي رجالي |
| الخصوصية والأرشفة والتصدير | حفظ اختياري محلي، حذف، TXT/JSON وطباعة | تعمل؛ غير مشفرة ومعزولة فقط بحدود أصل المتصفح |
| مراجعة الجودة والسيناريوهات | اختبارات الامتناع، مصدر غير موثق، رموز مخيفة، خطأ المطابقة، ومراجع التصدير | اختبارات فعلية في tests/ |
| NVIDIA / Kimi / نماذج أخرى | لا توجد بيانات اعتماد مُعدّة لهذه المنصة | غير متصل؛ لا يُقال إن النموذج رُكّب أو أن له استخداماً مجانياً مضموناً |
| VoiceStudio / ElevenLabs | يلزمان خدمة وتهيئة صوت وحقوقه | غير متصلين |
| Phone Harness | يحتاج هاتفاً أو بيئة اختبار متاحة | لم يجر اختبار جهاز Android/iPhone فعلي |
| OpenWA / WhatsApp OTP | ليس ضرورياً لقراءة محلية لا تتطلب حساباً | لم يُركب ولم تُرسل رسائل |
| سداد | لا متجر أو اشتراك طُلب لهذا المشروع | لم يُركب أو يُفعّل دفع |
| REA / free-claude-code / Hermes | أدوات تطوير لا تُمنح بها واجهة الموقع صلاحيات إدارية | لم تُثبّت داخل المنتج؛ لا صلاحيات جديدة للزوار |
| مسارات التشريعات والمذكرات والمسرح والسيناريو وAPK | لا تخدم تعبير الرؤى ضمن نطاقها المعتمد | لم تُطبق على هذا المشروع |

المسارات ليست حزم وظائف تُثبت لمجرد ذكرها. الحالة أعلاه تفصل ما يعمل الآن عما يتطلب حساباً أو خدمة أو مراجعة مستقلة.
