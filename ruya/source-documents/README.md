# استقبال المصادر

هذا المجلد داخل نطاق `**/source-documents/**` لسير MarkItDown المشترك في المستودع. ضع فيه فقط نسخ المصادر العامة التي يُسمح بمعالجتها. لا تضع أحلام المستخدمين أو بياناتهم أو مفاتيح API هنا.

لم تُرفق كتب كاملة في هذه المهمة؛ المجلد مهيأ للاستقبال فقط. ناتج التحويل أثر بحثي لا يصبح مادة معتمدة في `corpus.json` تلقائياً. تبقى مراجعة الصفحة والنسبة والحقوق ودرجة الحديث خطوة مستقلة. قوالب الاستيراد المحلية في المنصة تحفظ حالة `draft-unreviewed`.
