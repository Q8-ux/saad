نظام عربي باتجاه من اليمين إلى اليسار يجمع ٥٢ أداة ومصدرًا: قائمة اختبار الاختراق، والمستودعات العشرين لتحليل الأجهزة، وأدوات الفيديو الأربع لقراءة مستودعات GitHub.

## ما يعمل مباشرة؟

| الوظيفة | التنفيذ |
|---|---|
| مشاريع وتحقيقات وملاحظات | حفظ محلي في IndexedDB داخل المتصفح |
| الملفات الأصلية | تُحفظ كـ Blob مع التقرير؛ حد الملف ٦٤ ميغابايت |
| SHA-256 | حساب على كامل الملف داخل المتصفح |
| التوقيعات والنصوص والعشوائية | فحص محدود مع إظهار الإزاحات والحدود |
| PCAP وPCAPNG | قراءة حزم محفوظة، ملخص IPv4/TCP/UDP/ICMP/ARP وIPv6؛ حتى ٢٠ ألف حزمة |
| HAR | إحصاءات وطلبات محدودة بدون قيم الترويسات أو الاستعلامات وأجسام الطلبات |
| APK وZIP | قراءة الفهرس ورصد المسارات غير الآمنة بدون استخراج أو تنفيذ |
| كود نصي | مؤشرات مطابقة نصية أولية، مع أرقام الأسطر؛ ليست تدقيقًا شاملًا |
| التقارير | JSON وMarkdown وطباعة إلى PDF من المتصفح |
| النسخ الاحتياطي | مشاريع وتقارير وملفات؛ إعادة حساب البصمات والتحليل عند الاستيراد |
| خطوات التحقيق والتعلّم | قوائم تحقق وتقدم محفوظ لكل مشروع |
| مكتبة المصادر | بحث وتصنيف وشرح عربي للوظائف والمتطلبات وروابط المصادر |

الحفظ مرتبط بمتصفح وعنوان النسخة المستخدمة. نقل البيانات بين GitHub Pages والكمبيوتر أو تغيير المتصفح يحتاج تصدير نسخة احتياطية واستيرادها. حذف بيانات الموقع من المتصفح يحذف البيانات المحلية؛ لا توجد مزامنة أو نسخة سحابية تلقائية. النسخة الاحتياطية تتضمن الملفات الأصلية كما هي، حتى لو حُجبت أنماط أسرار في التقرير.

## تشغيل نسخة الكمبيوتر

على ويندوز، نزّل `Misbar-Windows.zip` من الإصدار وفكّه ثم افتح `Misbar.exe`. لا تحتاج نسخة EXE إلى تثبيت Python. يفتح البرنامج الواجهة على `http://127.0.0.1:8765/`. إغلاق نافذة البرنامج يوقف الخدمة المحلية.

لتشغيل المصدر باستخدام **Python 3.10 أو أحدث**:

```sh
cd arabic-security-lab
python lab.py
```

أو افتح `Start-Windows.cmd` على ويندوز، أو نفّذ `sh start.sh` على لينكس وماك. الواجهة والخادم لا يحتاجان حزم Python إضافية. خط Cairo مرفق ويعمل محليًا.

النسخة المحلية تكتشف برامج موجودة في PATH، إضافة إلى TShark وcapinfos في مسار Wireshark المعتاد على ويندوز. عدم اكتشاف أداة لا يثبت أنها غير مثبتة؛ قد تكون خارج PATH أو على جهاز آخر.

### التحليلات الخارجية المنفّذة

عند تثبيت الأداة المناسبة، تظهر في قائمة طريقة التحليل:

| الأداة | الإجراء المسموح |
|---|---|
| Binwalk | كشف التوقيعات؛ بدون استخراج |
| TShark | ملخص حتى ٢٠٠٠ حزمة من ملف محفوظ؛ بدون التقاط حي |
| capinfos | معلومات ملف الالتقاط |
| GNU strings | استخراج نصوص من الملف |
| Semgrep | قواعد محلية مرفقة للبايثون وجافاسكربت وتايبسكربت، مع إيقاف المقاييس وفحص التحديثات |

تُستخدم نسخة مؤقتة من الملف، ومهلة ٧٥ ثانية، وأوامر ثابتة دون shell أو معاملات حرة من المستخدم. المخرجات النصية محدودة إلى ٥١٢ كيلوبايت وتُحجب أنماط أسرار شائعة. التحليلات الخارجية تستخدم البرامج المثبتة لدى المستخدم ولا تُضمَّن هذه البرامج في مِسبار.

## REA وGhidraMCP

تم التحقق من المستودعات الرسمية بتاريخ ٢٦ نوفمبر ٢٠٢٦. REA إطار ربط وتحليل محلي؛ تختلف قدراته الفعلية حسب النسخة المنشورة ومزود التحليل والبرامج المثبتة. اقرأ [المتطلبات الحالية](https://github.com/morluto/rea/blob/main/docs/reference/supported-targets.md) و[التثبيت الرسمي](https://github.com/morluto/rea/blob/main/docs/getting-started/installation.md).

قسم الكمبيوتر يتيح تنزيل إعداد MCP لتشغيل **REA المثبت بالفعل**:

```json
{"mcpServers":{"rea":{"command":"rea","args":["mcp"]}}}
```

زر اكتشاف REA في نسخة الكمبيوتر يجري جلسة MCP فعلية (`initialize` ثم `tools/list` مع التصفح). لا يستدعي `tools/call` ولا يثبت اتصال مساعد خارجي. يظهر الخطأ إذا لم يُثبت REA أو لم يكتمل الاتصال. GhidraMCP جسر منفصل يحتاج إضافة وإصدار Ghidra متوافقين، ولا يُثبت تلقائيًا.

## ما يحتاج تجهيزًا منفصلًا؟

- قراءة الشريحة بواسطة flashrom تحتاج مبرمجًا وتوصيلًا وجهدًا مناسبين.
- rtl_433 وSniffle وHackRF تحتاج أجهزة استقبال أو لوحات متوافقة؛ نشر الواجهة لا يجعل الكمبيوتر يلتقط إشارات لاسلكية وحده.
- PulseView يحتاج محللًا منطقيًا للالتقاط الحي أو تسجيلًا محفوظًا.
- Qiling يحتاج معمارية ومكتبات وبيئة مناسبة؛ لا يشغّل كل صورة ثابتة مباشرة.
- ESPHome وTasmota يحتاجان التحقق من توافق اللوحة ووسيلة الاسترجاع. لا ينفّذ مِسبار كتابة أو مسحًا أو بثًا راديويًا.
- Home Assistant يشغّل تكاملات محلية وسحابية حسب نوع الجهاز والتكامل؛ وجوده لا يجعل كل الأجهزة مستقلة عن السحابة.
- بعض المصادر مثل TryHackMe وHack The Box وBurp وميزات CodeQL لها حدود مجانية أو خطط مدفوعة.

إدراج الأداة في المكتبة يعني توفير دليل وروابط ومتطلبات، ولا يعني تثبيتها أو اختبارها على جهاز المستخدم. الحالة «مكتشف محليًا» تعني العثور على الملف التنفيذي؛ لا تثبت توافق العتاد أو اكتمال جميع المتطلبات.

## حدود النتيجة

الفحص الأولي لا يثبت أمان ملف أو نظام. العشوائية المرتفعة قد تعني ضغطًا أو تشفيرًا، والتوقيع قد يكون تطابقًا عرضيًا. فحص الكود النصي محدود ويحتاج مراجعة سياق. تحليل الحزم لا يفك تشفير TLS ولا يستعيد مفاتيح البلوتوث. HAR يعرض حتى ٢٠٠ طلب، وتوقيعات الملف تغطي أول ٨ ميغابايت والنصوص أول ٤ ميغابايت حتى ١٠٠ نتيجة.

الخدمة مربوطة بـ loopback فقط، وتتحقق من Host وOrigin ورمز الجلسة للكتابة، ولا تسمح بـ CORS أو أوامر حرة أو قراءة مسارات ملفات يقدمها متصفح خارجي. استخدم الأدوات في مختبرات أو أنظمة ضمن نطاق عمل مسموح.

## الاختبارات

```sh
node --test tests/analysis.test.mjs
python -m unittest discover -s tests -p 'test_*.py' -v
```

تغطي البصمات وPCAP بترتيبي البايتات وPCAPNG وHAR وحجب الأسرار وZIP والمسارات غير الآمنة، إضافة إلى عزل الخدمة المحلية ومنع حقن الأوامر وجلسة MCP وتجميع صفحات الأدوات. تُبنى نسخة ويندوز في GitHub Actions وتُختبر جاهزية EXE باستعلام HTTP محلي.
