# استوديو الكتابة للآيفون — نسخة الشاشة الرئيسية

الرابط: https://q8-ux.github.io/saad/family-online-iphone/

افتحه في Safari ثم أضفه إلى الشاشة الرئيسية من قائمة المشاركة. إن ظهر خيار «فتح كتطبيق ويب» فعّله. لا تحتاج كلمة مرور إضافية، ويحتاج المحرر الإنترنت.

هذه نسخة ويب مستقلة النافذة. تستورد ملفات الواجهة الحالية من `family-online-studio` وتثبّت مسار أصولها الأصلي حتى تعمل الخطوط والتصدير. لا تنسخ نصوص المسرحية، ولا تغيّر الخادم أو واجهة المحرر الأصلية، ولا تخزّن API أو المسودات في service worker.

يقرأ المشغّل أحدث `index.html` لاختيار إصدارات CSS وJavaScript الحالية؛ لا يعرض المحتوى داخل iframe. اختيار مسارات الأصول محصور بأصل GitHub Pages ومسار المحرر. لا يوجد رمز API داخل هذه الملفات.

المشروع الأصلي للآيفون في [family-online-ios](../family-online-ios/README.md). يحتاج توقيع Apple قبل توزيعه كتطبيق أصلي.
