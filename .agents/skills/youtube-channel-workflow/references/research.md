# البحث وتقييم الفرصة

## اجمع عينة قابلة للمقارنة

1. حدّد الجمهور واللغة والصيغة: فيديو طويل أو Shorts أو بث. افصلها في التحليل.
2. ابحث عن المشكلة أو السؤال، ثم اجمع القنوات الصغيرة والمتوسطة والكبيرة، والنتائج الحديثة والضعيفة أيضًا. استخدم البحث العام للمعلومات العامة، أو YouTube Data API المتاح. نتائج البحث عينة انتقائية وليست تعدادًا للسوق.
3. استهدف مبدئيًا 3–5 قنوات و10–20 فيديو لكل اتجاه عندما يكون البحث هو المطلوب؛ هذا هدف عمل لا شرط يعطل طلبًا صغيرًا. اذكر نقص البيانات بدل اختلاقها.
4. سجّل عنوان الفيديو ورابطه ومعرّف القناة والنشر والرصد والمشاهدات والصيغة والمجال وطريقة اختيار العينة. استخرج التواريخ الفعلية دون افتراض أن تاريخ زحف محرك البحث هو تاريخ النشر.
5. قارن فيديوهات متقاربة العمر. إذا توفرت لقطتان من البيانات، احسب فرق المشاهدات على فرق الزمن للمقطع نفسه. من لقطة واحدة استخدم فقط «متوسط مشاهدات يومي منذ النشر» مع إيضاح قصوره.

## اقرأ النتيجة دون المبالغة فيها

احسب وسيط المشاهدات ووسيط متوسط المشاهدات اليومي وحجم العينة وعدد القنوات. قارن النجاح عبر قنوات متعددة؛ قد تعكس نتيجة قناة واحدة مهارة صاحبها أو مصدر جمهور لا يمكن تقليده. استبعد المقاطع غير المنشورة أو ذات النشر المستقبلي، وأظهر الاستبعادات. لا تحوّل نسبة المشاهدات إلى المشتركين إلى مقياس وصول أو ربح.

لا تقارن قيمة `outlier` إلا إذا عرفت خط أساس القناة وفترة القياس وحجم عيّنته. عند عدم وجود تاريخ كافٍ قل إن المؤشر غير محسوب. لا تضع درجة فرصة تبدو إحصائية من أوزان اعتباطية.

## رتّب القرار عمليًا

اعرض جدولًا موجزًا: الاتجاه، الدليل، ما يمكن للمستخدم إضافته، ساعات/تكلفة إنتاج تجربة، أقوى اعتراض، ودرجة الثقة. رتّب بالتالي:

1. قابلية إنتاج قيمة أصلية متكررة ضمن الوقت والميزانية المتاحين.
2. وجود إشارة طلب تتكرر في أكثر من قناة، مع مراعاة انتقائية العينة.
3. تكلفة اختبار صغيرة، ووصول واضح إلى المادة والمصادر.

عند نقص الأدلة اقترح اختبار ثلاثة فيديوهات مختلفة السؤال ضمن جمهور واحد. لا تعامل ثلاثة فيديوهات كدليل نهائي على ربحية مجال. اجعل هدف الاختبار تعلّم الموضوع والتغليف والاحتفاظ، وقارن بالقناة نفسها متى أمكن.

## فرق مصادر البيانات

| البيانات | المصدر المقبول | الحد |
|---|---|---|
| عنوان، نشر، مشاهدات عامة | صفحة يوتيوب أو Data API مع وقت الرصد | لا تعطي حجم البحث أو الإيراد |
| مصدر الزيارات والاحتفاظ ووقت المشاهدة | Studio أو Analytics المأذون للقناة | ليست متاحة سرًا للمنافسين |
| الإيراد | تقرير القناة المأذون مع المدة والعملة | لا تعممه على بلد أو قناة أخرى |
| التقدير المالي الخارجي | مصدره وصيغته وافتراضاته | تقدير فقط؛ لا يستخدم كإيراد محقق |
| تعليقات الجمهور | النص الفعلي ورابطه وتاريخه عند توفره | لغة التعليق لا تثبت بلد صاحبه |

## استخدم الأداة

تقوم `workflow.py analyze` بتجميع المشاهدات بحسب المجال والصيغة مع حد عمر افتراضي 7–90 يومًا. ترفض الصفوف ذات البيانات الخاطئة، وتدرج أسبابها. لا تجمع أكثر من لقطة للفيديو نفسه في هذا التحليل؛ استخدم لقطة واحدة موحدة الزمن قدر الإمكان. تعرض الأداة تحذير تفاوت أوقات الرصد، ولا تصف المتوسط بأنه «ترند».
