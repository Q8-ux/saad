# صيغ الإدخال والتشغيل

شغّل `scripts/workflow.py --help` وراجع الملف قبل تنفيذه لأول مرة. لا يحتاج إلى مكتبات إضافية أو شبكة. لا يجلب بيانات ولا يشغّل خدمات إنتاج. خزّن المدخلات والمخرجات خارج مجلد المسار، واحفظ المخرجات النهائية وفق مسار الملفات الحالي. يمنع البرنامج الكتابة فوق ملف أو مجلد موجود.

## تحليل عينة قنوات

```bash
python3 scripts/workflow.py analyze /absolute/sample.csv --output /absolute/analysis.json
```

CSV بترميز UTF-8 بهذه الحقول المطلوبة:

```csv
niche,channel_id,video_id,published_at,observed_at,views,format,url
تعليم,c1,v1,2026-10-01T10:00:00Z,2026-11-01T10:00:00Z,3100,long,https://www.youtube.com/watch?v=EXAMPLE
```

المعرّفات أعلاه أمثلة بنيوية، وليست قناة أو فيديو حقيقيًا. استخدم البيانات الفعلية في البحث. `format` إحدى `long,short,live` من الرصد المباشر؛ لا تستنتج Shorts من المدة وحدها. تقبل التواريخ ISO 8601 مع منطقة زمنية صريحة. `views` عدد صحيح غير سالب؛ الصفر قيمة صحيحة، والخانة الفارغة مجهولة وتُستبعد.

خيارا `--min-age-days` و`--max-age-days` افتراضيًا 7 و90 يومًا. تظهر الاستبعادات بأسبابها. ترفض الأداة التكرار في معرّف الفيديو، أو مصدرًا غير HTTPS، أو رصدًا/نشرًا في المستقبل، أو رصدًا أسبق من النشر. تجمع بحسب المجال والصيغة، وتعرض الوسطاء وعدد القنوات. `lifetime_views_per_day` هو المشاهدات ÷ العمر عند الرصد؛ ليس سرعة نمو حديثة ولا حجم بحث أو تقدير ربح. لا تصنّف الأداة المجالات كفائز وخاسر، بل تعرضها أبجديًا.

## تجهيز حزمة الإنتاج

اكتب المحتوى أولًا داخل JSON. المثال التالي نموذج توضيحي، وليس فيديو منتجًا أو حقيقة تحتاج مصادر:

```json
{
  "title": "كيف ترتب فكرة فيديو واحدة؟",
  "audience": "مبتدئو صناعة المحتوى العربي",
  "language": "ar",
  "description": "خطوات عملية لترتيب فكرة فيديو قبل التسجيل.",
  "tags": ["صناعة المحتوى", "يوتيوب"],
  "sources": [],
  "claims": [],
  "scenes": [
    {
      "id": "s1",
      "narration": "ابدأ بسؤال واحد تريد أن يخرج المشاهد بإجابته.",
      "visual": "مذكرة المستخدم وفيها سؤال واحد بخط واضح.",
      "duration_seconds": 8,
      "claim_ids": [],
      "asset_source": "تصوير أصلي سيُنتج لاحقًا",
      "rights_status": "pending"
    }
  ],
  "thumbnails": [
    {"text": "فكرة واحدة", "concept": "سؤال كبير بجانب مخطط من ثلاث خطوات"}
  ]
}
```

كل مصدر هو `{"id":"ref1","url":"https://...","note":"سبب الاعتماد"}`. كل ادعاء هو `{"id":"fact1","text":"...","source_ids":["ref1"],"verified":true}`. تشير `verified` إلى أن الكاتب راجع المصدر؛ البرنامج يتحقق من البنية والروابط، ولا يتحقق من صحة العبارة على الإنترنت. لا تضعها `true` لمجرد وجود رابط. تظهر الادعاءات غير المتحققة في سجل منفصل ولا تُضاف كملاحظات داخل كلام الراوي.

`scenes[].id` فريد، و`duration_seconds` موجب ومحدود؛ توقيته تقديري دائمًا في هذه الحزمة. `rights_status` إحدى `owned,licensed,not-needed,pending` وهي تصريح يُدخل بعد فحص الأصل. `claim_ids` يجب أن تشير إلى ادعاءات موجودة؛ `source_ids` إلى مصادر موجودة. تأكد بنفسك من وجود رابط لكل ادعاء فعلي في نص الراوي؛ لا يستخرج البرنامج الادعاءات آليًا. `thumbnails` من تصور واحد إلى ثلاثة؛ لا تمثل ملفات صور.

```bash
python3 scripts/workflow.py package /absolute/brief.json --output-dir /absolute/new-pack
```

تنتج الأداة:

- `script-draft.md`: نص الراوي مقسمًا إلى مشاهد.
- `storyboard.csv`: خطة اللقطات بتوقيت تقديري وحالة الحقوق.
- `metadata.json`: عنوان ووصف ووسوم وفصول فارغة حتى اكتمال الفيديو.
- `thumbnails.md`: التصورات النصية للصورة المصغرة.
- `production.md`: الزمن التقديري وسجل المصادر والادعاءات والأصول المعلقة.
- `manifest.json`: حالة `planning_only` و`video_rendered=false` و`published=false`.

تعتمد الحزمة على المحتوى المدخل. لا يُعد نجاح التصدير تحققًا من الحقائق أو إنتاجًا للصوت أو الفيديو أو إثباتًا لتراخيص الأصول. لا تعِد توقيت اللقطات التقديري إلى SRT أو فصول منشورة دون قياس الوسائط النهائية.
