# مرصد — نسخة الويب

واجهة عربية لعرض تقارير مرصد وتحليلها داخل المتصفح، مع معلومات المتصفح واختيار أجهزة بلوتوث أو منافذ تسلسلية متوافقة بإذن المستخدم. ملفات JSON والأرشيف والرسوم والتصدير تُعالج محليًا؛ لا توجد خدمة رفع أو مفاتيح API أو مكتبات خارجية.

مسار التشغيل: `https://q8-ux.github.io/saad/mirsad/`.

## الاستخدام

- «فتح تقرير الفحص»: اختر JSON من برنامج مرصد أو الصق محتواه. تظهر الأوقات الأصلية ومصدر التقرير؛ لا يُعرض كفحص حي.
- «قراءة المتصفح»: يعرض المعلومات التي يبلّغ عنها المتصفح، وقد تكون مقربة.
- «البلوتوث»: اختيار جهاز عبر نافذة المتصفح، ثم محاولة قراءة خصائص قياسية يسمح بها الجهاز. لا يقرأ الموقع جميع الأجهزة أو MAC أو RSSI تلقائيًا.
- «الأجهزة المتصلة»: اختيار منفذ تسلسلي إذا دعمه المتصفح؛ تُعرض معرّفاته دون فتحه أو الكتابة عليه.
- «التقارير والأرشيف»: تنزيل HTML وCSV وJSON، وحفظ آخر 20 تقريرًا داخل هذا المتصفح. يمكن طباعة HTML وحفظ PDF.

لا يستطيع موقع عادي مسح الواي فاي أو قراءة منافذ عمليات ويندوز وجدار الحماية مباشرة. تُعرض هذه البيانات من تقرير برنامج الكمبيوتر. وظائف التشويش والراديو المتخصص وبرمجة اللوحات غير مضافة.

## التحقق

شغّل `node --test tests/*.test.cjs` لاختبار الاستيراد والتحقق من البيانات وحماية HTML وCSV والأرشفة وحدود قراءة المتصفح. لا تتضمن الملفات المنشورة بيانات تجريبية أو تقارير مستخدمين.

النشر يستعيد آخر حزمة Pages ناجحة، ويستبدل مجلد `mirsad` فقط، ويتحقق من بصمات بقية المواقع. إدراج المشروع في النشر العام يتم بخطوة إضافية تحفظ بقية منطق النشر.
