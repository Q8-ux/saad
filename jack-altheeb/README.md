# جاك الذيب V5 🐺

لعبة طاولة خليجية تنافسية تعمل من المتصفح، بهوية نيون سينمائية وتجربة عربية RTL. تدعم اللعب الفردي ضد الذيب الآلي والغرف الخاصة من لاعبين إلى أربعة.

## المزايا

- لعب فردي سريع ضد خصم آلي يقيّم الحركات المتاحة.
- غرف خاصة أونلاين برمز قصير مع استعادة الجلسة بعد انقطاع الاتصال.
- قواعد مكتملة: إخراج بالستة، الصيد، الخانات الآمنة، مسار النهاية والفوز بأربع قطع.
- وضع تعليمي واقتراح للحركة الأنسب ومؤثرات صوتية اختيارية.
- هوية عربية احترافية بخطي Cairo وChanga، وشخصيات ورسومات أصلية.
- واجهة متجاوبة ومهيأة للوضع الأفقي وقابلة للتثبيت كتطبيق PWA.
- حسابات، خبرة، عملات، ترتيب لاعبين، وحماية أساسية عبر Helmet وتحديد معدل الأوامر.

## التشغيل محليًا

```bash
npm install
DEV_AUTH_BYPASS=1 npm start
```

ثم افتح `http://localhost:3000`.

## الفحص

```bash
npm run check
npm audit --omit=dev
```

## النشر على Render

- المستودع: `Q8-ux/saad`
- Root Directory: `jack-altheeb`
- Build Command: `npm install`
- Start Command: `npm start`
- Health Check Path: `/healthz`
- المتغيرات المطلوبة: `DATABASE_URL` و`JWT_SECRET`

> الغرف محفوظة في ذاكرة الخادم في هذه النسخة. للإنتاج متعدد النسخ أو للاستعادة بعد إعادة التشغيل، انقل حالة الغرف إلى Redis أو مخزن دائم.
