# موقع المحامية حصة العبيد

موقع عربي احترافي لمكتب محامية مستقلة، يتضمن:

- صفحة تعريف شخصية للمحامية
- عرض التخصصات القانونية
- شرح طريقة العمل
- نموذج طلب استشارة
- مولد مذكرات قانونية أولية يعمل داخل المتصفح
- نسخ وطباعة المسودة
- حفظ آخر مسودة محليًا في المتصفح
- تصميم متجاوب مع الهاتف والتابلت

## المعاينة

يمكن تشغيل الموقع بفتح ملف `index.html` مباشرة، أو نشر المجلد عبر GitHub Pages / Render / Netlify.

## قبل النشر الرسمي

يجب استبدال:

- صورة المحامية
- رقم الهاتف وواتساب
- البريد الإلكتروني
- عنوان المكتب
- ساعات العمل
- المؤهلات والخبرات الرسمية
- التخصصات الفعلية

## ملاحظة قانونية

مولد المذكرات ينشئ مسودة أولية فقط من البيانات المدخلة، ولا يغني عن المراجعة القانونية المهنية.
