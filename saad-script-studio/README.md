# استوديو سعد للسيناريو

أداة مستقلة لكتابة السيناريو بالعربية وتنسيقه، مع تخطيط المشاهد وكاتب مساعد اختياري.

- التشغيل: https://q8-ux.github.io/saad/saad-script-studio/
- المصدر: https://github.com/Q8-ux/saad/tree/main/saad-script-studio

## ما يعمل مباشرة

محرر للمشاهد والوصف والشخصيات والحوار وتوجيه الأداء والانتقالات، مع اختصارات Enter وTab وAlt+1…7. الحفظ محلي على الجهاز. لوحة المشاهد تغيّر ترتيب المشهد مع كامل محتواه. توجد مراجعة لبنية الفقرات وتقارير الشخصيات ونسخ للمسودة.

يحوّل النص المنظم إلى مشروع مستقل. أمثلة الإدخال:

```text
داخلي - مكتب - نهار
يفتح جابر الرسالة.
جابر: من أرسلها؟
خالد: لا أعرف.
```

للأسماء التي تأتي في سطر منفصل، استخدم `@جابر` قبل سطر الحوار، أو عدّل نوع الفقرة من شريط التنسيق. التحويل لا يضيف أحداثاً أو حواراً إلى النص الأصلي.

تُستورد ملفات المشروع JSON وFDX وFountain وTXT وMarkdown. لا تُستبدل المشاريع الحالية عند الاستيراد. يُصدّر النص إلى FDX فعلي بصيغة XML وFountain وTXT، والمشروع إلى JSON يتضمن الخطة والنسخ. ملف FDX يشمل النص وأنواع الفقرات وأرقام المشاهد والغلاف الأساسي؛ لا يضمن الاحتفاظ بتنسيق الإنتاج المتقدم أو الحوار المتوازي من أدوات أخرى.

تصدير PDF يستخدم محرك طباعة المتصفح ودعم الخطوط العربية فيه. اختر **حفظ كملف PDF** وأوقف ترويسة وتذييل المتصفح. هناك غلاف واتجاه RTL وخط Cairo مستضاف داخل المشروع. عدد الصفحات في الواجهة تقديري؛ العدد الفعلي يتحدد عند الطباعة. العربية في ملف FDX محفوظة، لكن عرضها في برنامج Final Draft نفسه يخضع لقيود البرنامج على RTL.

## الكاتب المساعد

من إعدادات الكاتب، أدخل مفتاح Gemini API مخصصاً لك. تُكتشف نماذج `generateContent` المتاحة للمفتاح بدلاً من تثبيت اسم نموذج قد يتوقف مستقبلاً.

1. أدخل الفكرة والبطل والهدف والعائق والمخاطر والنهاية الاختيارية.
2. اطلب خطة من ٢ إلى ٢٤ مشهداً.
3. راجع الخطة وعدّل عناوين المشاهد وملخصاتها.
4. اعتمد الكتابة. تُحفظ المسودة السابقة كنسخة قبل اعتماد أول مشهد جديد.
5. يمكن الإيقاف واستكمال المشاهد المتبقية. تحفظ الأداة كل مشهد مكتمل وتمنع اعتماد الردود المقطوعة أو غير الصالحة.

المفتاح يبقى في ذاكرة الصفحة ولا يُحفظ في GitHub أو ملفات المشروع أو localStorage. يُرسل إلى Google في ترويسة `x-goog-api-key` عبر HTTPS. يتطلب إعادة الاتصال بعد إعادة تحميل الصفحة. الفكرة والخطة والنص تُرسل إلى Google عند طلب التوليد؛ راجع إعدادات حسابك وشروط المزوّد. لا يرسل المحرر المحلي النص تلقائياً إلى أي خدمة.

**التوليد يستخدم حصة حساب API، وقد تكون له تكلفة.** إحصاءات الجلسة تعرض الطلبات والرموز التي يعيدها المزوّد ولا تحسب قيمة فاتورة. اكتشاف النموذج لا يضمن توافر حصته عند الكتابة. الاختبارات تستخدم ردوداً محاكاة؛ لم يُختبر التوليد على حساب حقيقي أثناء الإنشاء لعدم وجود مفتاح مصرح به.

الحفظ داخل المتصفح لا ينتقل تلقائياً إلى جهاز آخر. صدّر ملف المشروع للنسخ الاحتياطي والاستيراد على جهاز آخر. لا ترفع سيناريو خاصاً إلى المستودع العام؛ GitHub يستضيف شفرة الأداة فقط.

## التطوير والتحقق

الأداة ساكنة بلا اعتماديات تشغيل. لخدمة النسخة المحلية:

```sh
python -m http.server 8080 --directory saad-script-studio
```

لفحوص المنطق وتفاعلات الواجهة باستخدام Node.js 22 أو أحدث:

```sh
cd saad-script-studio
npm ci
npm test
npm run check
python -m unittest discover -s deployment -p 'test_*.py'
```

تستخدم اختبارات الواجهة DOM محاكياً، ولا تحل محل الاختبار البصري في المتصفح. اختُبر PDF العربي من HTML الطباعة بمحرك WeasyPrint وفُحصت صفحاته بصرياً؛ يجب أيضاً مراجعة أول تصدير من الجهاز والمتصفح المستخدمين فعلياً.

النشر يعيد آخر حزمة Pages ناجحة ويضيف مجلد هذه الأداة فقط، ثم يتحقق من بصمات ملفات المواقع الأخرى. يرفض النشر إذا لم يجد حزمة سابقة أو حدث تغيير خارج مجلد المشروع. يعمل أيضاً بعد نشر الحزمة العامة للمستودع لضمان إعادة إضافة الأداة.
