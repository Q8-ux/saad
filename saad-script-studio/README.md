# استوديو سعد للسيناريو

أداة عربية مستقلة لكتابة السيناريو، أُعيد بناؤها وفق «الخريطة الذهنية لبناء القصة» التي قدمها المؤلف.

- التشغيل: https://q8-ux.github.io/saad/saad-script-studio/
- المصدر: https://github.com/Q8-ux/saad/tree/main/saad-script-studio

## البناء قبل المشهد

تبدأ بخمس خطوات: جوهر القصة، الشخصية والحدث، السطر التمهيدي، ورقة الإيقاع، ثم خطة المشاهد. يوثّق الجوهر البطل والمشكلة والحاجة والهدف والعائق والمخاطر وسبب التحرك ووسائل الحل. ترتبط كل محاولة بنتيجة وقرار جديد، مع رابط يؤدي إلى الحدث التالي.

بطاقات الشخصيات تحفظ الرغبة والحاجة والدافع والمعرفة والقوس، مع الدور وحجمه الرئيسي أو الثانوي. بطاقات العلاقات تحفظ الرابط والتوتر والتغير وحدود معرفة الطرفين. تغيير اسم الشخصية يحدّث مراجعها في العلاقات والإيقاعات. حذفها يترك المراجع للمراجعة، فلا يمحو العلاقات تلقائيًا.

ورقة الإيقاع من ٢ إلى ٢٤ وحدة، وخطة دفعة الكتابة من ٢ إلى ٦٠ مشهدًا. قد يمتد إيقاع إلى عدة مشاهد. يسمح إيقاع النهاية أو التأمل بالإغلاق دون افتعال عائق. للتلفزيون قد تصنع الشخصية الحدث، وللفيلم قد يكشف الحدث الشخصية؛ يمكن الجمع بين الاتجاهين.

اعتماد الأساس مرتبط ببصمة محتواه. تغيير الدافع أو المعرفة أو العلاقة أو المخاطر أو ترتيب الإيقاع يستلزم مراجعة جديدة ويمنع التوليد من خطة قديمة. النسخ تحفظ النص والخطة وأساس القصة معًا. تعرض المراجعة البيانات الناقصة والتنبيه إلى تغير ترتيب المشاهد عن الخطة. هذه فحوص اكتمال واستمرارية، وليست شهادة على جودة النص أو خلوه من الثغرات الأدبية.

الصورة الأصلية مرفقة في نافذة المرجع. ملاحظاتها غير الواضحة، ومنها أرقام الإنتاج والصيغ غير المكتملة، محفوظة كحدود للمرجع ولم تُحوّل إلى قوانين كتابة.

## الكتابة والتصدير

يمكن الكتابة الحرة دون مفتاح. الخطة اليدوية تحول الإيقاعات إلى عناوين وبطاقات، ثم تفتح هيكلًا بفقرات وصف فارغة. المحرر يدعم عنوان المشهد والوصف والشخصية والحوار وتوجيه الأداء والانتقال، واختصارات Enter وTab وAlt+1…7. نقل المشهد يحمل محتواه وبياناته الدرامية.

تُستورد ملفات المشروع JSON وFDX وFountain وTXT وMarkdown كمشاريع مستقلة. تُرحّل مشاريع الإصدار الأول مع حفظ النص والركائز والنسخ، دون اختراع بيانات بناء مفقودة.

تُصدّر ملفات FDX وFountain والنص، أو المشروع الكامل مع الشخصيات والعلاقات والإيقاعات والنسخ. ويمكن طباعة السيناريو وملف البناء إلى PDF. أسلوب الحبر الملوّن هو الافتراضي: خط النسخ العربي بطابع يدوي، عناوين بالأحمر، أسماء بالأخضر، متن بالأزرق ورسمة قلم ودفتر صغيرة. الواجهة نفسها بخط القاهرة. يمكن اختيار خط القاهرة للطباعة من نافذة التصدير. ملف FDX يحفظ النص والأنواع وأرقام المشاهد؛ أسلوب الحبر يخص PDF.

تصدير PDF يفتح الطباعة؛ اختر حفظ PDF وأوقف ترويسة المتصفح. الخطوط مستضافة داخل المشروع. عدد الصفحات في الواجهة تقديري، والزمن يحتاج قراءة أداء. العرض العربي داخل Final Draft يتبع دعم ذلك البرنامج لاتجاه RTL وتنسيق الإنتاج.

## الكاتب المساعد الاختياري

يمكن ربط مفتاح Gemini API خاص بك، وتُكتشف نماذج generateContent المتاحة للحساب. تطوير الأساس يملأ الفراغات ولا يستبدل قيم المؤلف، ثم يراجعها المؤلف ويعتمدها. توليد الخطة يراعي الإيقاعات والمعرفة والعلاقات. كتابة المشاهد متتابعة وتحفظ كل مشهد مكتمل، وتتيح الإيقاف والاستكمال. الرد المقطوع أو غير الصالح لا يُعتمد.

المفتاح يبقى في ذاكرة الصفحة ولا يُحفظ في localStorage أو ملف المشروع؛ يُرسل في ترويسة x-goog-api-key. الفكرة والنص يُرسلان إلى Google عند طلب التوليد فقط. التوليد يستهلك حصة الحساب وقد تكون له تكلفة. إحصاءات الرموز لا تحسب الفاتورة. فُحص الاتصال والتوليد بردود محاكاة؛ لم يُختبر حساب حقيقي لعدم وجود مفتاح مصرح به.

المشاريع محفوظة على الجهاز. نقلها إلى جهاز آخر يتطلب تصدير ملف المشروع. المستودع العام يستضيف شفرة الأداة ومثالًا خياليًا مستقلًا؛ لا يحتوي على نصوص المؤلف الخاصة.

## التطوير والتحقق

الأداة ساكنة بلا اعتماديات تشغيل. باستخدام Node.js 22 أو أحدث:

```sh
npm ci
npm run check
npm test
python -m unittest discover -s deployment -p 'test_*.py'
python -m http.server 8080
```

اختبارات المنطق والواجهة تستخدم DOM محاكيًا. فُحص عرض PDF العربي بمحرك WeasyPrint وصفحات مرسومة؛ تبقى مراجعة أول تصدير من المتصفح الفعلي مطلوبة. النشر يستعيد آخر حزمة Pages ناجحة، ويضيف مجلد الأداة فقط، ثم يتحقق من بصمات جميع الملفات الأخرى. يُرفض إذا تغير ملف خارج المشروع.

خط Cairo بترخيص SIL OFL في assets/OFL-Cairo.txt، وخط Aref Ruqaa بالترخيص نفسه في assets/OFL-ArefRuqaa.txt. المصدر الأصلي للخطوط: https://github.com/google/fonts .


## التصور السينمائي

من قسم «التصور السينمائي» اختر مشهدًا أو اقترح تغطية لجميع المشاهد التي لا قائمة لها. يحافظ القسم على السيناريو ويستخرج الأفعال المرئية كمسودة لقائمة لقطات قابلة للتحرير. يمكن تعديل الوظيفة ووجهة النظر وحد المعرفة ونوع كل لقطة ووصفها وحركتها وإضاءتها وصوتها، وإعادة ترتيبها أو إضافة لقطة يدوية. الرسومات توضح حجم اللقطة فقط، وليست صورًا مولدة للشخصيات.

يحفظ ملف المشروع مرجع الاستمرارية وقوائم اللقطات. يتنبه القسم إلى تغيير نص المشهد أو بطاقته أو مرجع المسلسل بعد إعداد القوائم؛ المراجعة اليدوية تثبت تحديث المرجع. تحفظ النسخ هذا القسم مع النص والبناء، وتبقى البيانات قابلة للاستيراد بعد تحديث الأداة. لا تعطي فحوص الاكتمال حكمًا على جودة الإخراج أو الأدب.

تتوفر برومبتات مستقلة للصورة والفيديو، وملف نصي للقوائم والبرومبتات، وطباعة PDF بخط النسخ المتصل والحبر الملون. المقترحات محلية دون مفتاح API. لا تنفذ الأداة توليد صور أو فيديو، ولا ترسل السيناريو إلى الموقع المرجعي.

مرجع المصطلحات: https://vvsvs.pro/cinematique — أسماء تقنيات عامة وتفسيرات وبرومبتات أصلية للأداة، دون نسخ مكتبة الموقع أو صوره. لا يوجد تكامل API مع VVSVS.
