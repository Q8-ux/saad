# عقاري X — المكتب العقاري

منصة بثلاث لغات (العربية والإنجليزية والأردو) لعروض المكتب، وطلبات العملاء، والمعاينات، ومراجعة الإعلانات، والصفقات والعمولات. بيانات التشغيل في خادم وقاعدة Postgres منفصلين؛ GitHub Pages يستضيف الواجهة فقط.

- [موقع العملاء](https://q8-ux.github.io/saad/aqari-x/)
- [إدارة المكتب](https://q8-ux.github.io/saad/aqari-x/admin/)
- [تقرير المسارات والبحث](docs/routes-and-research.md)
- [سيناريو اختبار الهاتف](docs/mobile-qa.md)

النشر المعتمد على GitHub Pages يفصل واجهة العملاء والإدارة عن قاعدة البيانات وأسرار الخادم. يستخدم إجراء النشر نسخة المواقع السابقة ويحافظ على ملفات المشاريع الأخرى.

## ما يعمل

- مظهر نهاري افتراضي، مع خيار ليلي يحفظ اختيار الزائر. لا توجد بوابة دفع؛ العمولات سجلات متابعة داخلية فقط.

- بحث بالعربية والإنجليزية والأردو يجمع النوع والقسم والمحافظة والمنطقة والسعر والغرف والمساحة والمواصفات، ويفهم عبارات مثل «شقة بالجابرية ثلاث غرف بحدود ٥٠٠».
- اختيار مناطق المحافظات الست، المفضلة، مقارنة ثلاثة عقارات، حفظ البحث في الحساب، ومساعد محادثة يحتفظ بشروط البحث ويشرح بيانات الإعلان والمواعيد والعمولة من بيانات المكتب مع تحقق محلي من الفلاتر والأسعار.
- واجهة العملاء والإدارة والإعلانات الأولية مترجمة، مع Cairo محلي واتجاه RTL للعربية والأردو وLTR للإنجليزية. نصوص الإعلانات الجديدة التي يكتبها المعلن تبقى بلغتها الأصلية إلى أن تضاف ترجمتها.
- مساعد توليدي متصل بـOpenAI، مع تسجيل السؤال وتحويله إلى نص، وقراءة الرد بصوت سحابي عربي وإنجليزي وأردي. يستخدم gpt-5.4-mini للمحادثة، gpt-transcribe للتحويل إلى نص، وgpt-realtime-2.1-mini للصوت. يبدأ الميكروفون بفعل الزائر فقط، ويتوقف عند الإغلاق أو تغيير اللغة. عند تعذر الخدمة يبقى البحث المحلي متاحاً مع رسالة واضحة.
- إضافة عقار بصور حقيقية، ضغط الصور في المتصفح، انتظار مراجعة المكتب، وتصحيح البيانات قبل النشر.
- طلبات عملاء مركزية ومطابقة عروض داخل الميزانية ومراحل متابعة الطلب.
- جدول معاينات يحدده المدير، بتوقيت الكويت، وفترة حجز واحدة لكل موعد ومنع التزامن بقاعدة البيانات.
- إغلاق صفقة بسعر نهائي، وعمولة ثابتة أو نسبة بحسب الاتفاق، وتسجيل تحصيل بمرجع إيصال.
- أرشيف ملفات داخلي، سجل تدقيق، صلاحيات مستخدمين، تصدير بيانات العمل، وطباعة المقارنات وملفات العقارات.
- مسودات محتوى ومخطط فيديو وأرشيف حزم قابل للتنزيل. توليد NVIDIA اختياري عند إدخال المفتاح والنموذج الصحيح.

## حدود مهمة

العروض التسعة من HTML الذي قدمه صاحب المشروع؛ تظهر كـ«بيانات أولية» لأن التوفر غير مؤكد. لا توجد صور أصلية معها؛ الرسوم محايدة وموسومة بوضوح. فرق البدل لا يمثل سعر العقار، وإيجار الشقة في عمارة السالمية لا يمثل إيجار العمارة كلها.

حساب المالك أو الوسيط لا يثبت هويته أو ملكيته. التسجيل بالبريد وكلمة المرور، دون ادعاء إرسال OTP أو توثيق البريد والهاتف. يستخدم المدير رابط إعداد سرياً لمرة واحدة لإنشاء حسابه؛ لا يوجد رمز مدير في المصدر أو دخول إداري من localStorage.

رابط واتساب للمكتب يعمل، مع زر عائم بأيقونة فقط دون عرض الرقم في صفحات الزوار. تهيئة Meta تحفظ مشفرة؛ الإرسال الآلي وOTP غير منفذين. عامل MarkItDown مرفق وغير منشور أو متصل بالواجهة؛ الفيديو الصوتي والرندر عبر OpenShorts يحتاجان عاملاً خارجياً ومفاتيحه. لا تنشر المنصة إعلاناً على حساب اجتماعي تلقائياً.

## التشغيل والتطوير

يتطلب Node 24. المصدر يستخدم HTML/CSS/ES modules، وpg للخادم.

```bash
npm ci --ignore-scripts
npm test
npm run check
npm run dev
```

للخادم: `DATABASE_URL` و`VAULT_KEY` و`SETUP_TOKEN_HASH` و`ALLOWED_ORIGINS`. لا تضع قيم هذه المتغيرات في Git. التطبيق المنشور يتصل بعنوان `public/config.mjs`، وهو عنوان عام وليس مفتاحاً.

```bash
npm run bundle
```

تنتج الحزمة `.bundle/index.mjs`. نشر الخادم على Neon Functions يستخدم ملف ZIP يحتوي `index.mjs` في الجذر، وبيئة خادم خاصة. هوية المشروع: `spring-fog-50994544`، فرع التشغيل: `br-tiny-bread-b9dsnadw`، الوظيفة: `office`. هذه معرفات وليست أسراراً. راجع وثائق Neon الرسمية قبل أي تغيير في النشر أو البيئة.

`Publish Aqari X Office` ينشر `public/` فقط ويحافظ على كل الملفات المنشورة للمشاريع الأخرى من آخر نسخة GitHub Pages ناجحة. لا ينشر قاعدة البيانات أو المفاتيح أو عامل التحويل. هذا الإجراء لا يعيد نشر الخادم تلقائياً عند تغيير مصدره؛ يلزم نشر حزمة الخادم أيضاً.

## التحقق

اختبارات منطق البحث والأموال والخزنة والمستندات في `tests/*.test.mjs`. اختبارات HTTP في `tests/api-smoke.mjs` لا تعمل ضمن النشر ولا تتصل بالتشغيل افتراضياً؛ تتطلب إعداد QA عبر stdin، وتستخدم بيانات اصطناعية فقط. نتائجها المجمعة في `tests/api-results.json` حين تكتمل. لا تنشئ بيانات تجربة داخل فرع التشغيل.

التصدير الإداري نسخة من سجلات العمل، وليس نسخة شاملة لاستعادة النظام: لا يتضمن حسابات المستخدمين أو كلمات المرور أو الجلسات أو مفاتيح المزودين أو بايتات الملفات. يجب اعتماد خطة نسخ واستعادة خارجية قبل التشغيل التجاري المكثف.

## الأصول

خط Cairo مستضاف محلياً مع رخصته SIL Open Font License في assets/fonts/Cairo-OFL.txt، وأعيد استخدام ملفه من الأصول المتاحة في هذا المستودع. الرسوم الهندسية SVG من كود المشروع وليست صوراً للعقارات. لا يوجد اعتماد على SDK التصميم الأصلي أو شفرة telemetry المرفقة في HTML السابق.

## المساعد السحابي والصوت

طلبات المزود تمر عبر خادم المكتب؛ لا مفاتيح في الواجهة أو Git. المفتاح المحلي في ملف .env.local المتجاهل. في التشغيل يحفظ المفتاح بتشفير مغلف: مفتاح RSA خاص محمي بخزنة VAULT_KEY، واعتماد المزود مغلف بالمفتاح العام. لا تعيد واجهات الزوار أو التصدير أي سر.

المحادثة تستقبل العروض العامة والشروط وسياقاً محدوداً من المحادثة؛ لا تصل إلى العملاء أو مستنداتهم الخاصة. اختيار العقار والأسعار والوحدات يتحقق منه الخادم. لا تنفذ المحادثة حجزاً أو دفعاً أو إرسال رسالة. الصوت مولّد بالذكاء الاصطناعي، والرد الطويل يقرأ باختصار مع بقاء النص الكامل في المحادثة.

الحد اليومي من إعدادات المكتب يطبق على كل خدمة على حدة: المحادثة، قراءة الرد، وتحويل التسجيل إلى نص؛ صفر يوقفها. تسجل أعداد التوكن وعمليات الصوت دون حفظ تسجيلات الزوار. تذاكر القراءة موقعة وقصيرة الأجل ومقيدة بجلسة المساعد.

اختبار tests/cloud-api.mjs اختياري وصريح، ويتصل بالمزود باستهلاك فعلي عند تمرير عنوان الخادم. لا يعمل ضمن اختبارات النشر الآلية.


### رصد السوق التجريبي

دفعة من 29 ملخص مواصفات خارجية من 4Sale وسكن مع فلاتر المصدر وحالة أولية. التفاصيل والحدود في [توثيق الرصد](docs/market-research.md). الاستيراد الجماعي المأذون به يدعم JSON/CSV، ومرفقات صور وMP4/WebM بعد تسجيل التفويض. التواصل للزوار مع المكتب فقط.


### صور التجربة

تستخدم واجهة 1.3.1 عشر صور مولدة أصلية لتوضيح العروض المرجعية الـ38، مع تسمية مرئية بثلاث لغات. الصور لا تمثل العقارات الفعلية. تظل الصور المرفقة الأصلية أولى بالعرض. ملفات الصور في `public/assets/generated/`، وأوصاف التوليد في [توثيق الصور](docs/generated-property-images.md).
