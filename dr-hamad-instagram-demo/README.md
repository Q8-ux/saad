# DrHamad.s Instagram preview

A responsive Instagram-style preview of three knee education carousels.

- Eight slides per carousel (24 total), Arabic RTL and bundled Al-Mohanad fonts.
- Silver/light blue, navy/surgical blue, and beige/burgundy themes.
- Open posts, previous/next arrows, keyboard navigation, mobile swipes, jump dots.
- Local saved posts and direct share links, with no simulated follower statistics.

Serve this directory with any static server. No build or external dependencies.
The page is a visual demo, not a live Instagram integration. Existing medical text is retained from the source carousel slides; slide eight is a save/share closing slide.
