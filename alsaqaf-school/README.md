## الهوية والأصول

- خط AL-Mohanad بثلاثة أوزان، من أصول المستودع الموجودة؛ ملفات الخطوط الأصلية محفوظة دون تعديل.

- صورة الكتاب صورة تعليمية توضيحية مولدة، وليست صورة مبنى المدرسة أو منشأة فعلية، وهذا موضح في وصف الصورة والتعليق المرئي.
- النصوص غير الوصفية للشواهد في البطاقات وصياغة الترحيب نصوص تحريرية للموقع؛ لم تُنسب رؤية أو رسالة أو إنجازات غير مؤكدة إلى المدرسة.

## التشغيل والتحقق

افتح `dist/index.html` محلياً، أو قدم `dist/` بواسطة أي خادم ملفات ثابتة. الموقع يعمل على GitHub Pages في المسار `/saad/alsaqaf-school/`؛ كل الأصول نسبية. الروابط الداخلية تستخدم معرفات موجودة بالصفحة، وروابط إنستغرام الخارجية تحمل `noopener noreferrer`.

تعمل قراءة المحتوى والروابط دون JavaScript. JavaScript يحسّن قائمة الجوال ومؤشر القسم النشط فقط، ولا يستخدم localStorage أو خدمات تتبع أو طلبات API. لا توجد مفاتيح أو أسرار في ملفات الموقع. ملفات المحتوى والأصول ذاتية الاستضافة ولا تعتمد على تحميل إنستغرام لعرض الصفحة.
