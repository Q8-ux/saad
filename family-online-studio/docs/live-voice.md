# إصلاح التحدث المباشر

زر «تحدث مباشر» يبدأ الاتصال عند ضغط المستخدم بعد اكتمال تحميل المساعد. إذا لم يكتمل التحميل بعد، يبقى زر «ابدأ الحديث المباشر» متاحًا عند جاهزية الخدمة. لا يُطلب الميكروفون تلقائيًا عند فتح الصفحة أو تبديل نطاق العمل.

نُقلت أزرار البدء والكتم والإنهاء قبل الوصف والمرفقات، وأصبحت النافذة قابلة للتمرير على الهاتف. تظهر رسائل الخطأ قرب الأزرار. يحافظ العميل المشترك `assets/chunks/studio-realtime.mjs` على المرفقات وسجل الكتابة وأوامر التنفيذ الصوتية القائمة.

يستخدم العميل معالجة الميكروفون الآمنة نفسها: إعدادات صوت مدعومة، ومحاولة واحدة بإعدادات المتصفح الافتراضية عند عدم دعم القيود. لا تتكرر مطالبة الإذن بعد رفضه. يوضّح الفرق بين انتظار الإذن، والاتصال، والانقطاع، وانشغال الميكروفون بتطبيق آخر. يُحترم الكتم المختار أثناء انتظار الإذن، وتُوقف أي قناة ميكروفون متأخرة إذا سبقها إلغاء.

انقطاع WebRTC العابر يمنح الاتصال ١٠ ثوانٍ للتعافي دون فتح جلسة جديدة؛ الفشل المستمر ينهي الميكروفون والاتصال. إذا منع المتصفح تشغيل الصوت يظهر زر تشغيل صوت المساعد. تبقى إعدادات المزود والدخول وعزل الأعمال كما هي.

التحقق: ٢٧ اختبارًا للمحادثة والصوت والمرفقات والتنفيذ، واختبارات دورة حياة Realtime وعقد الخادم. اختُبرت أزرار البدء والكتم ووصول النص والإنهاء داخل المتصفح بمحاكاة للصوت، وبنافذتين ٣٩٠×٦٤٠ و٣٢٠×٤٨٠. لا يستخدم هذا الاختبار الميكروفون الحقيقي أو اتصال مزود حي. اختبار ميكروفون جهاز المستخدم وردّ المزود الفعلي يحتاج جلسة دخول وإذن ميكروفون صالحين على جهازه.
