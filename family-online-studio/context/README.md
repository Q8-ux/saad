# سياق استوديو الكتابة

المسار مطبق في خادم الاستوديو عند تجهيز طلب السينارست. يأخذ هوية العمل من عنوان الطلب والمخطوط الجاري، ويعيد استخدام ذاكرة العمل القائمة. المخطوط مصدر الوقائع؛ ملاحظات الكاتب توجيهات، ومقترحات المساعد ليست أحداثاً معتمدة. أعمال باركود وعائلة أونلاين وخارج الستوري مستقلة.

يحتفظ السياق بالمشهد والفقرة المختارين وترتيبهما وبصمة المصدر. يرفض معرفاً غير موجود. عند تجاوز حجم المشهد يختار الفقرة المطلوبة وما حولها بترتيب القصة ويعلن أن السياق مقتطف؛ ويرفض فقرة تتجاوز الحد وحدها بدلاً من استبدالها بصمت.

يسجل manifest.json التزام الخادم وبصمات ملفات التنفيذ ونتائج التحقق. الملف source/project-context.ts نسخة مراجعة لوحدة عامة من الخادم، وليس بديلاً عن خادم الإنتاج أو وحدة مستوردة في حزمة واجهة GitHub Pages. لا يضم هذا المجلد المخطوطات أو بذور الأعمال أو بيانات الوصول.

التحقق في المصدر الكامل: node scripts/check-project-context.mjs ثم node scripts/check-knowledge-memory.mjs وnode scripts/check-studio.mjs ثم npm run build. نجحت الفحوص الاصطناعية والبناء؛ لا تعني هذه النتيجة اختبار جودة توليد حي أو سلامة كل اقتراح إبداعي. لا يحتاج تغيير السياق الخادمي إلى استبدال حزمة الواجهة أو تغيير بوابة الدخول.
