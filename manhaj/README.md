# منهج

مساحة عربية RTL للمعلمين ورواد النشاط في الكويت، لإعداد الخطط والأنشطة والمواد الصفية. افتح `index.html` عبر خادم ملفات أو GitHub Pages.

## استوديو المعلم — مسار الفوتوشوب

- بطاقات أنشطة وشهادات تقدير وأوراق عمل بمقاسات مربع وأفقي وA4.
- نقل بيانات الفعالية إلى التصميم، وتعديل النص العربي والألوان ورفع صورة وشعار محليين.
- تصدير PNG وحزمة ZIP تحتوي مجلد .comp مع manifest.json وطبقات PNG مستقلة، وفق توثيق Compositor version 11.
- Compositor تطبيق ماك مستقل، وليس محررًا مضمّنًا ولا اتصال API. فك ضغط الحزمة وافتح مجلد .comp في تطبيق متوافق. النص طبقة صورة، وليس نصًا قابلًا للتحرير داخل Compositor.
- اجتاز منشئ ZIP اختبار CRC وبنية الحزمة ومراجع الصور. لم يتم فتح الحزمة في Compositor أو التحقق بصريًا من تصدير العربية. الصور ليست ضمن النسخة الاحتياطية؛ نزّل التصميم قبل مغادرة الصفحة.
- المصدر: https://github.com/robbietilton/Compositor/blob/main/docs/writing-comp-files.md

## جاهز
- حفظ الخطة والفعاليات محليًا باستخدام localStorage.
- إنشاء وتعديل وحذف بطاقات التنفيذ، وبنك من ستة أنشطة مقترحة.
- فهرس 12 كتاب حاسوب للفصل الأول بروابط وزارة التربية؛ لم تُنسخ الكتب ولم يُحلل محتواها. تاريخ مراجعة المصدر: 2026-10-09. افتح المكتبة الرسمية لبقية المواد والفصول، وتحقق من طبعة الكتاب.
- حفظ صور أو PDF حتى 5 MiB للشاهد في IndexedDB، وتنزيلها وحذفها.
- تقرير للطباعة أو الحفظ كـ PDF باستخدام المتصفح، وتصدير CSV عربي.
- نسخة JSON للخطط والفعاليات واستعادتها. المرفقات ليست ضمن النسخة النصية.

## حدود التشغيل
هذه مساحة محلية على الجهاز وليست نظامًا مشتركًا بين المدارس. مسح بيانات المتصفح يمسح البيانات والشواهد. لا تدخل بيانات الطلاب الشخصية. لا توجد مصادقة أو صلاحيات فعلية أو اعتماد رسمي أو دفع أو مساعد AI أو مزامنة تلقائية للمناهج.

## متطلبات المرحلة التالية حسب الأولوية
1. Backend آمن مع فصل بيانات المدارس، حسابات وصلاحيات وتخزين ملفات ونسخ احتياطية.
2. فهرسة المناهج حسب الصف والمادة والفصل والطبعة، وحفظ المصدر وتاريخ التحديث، ثم مراجعة بشرية لربط أنشطة المحتوى بنواتج التعلم.
3. تدقيق عربي بصري للجوال وPDF واختبار الحروف واتجاه النص.
4. الموافقات وسجل التغييرات والتقارير المعتمدة؛ ثم بوابة دفع كويتية إذا اعتمد النموذج التجاري.

## المسارات
أُضيف مسار الفوتوشوب كاستوديو ويب وجسر تصدير حزم إلى Compositor. بقية الأدوات الخارجية السابقة لم تُثبت في هذه النسخة. اختيار مسارات التحليل واستخراج المستندات والصياغة والتصميم والمراقبة المالية يتوقف على تشغيل Backend وصلاحيات المصادر؛ لا تُعد الروابط أو القوالب تكاملًا تشغيليًا.

## التحقق
اجتاز JavaScript فحص `node --check` وفحص معرفات DOM وتطابق مراجع العناصر وعدم وجود روابط ChatGPT. اختبار المتصفح الكامل يتطلب تثبيت Chromium؛ لا يعد تصدير PDF أو الجوال متحققًا بصريًا حتى اكتماله.
