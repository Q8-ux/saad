# استوديو الشطرنج — تطبيق مسار الفوتوشوب

واجهة عربية RTL لإنتاج بطاقات تحدّي للشطرنج: 1080×1080، 1080×1350، 1080×1920. تتيح تغيير العنوان والعبارة واسم اللاعب واللون ووضع الرقعة FEN، وإضافة شعار يختاره المستخدم. لا تحتوي قوالب مقتبسة من مشاريع المستخدم الخاصة.

الصادرات: PNG وJPEG وZIP يحتوي `ChessCard.comp` بطبقات PNG مستقلة للخلفية والرقعة والنص والشعار. يتبع manifest إصدار 11؛ النص نقطي. التصدير محلي ولا يرسل صورة المستخدم إلى الخادم. فتح `.comp` يتطلب Mac يدعم Compositor.

الصفحة مرتبطة باللعبة عبر زر «بطاقة الشطرنج» في غلاف GitHub Pages. لا تقرأ الحالة من iframe خدمة Render؛ يدخل المستخدم FEN يدوياً، أو تمرر أي واجهة موثوقة `?fen=...`. الحالة الافتراضية هي بداية المباراة. ليس محللاً قانونياً لوضع الرقعة ولا مولداً لأفضل نقلة أو نتيجة فوز.

لكانفا: تنزيل PNG ورفعه داخل تصميم المستخدم. لا تربط صفحة عامة بحساب Canva الشخصي للمستخدم ولا تدعي توفر رفع مباشر أو مزامنة. أدوات الموصل داخل جلسة الوكيل يمكنها التعامل مع صورة يعتمدها المستخدم لاحقاً، وفق سياسة عدم إعادة استخدام المشاريع الخاصة.

النشر يستعيد آخر artifact لنشر Pages ناجح ويضيف الاستوديو وزر الغلاف فقط؛ يتحقق من بقاء باقي الملفات دون تغيير. لا يغير الخادم أو محرك اللعب. استخدم `deploy-chess-studio.yml` للنشر؛ أي إعادة بناء كاملة للمستودع لاحقاً تحتاج تضمين هذا المسار والزر أو إعادة تشغيل workflow الاستوديو بعد اكتمالها.

التحقق: `node --test chess-design-studio/tests/core.test.mjs` و`python -m unittest discover -s chess-design-studio/tests`. لم يُجر اختبار واجهة داخل متصفح في البيئة المحلية.
