# كب كت

محرّر فيديو عربي يعمل في المتصفح باستخدام محرك [OpenCut Classic](https://github.com/OpenCut-app/opencut-classic). تُحفظ المشاريع والملفات على جهاز المستخدم عبر تخزين المتصفح. العرض والمعالجة والتصدير محلية.

[افتح محرّر كب كت](https://q8-ux.github.io/saad/kab-kat/)

## استخدام المحرّر

1. استورد فيديو أو صورة أو ملفًا صوتيًا، ثم اضغط زر الإضافة بجوار الملف لإدراجه في الخط الزمني.
2. حدّد مقطعًا لتقصه من الخصائص. حرّك مؤشر التشغيل إلى موضع القطع واختر «تقسيم» لإنشاء مقطعين. أضف عنوانًا عربيًا من زر «نص».
3. اختر المقاس الأفقي أو العمودي أو المربّع ثم صدّر الملف. يدعم المحرّر MP4 وWebM بحسب ترميزات المتصفح والجهاز.

يمكن إدارة المشاريع المحلية من «مشاريعي». التخزين مرتبط بالمتصفح والجهاز الحاليين. التصدير يتطلب متصفحًا حديثًا يدعم WebAssembly وWebCodecs.

## تشغيل المشروع محليًا

من جذر المستودع، يلزم Git وNode.js 22.12 فأحدث.

```bash
cd kab-kat/source
npm ci
npm run dev
```

لإنتاج نسخة ثابتة، شغّل `npm run build` في نفس المجلد. ستجد ملفاتها في `dist/`.
