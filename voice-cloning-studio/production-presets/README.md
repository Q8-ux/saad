# راوي بوحمدان

إعداد إنتاج لصوت رجالي جهوري بالفصحى، للحكايات التاريخية والتشويق.

- الصوت المتاح: Fouad — Deep & Evocative، معرّفه في `bohamdan-narrator.json`.
- الأداء: سرعة طبيعية، وقفات واضحة، هدوء في الرثاء، حضور أكبر عند التحولات.
- المعالجة: دفء بسيط ووضوح للكلمات وضبط ديناميكي؛ لا تغيير لطبقة الصوت أو تسريع للنص.
- تم إخراج تعليق البسوس بهذا الصوت: 306.024 ثانية، مع 20 مقطعًا متوافقًا مع الشرائح.
- فحص الملف تقنيًا: MP3، 48 kHz، ستيريو، نحو ‎−16.43 LUFS وقمة ‎−1.94 dBTP. الفحص التقني لا يحل محل الاستماع.

## إعادة الاستخدام

اقرأ الإعداد وأرسل النص عبر اتصال HeyGen للنطق، ثم طبّق المعالجة المسجلة في `processing`. المفاتيح، إن احتاج التنفيذ إليها، تبقى على الخادم أو في الاتصال الخاص. لا تحفظها في المصدر. أسماء إعدادات الصوت هنا تصف المعالجة اللاحقة؛ ليست معاملات إضافية لواجهة التوليد.

هذا تسجيل لإعداد الإنتاج داخل مسار الأصوات. ليس محرك استنساخ جديدًا، ولا ملفًا مستنسخًا من شخص، ولا اختيارًا أضيف إلى قائمة أصوات Microsoft في الواجهة. لا يتطلب هذا التسجيل استضافة Voicebox أو تغيير المنصة الحالية.

المقاطع الناتجة والأصول الخاصة محفوظة خارج مستودع المصدر؛ يضم هذا المجلد بيانات الصوت العام وإعدادات إنتاجه فقط.

## معالجة ملف مولّد

يتطلب Python 3 وFFmpeg. يحتفظ بالأصل ويرفض الكتابة فوق ملف قائم.

```sh
python3 render_narrator.py --voice narration.wav --effects effects.wav --output bohamdan.mp3
```

احذف `--effects effects.wav` عند معالجة التعليق منفردًا. أداة المعالجة لا تولّد كلامًا جديدًا ولا تنشئ هوية صوتية.
