## الربط مع محرك الشعر

يدعم التطبيق الآن `fcc` ضمن الاختيار الخادمي نفسه الذي يخدم التحليل والكتابة والمراجعة والإصلاح وفحص سلامة المحتوى. تعبر النصوص فقط؛ يبقى التسجيل وتفريغ الصوت والأرشيف على مساراتهما القائمة. يبقى المحرك الحالي افتراضيًا حتى تكتمل الإعدادات وتنجح تجربة فعلية.

| متغير الخادم | القيمة المطلوبة |
| --- | --- |
| `FCC_BASE_URL` | عنوان خادم FCC المملوك للمشروع، عبر HTTPS وينتهي اختياريًا بـ `/v1` |
| `FCC_API_KEY` | رمز Proxy Authentication الخاص ببوابة FCC، محفوظ كسر |
| `FCC_MODEL` | معرّف نموذج صريح متاح في FCC بصيغة `provider/model` |
| `POETRY_AI_PROVIDER` | `fcc` بعد نجاح التجربة فقط |
| `POETRY_AI_FALLBACK_PROVIDER` | اختياري؛ مزود مهيأ، ومحاولة واحدة بعد رفض صريح `429/502/503/504` |

لا يُرسل مفتاح OpenAI إلى FCC؛ يستخدم الربط رمز البوابة وحده. تُرفض عناوين HTTP وlocalhost والعناوين الرقمية وروابط إعادة التوجيه. يطلب المحول JSON ثم يتحقق من المخطط الكامل قبل تمرير الناتج إلى بوابات جودة الشعر القائمة. الرد المبتور أو غير المطابق أو المرفوض أو فشل الشبكة المبهم لا يؤدي إلى إعادة إرسال تلقائي لمزود آخر.

يعرض `/api/admin` للمشرف حالة الدعم والإعداد والاختيار فقط، دون كشف العنوان أو المفتاح. وجود الإعدادات لا يثبت اتصالًا حيًا أو توفر حصة مجانية. `liveVerified: false` يعني أن استجابة حالة الإدارة لا تجري اختبار توليد مدفوعًا تلقائيًا.

## تشغيل خادم دائم

FCC تطبيق Python ولا يعمل داخل Cloudflare Workers أو GitHub Pages. يحتاج كمبيوترًا يعمل أو خادمًا منفصلًا دائمًا. وصول Cloudflare إلى `127.0.0.1:8082` لا يصل إلى كمبيوتر المستخدم.

للتشغيل البعيد، فعّل Proxy Authentication، واجعل واجهة الإدارة محلية أو خلف وصول خاص. اسمح لخادم التطبيق بالوصول إلى `/v1/chat/completions` عبر HTTPS؛ لا تعرض واجهات الإدارة أو جلسات البرمجة للعامة. اضبط داخل FCC مزودًا تملك حق استخدامه ومفتاحه ونموذجه، وراجع قائمة البدائل التي قد تستقبل النصوص.

بعد توفير الخادم: أضف المتغيرات الثلاثة السرية/الخادمية، واختبر بقصة اصطناعية، ثم اختر `fcc` وأعد النشر. تحقق من التحليل وتوليد القصيدة وسلامة JSON والجودة. عند فشل التجربة، أعد `POETRY_AI_PROVIDER` إلى قيمته السابقة وأعد النشر. لا تغيّر بيانات المستخدمين أو قاعدة البيانات.

المجانية والحصص وشروط الاستخدام تعتمد على المزود. لا يوفر FCC نماذج Claude المدفوعة مجانًا بمجرد تشغيل واجهتها، ولا يضمن جودة الشعر العربي أو رصيدًا شهريًا ثابتًا.
