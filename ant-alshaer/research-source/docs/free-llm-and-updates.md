# مزودو الذكاء وتحديث التطبيق

المصدر المرجعي للاكتشاف: https://github.com/open-free-llm-api/awesome-freellm-apis . لا يُنفّذ كود خارجي من الدليل ولا تُستورد إعداداته تلقائيًا.

تعمل مراحل التحليل والكتابة والمراجعة والإصلاح وفحص سلامة المحتوى عبر الاختيار الخادمي نفسه. يبقى OpenAI هو الاختيار الافتراضي القائم. لا تحتاج كتابة النص إلى مفتاحه إذا اختير مزود آخر مهيأ. الصوت والرفع يحتفظان بمساراتهما الحالية.

| الإعداد | الغرض |
| --- | --- |
| POETRY_AI_PROVIDER | openai أو gemini أو groq أو nvidia أو openrouter |
| POETRY_AI_FALLBACK_PROVIDER | مزود ثانٍ مسمى؛ الرجوع مرة بعد رفض 429/502/503/504 فقط |
| GROQ_API_KEY / GROQ_MODEL | مفتاح Groq ونموذجه؛ الافتراضي qwen/qwen3.8-27b |
| GEMINI_API_KEY / GEMINI_MODEL | حساب Gemini ونموذج مفعّل فيه |
| NVIDIA_API_KEY / NVIDIA_MODEL | حساب NVIDIA ونموذج صريح متاح في الحساب |
| OPENROUTER_API_KEY / OPENROUTER_MODEL | نموذج مثبت ينتهي بـ :free |

توضع المفاتيح في إعدادات الخادم فقط. لا يثبت وجود دعم برمجي وجود مفتاح أو حصة مجانية أو جودة شعرية. يحافظ التطبيق على مخطط JSON وعقد الأبيات والمراجعة وسلامة المحتوى قبل الحفظ. لا تبديل عند رد مبتور أو خطأ شبكة مبهم أو مصادقة مرفوضة.

يعرض /api/version معرف البناء؛ يفحصه التطبيق كل دقيقة وعند العودة إليه أو عودة الاتصال. يتحدث تلقائيًا عندما تكون الشاشة خالية ولا يوجد تسجيل أو عمل جارٍ. يؤجل التحديث أثناء القصيدة. صفحات HTML ومسارات API لا تُخزّن مؤقتًا؛ الملفات ذات الأسماء الموقعة تبقى قابلة للتخزين.

النسخة المرتبطة ببوابة GitHub هي «أنت الشاعر» الأصلية. لا تُستبدل بالإصدار الثاني المستقل ولا تُشارك قاعدة بياناته.

## إصلاح التسجيل — 8 نوفمبر 2026

أظهرت السجلات طلبَي تفريغ عاد كل منهما برمز 422؛ لا تكشف السجلات هل كان السبب عدم وجود كلام أو قرار السلامة. أصلح التغيير عدم توافق حقل language مع gpt-transcribe باستعمال languages، مع مهلة محددة وعدم إعادة إرسال صوت مبهمة النتيجة. يوحد التسجيل المباشر مع الملف المرفوع: حفظ النص ثم بدء تحليله تلقائيًا. يميز NO_SPEECH_DETECTED عن فشل إعداد المزود وعن CONTENT_NOT_ALLOWED.

نجح اختبار HTTP اصطناعي على SDK الحقيقي واختبار تسلسل معالج التسجيل. لم يُختبر ميكروفون هاتف المستخدم فعليًا ولم يُعتمد تسجيل حقيقي.
