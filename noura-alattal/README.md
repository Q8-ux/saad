# منصة د. نورة العتال — الدورات والمراجع التعليمية

الرابط: https://q8-ux.github.io/saad/noura-alattal/

واجهة عربية RTL بخط المهند، ودورات مقترحة ومراجع للطلاب. لا تتضمن الواجهة محرراً أدبياً أو مسودات أو توليد نصوص. حُذف قسم مكتبة الفيديو وروابطه وملفات تشغيله بناءً على طلب صاحب الموقع في 4 أكتوبر 2026.

## المحتوى

- صفحات الدورات الخمس ومحاورها وطلب الاشتراك.
- المكتبة المعرفية وأعمال الدكتورة والأبحاث والأمثلة التعليمية.
- قائمة متجاوبة وروابط تنقل متوافقة مع لوحة المفاتيح.

## الإدارة والبيانات

`admin/` مساحة عامة لتجهيز إعدادات الدورات على الجهاز وتصديرها. ليست لوحة صلاحيات آمنة ولا تغيّر الموقع المنشور. احتُفظ بمفتاح الإعدادات السابق `noura-admin-preview-v1` وبفهارس قائمة التجهيز المتبقية.

البرامج والمحتوى التدريبي المقترح يحتاجان اعتماد الدكتورة. طلب الاشتراك الحالي يفتح البريد؛ التسجيل والدفع الفعليان يحتاجان خدمات مستقلة. لم يتغير سلوك الاشتراك ضمن هذا التحديث.

## التحقق والنشر

فحص JavaScript: `node --check noura-alattal/assets/navigation.js` و`node --check noura-alattal/assets/admin-reference.js`.

ينشر `.github/workflows/deploy-noura-library.yml` تغييرات هذا المشروع وحده. يستعيد أحدث حزمة GitHub Pages من تشغيل ناجح، ويستبدل مجلد `noura-alattal/` لتطبيق حذف الملفات، ويقارن بصمات جميع الملفات المنشورة خارجه ويرفض النشر إذا تغيرت. يتحقق أيضاً من وجود الدورات وغياب روابط القسم المحذوف.

معرّف الإصدار: `20261004-courses-v2`.

## الأصول

استُخدمت ملفات خط المهند والصور الموجودة بالمشروع دون تغيير في هذا التحديث.
