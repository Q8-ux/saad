# منصة د. نورة العتال — مرجع الطلاب ومكتبة الفيديو

الرابط: https://q8-ux.github.io/saad/noura-alattal/#videos

واجهة عربية RTL بخط المهند، ودورات مقترحة ومراجع للطلاب. لا تتضمن واجهة الموقع أو إعدادات الدورات محرراً أدبياً أو مسودات أو توليد نصوص.

## مكتبة الفيديو

- ستة مقاطع تم التحقق من معرفاتها وعناوينها وناشريها عبر YouTube oEmbed في 3 أكتوبر 2026: تعريف قصير بورشة د. نورة العتال، محاضرة TED لأندرو ستانتون، وأربع محاضرات من سلسلة BAFTA لكتاب السيناريو.
- فلترة بحسب الموضوع وبحث محلي، وبحث خارجي حقيقي عبر Invidious API. نتائج البحث العامة منفصلة عن المراجع المختارة؛ لا تُنسب للدكتورة تلقائياً.
- حفظ الفيديوهات على الجهاز، ومشغل Invidious داخل نافذة مع خيار مشغل يوتيوب والرابط الأصلي عند تعذر التشغيل.
- قراءة نصوص الترجمة الأصلية المتاحة من المصدر، واختيار اللغة والبحث في النص والانتقال بالتوقيت. لا يُنشأ نص لفيديو لا يوفر ترجمة.
- رابط مراجع الفيديو مرتبط بكل صفحة دورة. المقاطع الخارجية مراجع إضافية وليست دورات معتمدة للدكتورة.

## إعداد مصدر Invidious

القيمة `apiBase` في `assets/video-catalog.js` تشير حالياً إلى `https://invidious.f5.si`، وهو مصدر عام يعلن دعم API وCORS وتم اختبار البحث والتضمين منه. يمكن استبداله بأصل HTTPS لنسخة Invidious خاصة تدعم CORS وتضمين الفيديو.

هذا التحديث لا ينشر خادم Invidious مستقلاً. GitHub Pages يستضيف الواجهة فقط؛ الخادم العام خارج سيطرتنا وقد يقيّد الوصول. البحث الخارجي يرسل عبارة البحث فقط دون بيانات حساب أو ملفات أو مفاتيح. المشاهدة عبر يوتيوب تتصل بخدمة يوتيوب، وعناوين الصور المصغرة تتصل بخوادم الصور الخاصة به.

لتشغيل نسخة خاصة يلزم خادم منفصل مع Invidious وPostgreSQL وInvidious Companion وفق تعليمات المشروع: https://github.com/iv-org/invidious .

## الإدارة والبيانات

`admin/` مساحة عامة لتجهيز إعدادات الدورات على الجهاز وتصديرها. ليست لوحة صلاحيات آمنة ولا تغيّر الموقع المنشور. احتُفظ بمفتاح الإعدادات السابق `noura-admin-preview-v1`. لا تُحمّل الواجهة ملفات أدوات الكتابة القديمة.

المحفوظة تستخدم `noura-video-library-v1`، وتُفقد عند مسح بيانات المتصفح. لا يرسلها التطبيق لخادم. التسجيل والدفع الفعليان يحتاجان خدمات مستقلة واعتماد البرامج.

## التحقق والنشر

شغّل `python3 -m http.server 8765` من جذر المستودع، وافتح `/noura-alattal/#videos`.

اختبارات المدخلات غير الموثوقة والترجمات والتوقيت والأخطاء والمهلة: `node --test noura-alattal/tests/video-library.test.cjs`.

ينشر `.github/workflows/deploy-noura-library.yml` تغييرات هذا المشروع وحده، بعد استعادة أحدث حزمة GitHub Pages من تشغيل ناجح. يقارن بصمات جميع الملفات المنشورة خارج `noura-alattal/` ويرفض النشر إذا تغيرت. محرك النشر العام لا يعاد تشغيله لمجرد تعديل د. نورة.

## الأصول والمصادر

ملفات خط المهند والصور الموجودة أُعيد استخدامها من المشروع، ولم يُستبدل الشعار. صور الفيديو من الناشر على يوتيوب؛ لا تحتوي الحزمة على نسخ من الفيديوهات أو نصوص ترجمتها. بيانات المصادر في `assets/video-catalog.js`، مع معرفات الفيديو والعناوين الأصلية وأسماء الناشرين.

البرامج والمحتوى التدريبي المقترح يحتاجان اعتماد الدكتورة قبل تقديمهما بوصفهما مقرراتها. نسبة ملكية القناة التي تنشر مقطع الورشة لا تثبت اعتمادها الرسمي للموقع أو بقية المكتبة.
