# مسار الرصد والاستخلاص الذكي — منصة د. نورة العتال

## الهدف
رصد المصادر العامة الموثوقة في الأدب والنقد والمسرح والسيناريو، واستخلاص معلومات تعليمية قابلة للمراجعة قبل إدراجها في المنصة. لا يتضمن محرر نصوص أو مختبر كتابة.

## مراحل المعالجة
1. Source Registry: مصادر محددة مع الترخيص ووتيرة المراجعة.
2. Fetch Adapter: جلب قانوني وفق شروط المصدر، دون تجاوز حماية أو تسجيل دخول.
3. Deduplication: إزالة المكرر باستخدام URL canonical وبصمة المحتوى.
4. Extraction: العنوان، المؤلف، التاريخ، الموضوع، الاقتباسات المسموح بها.
5. Classification: الدورات، المكتبة المعرفية، الأبحاث، المقالات، الأعمال.
6. Evidence Review: التحقق من المصدر والتاريخ والسياق، ووضع درجة ثقة مفسرة.
7. Editorial Approval: اعتماد بشري إلزامي قبل النشر.
8. Publish Export: تصدير JSON للموقع بعد الاعتماد فقط.

## مخطط السجل
```json
{"id":"string","title":"string","source_url":"https://example.org","author":null,"published_at":null,"retrieved_at":"ISO8601","language":"ar","category":"research","summary_ar":"string","evidence":[],"rights":"link-only","confidence":"needs-review","status":"pending"}
```

## معايير الحظر
- لا نشر تلقائي؛ لا ادعاءات بلا مصدر؛ لا نسخ مطول لمحتوى محمي.
- لا مختبر نصوص بأي تسمية، ولا توليد أعمال باسم الدكتورة.
- لا عرض الدورات المقترحة كدورات رسمية قبل اعتمادها.
- لا تخزين بيانات شخصية أو مفاتيح API في GitHub Pages.
- لا اعتبار ملف المواصفات هذا خدمة رصد فعالة؛ يلزم Backend/Workflow مجدول ومصادر معتمدة.

## بوابات الجودة
فحص الإملاء، الروابط، المصادر، التكرار، حقوق الاستخدام، خط المهند، RTL، استجابة الجوال، وعدم ظهور مختبر النصوص.
