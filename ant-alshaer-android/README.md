# أنت الشاعر — تطبيق أندرويد

تطبيق أندرويد للموقع المنشور على <https://q8-ux.github.io/saad/ant-alshaer/>. يفتح الموقع من رابط GitHub فقط داخل WebView آمن، ويحافظ على واجهة العربية وتصميم الهاتف. يحتاج الإنترنت للوصول إلى خدمات التحليل والتفريغ الصوتي؛ ولا يحتوي APK على مفاتيح خادم أو أسرار.

## تنزيل نسخة التجربة

[تنزيل أنت الشاعر 1.0.0 لأندرويد](https://github.com/Q8-ux/saad/raw/refs/heads/main/ant-alshaer-android/downloads/ant-alshaer-1.0.0-test.apk)

هذه نسخة موقّعة بمفتاح اختبار Android للتثبيت المباشر والتجربة. إصدار Google Play سيحتاج مفتاح رفع دائم يملكه صاحب التطبيق.

## الوظائف

- كتابة القصيدة وتحرير الأبيات وتحليلها من الواجهة الحالية.
- إذن الميكروفون عند طلب المستخدم فقط، مع إيقاف التسجيل عند مغادرة التطبيق.
- رفع الملفات من منتقي ملفات أندرويد دون فرض حد حجم من التطبيق نفسه، ودون طلب صلاحية شاملة للتخزين.
- تنزيل بطاقات القصائد والملفات التي ينشئها الموقع، والطباعة إلى PDF عبر خدمة طباعة أندرويد.
- فتح واتساب والروابط الخارجية في تطبيقاتها المناسبة.
- شاشة واضحة لإعادة المحاولة عند انقطاع الإنترنت، ودعم زر الرجوع ولوحة المفاتيح وحواف الشاشة.

## البناء

الحد الأدنى Android 8.0 (API 26)، والهدف Android 16 (API 36)، باستخدام JDK 17 وGradle 8.13 وAndroid Gradle Plugin 8.13.2. لا توجد مكتبات تشغيل خارجية.

ينفذ GitHub Actions فحوص سياسة الروابط والصلاحيات والبروتوكول الأصلي، ثم يبني APK release غير موقّع. مفتاح التوقيع لا يُحفظ في المستودع. نسخة Google Play النهائية يجب توقيعها بمفتاح رفع دائم يملكه صاحب التطبيق.

للفحص المحلي:

```bash
node tools/bridge.test.mjs
python3 tools/check-source.py
mkdir -p build/policy
javac -encoding UTF-8 -d build/policy app/src/main/java/com/q8ux/antalshaer/BrowserPolicy.java tools/PolicySelfTest.java
java -cp build/policy PolicySelfTest
```

## الخصوصية

التطبيق لا يطلب الموقع أو جهات الاتصال أو الوصول العام للصور والملفات. يطلب الميكروفون فقط عندما يبدأ المستخدم وظيفة صوتية. ما يرفعه المستخدم يعالجه الموقع والخدمات المرتبطة به وفق سياسة الموقع.
