# مسار المترجم — Masar Translate Browser

متصفح إنترنت أصلي لنظام Android (وليس واجهة iframe) مع ترجمة الصفحات عبر واجهة **LibreTranslate**.

## الوظائف المنفذة
- فتح مواقع HTTPS والبحث من شريط العناوين؛ محرك البحث الافتراضي Google.
- حتى 10 تبويبات، رجوع/تقدم/تحديث، فتح الروابط في تبويب جديد بالضغط الطويل.
- المفضلة وسجل التصفح (محليان على الجهاز).
- ترجمة النصوص الموجودة في DOM إلى 13 لغة مع كشف لغة المصدر تلقائياً، مع زر لاستعادة النص الأصلي.
- حفظ تنسيق الصفحة من خلال تعديل **text nodes** فقط؛ لا يتم إدخال HTML المترجم ككود.
- تنزيل الملفات عبر مدير تنزيلات Android؛ يتطلب رابط HTTPS.
- واجهة عربية داكنة بنفسجية، واتجاه RTL للنصوص وLTR لعناوين URL.
- إعداد خادم ترجمة ومفتاح API محلي دون تضمين أي مفتاح في الكود.

## البناء
يتطلب **JDK 17** و**Android SDK 35** و**Gradle 8.10.2**. من جذر هذا المجلد:

```bash
gradle :app:assembleDebug
```

الملف الناتج: `app/build/outputs/apk/debug/app-debug.apk`. يمكن بناء APK في GitHub Actions عبر workflow باسم `masar-translate-browser-android.yml`، ويُرفع كـ artifact بعد نجاح التنفيذ.

## تشغيل LibreTranslate محلياً
للتشغيل الشخصي وفق توثيق المشروع الأصلي:

```bash
pip install libretranslate
libretranslate
```

الخادم الافتراضي غالباً `http://localhost:5000`. **مهم:** `localhost` من هاتف Android يعني الهاتف نفسه، وليس جهاز الكمبيوتر. يُفضّل خادم HTTPS يمكن للهاتف الوصول إليه، أو `http://10.0.2.2:5000` لمحاكي Android عند تشغيل الخادم على الكمبيوتر. إعداد الشبكة يسمح HTTP فقط لأسماء الأجهزة المحلية المحددة.

الخدمة `https://libretranslate.com` تتطلب عادة مفتاح API مدفوع. أدخل مفتاحك من «⚙ الإعدادات». لا تضع المفاتيح في GitHub أو في الواجهة العامة.

## ملاحظات تقنية وحدود الإصدار الأول
- ليست نسخة كاملة من Chrome/Firefox: تعتمد على نظام Android WebView المثبّت على الجهاز.
- بعض صفحات SPA تتغير أثناء الترجمة، وقد تحتاج الضغط على «ترجمة» مجدداً.
- يُترجم حتى 220 عقدة نصية / 45 ألف حرف في كل مرة؛ ولا يشمل النصوص داخل الصور أو PDF أو iframe من نطاق آخر.
- في الإصدار الحالي، تُرسل النصوص الظاهرة إلى خادم الترجمة الذي تحدده؛ **لا تستخدم خادماً عاماً للبيانات السرية**.
- صفحة الموقع الأصلية محمية من تنفيذ الترجمة المُعادة كـ HTML؛ ويتم رفض روابط التنقل ذات البروتوكولات غير الآمنة.
- يدعم API للترجمة الدفعية `q: string[]`؛ يجب أن يدعم الخادم هذا النمط وتتوفر فيه حزمة اللغة المطلوبة.
- مفاتيح API تحفظ في إعدادات التطبيق الخاصة بالجهاز دون نسخ احتياطي؛ لا يُنصح باستخدام مفاتيح إدارية.
- لم يُجرَ اختبار على جهاز Android فعلي ضمن بيئة الإنشاء؛ استخدم APK المبني عبر CI لاختبار الوظائف.

## الترخيص والمصدر
هذا التطبيق **عميل جديد مستقل** يستخدم API ولا ينسخ ملفات LibreTranslate. مشروع LibreTranslate نفسه مرخص `AGPL-3.0`، ويعمل عبر Argos Translate:
- المصدر: https://github.com/LibreTranslate/LibreTranslate
- API: https://docs.libretranslate.com/guides/api_usage/

إذا عدّلت أو وزّعت خادم LibreTranslate ذاته، التزم بشروط AGPL-3.0. راجع التزامات الترخيص الفعلية قبل التوزيع التجاري.
