◆

غير مفعّل في نسخة GitHub العامة

لا يمكن وضع مفتاح الذكاء الاصطناعي داخل GitHub Pages بأمان؛ أي مفتاح في الصفحة يمكن استخراجه. لتفعيله دون ظهور نطاق خارجي نحتاج خادمًا مستقلًا ونطاقًا خاصًا بالمكتب.

عن نظام سابق الداخلي

نسخة ثابتة مستقلة تعمل بالكامل على GitHub Pages، بلا تحويل إلى أي نطاق آخر. إدارة القضايا الجديدة تحفظ البيانات داخل متصفح الجهاز فقط. لا تستخدم هذه النسخة العامة للبيانات القانونية الحساسة أو كبديل عن قاعدة بيانات مؤسسية وصلاحيات وصول وتشفير ونسخ احتياطية.
