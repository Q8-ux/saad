# الموسوعة الفقهية الكويتية — موقع مستقل

بحث وقراءة في المجلدات الـ٤٥ من ملفات وزارة الأوقاف الكويتية، مع روابط Word/PDF الأصلية، وفهرس عربي محلي، ومفضلة وملاحظات ونسخ احتياطي. خط القاهرة للواجهة وأميري للقراءة. يعمل دون حساب أو مفتاح API.

التطبيق المرجعي: https://apps.microsoft.com/detail/9nrk41s0rxnx

المصدر: https://bohoth.awqaf.gov.kw/ar/الموسوعة%20الفقهية

## التشغيل والفحص

```sh
npm test
npm run check
python tools/build.py
```

انشر `dist/` على خادم ثابت. بيانات Word مستخرجة آليًا؛ الرموز والخطوط الخاصة والآيات تستلزم مقابلة الأصل المصوّر. ترقيم المواضع رقمي ولا يمثل صفحات المطبوع. هذا موقع مستقل وليس إصدارًا رسميًا أو نقلًا لشيفرة تطبيق ويندوز.

## إعادة بناء البيانات

ملف `official-links.json` يثبت روابط المجلدات، و`official-sources.json` يثبت SHA-256 وعدد المواضع لكل ملف، لمنع النشر التلقائي إذا تغير المصدر دون مراجعة. تُبنى البيانات ضمن إجراء النشر، وتُنشر في أثر Pages دون تضخيم مستودع الشيفرة.

```sh
python tools/import_official.py --links official-links.json --cache /path/private-cache --antiword /path/antiword --resources /path/antiword/Resources
```

لا تنشر cache أو ملفات Word الخام أو ملفات بحث خاصة. النص الأصلي من وزارة الأوقاف؛ رخصة المستودع لا تغيّر حقوق المصدر. تراخيص الخطوط مرفقة. لا تستخدم محرك البحث بوصفه مولّد فتوى؛ ترتيب النتائج بحثي ولا يختار مذهبًا أو قولًا.
