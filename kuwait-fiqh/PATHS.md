# المسارات المطبّقة وحدودها

| المسار | التطبيق داخل المشروع | الدليل |
| --- | --- | --- |
| ذوق الواجهات | اتجاه هادئ مناسب للقراءة، القاهرة وأميري، فصل البحث عن متن المصدر | DESIGN.md، styles.css |
| إتقان الواجهات | RTL، الجوال، حالات عدم النتائج وفشل الاتصال، لوحة المفاتيح وترميز النصوص | index.html، app.mjs، اختبارات المتصفح |
| المواصفات والتنفيذ المنضبط | مواصفة وخطة ومهام ومعايير قبول مرتبطة بالتحقق | specs/001-encyclopedia/ |
| استخلاص النصوص والتحقق من المصدر | استيراد آلي من ملفات الوزارة، SHA-256، روابط الأصل، أعلام جودة الاستخراج | tools/import_official.py، data/catalog.json |
| البحث والاسترجاع | فهرس عربي قابل لإعادة البناء، نتائج مع إحالة وسياق؛ لا توليد حكم فقهي | engine.mjs، search-worker.mjs |
| الصوت في المتصفح | إملاء بحث بإذن المستخدم، قراءة بصوت عربي عند توفره، بدائل نصية | app.mjs |
| العمل دون اتصال | تخزين القشرة والكتل التي سبق فتحها فقط، بمسار معزول | sw.js |

تطبيق منهج Spec Kit هنا يدوي؛ لم يُثبت Specify CLI أو تُفعّل أوامر غير موجودة. لا تُنسخ قواعد سابق أو قاعدة تشريعاته المقيدة إلى المشروع. لا حاجة لمسارات الدفع والعقار والفيديو والمذكرات القانونية لهذا النطاق.
