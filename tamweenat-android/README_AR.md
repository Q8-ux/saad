# تطبيقا نظام تموينات لأندرويد

هذا المشروع يبني تطبيقين مستقلين من المصدر نفسه:

| التطبيق | معرّف الحزمة | الواجهة |
| --- | --- | --- |
| نظام تموينات – المطاعم | `com.digizone.tamweenat.restaurant` | `https://q8-ux.github.io/saad/tamweenat/login.html` |
| نظام تموينات – الإدارة | `com.digizone.tamweenat.admin` | `https://q8-ux.github.io/saad/tamweenat-admin/` |

## خصائص النسختين

- يعملان كتطبيقين منفصلين ويمكن تثبيتهما معاً على الجهاز نفسه.
- كل تطبيق يسمح بالتصفح داخل مساره المخصص فقط.
- الروابط الخارجية تفتح في التطبيق المناسب خارج النظام.
- الاتصالات غير المشفرة محظورة، وأخطاء شهادة SSL لا يتم تجاوزها.
- دعم رفع الملفات، زر الرجوع، التخزين المحلي للواجهة، وشاشة واضحة عند انقطاع الإنترنت.
- تطبيق المطاعم يدعم الاستماع الممتد حتى 45 ثانية، ويتحمل الوقفات القصيرة، ويحلل الأصناف والكميات والأسعار ثم يقرأ ملخص الطلب صوتياً وينتظر موافقة العميل قبل تعديل السلة. يُطلب إذن المايكروفون عند الاستخدام فقط.
- لا توجد مفاتيح سرية أو كلمات مرور مخزنة داخل التطبيق.

## البناء

تنفذ GitHub Actions الأمرين التاليين:

```bash
gradle -p tamweenat-android :app:assembleRestaurantDebug :app:assembleAdminDebug
```

ملفات APK التجريبية موقعة بمفتاح Android التجريبي. إصدار المتجر يحتاج مفتاح توقيع خاص يُحفظ كسراً في GitHub Actions ولا يُضاف إلى المستودع.
