أسئلة شائعة

هل كل الفيديوهات تأتي دون علامة مائية؟

لا. عندما توفر المنصة ملفًا أصليًا بلا علامة مائية يمكن اختيار الملف المناسب، لكننا لا نضمن ذلك لكل فيديو، ولا نطمس العلامات المدمجة داخل المحتوى.

هل أستطيع تنزيل الفيديوهات الخاصة؟

لا. الموقع مخصص للمحتوى العام المتاح دون تجاوز تسجيل الدخول أو أنظمة الحماية أو قيود الاشتراكات.

هل الموقع مستقل عن الخدمات الأخرى؟

نعم. الواجهة ومحرك التحميل مفتوحا المصدر ضمن مشروعك، ولا يعتمد التشغيل على خدمة SSSTik أو نسخ أكوادها.

لماذا يظهر خطأ اتصال بالخادم؟

تحتاج عملية استخراج الفيديو إلى خادم يشغّل yt-dlp. عند فتح نسخة GitHub Pages اضغط إعداد الخادم وأدخل عنوان خدمة API المنشورة.

Video Hub • مشروع مستقل • حمّل فقط المحتوى الذي تملك حق حفظه، والتزم بشروط المنصة وحقوق المبدعين.

⚙ إعداد محرك التحميل

لتشغيل نسخة GitHub Pages، أدخل رابط خادم API الخاص بك (مثل خدمة Render). عند تشغيل الموقع من الخادم نفسه، اترك الحقل فارغًا.
