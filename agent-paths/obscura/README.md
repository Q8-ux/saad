# مسار Obscura لفحص المشاريع والبحث في المصادر العامة

Obscura متصفح يعمل من سطر الأوامر. يفتح صفحات المشاريع، ينفّذ JavaScript ويقارن ما ظهر بعلامات متوقعة، مثل اتجاه العربية ووجود الخدمات أو ظهور أصناف الكتالوج. يستخدم المسار النسخة الرسمية ‎0.2.6 ويتحقق من بصمة الإصدار عند التثبيت.

## التشغيل

من جذر المستودع على Linux أو macOS، مع Python 3.9 أو أحدث.

```bash
bash agent-paths/obscura/install.sh .local/obscura
python3 agent-paths/obscura/check.py all --binary .local/obscura/obscura --screenshots
```

شغّل مشروعًا واحدًا باستبدال `all` بقيمة من الجدول. استخدم `--output` لتحديد مجلد النتائج. يعرض `report.md` ملخص الفحص، ويحتوي `report.json` التفاصيل وروابط المصادر الملتقطة. عند طلب الصور، يلتقط الفحص لقطتين عامتين للمكتبة وموقع د. حمد. ترجع العملية برمز خروج `1` إذا بقي أي فحص متعذرًا أو غير محسوم أو مقيّدًا.

في [GitHub Actions](https://github.com/Q8-ux/saad/actions/workflows/obscura-project-checks.yml)، اختر **Run workflow** ثم `all` أو المشروع. يحتوي ملخص التشغيل على النتائج، وتتوفر ملفات التقرير والصور باسم `obscura-report` حتى عند تعذر بعض الفحوص.

| الخيار | الفحص | ما يفيدك فيه |
| --- | --- | --- |
| `sabeq` | النطاق والواجهة العامة والخدمات ومعاينة الإدارة | اكتشاف تعطل رابط النشر أو اختفاء جزء من الواجهة |
| `poetry` | البوابة ووجهة التطبيق الأصلي ومعرّف بنائه عند إتاحته | معرفة هل الخلل في البوابة أم يحتاج تحققًا داخل التطبيق |
| `library` | دليل الخدمات العربي والإنجليزي واتجاههما وصفحة الفهرس الداخلية | كشف أخطاء اللغة والاتجاه أو فقدان إحدى الصفحات الداخلية |
| `doctor` | مكتبة المنشورات ومقال خشونة الركبة واستخراج روابطه الخارجية | تجهيز قائمة روابط للمراجعة وتوثيق العرض بلقطة شاشة |
| `chess` | بوابة الشطرنج وواجهة اللعبة خلفها | تمييز تحميل البوابة عن وصول اللعبة الفعلية |
| `store` | ظهور بطاقات الكتالوج وفتح صفحة إتمام الطلب | التقاط حالات تحميل الصفحة مع غياب المنتجات |
| `research` | فتح واجهة مسار البحث في التعليقات | رصد حالة نشر الواجهة قبل البحث في بياناتها |
| `animation` | فتح الاستوديو ووجود عنصر معاينة المشاهد | التأكد من ظهور مدخل المعاينة بعد النشر |

## البحث في نصوص التعليقات

يمكن البحث في تصدير JSON أو JSONL مصرح باستخدامه عبر أداة البحث العربية الموجودة في المستودع. يحتفظ الملف بعنوان المنشور ونص التعليق والمنصة. استبدل مثال الاستشارة بموضوعك.

```bash
node agent-paths/social-comment-search/scripts/search-comments.mjs \
  --input /path/to/comments.jsonl --query 'استشارة قانونية' \
  --terms 'محامي، استشارة، قانونية' --country KW
```

يعتمد جمع التعليقات الحية على واجهة المنصة وصلاحيات الحساب. يعرض فحص النشر حالة `401` أو `403` أو `429` كقيد وصول. يعتمد فحص الروابط الطبية على وجودها في المقال، وتبقى قراءة المصدر والتحقق من الاستشهاد خطوة بحثية مستقلة.

## اختبار الوظائف داخل التطبيق

يحتاج تسجيل الصوت وتحليله في «أنت الشاعر» إلى جلسة مصرح بها، وتسجيل تجريبي وميكروفون على متصفح يدعم التسجيل. تحقق من المذكرات والسداد في بيئة الاختبار الخاصة بسابق. راجع ظهور المنتجات والطلبات في اختبار المتجر عبر Chromium عند اختلاف النتيجة بين المتصفحات. توثّق [ملاحظات إصدار Obscura](https://github.com/h4ckf0r0day/obscura/releases/tag/v0.2.6) حدود دعم الوسائط وواجهات الويب.
