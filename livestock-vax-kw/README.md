# نظام وقاية لتحصين الثروة الحيوانية

واجهة عربية لتنظيم طلبات تحصين المواشي، مواقع المربين، الفرق الميدانية، سجلات الجرعات، المخزون والتقارير.

- [واجهة المربين](https://q8-ux.github.io/saad/livestock-vax-kw/)
- [لوحة الإدارة](https://q8-ux.github.io/saad/livestock-vax-kw/admin/)

### المساعد الصوتي
داخل واجهة وقاية يظهر زر **مساعد وقاية**. يدعم:
- الكتابة.
- التحدث بالعربية `ar-KW` عند دعم المتصفح لـ Web Speech.
- رد صوتي عبر Speech Synthesis.
- فتح أقسام المواعيد والطلبات والقطعان والفرق والتحصينات والتقارير.
- تجهيز طلب تصميم لمسار Canva.
- تمرير طلبات معالجة الصور لمسار Compositor.

> GitHub Pages استضافة ثابتة. الذكاء التوليدي الكامل، Voice Realtime الحقيقي، ومعالجة الصور الثقيلة تحتاج Backend آمن ولا يتم ادعاء تشغيلها داخل المتصفح بدون خادم.

البيانات الظاهرة في النسخة المنشورة تجريبية. تحفظ إضافات نسخة GitHub داخل المتصفح للعرض فقط، ولا تمثل قاعدة بيانات مركزية أو نظام صلاحيات إنتاجياً.


### مسار Google Calendar
- ينشئ حجزاً لموعد التحصين بعد اعتماد الطلب.
- يدعم إعادة الجدولة والإلغاء.
- تذكير قبل الموعد بـ 24 ساعة وساعتين.
- تذكير منفصل للجرعة التالية.
- يمكن ربط المساعد الذكي بأوامر مثل: «احجز موعد عبدالله سالم غداً الساعة 9» أو «ذكّر الفريق 1 بموعد كبد».
- إلى أن يتم ربط Google Calendar، يمكن استخدام ملف ICS كخيار احتياطي.


### مسار Google Maps
- فتح موقع المربي/الحظيرة من الإحداثيات أو وصف الموقع.
- فتح اتجاهات القيادة إلى الزيارة.
- إنشاء مسار يومي متعدد الوقفات للفريق.
- استخدام موقع الجهاز كنقطة انطلاق عند السماح بالموقع.
- مشاركة رابط موقع Google Maps.
- يمكن للمساعد تنفيذ أوامر مثل: «افتح موقع عبدالله سالم» و«اعرض مسار الفريق 1».
- تحسين ترتيب الوقفات تلقائياً، ETA الحي، Distance Matrix وPlaces تحتاج Google Maps Platform API ومفتاحاً آمناً.


### مسار WhatsApp
- الإدارة تحدد قواعد الإسناد حسب المنطقة ونوع الحيوان والأولوية، مع Override يدوي.
- الافتراضي الحالي: كبد → الفريق 1، الوفرة → الفريق 3، العبدلي → الفريق 2، الجهراء → الفريق 4.
- بعد الإسناد تُجهز رسالتان: رسالة للمربي ورسالة للفريق.
- يمكن فتح محادثة WhatsApp مباشرة للمربي أو للفريق من رابط `wa.me`.
- أرقام الفرق تحفظ في إعدادات محلية داخل نسخة العرض ولا تظهر للعامة.
- يدعم قوالب: تم الإسناد، تذكير، إعادة جدولة.
- الإرسال التلقائي، حالة التسليم، والقوالب المعتمدة تحتاج WhatsApp Business Cloud API أو مزوداً معتمداً.
