# رندرة خوارزميات

الفيديو موشن جرافيك مدته خمس دقائق مع التسجيلات الموجودة و85 مجموعة ترجمة مرتبطة بتوقيت الصوت. لا يتصل هذا التصدير بأي مزود توليد صوت أو فيديو.

يتطلب Python وFFmpeg وPillow مع دعم العربية RAQM وNumPy. من جذر هذا المشروع شغل:

```bash
python3 render_episode.py --samples
python3 render_episode.py
```

المخرج في `deliverables/khawarizmiat-motion-episode.mp4`. النسخة المحفوظة في الحزمة الكاملة تستخدم صوت WAV الأصلي. إعادة البناء من GitHub تفك مسار MP3 الموجود محليا وتحافظ على مدته من دون تغيير سرعته.

الصور الموجودة للباب رسوم تخيلية من النسخة الأولى وليست صور إثبات أو تصويرا واقعيا. لا توجد مشاهد ممثلين حية في هذا التصدير. التفاعل الفعلي في صفحة المعاينة وليس في ملف MP4.
