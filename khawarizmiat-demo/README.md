# خوارزميات — قبل لا تنشر

واجهة حلقة تفاعلية رأسية بأسلوب شاشة الهاتف. الأفعال والحسابات والأرقام المتداولة داخل المشاهد جزء من عمل خيالي. لا يوجد اتصال بحساب سنابشات أو خوارزميته أو رفع تلقائي للصور والتعليقات.

## التشغيل

الواجهة بلا إطار عمل أو خطوة بناء. يلزم تقديم ملفات هذا المجلد عبر خادم ملفات ثابتة، مع الملفات التالية داخل `assets/`:

- `episode.json`: السيناريو الكامل مع مصفوفة `scenes` ذات الحقول `id`, `start`, `end`, `title`, `mode`.
- `timeline.json`: مصفوفة مقاطع الترجمة `{id, sourceId, scene, speaker, text, start, end}`. `scene` هو المعرف `s1` إلى `s10`.
- `episode.mp3`: المسار الصوتي الكامل ومدته 300 ثانية. هو الساعة الوحيدة للمشغّل.
- `Cairo.ttf`: خط الواجهة العربي. يعمل بديل النظام عند غيابه.
- `khawarizmiat-script.pdf` و`khawarizmiat-script.docx`: ملفات التنزيل النهائية.

لنسخة HTML مستقلة، ضمّن `styles.css`, `engine.js`, و`app.js` وأضف قبل تشغيل التطبيق:

```js
window.KHAWARIZMIAT_DATA = {
  episode: { /* episode.json */ },
  timeline: [ /* timeline.json */ ],
  audioUrl: 'data:audio/mpeg;base64,...'
};
```

يمكن تمرير `shareUrl` فقط عندما يصبح رابط العرض متاحًا ومؤكدًا. عند غيابه تشارك النسخة المستقلة وصف الحلقة؛ لا تخترع رابط نشر. رابط ملفات GitHub في الهامش لا يظهر إلا عند تقديم الصفحة من نطاق `github.io`.

## السلوك

- التشغيل والإيقاف والتقديم والعودة والمشهد السابق والتالي وإعادة الحلقة والكتم.
- قرار المشهد الرابع يغيّر ترتيب بطاقتي الاتهام والسياق فعليًا.
- طبقة كشف الإطار الأصلي في المشهد الخامس تعمل باللمس والفأرة ولوحة المفاتيح.
- لعبة المشهد السادس تستقبل الترتيب وتتحقق منه وتسمح بالتصحيح؛ يظهر الحل مع نهاية المشهد.
- المشهد الثامن يحفظ مراجعة الاتهام والملف الأصلي داخل حالة محلية.
- ترتيب توصيات المشاهد يعتمد على وقت المشاهدة والإعجاب والحفظ والقرار المعلن وزيارات الإعادة.
- الزيارة التالية تحتفظ بالموقف السابق وتبرز دليل العلامات الثلاث دون تغيير الواقعة.
- الأدلة لا تظهر قبل بلوغ مواضعها أو كشفها. يمكن استكمال موضع محفوظ.
- العدسة لا تفتح الكاميرا إلا بالضغط على زر تشغيلها؛ تتوقف عند إغلاق النافذة أو مغادرة الصفحة. لا تتعرف على الوجوه ولا ترفع الصور. يسمح حفظ صورة من الكاميرا أو المشهد المعد مسبقًا.
- المشاركة تبدأ بفعل المستخدم وتتعامل مع إلغاء نافذة المشاركة دون إعلان نجاح.

الحفظ عبر `localStorage`، مع تنقية المدخلات ومعالجة رفض التخزين. لا توجد بيانات مشاهدة مشتركة بين مستخدمين أو خدمة تحليلات خارجية.

## التحقق

نجح `node --check` لملفي JavaScript، مع تحقق منطقي لتنقية الحالة، وتحمل التخزين التالف والمرفوض، وترتيب البطاقات، والتحقق من اللغز، وتأثير الإعجاب والحفظ وإعادة الزيارة في ترتيب المقترحات. نجح تحقق فرادة معرفات HTML ووجود أهداف DOM الثابتة والمولّدة.

التحقق البصري والتفاعل داخل المتصفح يجريان بعد تجميع الأصول بواسطة مالك العمل.

## مراجعة الحوار الخليجي

ملفا PDF وWord يتضمنان الحوار بلهجة خليجية قريبة من الكويت. النسخة الصوتية والتفاعلية الحالية تعرض التسجيل السابق إلى حين اكتمال إعادة التسجيل ومطابقة الترجمة عليه.
