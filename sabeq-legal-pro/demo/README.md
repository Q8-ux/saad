# Legal platform demo

Independent, static demonstration of the legal-office workflow. This demo has no authentication and no production data or API connection.

- Client, case, meeting, invoice, memo and template create/edit/view/delete.
- Arabic, English and Urdu interface; responsive RTL and LTR layout.
- Local browser storage under legal-platform-independent-demo-v1, with reset.
- Amounts stored in integer fils, with paid amount validation.
- Local memo templates, plain-text import and export. No AI generation or legal sources are represented.
- The content security policy prevents network API requests from the demo.
- Fonts reuse the existing Al Mohanad font assets in the same GitHub Pages repository.

The production application, its authentication and its database remain unchanged.

Publication: the repository's existing Pages workflow includes this directory through sabeq-legal-pro/**.
