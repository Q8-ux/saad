# منصة العقود والترجمة القانونية

[فتح الموقع مباشرة](https://q8-ux.github.io/saad/sabeq-legal-pro/)

يفتح الموقع دون شاشة دخول، ويعرض الواجهة الكاملة بأقسامها الأحد عشر: لوحة التحكم، المساعد القانوني الذكي، البحث القانوني، قاعدة القوانين، العملاء، القضايا، الجلسات والمهام، الفواتير، المذكرات، الإعدادات، وإدارة المكاتب.

أقسام إدارة المكتب نسخة استعراض عامة ببيانات وهمية، منفصلة عن سجلات المكاتب. البحث وفتح الوثائق والتنقل وتغيير اللغة والمظهر تعمل محلياً. الحفظ والرفع والتعديل وتغيير الحسابات غير متاحة في الاستعراض. محول طلبات المكتب لا يتصل بالخادم ولا يتضمن جلسات أو مفاتيح أو بيانات حقيقية. النصوص التجريبية ليست مصادر قانونية.

المساعد القانوني يتصل بالخدمة القائمة عبر `https://sabeq-legal-research-api.onrender.com/api/legal/assistant`. يُرسل فقط السؤال المكتوب وسياق محدود من المحادثة واللغة، دون ملفات المكتب أو جلسات الدخول. لا يحتوي الموقع على مفتاح مزود الذكاء الاصطناعي. تتاح متابعة الحوار، إيقاف الطلب، إعادة المحاولة، نسخ الإجابة والمصادر، وبدء محادثة جديدة. تبقى المحادثة في الذاكرة أثناء التنقل وتُمسح بإعادة تحميل الصفحة. تُعرض المصادر المسترجعة دون اعتبارها نصوصاً معتمدة؛ روابط المصادر القابلة للفتح مقصورة على HTTPS للنطاقات الحكومية الكويتية. تتطلب الإجابات مراجعة قانونية والتحقق من آخر التعديلات.

تستخدم الواجهة العربية والإنجليزية والأردية، وخط المهند بنص أساس 20 بكسل على الكمبيوتر و22 بكسل على الجوال، مع توقيع صغير ثابت بالإنجليزية. المصدر الكامل لهذه الواجهة موجود في `source/`، ويعاد بناء الملفات المنشورة بالأوامر:

```sh
npm ci
npm test
npm run typecheck
npm run build
```

تقوم آلية GitHub Pages الموجودة في المستودع بنشر المجلد عند تحديثه. بقيت النسخة التجريبية السابقة في `demo/`.
