# منصة العقود والترجمة القانونية

[فتح الموقع مباشرة](https://q8-ux.github.io/saad/sabeq-legal-pro/)

يفتح الموقع دون شاشة دخول، ويعرض الواجهة الكاملة بأقسامها العشرة: لوحة التحكم، البحث القانوني، قاعدة القوانين، العملاء، القضايا، الجلسات والمهام، الفواتير، المذكرات، الإعدادات، وإدارة المكاتب.

هذه نسخة استعراض عامة ببيانات وهمية، منفصلة عن سجلات المكاتب. البحث وفتح الوثائق والتنقل وتغيير اللغة والمظهر تعمل محلياً. الحفظ والرفع والتعديل وتغيير الحسابات غير متاحة في الاستعراض. لا تتصل الواجهة بأي واجهة خلفية، ولا تتضمن جلسات أو مفاتيح أو بيانات حقيقية. النصوص التجريبية ليست مصادر قانونية.

تستخدم الواجهة العربية والإنجليزية والأردية، وخط المهند، والتصميم المتجاوب مع الجوال. المصدر الكامل لهذه الواجهة موجود في `source/`، ويعاد بناء الملفات المنشورة بالأوامر:

```sh
npm ci
npm test
npm run typecheck
npm run build
```

تقوم آلية GitHub Pages الموجودة في المستودع بنشر المجلد عند تحديثه. بقيت النسخة التجريبية السابقة في `demo/`.
