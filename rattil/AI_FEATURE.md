# رَتِّل — ميزة التحليل الذكي على GitHub

الموقع الحي:
https://q8-ux.github.io/saad/rattil/

تستخدم نسخة GitHub Pages التعرّف الصوتي المتاح في المتصفح أثناء التسجيل، ثم تطابق الكلمات محليًا مع نص المصحف العثماني من Al Quran Cloud. لا يوجد مفتاح API سري داخل ملفات JavaScript العامة.

بعد ظهور النتيجة:

- الضغط على اسم السورة يفتح صفحة المصحف من أول السورة ويبدأ تشغيلها بصوت القارئ المختار.
- الضغط على رقم الآية أو نصها يفتح موضع الآية، يميّزها بصريًا، ويبدأ تشغيلها.
- تظهر الكلمات الملتقطة كخيارات؛ اختيار كلمة يستخرج جميع الآيات التي تحتوي عليها.
- يمكن كتابة كلمة قرآنية يدويًا، ويعرض الموقع عدد جميع المواضع والنتائج على دفعات.
- الضغط على أي آية ضمن نتائج الكلمة يفتح موضعها في المصحف ويشغّلها بالقارئ المختار.
