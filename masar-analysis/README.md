# مسار التحليل

وحدة مستقلة تجمع أدلة من الويب وتعيدها مع روابطها وتوقيت جمعها، ثم تحللها بواسطة نموذج مشروعك عند تفعيله. تصلح للربط من Backend أي مشروع عبر REST API، أو للوكيل عبر CLI وMCP. **هذه خدمة خادم، ولا تعمل داخل GitHub Pages وحده.**

## ما تم بناؤه

- استخراج النصوص بواسطة Scrapling، مع حذف نصوص السكربتات وعناصر التنقل الشائعة.
- ربط متصفح Patchright Enhanced من تثبيت منفصل؛ لا توجد نسخة من شفرته داخل هذه الوحدة.
- تثبيت Agent-Reach كطبقة تجهيز وفحص، واستخدام أدواته الفعلية للمنصات. لا يوجد افتراض بوجود أمر غير حقيقي مثل `agent-reach read`.
- بحث اختياري عبر Exa MCP، ثم جمع الصفحات الناتجة ضمن حدود المشروع.
- إزالة تكرار الروابط والمحتوى، وإظهار الأخطاء والنتائج الجزئية دون اختلاق نجاح.
- نتائج JSON تحمل المصدر، وقت الجمع، بصمة المحتوى، وطريقة الاستخراج. وقت الجمع **ليس** تاريخ النشر.
- وضع مقتطفات يعمل دون مفتاح نموذج، ووضع تحليل يتصل بنموذج مشروعك من الخادم.
- مفاتيح مستقلة للمشاريع، وقائمة نطاقات، وحدود استهلاك، ومنع الوجهات الداخلية وإعادة توجيهها.

## الحالة الفعلية

راجع [تقرير التحقق](VALIDATION.md). تم تشغيل خدمة HTTP المحلية واختبار الاستخراج والضوابط. **لا يعني هذا أن الخدمة منشورة على خادم دائم، أو أن حسابات X وReddit متصلة، أو أن جميع المصادر تعمل.** تنزيل Chromium تعذّر في بيئة التجهيز؛ اختبار المتصفح الحي معلّق. نموذج التلخيص لم يُربط بمفتاح حقيقي.

## التشغيل

المتطلبات: Linux أو macOS أو WSL، Python 3.11+، وGit. المتصفح يحتاج Node.js 22+ ومكتبات Chromium المناسبة للنظام.

```bash
git clone https://github.com/Q8-ux/saad.git
cd saad/masar-analysis
python3 scripts/install.py
.venv/bin/masar serve
```

يثبّت البرنامج الاعتمادات محلياً في `.venv`، ويحمل نسخة Enhanced محددة داخل `.runtime`، ويولّد مفتاحاً محلياً في `.env`. لا يطبع المفتاح، ولا يستورد جلساتك، ولا يغيّر إعدادات الوكيل العامة. إذا تعذّر تنزيل المتصفح تستطيع تجهيز وتشغيل الجزء الأساسي:

```bash
python3 scripts/install.py --core-only
.venv/bin/masar doctor
.venv/bin/masar analyze "لخّص محتوى هذه الصفحة" --url https://example.com/ --provider web
```

المنفذ الافتراضي `8787` على الجهاز نفسه. يُنشأ `config.local.json` للمشروع `demo`. لتسمية مشروع عند تجهيز نسخة جديدة قبل إنشاء إعداداتها:

```bash
.venv/bin/masar init --project tamweenat --allow example.com --allow '*.example.org'
```

أمر `init` يرفض الكتابة فوق إعداد موجود. بعد استخدام المثبّت، عدّل اسم المشروع واسم متغير المفتاح في الإعداد المحلي إن رغبت. الإعداد `allowed_hosts: ["*"]` يسمح بالمواقع العامة؛ حدد النطاقات الفعلية لتقييد مشروع معين.

## الربط بأي مشروع

ضع على **الخادم الخلفي** للمشروع:

```dotenv
MASAR_API_URL=http://127.0.0.1:8787
MASAR_API_KEY=YOUR_PRIVATE_PROJECT_TOKEN
```

ثم أرسل:

```http
POST /v1/analyze
Authorization: Bearer YOUR_PRIVATE_PROJECT_TOKEN
Content-Type: application/json

{"query":"قارن المعلومات وحدد الثغرات","urls":["https://example.com/"],"language":"ar","use_llm":false}
```

أمثلة جاهزة: [Python](examples/client.py)، [Node.js](examples/client.mjs)، [MCP](examples/mcp.json).

| الواجهة | الوظيفة |
|---|---|
| `GET /healthz` | فحص تشغيل الخدمة فقط |
| `GET /v1/capabilities` | حالة المكونات والإعدادات؛ يتطلب مفتاح المشروع |
| `GET /v1/openapi.json` | وصف API للاستيراد في أدوات الربط؛ يتطلب المفتاح |
| `POST /v1/analyze` | الجمع والتحليل وإرجاع الأدلة والأخطاء |
| `masar analyze` | استدعاء محلي للوكيل |
| `masar mcp --project demo` | أدوات MCP محلية عبر stdio |

الطلب يدعم `provider`: `auto`, `web`, `browser`, `youtube`, `x`, `reddit`. الوضع التلقائي يختار الأداة حسب نطاق الرابط، ولا يحاول تجاوز رفض الوصول. استخدم `discover: true` للبحث عن مصادر انطلاقاً من السؤال؛ يعتمد نجاحه على إتاحة Exa. يمكن الجمع بين البحث وروابط محددة.

الاستجابة تحمل `status: ok | partial | failed`. افحصها حتى عندما تكون استجابة HTTP ناجحة؛ `200` يعني أن عملية المعالجة اكتملت، لا أن كل مصدر أمكن قراءته. لكل مصدر `S1` ونحوه، وتستشهد نتائج التحليل بهذه المعرفات. لا يعرض المسار درجة ثقة عددية مصطنعة.

## تفعيل التحليل الذكي

في إعداد المشروع ضع `llm: true`، ثم عرّف هذه القيم على الخادم:

```dotenv
MASAR_LLM_BASE_URL=https://YOUR_MODEL_PROVIDER/v1
MASAR_LLM_MODEL=YOUR_MODEL_NAME
MASAR_LLM_API_KEY=YOUR_SECRET
```

الواجهة المتوقعة هي `POST /chat/completions`. يمكن استخدام مزود متوافق أو بوابة النموذج الحالية لمشروعك. ثم أرسل `use_llm: true`. لا يوجد مفتاح وهمي أو نموذج مجاني مفترض.

يعيد وضع النموذج: نتائج مرتبطة بالمصادر، معلومات ناقصة، اعتراضات محتملة، وتوصيات مرتبة. فشل النموذج أو استشهاده بمعرف غير موجود يعيد مقتطفات مع خطأ واضح. فحص معرفات الاستشهاد لا يثبت صحة كل استنتاج؛ لا يزال تقييم مضمون الأدلة مهماً. النصوص المستخرجة تُرسل إلى المزود الذي تهيئه فقط عند تفعيل هذا الوضع وطلبه.

## المنصات والمكونات

| المكوّن | ما يفعله | ما يلزم للتفعيل |
|---|---|---|
| Scrapling | تحليل HTML إلى نص قابل للاستخدام | موقع عام قابل للقراءة ويسمح بجمعه |
| Patchright Enhanced | إدارة عمر المتصفح مع محولنا لعزل طلباته | بناء الجزء المطلوب، Chromium، ثم `browser: true` |
| Agent-Reach | تجهيز وفحص الأدوات الأصلية | أدوات القناة نفسها وإعدادها |
| YouTube / yt-dlp | معلومات فيديو وترجماته عند توافرها | `social: true` وعزل الشبكة لأدوات المنصات؛ الترجمة قد لا تتوافر |
| X / twitter-cli | قراءة منشور محدد | جلسة مشروع مهيأة صراحة، وأداة twitter |
| Reddit / rdt-cli | قراءة منشور محدد | تسجيل دخول مهيأ وأداة rdt |
| Exa MCP | البحث عن روابط مصادر | اتصال بالخدمة؛ لا ضمان لحصصها أو استمرار إتاحتها |

ملف `requirements.lock` يثبت الإصدارات. لتحقق محلي أوسع:

```bash
.venv/bin/masar doctor --upstream
```

فحص Agent-Reach مستقل وقد يعرض قنوات لا تملك هذه الوحدة محولات لها. دعمه لقناة لا يعني تلقائياً دعم المسار لكل عملياتها. X وReddit هنا لقراءة منشورات محددة، وYouTube لفيديو محدد، لا لتصدير حسابات كاملة أو تنزيل الفيديو.

بالنسبة إلى X: تستخدم الأداة `TWITTER_AUTH_TOKEN` و`TWITTER_CT0` من بيئة المشروع. بالنسبة إلى Reddit: عرّف `MASAR_REDDIT_CREDENTIAL_FILE` بمسار ملف جلسة خاص بالمشروع، بصيغة `{"cookies":{"reddit_session":"..."}}`. يستخدم المحول عميل rdt مباشرة كي لا يقوم أمر الدخول الافتراضي بقراءة متصفحاتك تلقائياً. لا تُرسل الجلسات في API ولا تضعها في GitHub. قبل تمكين أدوات المنصات، جهّز حاوية/عامل شبكي يمنع الوصول إلى الشبكات الخاصة وبيانات الاستضافة الداخلية، ثم عرّف `MASAR_UPSTREAM_EGRESS_ISOLATED=1`. هذا المتغير **إقرار بإعداد العزل وليس تطبيقاً له**. بخلاف ناقل الويب الخاص بنا، قد تُجري هذه الأدوات اتصالات خاصة بها.

الخدمة ترفض تشغيل أكثر من مشروع عندما تكون الجلسات الاجتماعية مفعّلة، منعاً لمشاركة جلسة منصة بين مشاريع مختلفة. يمكن مشاركة الخدمة للمصادر العامة بمفاتيح منفصلة، أو تشغيل نسخة لكل مشروع.

## تشغيل المتصفح

المثبّت يبني `BrowserManager` والاعتمادات التي يستخدمها فقط. البناء الكامل للمستودع المثبت يفشل بسبب حقل `locale` غير موجود؛ لا يعتمد محولنا على ذلك الجزء. يثبت ملف npm إصدار Patchright `1.57.0` المطابق لملف القفل الأصلي.

يمكن تعريف `MASAR_BROWSER_EXECUTABLE_PATH` لمسار Chromium متوافق موجود مسبقاً. يُنشأ ملف متصفح مؤقت دون ملفاتك الشخصية. تمر طلبات GET للصفحة عبر ناقل Python الذي يتحقق من الوجهة؛ تُمنع WebSocket وطلبات الكتابة والتحميلات والوسائط. قد لا تعمل المواقع التي تعتمد على POST أو تسجيل الدخول أو تحديات الوصول في هذا الوضع، ويُعاد خطأ واضح.

## النشر

الحاوية المرفقة تشغل الويب وMCP وواجهة التحليل الأساسية؛ **لا تحتوي متصفحاً** ولا تنشئ عزلاً شبكياً كاملاً لأدوات المنصات. بعد توليد الإعدادات:

```bash
docker compose up --build -d
```

الحاوية تقرأ ملف الإعداد الذي لا يحتوي أسراراً، وتتلقى المفتاح من `.env`. ضع أمام الخدمة HTTPS وبوابة دخول مناسبة إذا أردت الوصول من خادم آخر، وحدد حجم جسم الطلب في البوابة بـ64 كيلوبايت. استخدم عملية Uvicorn واحدة كما في الإعداد المرفق؛ محدد الاستهلاك محلي للعملية، ويحتاج مخزناً مشتركاً عند التوسع لعدة نسخ. لا توجد جدولة دورية أو تكلفة استضافة أنشئت تلقائياً.

لا يكتب المسار نصوص المصادر إلى قاعدة بيانات ولا يسجل رموز الدخول. حجم الاستجابة لكل طلب مصدر محدود، وعدد المصادر محدود، وتنظيف HTML لا يجعل محتوى الإنترنت موثوقاً. لا يشمل الإصدار الحالي OCR أو PDF أو جمع مواقع كاملة.

- [Scrapling](https://github.com/D4Vinci/Scrapling) — محلل المحتوى.

تراخيص المكونات الأصلية مستقلة عن ترخيص ملفات الربط. افحص وضع ترخيص Enhanced قبل إدخاله ضمن منتج تعيد توزيعه. وصف أي أداة بأنها تستطيع الوصول إلى «أي موقع» ليس ضماناً لتوافر البيانات أو صلاحية الوصول إليها.
