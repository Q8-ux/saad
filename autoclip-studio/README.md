# AutoClip Studio — استوديو القص الذكي

[افتح الموقع](https://q8-ux.github.io/saad/autoclip-studio/) · [المحرك الأصلي](https://github.com/zhouxiaoka/autoclip)

واجهة مستقلة لمشروع AutoClip، لتحويل الفيديو الطويل إلى مقاطع قابلة للمراجعة والتصدير. العربية هي اللغة الافتراضية، مع الإنجليزية والأردية ودعم RTL والجوال. المستخدم: **saad.albabhan**.

## ما يعمل الآن

- استيراد فيديو محلي، اختيار الأزمنة بأرقام عربية أو إنجليزية أو أردية، وإدارة المقاطع.
- حفظ خطة المقاطع JSON وإعادة فتحها مع الفيديو الأصلي المطابق.
- تصدير مقاطع حتى 3 دقائق بالصوت، بالمقاس الأصلي أو باقتصاص مركزي 9:16 أو 16:9. يستخدم المتصفح MP4 عند دعمه أو WebM مع بيانات المدة. يجري التصدير بالزمن الحقيقي وبحد أقصى 1280 بكسل للضلع الأطول؛ أبق الصفحة ظاهرة.
- استيراد وتحرير SRT/VTT، تنزيل ترجمة كل مقطع بتوقيت يبدأ من الصفر، وحرق الترجمة داخل الفيديو.
- فحص الأزمنة والتكرار وحدود التصدير؛ قراءة TXT/MD محليًا؛ تنزيل خطة نشر JSON وروابط UTM. ملفات الفيديو تُنزّل منفصلة.

## المسارات المركبة

| المسار | وظيفته | التشغيل |
| --- | --- | --- |
| AutoClip | تحليل الفيديو واقتراح المقاطع واستيراد YouTube/Bilibili | يتطلب تشغيل المحرك الأصلي وربطه من «محرك AutoClip» |
| Agent-Reach / Scrapling / Patchright | البحث والتحليل عبر masar-analysis | خادم ربط وخدمة تحليل مهيأة |
| VoiceStudio | التعليق الصوتي عبر عقد خدمة الصوت الموجود | خادم ربط وroute10-hub ومزود متوافق |
| Poolday | إنتاج مشاهد تكميلية | خادم ربط ومزود مهيأ |
| MoneyPrinterTurbo | بديل لإنتاج الفيديو | خادم ربط ومزود مهيأ |
| OpenShorts | معالجة مصدر جديد | خادم ربط ومزود مهيأ؛ لا يعيد قص المقاطع الحالية |
| MarkItDown | استخراج نصوص PDF وWord | خادم ربط وخدمة المستندات؛ TXT/MD محلي |
| Block Buzz | إرسال طلب مراجعة إلى غرفة الوكلاء | CLI وخادم وقناة خاصة مهيأة؛ الإرسال بفعل المستخدم فقط |
| الترجمة ومراجعة الجودة | SRT/VTT وفحوص المقاطع | محلي |

هذه تكاملات حقيقية بعقود API، وليست حسابات مزودين مفعلة أو محركات مستضافة ضمن GitHub Pages. حالة «الخدمة مهيأة» تُحدّث من خادم الربط، ولا تضمن نجاح مزود خارجي. [دليل تفعيل الخادم](backend/README.md). تطبيق VoiceStudio المكتبي يحتاج محول API متوافقًا مع عقد الخادم الحالي؛ وجود البرنامج وحده لا يفعّل خدمة الويب.

أُضيفت مواصفة وخطة تحقق بأسلوب التطوير القائم على المواصفات في `specs/001-autoclip-studio/`. أدوات التطوير لا تظهر للزائر كمسارات إنتاج.

## تشغيل محلي

```sh
cd autoclip-studio
npm run dev -- --host 0.0.0.0 --port 4173
```

تعمل ملفات `dist` مباشرة من خادم HTTP، بلا بناء إلزامي أو تنزيل مكتبات عند فتح الموقع. لا تفتح `index.html` عبر `file://` لأن التطبيق يستخدم JavaScript modules.

```sh
npm test
npm run check
# فقط لإعادة بناء مكتبة إصلاح مدة WebM المثبتة الإصدار:
npm ci
npm run build:vendor
```

سير النشر الموحد في `.github/workflows/deploy-pages.yml` يختبر المشروع وينشر **محتويات dist فقط** في `/saad/autoclip-studio/`، ويحافظ على بقية مواقع المستودع. الخادم والاختبارات وملفات البيئة لا تُنسخ إلى موقع Pages.

## البيانات والحدود

القص المحلي لا يرفع الفيديو. بدء تحليل AutoClip يرفع المصدر إلى الخادم الذي اختاره المستخدم. تشغيل مسار إنتاج يرسل النص والروابط إلى الخدمات المهيأة. أسرار المزودين تبقى في الخادم؛ رمز وصول الاستوديو في ذاكرة الصفحة فقط، واللغة وعناوين الخوادم غير السرية يمكن حفظها محليًا.

ملف المشروع يحفظ خطة القص فقط؛ احتفظ بالمصدر وملف SRT منفصلين. لا يوجد نشر اجتماعي تلقائي، أو تفريغ صوتي محلي تلقائي، أو ترجمة آلية بين اللغات. اختيار لغة الواجهة لا يترجم محتوى الفيديو. القص العمودي مركزي وليس تتبعًا تلقائيًا للوجه. التوافق الفعلي للترميزات يعتمد على المتصفح.

مكتبة [fix-webm-duration](https://github.com/yusitnikov/fix-webm-duration) إصدار 1.0.1 مرخصة MIT؛ إشعاراتها وإشعارات tslib موجودة في `dist/vendor/`.
