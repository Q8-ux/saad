# مسار استوديو تيك توك

استخدم [تبويب الإنتاج والنشر](https://q8-ux.github.io/saad/tiktok-growth/#production) لربط خطة الحساب بسكربت الفيديو وخطة القص والوصف. الملفات وبيانات المشاريع تبقى على جهاز المستخدم في هذا التدفق. اقرأ [مسارات العمل](references/workflow.md) لاختيار خطوات الكتابة أو المونتاج أو النشر أو القياس.

1. استخرج المطلوب والموضوع والجمهور والمنصة والمصدر من الطلب وملفاته. عند توفر مشروع محفوظ أو حزمة إنتاج، خذ منه بيانات الفيديو المختار. ابدأ بمعالجة الافتراضات البسيطة، واطلب الأصل أو الإذن أو أرقام الأداء فقط حين تحتاجها لتنفيذ الخطوة المطلوبة.
2. **اكتب وصمّم.** قدّم فكرة قابلة للتصوير، افتتاحية بصرية وصوتية ونصية، سكربتًا وخطة لقطات ووصفًا بحسب الطلب. احتفظ باللهجة الكويتية أو الخليجية حين تناسب الجمهور. عند الحاجة إلى فيديو جديد، فرّق بين مخرجات التخطيط وتصوير المستخدم وإنتاج الأصول ورندرة النسخة النهائية. استخدم أداة إنتاج متاحة ومأذونًا باستخدامها، مع تسجيل أي متطلبات تشغيل فعلية.
3. **اختر المصدر واقصص.** استخدم الملف الأصلي أو نسخة من قناة المستخدم أو ملفًا مرخصًا. استخرج أوقات المقاطع من المشاهدة أو التفريغ المؤقت. استعمل AutoClip للقص والاقتصاص وحرق SRT/VTT محليًا، أو استدعِ مسار المونتاج الذكي عند طلب معالجة التفريغ أو الصوت أو دفعة من المقاطع. استخدم الرابط المرجعي وحده للتخطيط. اقترح أوقاتًا عند معاينة المادة أو قراءة تفريغ مؤقت. قصّ وصدّر بعد الحصول على ملف الفيديو.
4. **حضّر حزمة النشر.** سلّم الفيديو أو خطة العمل المتوفرة مع وصف قابل للنسخ وغلاف مقترح وموعد إذا طُلب. افحص إطار ٩:١٦ ونص الشاشة والصوت وثبات المعنى وحقوق الاستخدام. وجّه المستخدم لرفع الملف من TikTok Studio بحسابه ومراجعة إعدادات المشاهدة هناك. سجّل «منشور» عند توفر رابط منشور أو تأكيد من الحساب.
5. **حسّن الحساب.** اقرأ نتائج TikTok Studio التي يقدّمها المستخدم. حدد هدف التجربة والمقياس والمرجع والزمن. قارن عينة من مقاطع متقاربة، ثم اقترح تعديلًا واحدًا للاختبار التالي. قدّم الفرضية والدليل ودرجة الثقة باختصار.

عند تسليم المقاطع أو الأدلة، ميّز المصادر المستخدمة، الملفات التي تم إنتاجها، والمراحل التي تعتمد على خدمة أو تسجيل دخول. اربط الكود أو المسار بمستودع GitHub الخاص بالمشروع.
