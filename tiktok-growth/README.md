# مسار نمو تيك توك الخليجي
الموقع: https://q8-ux.github.io/saad/tiktok-growth/

مساحة سعد لإدارة خطة الحساب من الصفر باتجاه 100 ألف متابع؛ لا ضمانات نمو أو أرباح.
واجهة عربية RTL بخط المهند من ملفات المستودع المشتركة.

## الوظائف
المراحل السبع وبرومبتاتها وقراراتها؛ 30 مهمة قابلة للتعديل؛ 20 فكرة أولية؛ محرر سكربت وقائمة جودة تمنع اعتماد النشر قبل إكمال المراجعة؛ تسجيل إجمالي المتابعين وقياسات الفيديو؛ دفتر تجارب؛ خطط الدخل وحاسبة سيناريو؛ إعداد الهوية؛ نسخ احتياطي واستيراد JSON.

مركز 16 مساراً: التصميم، الهندسي/Spec Kit، تحليل قوقل، التحليل، Compositor، كانفا، أتمتة المحتوى، OpenShorts، VoiceStudio، Poolday، الصيني/MoneyPrinterTurbo، AutoClip، الكابتشن، MarkItDown، Buzz، المالي.
لكل مسار وظيفة وحالة تشغيل ومهمة سياقية ورابط مصدر أو أداة موجودة.
تحميل حزمة إنتاج JSON؛ استيراد TXT/MD محلي؛ سجل تكلفة بالدينار مع حد 80% و100% من الميزانية الشهرية.

## حدود التشغيل
لا حساب دخول أو مزامنة. الصفحة عامة وبيانات العمل تحفظ في localStorage بمتصفح الجهاز؛ لا ترفع إلى GitHub.
لا ربط آلي بـTikTok أو Canva أو حسابات المزودين؛ لا توليد فيديو/صوت أو نشر اجتماعي من هذه الصفحة.
AutoClip وSaad Studio أداتان منفصلتان تفتحان عبر رابط.
محركات OpenShorts/VoiceStudio/Poolday/MoneyPrinterTurbo/التحليل/Buzz وPDF/Word تحتاج خدماتها وخادماً آمناً ومفاتيح خارج JavaScript العام.
لا تستخدم مشاريع سعد الخاصة كقوالب.
صدّر البيانات قبل مسح المتصفح أو تغيير الجهاز. النسخة الاحتياطية تشمل السكربتات والملاحظات والمصروفات.

## النشر
deploy-tiktok-growth.yml يستعيد آخر artifact ناجح ثبت نشره ثم يستبدل ملف هذه المساحة فقط.
سير النشر الموحد ينسخ هذا المشروع أيضاً كي يبقى في الإصدارات المستقبلية.
تحقق محلي: JavaScript syntax وفحوص تنفيذ بوظائف DOM محاكية للحفظ وبوابة الجودة والحسابات والمصروفات.
لم يتوفر اختبار بصري بمتصفح في بيئة التنفيذ.
