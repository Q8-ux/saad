# مسار الهاتف

صفحة عربية لتحليل بيانات رقم الهاتف داخل المتصفح، بخط القاهرة واتجاه RTL وتصميم مناسب للجوال.

## النتيجة الفعلية

- دولة الترقيم ومفتاحها ونوع الرقم، مع التحقق من الطول والنمط.
- التنسيقات الدولية والمحلية وE.164.
- اسم المشغل الأصلي حين تتوفر بياناته، دون ادعاء معرفة المشغل الحالي بعد نقل الرقم.
- المنطقة المرتبطة بتخصيص الرقم والمناطق الزمنية المحتملة حين تتوفر بياناتها.
- نسخ التقرير وتنزيله محلياً.

مطابقة خطة الترقيم لا تثبت وجود مشترك أو تشغيل الخط أو ملكيته. لا تستخرج هذه الصفحة اسم المالك أو GPS أو حسابات التواصل أو عنوان IP من رقم الهاتف.

## الخصوصية

لا تخزن الصفحة أرقام المستخدمين في cookies أو localStorage أو الخادم. التحليل يجري محلياً. عند الحاجة تُحمّل ملفات metadata من الموقع نفسه باستخدام مفتاح الدولة فقط؛ لا يرسل الطلب رقم الهاتف الكامل. لا تحليلات زيارات ولا مزود بحث خارجي. نسخ وتنزيل التقرير يتمان بناءً على طلب المستخدم.

## التشغيل والبناء

```sh
npm ci
python -m pip install -r requirements-data.txt
python scripts/generate_data.py
python scripts/generate_fixtures.py
npm run build
npm test
npm run check
```

تُضاف نسخة خط القاهرة المعتمد وملف ترخيصه إلى `public/assets/` قبل التحقق. workflow النشر ينسخهما من `ant-alshaer/fonts/` في المستودع المشترك.

النشر عبر GitHub Pages: https://q8-ux.github.io/saad/phone-track/
