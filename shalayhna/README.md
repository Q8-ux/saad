# شاليهنا — دليل شاليهات الكويت

صفحة مستقلة داخل مستودع `Q8-ux/saad`، وتعمل مباشرة عبر GitHub Pages من المجلد `shalayhna/`.

## ما تتضمنه النسخة الحالية

- 39 سجلًا لشاليهات وجهات حجز منشورة علنًا
- بحث وتصفية حسب المنطقة ونوع جهة الاتصال وحساب إنستغرام
- واجهة عربية وإنجليزية
- نموذج طلب حجز يفتح رسالة واتساب مجهزة ولا يخزن بيانات المستخدم
- روابط المصدر وإنستغرام وبحث Google Maps لكل شاليه
- خط AL-Mohanad المرفق
- صور توضيحية مولدة للمشروع وليست صور الشاليهات المدرجة

## حقوق الصور

لا تُستخدم صور حسابات إنستغرام أو منصات الإعلانات والحجز داخل الموقع قبل الحصول على إذن كتابي من صاحب الحق. حقل `photoConsent` في البيانات مضبوط على `false` لجميع السجلات حتى يتم توثيق الموافقة.

## التشغيل

افتح `index.html` محليًا أو شغّل خادم ملفات ثابتًا من المجلد.
