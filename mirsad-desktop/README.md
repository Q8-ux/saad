# مرصد الكمبيوتر

برنامج ويندوز بواجهة عربية للفحص المحلي. ملف EXE يثبت داخل حساب المستخدم ويستخدم أدوات ويندوز وبطاقات الكمبيوتر الموجودة. لا يحتاج Python أو Node أو اشتراك أو مفتاح API أو تنزيل مكتبات عند التشغيل. تُعرض الواجهة في نافذة Microsoft Edge المثبتة على الكمبيوتر، وتبقى القراءات في الجهاز.

## التشغيل

1. افتح `Mirsad-Setup.exe` ثم اختر «تثبيت مرصد الكمبيوتر».
2. بعد التثبيت، افتح «مرصد الكمبيوتر» من سطح المكتب أو قائمة ابدأ.
3. يبدأ فحص الأقسام تلقائيًا. يعرض كل قسم حالته وسبب التعذر إن وجد.
4. اختر «التقارير والأرشيف» لتنزيل تقرير HTML عربي أو CSV أو JSON. يمكن فتح HTML وطباعته أو حفظه PDF من نافذة الطباعة.

تستطيع اختيار «تشغيل دون تثبيت». تتضمن الحزمة أيضًا `Mirsad.exe` للتشغيل المباشر.

## المتطلبات

- ويندوز 10 أو 11 بنواة 64 بت، على معالج Intel أو AMD.
- Microsoft Edge وWindows PowerShell الموجودان عادة ضمن ويندوز.
- تعريفات سليمة للبطاقات. فحص الواي فاي يحتاج بطاقة واي فاي فعلية، والبلوتوث يحتاج بطاقة متوافقة ومفعلة.
- قد يحتاج ويندوز إلى تفعيل خدمات الموقع وأذونات تطبيقات سطح المكتب لإتاحة مسح الواي فاي.
- قد تمنع سياسات أجهزة المؤسسات بعض القراءات أو إنشاء الاختصارات. لا يتجاوز البرنامج تلك السياسات.

## الوظائف المدمجة

| الوظيفة | القراءة الفعلية |
|---|---|
| الواي فاي | أسماء نقاط الوصول وعناوينها وقوة الإشارة والقنوات والنطاق والحماية ووقت الرصد عبر Native WLAN |
| البلوتوث | الأجهزة التقليدية المعروفة أو القابلة للاكتشاف، وإعلانات BLE عبر Windows Runtime عند دعم الجهاز |
| الشبكة المحلية | جدول جيران ويندوز؛ اكتشاف نشط اختياري لشبكة IPv4 خاصة واحدة، بحد أقصى 254 عنوانًا |
| المحولات | الحالة والعناوين والبوابة وملقمات الأسماء وسرعة الارتباط |
| الاتصالات | منافذ TCP وUDP المحلية والعمليات المالكة لها |
| الحركة | بايتات الاستلام والإرسال والأخطاء؛ معدل تقريبي من قراءتين متتاليتين |
| الأجهزة | أجهزة USB والشبكة والبلوتوث والمنافذ التسلسلية التي يعرفها ويندوز |
| النظام والحماية | مواصفات الكمبيوتر وحالة ملفات جدار حماية ويندوز |
| الرسوم | توزيع نقاط الوصول الجديدة حسب القناة، وتاريخ الإشارة عند توافر قراءات جديدة |
| التقارير | HTML عربي، CSV، JSON، وحفظ آخر 20 فحصًا يدويًا |

## حدود مهمة

هذه ليست مطابقة كاملة لبرامج ESP32-TOOLS التي تعمل على لوحات إلكترونية متخصصة. التقاط وإرسال IR وراديو sub-GHz وتحليل الطيف وGPS وتثبيت firmware ليست وظائف مدمجة في هذه النسخة؛ تحتاج أجهزة وبروتوكولات ودعمًا محددًا. عرض منافذ USB لا يجعل تلك القطع مدعومة تلقائيًا. التشويش وفصل الاتصالات والبوابات المضللة غير مضافة.

غموض أو غياب نتيجة لا يثبت غياب الأجهزة. الأجهزة التي لا تبث أو لا ترد قد لا تظهر. قوة الإشارة لا تقيس المسافة أو الاتجاه. توزيع شبكات الواي فاي ليس تحليلًا للطيف الراديوي. يميز البرنامج نتائج الواي فاي المحفوظة لدى ويندوز، ولا يضيفها إلى منحنى القراءات الجديدة. يحتفظ بوقت القراءة السابقة إذا تعذر تحديثها. لا يمثل فحص جدار الحماية تدقيقًا أمنيًا شاملًا.

## الخصوصية والتثبيت

الخادم مربوط بـ `127.0.0.1` على منفذ عشوائي ويحتاج جلسة عشوائية محلية. لا توجد نقطة تشغيل أوامر عامة ولا رفع تقارير أو تحليلات إلى خدمة خارجية. أوامر النظام ثابتة، وواجهات التغيير مقيدة بالأصل وبحماية CSRF. لا يستخرج البرنامج كلمات مرور الشبكات أو محتوى الملفات أو الحزم. يستخدم Edge ملف مستخدم منفصلًا للواجهة.

مجلد التثبيت: `%LOCALAPPDATA%\Programs\Mirsad`.
الفحوص التي تحفظها يدويًا: `%LOCALAPPDATA%\Mirsad\Sessions`.
للإزالة: إعدادات ويندوز ← التطبيقات ← مرصد الكمبيوتر ← إلغاء التثبيت. تبقى الفحوص المحفوظة في مجلد المستخدم. لا يحتاج التثبيت صلاحية مسؤول ولا يُضاف البرنامج إلى بدء التشغيل.

الملف غير موقع بشهادة تجارية. لا يتضمن البناء ادعاء اعتماد أو شهادة أمان من Microsoft. تحقق من بصمة SHA-256 في ملف الحزمة عند النقل.

## البناء من المصدر

لا يستخدم المشروع حزم Go خارج المكتبة القياسية. يحتاج تطويره إلى Go 1.24 أو أحدث. المورد `resource_windows_amd64.syso` يحتوي الأيقونة وبيانات الإصدار والبيان ويُبنى من `assets/app.rc` باستخدام GNU windres عند تعديل الأيقونة.

```powershell
go test ./...
$env:GOOS='windows'
$env:GOARCH='amd64'
$env:CGO_ENABLED='0'
go build -buildvcs=false -trimpath -ldflags='-s -w -H=windowsgui' -o Mirsad-Setup.exe .
Copy-Item Mirsad-Setup.exe Mirsad.exe
```

الاختبارات تغطي حدود الجلسة وCSRF ومنع قراءة المسارات وحماية تقارير HTML وCSV ونطاق الاكتشاف وحساب القنوات ومحاذاة هياكل واجهات ويندوز. يمكن إجراء فحص تكامل للقراءات المدمجة على ويندوز بتعيين `MIRSAD_WINDOWS_SMOKE=1` قبل `go test`، واختبار المثبت والتقارير باستخدام `tools/windows-smoke.ps1` بعد بناء الملف في مجلد `out`.

واجهات الراديو تحتاج تحققًا على الكمبيوتر المستهدف. لا يثبت نجاح البناء أو الاختبار على آلة افتراضية أن بطاقة معينة تدعم جميع أنواع القراءة.
