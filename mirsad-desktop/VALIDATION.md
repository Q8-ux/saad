# سجل التحقق

- بُني ملف Windows PE32+ x64 بواجهة رسومية وأيقونة وبيانات إصدار وبيان تشغيل بصلاحية المستخدم.
- نجحت اختبارات Go لحماية الجلسة وCSRF وحدود نطاق الاكتشاف وحماية التقارير ومحاولات قراءة المسارات.
- نجحت 12 مجموعة تحقق للواجهة، تشمل البحث والترقيم، و101 سجل، ونصوص شبكات غير موثوقة، ونتائج فارغة، وخطأ التحديث مع نتائج سابقة، وتنزيل التقرير والأرشفة.
- روجعت الواجهة عند 320 و390 و768 و1440 بكسل، واختُبر إعادة تدفق تخطيطها بتكبير CSS بنسبة 200٪. هذا الأخير فحص تخطيط، وليس اختبار وصول شاملًا.
- لم يُسجل اختبار صفحات الواجهة طلبات إلى وجهات خارج الخادم المحلي، ولم يُسجل خطأ JavaScript. لا يمثل هذا تدقيقًا لكل اتصالات نظام التشغيل أو المتصفح.
- يحتاج فحص الواي فاي والبلوتوث الفعلي إلى تشغيل النسخة على الكمبيوتر المستهدف ذي البطاقة المتوافقة.

نجحت اختبارات Windows Server 2025 في التشغيل [45728965488](https://github.com/Q8-ux/saad/actions/runs/45728965488) للشفرة ذات المعرف `588bf7b09b018ba747cea6e1ca3f2ff003a14f0d`، بتاريخ 26 نوفمبر 2026. شملت الاختبارات بنية واجهات ويندوز، وقراءات النظام والمحولات والمنافذ والأجهزة والعدادات والحماية، والتثبيت والاختصارات العربية وتسجيل الإزالة، وتنزيل التقارير وحفظ الأرشيف والإغلاق. كما نجح اختبار استقلال الجلسات عند فتح أكثر من نافذة.

لم تتوفر بطاقة واي فاي أو بلوتوث قابلة للفحص في آلة الاختبار؛ أعاد القسمان تعذر القراءة صراحة. لذلك لم يُثبت الاختبار فعالية المسح على بطاقة المستخدم. لا تمثل الآلة الافتراضية اختبارًا فعليًا على ويندوز 10 أو 11 أو على جهاز المستخدم.
