# مسار الفوتوشوب — Compositor

وحدة إنتاج صور للمشاريع، وليست محررًا داخل الموقع. التطبيق الأصلي:
https://github.com/robbietilton/Compositor

## المنفذ فعليًا

أداة Python تجمع طبقات الصور المعتمدة في ملف `design.comp` قابل للتحرير في Compositor، وتصدر PNG وJPEG وWebP وPDF مسطحًا. إعداد مستقل `compositor.config.json` داخل كل مشروع يحدد الاستخدام والقيود. يحفظ التقرير بصمات الأصول، ويمنع تشويه نسبة الصورة والكتابة فوق نسخة سابقة. الصور الأصلية لا يعاد حفظها أو تعديلها.

هذه إعدادات إنتاج وتشغيل يدوي؛ لم تُستبدل الصور المنشورة ولم يتصل الموقع بالأداة تلقائيًا. لا توجد API أو MCP أو خدمة إزالة خلفية في هذه الوحدة. إضافة إزالة الخلفية تتطلب قناعًا معتمدًا أو PNG مفرغًا. قياس حجم الوجه ومراجعته بشري؛ الأداة لا تكتشف الوجوه ولا تجري تنعيمًا أو تغييرًا لملامحها.

## التشغيل

من جذر المستودع:

```bash
python3 -m venv /tmp/compositor-venv
/tmp/compositor-venv/bin/pip install -r masar-photoshop/requirements.txt
/tmp/compositor-venv/bin/python masar-photoshop/compositor.py \
  --profile sabeq-legal/compositor.config.json \
  --job /private/approved-team/job.json \
  --output /private/approved-team/version-01
```

الناتج يمكن إنتاجه على Linux أو Windows أو Mac باستخدام Python. فتح ملف `.comp` وتحريره بصريًا يتطلب Compositor على Apple Silicon وmacOS 26 أو أحدث. لم يُجر اختبار داخل تطبيق Mac في هذه البيئة.

## نموذج ملف المهمة

المسارات نسبية إلى ملف المهمة، ويمكن أن تكون مطلقة. جميع الطبقات المطلوبة يجب تجهيزها أولًا. مثال صورة فريق 1200×1500؛ الأرقام توضيحية ولا تمثل معايرة حجم الوجه:

```json
{
  "size": [1200, 1500],
  "dpi": 72,
  "layers": [
    {"name": "خلفية الهوية المعتمدة", "file": "background.png", "box": [0, 0, 1200, 1500]},
    {"name": "الصورة الأصلية", "role": "subject", "file": "portrait.png", "mask": "approved-mask.png", "box": [0, 0, 1200, 1500]}
  ]
}
```

رتب الطبقات من الأسفل للأعلى. `box` هو x، y، العرض، الارتفاع؛ يجب الحفاظ على نسبة أبعاد الأصل. القناع رمادي، أبيض للإظهار وأسود للإخفاء، بأبعاد الأصل بعد تصحيح EXIF. `opacity` بين 0 و1. القص المتعمد يكون بوضع الطبقة خارج حدود اللوحة مع مراجعة الوجه. الصور المفرغة لا تحتاج قناعًا.

للشعار والعناوين: أضف PNG شفافًا في طبقة منفصلة. النصوص في هذا الإصدار طبقات نقطية؛ لا يدعي دعم تحرير العربية أو تحميل الخطوط داخل Compositor. تجهيز النص العربي يكون من التصميم المعتمد، ثم مراجعته قبل الإدخال. ملفات الخطوط والشعارات ليست مرفقة ولم تُغيّر هويات المشاريع.

للطباعة: `pixels = cm / 2.54 * dpi`؛ المقاسات الحقيقية تؤخذ من الطلب أو إعداد الفريم الموجود. PDF الناتج صورة مسطحة بنظام RGB؛ ليس ملف CMYK جاهزًا للطباعة الاحترافية ولا PDF متجهًا.

## حدود وضمانات

لا يوجد نشر تلقائي ولا إدخال صور خاصة في GitHub. ضع الأعمال الخاصة خارج المستودع العام. كل التصديرات تحتاج مراجعة بصرية قبل رفعها للموقع. الاقتصار على المزج العادي والمقنعة في هذا المحول يجعل التصدير البرمجي مطابقًا لتلك العمليات المدعومة؛ مؤثرات Compositor المتقدمة لا تستورد هنا. حدود المحول أقل من التطبيق: 100 طبقة، 20 مليون بكسل للتصدير، و100 مليون بكسل للأصول.

البديل العملي: استخدم Compositor لإنتاج الأصول والتحرير على Mac. عند الحاجة لمحرر يعمل للزوار على Android أو المتصفح، يلزم محرك Canvas مستقل؛ هذا المستودع لا يوفر ذلك.
