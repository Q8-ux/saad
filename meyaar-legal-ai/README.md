# مِعيار | Meyaar Legal AI

نموذج أولي ثنائي اللغة لمنصة SaaS قانونية مخصصة لتحليل ومراجعة المذكرات القانونية للمحامين ومكاتب المحاماة.

## المزايا الحالية

- واجهة عربية RTL وإنجليزية LTR.
- تبديل فوري بين اللغتين.
- صفحة هبوط احترافية ومتجاوبة.
- عرض خدمات تحليل المذكرات.
- مؤشر تجريبي لقوة المذكرة.
- تجربة رفع ملف تفاعلية.
- باقات اشتراك بالدينار الكويتي.
- نافذة تسجيل دخول تجريبية.
- تصميم متوافق مع الهاتف والتابلت والكمبيوتر.

## التشغيل

افتح ملف `index.html` مباشرة، أو انشر المجلد باستخدام GitHub Pages أو Netlify أو Vercel.

## ملاحظة

هذه النسخة واجهة تفاعلية أولية. الربط الفعلي مع Supabase وOpenAI والدفع الإلكتروني يحتاج مرحلة Backend منفصلة.
