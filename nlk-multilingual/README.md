# بوابة مكتبة الكويت الوطنية — نموذج متعدد اللغات

**Independent, non-official National Library of Kuwait UX prototype**

> ⚠️ هذا المشروع نموذج تطويري مستقل للعرض والمناقشة فقط، **ولا يمثل مكتبة الكويت الوطنية أو حكومة دولة الكويت**. لا تُرسل معاملات أو بيانات حساسة عبره. الموقع الرسمي: https://www.nlk.gov.kw/

## ما تم تنفيذه

- واجهة رئيسية RTL/LTR متجاوبة، مستوحاة بصرياً من العمارة والهوية الثقافية الكويتية، دون نسخ الشعارات الرسمية أو الصور المحمية.
- **6 لغات بترجمة واجهة يدوية:** العربية، الإنجليزية، الفرنسية، الأوردية، الهندية، الصينية المبسطة.
- تحويل الاتجاه تلقائياً للغتين العربية والأوردية، وتحديد `lang` و`dir` على الصفحة.
- دليل **8 خدمات معلنة** يفتح كل منها صفحة جديدة داخل الموقع المطوّر؛ لا توجد روابط خروج إلى صفحات الموقع القديم في واجهة المستخدم.
- بحث فوري **داخل دليل الخدمات المحلي فقط**، مع فلاتر حسب الفئة، ورسائل عدم وجود نتائج.
- بحث صوتي اختياري عبر واجهة المتصفح SpeechRecognition، يخضع لدعم المتصفح وموافقة المستخدم. قد يعالج موفّر المتصفح الصوت خارج الجهاز وفق سياساته؛ لا يرسل المشروع الصوت إلى خادم تابع له.
- أدوات إتاحة: رابط تجاوز المحتوى، تنقل بلوحة المفاتيح، تكبير النص، زيادة التباين، تحديث حي للنتائج، احترام تقليل الحركة، ودعم الأجهزة الصغيرة.
- تصميم CSS أصلي دون مكتبات JavaScript خارجية، ويعمل كصفحة ثابتة.
- لافتة واضحة تفصل النموذج غير الرسمي عن الموقع الحكومي.
- `noindex,nofollow` لحين الحصول على ترخيص/موافقة للنشر والتسمية.

## التشغيل محلياً

يمكن فتح `index.html` مباشرة في المتصفح، أو تشغيل خادم ملفات ثابتة:

```sh
python3 -m http.server 8080 --directory nlk-multilingual
```

ثم افتح `http://localhost:8080/?lang=ar` أو `?lang=en`، وهكذا. لا يتطلب المشروع مفتاح API.

## مسارات التكامل المقترحة

1. **مسار الترجمة:** ترجمات مراجعة بشرياً، مصطلحات مكتبية موحدة، ملفات نصوص مترجمة مع ضبط اتجاه الصفحة وارتباط اللغة بالرابط.
2. **مسار البحث والمكتبة:** واجهة موحدة للفهرس عند إتاحة API رسمية وفق معايير MARC21 وZ39.50 / SRU، وربط المستودع الرقمي عبر OAI-PMH وDublin Core إن كانت الأنظمة تدعمها فعلاً.
3. **مسار المساعد المعرفي:** إجابات موثقة بإحالات إلى كتب/صفحات مصرح بفهرستها فقط؛ عدم توليد بيانات كتب أو مراجع وهمية.
4. **مسار الصوت:** بحث وإملاء صوتي اختياري، وقراءة نصوص متاحة حقوقياً فقط، مع مراجعة خصوصية مزود الصوت.
5. **مسار الأرشفة:** رقمنة مقتنيات مرخصة وفق IIIF عند إتاحة الصور والبيانات، مع OCR عربي مؤكد الجودة ومراجعة بشرية.
6. **مسار الخدمات الحكومية:** معاملات حقيقية فقط عبر ربط مصرح به وخوادم رسمية، وإثبات هوية مناسب، وتتبع تدقيق وصلاحيات موظفين.
7. **مسار مراقبة الجودة:** اختبارات أمنية وإتاحة وترجمات، ومراقبة روابط الخدمات وصلاحية المحتوى، وموافقة المحتوى من المكتبة.

## اشتراطات الانتقال للإنتاج

- موافقة رسمية على التطوير والربط، وحقوق استخدام الهوية والشعار والمحتوى.
- وثائق تكامل الفهرس، قواعد البيانات والمكتبة الرقمية، والأذونات ونطاق بيانات القراءة/الاستعارة.
- تدقيق موافقات الناشرين ورخص الصور والمواد الرقمية قبل إتاحتها.
- سياسة خصوصية وحفظ بيانات مكتوبة؛ الأمان: HTTPS، فصل الخدمات الحساسة عن الواجهة، منع أسرار API من الواجهة، SSO/الأدوار، ومراقبة الوصول.
- مراجعة متخصصة للترجمات القانونية (خصوصاً حقوق المؤلف وISBN) قبل اعتمادها.
- تدقيق WCAG 2.2 AA عبر أدوات آلية واختبار قارئ شاشة ولوحة مفاتيح؛ لا تكفي الأدوات الآلية وحدها.
- لوحة إدارة محتوى موثوقة وصلاحيات مراجعة قبل نشر أي تحديث.
- خطة نقل تدريجي دون تعطيل النطاق `nlk.gov.kw`.

## الخط العربي — Cairo (تحديث 12 نوفمبر 2026)

- اعتمد خط **Cairo** في الواجهة العربية (العناوين 700، النصوص 400).
- يُحمّل Cairo من Google Fonts مباشرة في المتصفح، مع استخدام `Noto Sans Arabic` عند تعذّر تحميله.
- استُبدل تفضيل Noor السابق بعد طلب المستخدم تغيير الخط؛ لم نعد نعتمد وجود Noor مثبتاً لدى الزائر.
- بقيت بقية اللغات بخطوطها المناسبة دون تغيير، وما زالت النسخة غير رسمية.

## ترحيل الصفحات القديمة إلى صفحات داخلية — 12 نوفمبر 2026

أُضيف ملف `page.html` بقالب واحد قابل للوصول المباشر عبر روابط `?topic=<slug>&lang=<locale>`؛ هذا مناسب للنشر الثابت على GitHub Pages دون إعادة توجيه مسارات 404. توجد **14 صفحة متميزة المحتوى والروابط**:

- `catalog`: فهرس المكتبة (دليل معلوماتي، بلا فهرس حي).
- `databases`: قواعد البيانات الأكاديمية.
- `bibliography`: الببليوجرافيا الوطنية.
- `digital`: المكتبة الرقمية؛ المشروع تحت التطوير.
- `copyright`: إدارة حق المؤلف.
- `isbn`: الرقم الدولي المعياري للكتاب.
- `deposit`: الإيداع القانوني.
- `rooms`: القاعات والمسرح.
- `about`: التعريف بالمكتبة.
- `services`: دليل الخدمات الجامع.
- `collections`: المجموعات والمصادر.
- `portal`: بوابة مكتبات دولة الكويت (تعريفية).
- `theses`: رسائل الماجستير والدكتوراه (تعريفية).
- `public`: فهرس المكتبات العامة (تعريفي).

**كل النصوص التفصيلية على مستوى الصفحة متاحة باللغات الست**، مع تنقّل داخلي وقائمة الصفحات المرتبطة ومسار العودة وتكيّف اتجاه العرض، واستخدام Cairo للعربية. حُذفت روابط النطاق القديم من `index.html` و`app.js` و`page.html` و`pages.js`؛ روابط الموقع القديم في قسم المراجع بهذه الوثيقة فقط وليست جزءاً من واجهة المستخدم.

**لا توجد معاملات فعلية أو بيانات مقنيات حقيقية**. لا ينبغي ادعاء أن الواجهة تستطيع حجز القاعات، إصدار ISBN، الإيداع، أو بحث الفهرس الكامل قبل تكامل مصرح به.

### فحص الجودة

```sh
node nlk-multilingual/verify.mjs
```

يشمل التحقق: صياغة JavaScript، اكتمال نصوص الواجهة والصفحات باللغات الست، الربط الداخلي، منع الروابط القديمة في الواجهة، وجود ملفات التصميم، وخط Cairo.

### روابط نموذجية

- صفحة ISBN العربية: `page.html?topic=isbn&lang=ar`
- المكتبة الرقمية بالإنجليزية: `page.html?topic=digital&lang=en`
- صفحة الخدمات بالفرنسية: `page.html?topic=services&lang=fr`
