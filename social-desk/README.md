# مكتب السوشيال الذكي

واجهة عربية RTL مستوحاة من المرجع المرئي الذي قدمه صاحب المشروع: بطاقات الأدوار الستة، مسار التجهيز، معاينة المنشور، سجل التنفيذ، ودليل الأدوات الاثنتي عشرة.

الرابط العام: https://q8-ux.github.io/saad/social-desk/

## الوظائف المتاحة

- إنشاء حملات حسب المشروع والمنصة والهدف ونبرة الكتابة، وإضافة معلومات ورابط مرجعي.
- تجهيز خطة ومسودة بقوالب محلية واضحة المصدر، مع عرض الخطوات وإيقافها مؤقتًا.
- تعديل النص واعتماده؛ أي تعديل لاحق يلغي الموعد القديم ويحتاج مراجعة النسخة.
- تحميل تصميم SVG عربي مع تضمين خط Cairo، ونسخ النص.
- حفظ مواعيد محلية بتوقيت الكويت، مع تقويم ومكتبة قابلة للبحث والتصفية.
- أرقام فعلية لمساحة العمل، ونسخ JSON احتياطية واستيرادها دون تكرار الحملات.
- روابط GitHub الأصلية للأدوات؛ لا تدعي الواجهة أنها مثبتة أو متصلة.

## حدود التشغيل الحالية

الحفظ داخل متصفح المستخدم، ولا توجد مزامنة حسابات أو قاعدة بيانات مشتركة. القوالب المحلية ليست استدعاءات Grok أو بحثًا حيًا. المواعيد لا ترسل محتوى إلى منصات التواصل. لا توجد أرقام وصول أو تفاعل مفترضة.

## خادم التوليد الاختياري

اختر «خادم توليد متصل» من الإعدادات وحدد عنوان HTTPS لبوابة خاصة بك أو سير عمل n8n. يحتفظ الخادم بمفتاح المزود. رمز جلسة الخادم اختياري ويحتفظ به المتصفح في الذاكرة فقط؛ لا يدخل في localStorage أو النسخ الاحتياطية. لا يُختبر الاتصال بمجرد حفظ العنوان؛ تظهر نتيجة الاتصال عند تجهيز حملة جديدة.

يرسل المتصفح POST مع `Content-Type: application/json`، ويضيف `Authorization: Bearer ...` إذا حُدد رمز جلسة:

```json
{"version":1,"task":"social-content","brief":{"topic":"موضوع","brand":"مشروعي","platform":"إنستغرام","goal":"زيادة التفاعل","tone":"عربية واضحة","facts":"المعلومات المعتمدة","sourceUrl":""}}
```

الاستجابة المطلوبة:

```json
{"output":{"hook":"العنوان","body":"النص","cta":"دعوة للتفاعل","hashtags":["#مشروعي"]}}
```

يجب أن يدعم الخادم CORS للأصل `https://q8-ux.github.io` وطلب OPTIONS عند إرسال Authorization. يحظر الخادم إساءة استخدامه ويستخدم مصادقة وحدود طلبات مناسبة. الواجهة لا تقدم خادمًا عامًا أو مفاتيح نموذج. فشل HTTP أو استجابة غير صالحة أو انقضاء مهلة 45 ثانية يوقف المرحلة ويظهر في السجل دون ادعاء النجاح.

## التحقق

```sh
node --check app.js
node --check core.mjs
node --test tests/*.test.mjs
```

انشر الملفات `index.html`, `styles.css`, `app.js`, `core.mjs`, و`assets/` من أي استضافة ثابتة. النشر في هذا المستودع يحافظ على بصمات ملفات المشاريع الأخرى من أحدث حزمة GitHub Pages نُشرت بنجاح، ويرفض الرجوع إلى حزمة أقدم إذا كانت الحزمة الأخيرة غير متاحة.

خط Cairo مضمّن وفق SIL Open Font License؛ الترخيص في `assets/Cairo-OFL.txt`. الشعار والأيقونات رسوم SVG أصلية لهذا المشروع. لم يُنسخ من الفيديو أي شعار تجاري أو كود.
