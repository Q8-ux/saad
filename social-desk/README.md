# مكتب السوشيال الذكي — التشغيل الفعلي

الرابط: https://q8-ux.github.io/saad/social-desk/

واجهة عربية لفريق المحتوى مرتبطة بخادم Node.js 24 على Neon Functions وقاعدة PostgreSQL مستقلة. لا يوجد وضع قوالب محلية أو توليد احتياطي يدعي نجاح الذكاء الاصطناعي.

## ما يعمل الآن

- تسجيل دخول مالك واحد باسم `saad`؛ كلمة المرور محفوظة كاشتقاق scrypt في بيئة الخادم، وليست في المصدر.
- الحملات والنتائج والأحداث محفوظة في PostgreSQL، مع مراجعات متفائلة وأقفال قصيرة تمنع تداخل الطلبات.
- رصد أخبار فعلية من Google News RSS أو Bing News RSS، مع مصدر Hacker News / Algolia البديل لموضوعات التقنية. يسجل البحث طريقته وكلماته وتاريخه؛ لا يدعي أنه ترتيب ترندات التواصل.
- استراتيجية وكتابة وتوجيه بصري عبر طلبات فعلية إلى xAI Responses API أو نموذج مفعّل في Neon AI Gateway. يسجل كل نجاح معرف استجابة المزود والنموذج واستهلاك التوكنات إن أرسله المزود.
- تصميم SVG عربي مبني على المحتوى والتوجيه البصري، مع تضمين خط Cairo. هذا رسم برمجي وليس صورة مولدة من ComfyUI.
- مفاتيح Grok وPostiz تتحقق عبر مزودها ثم تحفظ مشفرة AES-256-GCM في الخادم. المتصفح لا يخزن مفاتيح المزودين.
- Postiz: قراءة الحسابات المتصلة، إرسال النسخة المعتمدة لجدولة فعلية، وحفظ إيصال المزود. يدعم الإرسال الحالي X وLinkedIn وFacebook وThreads وInstagram؛ منصات الفيديو تحتاج إعدادات إضافية غير منفذة.
- لا تسجل الجدولة دون إيصال مطابق للحساب. غموض الإرسال يصبح `uncertain` ويمنع الإعادة العمياء. تعديل حملة مرتبطة بإيصال خارجي يتطلب معالجة الجدولة في Postiz أولًا.
- تحليلات فعلية من `/analytics/{integration}?date=30` بعد ربط حساب، دون أرقام مفترضة.

## حالة التفعيل التي تحققت في 24 نوفمبر 2026

- الخادم وقاعدة البيانات وتسجيل الدخول عبر API: تعمل.
- حملة فحص محفوظة في قاعدة البيانات، ونتيجة رصد من 8 أخبار عبر Hacker News / Algolia: تحققت بطلب حي.
- بوابة النماذج في الحساب لا تعرض نماذج مفعّلة برصيد متاح. لا يوجد مفتاح xAI مضاف لهذا النظام حتى هذه المراجعة. طلب التوليد أعاد `503 AI_NOT_CONFIGURED` دون مسودة مزيفة.
- حسابات Postiz غير متصلة. لم يتم اختبار كتابة أو جدولة منشور خارجي، ولم ينشر أي محتوى.
- لم يُشتر رصيد ولم يُفعّل اشتراك مدفوع.

## أول تفعيل

سجل الدخول ثم افتح إعدادات الخدمات. أضف مفتاح xAI فعالًا واسم نموذج متاح، ومفتاح Postiz لحساباتك إذا أردت النشر والتحليلات. يتصل النظام بالمزود للتحقق قبل حفظ المفتاح. لا تضع المفاتيح في GitHub أو المحادثة. بيانات الدخول الأولية تسلم للمالك بشكل خاص؛ لا توجد كلمة مرور افتراضية عامة.

رسم التصميم يبقى ملتزمًا بقيود مشروع الدكتور حمد على الصور المولدة؛ يحتاج المحتوى الطبي والقانوني إلى مراجعة مختصة قبل اعتماده.

## الملفات والنشر

- `index.html`, `styles.css`, `app.js`, `core.mjs`, `cloud.mjs`, `assets/`: واجهة GitHub Pages.
- `server/index.mjs`: الخادم والتحكم في حالة الحملات.
- `server/engine.mjs`: التشفير والمصادر والنماذج والنشر.
- `server/schema.sql`: الجداول الجديدة في قاعدة المشروع المستقلة.
- `server/neon-deployment.json`: معرفات الموارد فقط، دون أسرار.
- `server/package-lock.json`: تبعيات مثبتة الإصدار. الحزمة المنشورة تُبنى بـ esbuild وتحتفظ بإشعارات التراخيص.
- `deployment/publish-pages.py`: يضيف ملفات الواجهة فقط ويحافظ على بصمات المشاريع الأخرى في آخر حزمة Pages منشورة.

لتحديث الخادم:

```sh
npm ci --prefix server
server/node_modules/.bin/esbuild server/index.mjs --bundle --platform=node --format=esm --target=node24 --outfile=build/index.mjs
```

نفذ بناء الحزمة من جذر المستودع عند استخدام المسارات الكاملة `social-desk/server/...`. انشر ZIP يحتوي `index.mjs` على الوظيفة الموجودة باستخدام أدوات Neon. أضف `APP_SECRET` و`OWNER_PASSWORD_HASH` في البيئة الآمنة عند أول نشر فقط؛ احفظ البيئة عند تحديث الكود. `DATABASE_URL` وبيانات بوابة Neon تحقنها المنصة. لا تنشر مجلد الخادم داخل GitHub Pages.

## الاختبارات

```sh
node --check app.js
node --check cloud.mjs
node --check server/index.mjs
node --test tests/*.test.mjs server-tests/*.test.mjs
```

اختبارات عقود المزود تستخدم استجابات اختبارية وتثبت سلوك النجاح والفشل، ولا تثبت اتصال Grok أو النشر الحي دون بيانات اعتماد. فحص API الحي المذكور أعلاه منفصل عنها. CORS يسمح بأصل GitHub Pages ومعاينة التطوير المحددة، وجلسة المالك مؤقتة، وطلبات النموذج محدودة في قاعدة البيانات.

Cairo وفق SIL OFL، والتراخيص في `assets/Cairo-OFL.txt`. روابط المشاريع الاثني عشر في الواجهة مكتبة مرجعية وليست ادعاء بتثبيت هذه الخدمات.
