# استوديو يوتيوب الذكي

أداة عربية تعمل بالكامل داخل المتصفح لبناء حزمة فيديو يوتيوب مترابطة حول كلمة مفتاحية واحدة.

## الوظائف

- فحص جاهزية الفكرة قبل التصوير.
- توليد عنوان وهوك وسيناريو ووصف ووسوم.
- توليد برومبت للصورة المصغّرة.
- تدقيق الفكرة واقتراح اختبار الطلب والمنافسة.
- حفظ المشاريع محلياً في المتصفح دون حساب.
- تصميم RTL متجاوب مع الجوال.
- ربط اختياري مع OpenAI لتوليد مخصص فعلياً.
- ربط اختياري مع YouTube Data API لتحليل النتائج والمشاهدات.

## الربط الذكي

من زر «الربط الذكي» يمكن إدخال مفتاح OpenAI ومفتاح YouTube Data API. تُحفظ المفاتيح في ذاكرة جلسة المتصفح فقط وتُحذف عند إغلاقه. هذه الآلية مناسبة للاستخدام الشخصي؛ النسخة التجارية يجب أن تستخدم خادماً خلفياً لحماية المفاتيح.

## ملاحظة مهنية

لا تدّعي الأداة ضمان التصدّر. نتائج يوتيوب تتأثر بقوة الموضوع، الصورة والعنوان، نسبة النقر، الاحتفاظ بالمشاهد، وملاءمة المحتوى للجمهور. التحقق الحقيقي من حجم البحث يحتاج بيانات يوتيوب أو خدمة خارجية.

## التشغيل

افتح `index.html` مباشرة، أو استخدم رابط GitHub Pages للمجلد.
