# استوديو يوتيوب الذكي

[افتح واجهة التشغيل على GitHub Pages](https://q8-ux.github.io/saad/youtube-studio-ai/?v=20261117-4)

اضغط **تشغيل التجربة الكاملة** لفتح مثال «كيف تبدأ مشهدًا يشدّ المشاهد؟» داخل الاستوديو مباشرة. لا تتطلب التجربة حسابًا أو مفتاح خدمة.

## الوظائف

- سكربت عربي أصلي من سبعة مقاطع مع خطة لقطات وتوقيت تقديري وعناوين بديلة ووصف ووسوم وثلاثة تصورات للصورة المصغرة.
- تعديل أي قسم وحفظ التعديل مع المشروع وإعادة فتحه بعد إعادة تحميل الصفحة.
- تصدير النص بصيغة Markdown والحزمة بصيغة JSON.
- تجهيز خطة محلية لموضوع جديد، مع تمييزها عن النص المولّد من خدمة متصلة.
- ربط اختياري بخدمة التوليد وYouTube Data API. وجود المفتاح لا يعني تحقق الاتصال؛ يظهر النجاح أو الخطأ عند الاستخدام.
- حفظ المشاريع محليًا في المتصفح، مع بقاء العرض والتصدير ممكنين إذا منع المتصفح التخزين.

هذه واجهة كتابة وتخطيط. لا تدّعي إنتاج صوت أو صور أو MP4 أو النشر على قناة يوتيوب. التوقيت المعروض تقديري إلى حين إنتاج الوسائط وقياسها. لا تستخدم درجات جاهزية أو نسب نقر غير مقاسة.

## الخصوصية والتخزين

المشاريع محفوظة في المتصفح نفسه؛ صدّر نسخة للاحتفاظ بها أو نقلها إلى جهاز آخر. مفاتيح الخدمات الاختيارية تبقى في تخزين جلسة المتصفح ولا تُدرج في أرشيف المشاريع أو ملفات التصدير. لا تضع مفاتيح مشتركة في الشفرة العامة.

## الفحص

```bash
node --check app.js
node --check enhanced.js
node --test tests/workflow.test.cjs
```

تغطي الفحوص فتح المثال، حفظ التعديل واسترجاعه، محتوى تصدير JSON، تعطل أو فساد التخزين، واستمرار توليد النص عندما يفشل البحث الاختياري. اختُبر فتح المثال وتعديله واسترجاعه وتنزيل حزمته في المتصفح، وعرضه داخل نافذة جوال بعرض 390 بكسل. لم يُنفذ اتصال مدفوع بخدمة توليد أو نشر على يوتيوب ضمن هذا الإصلاح.
