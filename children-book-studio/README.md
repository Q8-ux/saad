# حكاية — استوديو كتب الأطفال

مساحة عربية لتخطيط مشروع كتاب أطفال من أول رصد للسوق إلى ملف جاهز للمراجعة الطباعية.

## التشغيل

- واجهة GitHub Pages: `https://q8-ux.github.io/saad/children-book-studio/`
- المصدر: `https://github.com/Q8-ux/saad/tree/main/children-book-studio`

## المسارات المتاحة

1. رادار اتجاهات مع مصادر وروابط وسجل أدلة يضيفه المستخدم.
2. بنك أفكار حسب العمر والاتجاه والمهارة المطلوبة.
3. بطاقة مشروع قابلة للتحرير، ولوحة لكتابة نص كل صفحة ووصف مشهدها.
4. مرجع شخصية وأداة لصياغة توجيه رسم يحافظ على ملامح وألوان ثابتة.
5. أنشطة تعلم وملاحظة، مع حقول لإرفاق روابط صوت أو فيديو عامة.
6. قائمة تدقيق للطباعة والنشر، وطباعة صفحات المشروع إلى PDF من المتصفح.
7. حفظ محلي في المتصفح وتصدير أو استيراد نسخة JSON.

## الحدود الحالية

- بنك الأفكار قوالب بداية تحريرية يعمل محلياً؛ ليس بحثاً آلياً مباشراً عن الأكثر مبيعاً.
- إشارة نمو كتب الأنشطة في الواجهة مستندة إلى تقرير عن مبيعات الولايات المتحدة لعام 2025، ولا تعني أن المبيعات في الكويت أو الخليج تتبع الاتجاه نفسه.
- مولّد توجيهات الرسم لا ينشئ الصور؛ استخدم النص في أداة الرسم التي تختارها، أو أضف تكاملاً آمناً بعد تحديد خدمة التوليد.
- إنشاء QR مباشر، تحويل النص إلى صوت، التعاون بين عدة مستخدمين، والتصدير الطباعي المعتمد غير متصلين في هذه النسخة.
- كل البيانات تبقى داخل التخزين المحلي للمتصفح. لا تُدخل معلومات شخصية عن الأطفال.
