# حكاية — استوديو كتب الأطفال

استوديو عربي متخصص في الكتب التعليمية للأطفال من 3 إلى 6 سنوات. ينفّذ بحثاً حياً، يحلل العينة بشفافية، ثم ينتج كتاباً أصلياً كاملاً بنصوص وأنشطة ورسوم SVG قابلة للطباعة.

## التشغيل

- واجهة GitHub Pages: `https://q8-ux.github.io/saad/children-book-studio/`
- المصدر: `https://github.com/Q8-ux/saad/tree/main/children-book-studio`

## المسارات المتاحة

1. بحث حي عند الطلب عبر Open Library Search API، مع المصدر ووقت الرصد وحجم العينة.
2. تحليل محلي لسنوات النشر واللغات والموضوعات وعدد الطبعات وتوفر الأغلفة.
3. فرص تحريرية أصلية مشتقة من العينة، مع تنبيه واضح إلى حدود الدليل.
4. إنتاج كتاب مكتمل البنية: غلاف، رحلة قصصية قصيرة، دروس، أنشطة مرتبطة بكل درس، مراجعة، دليل أسرة، وخاتمة.
5. خيارات 12 أو 16 أو 20 أو 24 صفحة، مع تغيير المهام بحسب المهارة المختارة وتدرّج النشاط للعمر.
6. رسوم SVG أصلية فعلية لكل صفحة، مع نص الصفحة الكامل والنشاط ظاهرين في المعاينة ونسخة HTML والطباعة.
7. تنزيل كتاب HTML ذاتي الاكتفاء، وتنزيل JSON، وطباعة المعاينة إلى PDF.
8. نقل الكتاب المنتج إلى محرر الصفحات والمكتبة المحلية لاستكمال التعديل.
9. مرجع شخصية وأنشطة وQR محلي، مع تصدير أو استيراد نسخة المشروع.

## حدود الدليل والإنتاج

- بيانات Open Library إشارات فهرسية وليست بيانات مبيعات أو طلب أو ترتيباً للأكثر رواجاً. `edition_count` عدد طبعات وليس مقياس شعبية.
- البحث العربي قد تكون تغطيته أقل من الإنجليزية؛ لذلك يمكن توسيع الاستعلام بمصطلحات تعليم مبكر إنجليزية مع إظهار ما جرى البحث عنه.
- النموذج يضم اقتراحات متفاوتة للأعمار 3–4 و4–5 و5–6، ويحتاج مراجعة تربوية وتجربة قراءة مع أسر وأطفال قبل النشر.
- إشارة نمو كتب الأنشطة في الواجهة مستندة إلى تقرير عن مبيعات الولايات المتحدة لعام 2025، ولا تعني أن المبيعات في الكويت أو الخليج تتبع الاتجاه نفسه.
- رسوم SVG إنتاج أولي أصلي وقابل للتعديل؛ لا تحل تلقائياً محل مراجعة رسام ومصمم كتب محترف قبل النشر التجاري.
- الطباعة من المتصفح لا تضمن النزف أو CMYK أو مطابقة ملف KDP النهائي؛ افحص الملف داخل أداة المعاينة الخاصة بالمطبعة أو منصة النشر.
- تحويل النص إلى صوت، التعاون بين عدة مستخدمين، وتصدير ملفات الطباعة المعتمدة غير متصلة في هذه النسخة.
- كل بيانات المشاريع تبقى داخل التخزين المحلي للمتصفح. إنشاء QR يتم في المتصفح باستخدام مكتبة qrcodejs المرفقة. لا تُدخل معلومات شخصية عن الأطفال.
