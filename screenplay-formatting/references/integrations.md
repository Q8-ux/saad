# المسارات المستخدمة وحدودها

| المسار | الاستخدام الفعلي | الحالة في هذا المسار |
| --- | --- | --- |
| مهارة Documents | إنشاء Word وOOXML عربي ورسم كل صفحة قبل التسليم | مستخدمة في البناء والتحقق |
| مهارة PDF | تحقق من عدد الصفحات وحدود النص وتضمين الخط؛ مراجعة صور الصفحات | مستخدمة في البناء والتحقق |
| استوديو السيناريو | استيراد مخطط blocks الذي تستخدمه أداة الكتابة | مدخل قابل للتشغيل؛ لا ادعاء بتعديل واجهة الاستوديو |
| Final Draft | استيراد FDX والمحافظة على النص وأنواع الفقرات | مدخل قابل للتشغيل |
| مسار السطر الأخير | نسخة من المُراجع السابق، تقرير منفصل للحوارات | قابل للتشغيل عبر `--last-line-review`؛ خمسة مؤشرات آلية فقط |
| المسار الاحترافي للكتابة | فصل الوصف والأداء والحوار والانتقال والتدقيق قبل أي إعادة صياغة | مرجع تحريري؛ لا يوجد مُراجع شامل مبرمج جرى إثباته |
| مسار أدوات التصميم | توزيع الأعمدة والفراغ والتباعد والتحقق من العربية والطباعة | مبادئ تخطيط مستخدمة؛ لا تحميل مكتبات واجهات غير لازمة |
| مسار التحليل | مقارنة الصور واستخراج ما يمكن إثباته وتسجيل الافتراضات | تحليل مرجعي؛ خدمة السحب الخارجية غير لازمة لهذا المصدر |
| MarkItDown | استخراج النص من مصادر أخرى ثم مراجعته بشرياً قبل تحديد المتحدثين | لا يستعيد تنسيق السيناريو أو مزامنة الحوار؛ ليس شرطاً للمُنسّق |
| مسارات الوكلاء والصوت والفيديو | ليست متطلبات لإنتاج قالب طباعي ثابت | لم تُثبت على أنها تبعيات، تجنب كلفة وتعقيد غير لازمين |

- [مسار السطر الأخير](https://github.com/Q8-ux/saad/tree/main/last-line-path)، المُراجع `last_line.py` بالـblob `303d5ce23ca9dc2bcaad0f5482647fd1335b3be4`. نسخة المُراجع المرفقة غير معدلة؛ لا تنسب إليها اختبار القواعد المئة.
- [مسار التحليل](https://github.com/Q8-ux/saad/tree/main/masar-analysis).
- [MarkItDown](https://github.com/Q8-ux/saad/tree/main/markitdown-service).
- [خطة الوكلاء](https://github.com/Q8-ux/saad/blob/main/agent-paths/integration-plan.json) تصف نفسها بأنها مقترحة وغير مثبتة؛ لا تعاملها كتشغيل فعلي.
- [Amiri](https://github.com/aliftype/amiri)؛ الخط المرفق تحت OFL 1.1، ولا يمثل إثباتاً لاسم الخط الموجود في الصور.
