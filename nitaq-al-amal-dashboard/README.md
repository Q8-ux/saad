# نطاق العمل

واجهة عربية تجريبية لمتابعة حضور وانضباط الموظفين في وزارة الكهرباء والماء والطاقة المتجددة.

## المزايا

- لوحة مؤشرات للحضور والغياب والتأخير
- متابعة الحضور اللحظي
- إدارة الموظفين والإدارات والمحطات
- عرض المناوبات والمخالفات والطلبات الإدارية
- تنبيهات تشغيلية
- واجهة عربية RTL متجاوبة مع الجوال والكمبيوتر

## التشغيل

افتح ملف `index.html` مباشرة في المتصفح، أو شغّله عبر أي خادم ملفات ثابت.

## تنبيه

هذه النسخة نموذج واجهة أمامية ببيانات تجريبية. التشغيل الفعلي يحتاج إلى:

- قاعدة بيانات مركزية
- نظام تسجيل دخول وصلاحيات
- واجهة API للموظفين والحضور والمناوبات
- تكامل آمن مع تطبيق الهاتف أو أجهزة تسجيل الحضور
- سجل تدقيق وتشفير وضوابط لحماية بيانات الموظفين
