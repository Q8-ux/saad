# أفراح الماضي — دعوة زفاف حمد

صفحة دعوة عربية للجوال مستلهمة من أسلوب Apple Invites، بصور زفاف المستخدم الأصلية وخط المهند، وألوان العاجي والذهبي.

الرابط: https://q8-ux.github.io/saad/hamad-wedding/

## بيانات المصدر

- العريس: حمد.
- الداعون: عائلة الماضي — ناصر ماضي راضي الشمري وإخوانه.
- الموعد: الثلاثاء 20 أكتوبر 2026 مساءً، بتوقيت الكويت. البطاقة لا تحدد ساعة البداية.
- المكان: ديوان الماضي، سعد العبدالله، قطعة 8، شارع 24، مقابل المعسكر.
- الموقع المستخرج من رمز البطاقة: `29.3181267, 47.7118721`؛ الإحداثي الثاني في رابط كاميرا الخريطة مختلف عن دبوس الموقع، ولذلك استخدمنا دبوس الموقع.
- أرقام العائلة: `65005654`، `99732147`، `50168888`، `66002205` مع رمز الكويت `965`.
- رقم الاستوديو `55009914` ليس رقم تواصل للعائلة ولم يُدرج ضمن أزرار واتساب.
- تحفظ صورة البطاقة الأصلية كما وردت، دون تغيير ملامح العريس. عرض الصورة المقرب في الصفحة يتم بواسطة CSS.

## الوظائف الفعلية

- فتح محادثة واتساب مستقلة لكل رقم من أرقام العائلة.
- تأكيد الحضور أو الاعتذار أو الرد لاحقًا، مع الاسم والعدد والرقم المستلم. تفتح رسالة جاهزة في واتساب ويرسلها الضيف بنفسه. لا يُسجل الرد مركزيًا ولا يدّعي الموقع أن الرسالة وصلت.
- Google Maps وخرائط Apple عند إحداثيات رمز البطاقة، مع عرض رمز الموقع الأصلي.
- تقويم Apple/Outlook بملف ICS وتقويم Google. يحفظ كتاريخ طوال اليوم لأن الساعة غير معطاة، مع ذكر «مساءً» في التفاصيل.
- عداد أيام يعتمد منتصف الليل في الكويت؛ لا يفترض ساعة للحفل.
- مشاركة الجهاز أو واتساب أو نسخ الرابط، مع QR خاص برابط الدعوة.
- عرض البطاقة الأصلية وحفظها؛ مظهر ليلي اختياري؛ تفضيل تقليل الحركة؛ واجهة RTL وخطوط محلية.
- تثبيت اختياري من المتصفح ونسخة تعمل دون اتصال بعد أول تحميل ناجح. فتح واتساب والخرائط يحتاج اتصالًا.
- ترحيب اختياري باسم الضيف بواسطة `?to=`، ويُعرض كنص آمن، ولا ينتقل الاسم عند مشاركة الرابط العام.
- لا تسجيل دخول، لا مفاتيح API، لا تعقب أو طلب موقع الضيف. الصفحة عامة لمن يملك الرابط؛ `noindex` لا يمثل حماية وصول.

## فحص محلي

```sh
node --check hamad-wedding/dist/assets/app.mjs
node --check hamad-wedding/dist/sw.js
node --test hamad-wedding/tests/event.test.mjs
python hamad-wedding/deployment/validate.py
python hamad-wedding/tests/test_publication.py
```

مصدر الصفحة `dist/` بلا أدوات بناء أو اعتماديات تشغيل خارجية. لم يتوفر متصفح QA معتمد أثناء التنفيذ؛ الفحوص تغطي البيانات والمنطق والملفات والنشر ولا تعادل اختبارًا بصريًا على iPhone وAndroid.

## النشر

يُنسخ `deployment/deploy-hamad-wedding.yml` إلى `.github/workflows/deploy-hamad-wedding.yml`. يستعيد النشر آخر حزمة GitHub Pages نُشرت بنجاح، ثم يستبدل مجلد الدعوة فقط ويقارن بصمات جميع الملفات الأخرى. عند عدم توفر الحزمة السابقة يمتنع عن النشر بدل استبدال بقية المشاريع. يتشارك قفل `pages-v2` المستخدم في المستودع.

## المراجع والميزات المؤجلة

راجعت [دليل Apple Invites الرسمي](https://support.apple.com/guide/apple-invites/welcome/ios) و[ميزات مواقع الزفاف من Joy](https://withjoy.com/wedding-website/). اخترت الوصول للموقع، الرد، مشاركة الرابط، التقويم وتجربة الجوال لهذه النسخة. إدارة الضيوف في قاعدة بيانات، ألبوم صور جماعي، تنبيهات آلية وتذاكر دخول فردية تحتاج استضافة خلفية وتحديد الصلاحيات؛ لم توضع لها واجهات توحي بأنها تعمل.

صورة الدعوة وأصول العائلة غير مشمولة بأي ترخيص عام قد ينطبق على شيفرة المستودع.
